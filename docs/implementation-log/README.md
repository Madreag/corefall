# Implementation Log

Create one note per milestone or substantial feature implementation.

Suggested filename:

```text
YYYY-MM-DD-milestone-<id>-<short-title>.md
```

Each note should include:

- Assigned milestone or feature ids.
- Planning docs read.
- Open DR gates checked.
- Files changed.
- Commands run.
- Run-bundle paths.
- Feature checklist rows updated.
- Roadmap sections updated, or a short reason why no roadmap update was needed.
- Changelog entry added.
- Bugs found and fixed.
- Known issues.
- AI self-ratings for full implementation and quality.
- Human review status.

The repo-only changelog lives at:

```text
../../CHANGELOG.md
```

The canonical roadmap and checklist live in the vault:

```text
docs/plan/spec/prototype-roadmap.md
docs/plan/spec/feature-completion-checklist.md
```
