# DR-044: Audiovisual Production Pipeline (AI-Driven, 3-Tier)

> [!success] Status: CLOSED-DIRECTION (project owner committed 2026-05-06)
> Three-tier asset pipeline driven by AI agents end-to-end. Tier 1 = procedural SVG/geometric placeholders (M0..M2). Tier 2 = ComfyUI / Stable Diffusion / Flux / SD3.5 generated pixel art via SDXL+pixelart-XL LoRA + PixelArt-Detector palette quantization (M2..M5). Tier 3 = AI-agent-polished final art with locked palette + faction recolor + spritesheet packing + procedural variation (M5+). Same 3-tier structure for animation (procedural → AnimateDiff/SVD → AI-agent-polished), VFX, lighting, music, video. **All assets must be generatable, regeneratable, and testable by AI agents without human bottleneck. Human review is QA/approval, not asset creation.**

## Decision

**Three-tier AI-driven audiovisual production pipeline:**

### Tier 1 — Programmable placeholders (M0..M2)
- **Visual:** SVG-based geometric placeholders generated by Python scripts (`tools/asset_gen/`). Solid colors per faction; rect/circle/path silhouettes; CSS-style faction recolor. Rendered to PNG at multiple resolutions on build. Looks intentional, not "MS Paint."
- **Animation:** Procedural transform animations (Bevy `Animation` plugin); per-frame sprite swap from generated 2-3 frame SVG sequences (idle bob, walk cycle, fire flash).
- **VFX:** Particle primitives — colored circle/line/quad with Bevy particle plugin or custom shader.
- **Audio:** Generated sine/square/triangle synth blips at distinct frequencies (200ms each); placeholder license-clean fonts (JetBrains Mono + Press Start 2P).
- **Generated by:** Python scripts under `tools/asset_gen/`. Run as build-step. Zero artist required.
- **Output:** 16x16 / 32x32 / 64x64 PNG sprites, OGG audio, TTF fonts, all checked into `game/assets/placeholders/`.

### Tier 2 — ComfyUI / diffusion model placeholders (M2..M5)
- **Visual:** Stable Diffusion XL (SDXL) base + **Pixel Art XL LoRA** (Civitai #120096) + ControlNet (Canny / Depth / OpenPose for character consistency) + PixelArt-Detector custom node (palette quantization, downscale, dithering) + LoSpec palette JSON (32-color faction palette).
- **Concept→sprite pipeline:** Text prompt → SDXL+LoRA generates 1024px concept → ControlNet (depth + canny) for orthographic consistency (front/side/back/3-quarter views) → PixelArt-Detector downscale to game resolution (16/32/64/128 px) + palette quantize → automated background removal (rembg) → sprite-sheet packer (TexturePacker CLI / aseprite headless).
- **Backgrounds + sky + parallax layers:** Flux.1-dev (high quality, 24GB+ VRAM) for atmospheric concept art → ControlNet tile-mode → SDXL pass for stylization → vertical-band layered output (sky / horizon / midground / foreground) for parallax scroll.
- **Animation:** ComfyUI Sprite Sheet Generator workflow (LoadImage → orthographic-views generator → AnimateDiff motion module for idle/walk/run/fire/death) + temporal-consistency LoRA + AI-agent frame correction → palette quantize per frame.
- **Video / cutscene:** AnimateDiff (1-2s loops; idle ambient; weather background loops) + Stable Video Diffusion (image-to-video, 4s clips for briefing/debrief comic-panel transitions) + RunwayML Gen-3 fallback for 8-12s cinematic intros (cloud, post-launch only).
- **VFX:** Flame/smoke/explosion/blood/breath particle textures generated by SDXL+ControlNet Tile → spritesheet animation frames → procedural transform in Bevy.
- **Audio:** Stable Audio Open 1.0 for SFX (sub-47s clips, runs locally on 32GB VRAM; Stability AI Community License and commercial-use registration/enterprise review required before public sale/release). Suno/Udio/ElevenLabs for music tracks (cloud, watch licensing). MusicGen/AudioCraft allowed for private prototypes with ledger entries; release/sale assets require replacement, self-trained weights, or commercial licensing.
- **Generated by:** ComfyUI workflows committed under `tools/comfyui_workflows/` as `.json` files. Run via ComfyUI API from a Python orchestrator (`tools/asset_gen/comfy_runner.py`). Re-runnable on demand. Deterministic seed per asset.
- **Output:** Same file paths as Tier 1; replaces Tier 1 by file-name swap. Logged in `references/usage-ledger.md` with prompt + seed + model + LoRA + license.

### Tier 3 — AI-agent-polished final (M5+)
- **Visual:** Tier 2 output as base; AI agent (Aseprite headless API + custom Python tooling) does cleanup pass — pixel-perfect line correction, palette enforcement, dithering polish, faction-recolor variants. Hero assets (player chassis, signature weapons, named NPCs) receive stricter AI-agent cleanup gates. Procedural variants for non-hero assets via parametric palette swap + decal overlay.
- **Animation:** Tier 2 as base; AI agent runs frame-cleanup pass (smoothing easing curves, fixing pixel-pop) + adds animation event tags (footstep frame, casing-eject frame, muzzle-flash anchor frame). Skeletal-rigged hero chassis via Spine-style format (using `bevy_spine`).
- **VFX:** Full particle system per spec/vfx-and-particles. Final tuned in-game with art-director playtest.
- **Audio:** Final mix via FMOD Studio (free-tier under $200K/yr revenue) or bevy_kira_audio + custom Rust mixing. Mastered for diegetic-first per DR-020.
- **Music:** Final scoring pass with Suno v5 / Udio / ElevenLabs Music or local MusicGen/Stable Audio Open fallback; AI-agent stem cleanup; adaptive layering in-engine.
- **Generated by:** AI agent (Codex/Claude/Droid) drives Aseprite headless, Spine/DragonBones automation, FMOD/Kira project generation, and a master `cf-asset-pipeline` CLI tool that orchestrates regeneration. Human review at major asset milestones is approval only; no human-crafted asset step is allowed.

### Resolution + palette + style locks (closes DR-019 OPEN sub-decisions)

| Lock | Value | Rationale |
|---|---|---|
| Base sim resolution | **480×270 logical canvas** | Sweet spot for Cortex-style mech scale + readable infantry; integer-scales to 1920×1080 (4×), 3840×2160 (8×), 1280×720 (Deck, ~2.67× → integer 2× with letterbox). |
| Pixel scale | **Variable per layer** | Battlefield = 1× pixel-perfect. UI = vector/SDF (resolution-independent comic-noir). Background parallax = 1× / 2× / 4× depending on depth. |
| Palette size | **64 colors per faction (4 factions × 16-color sub-palette + shared 8-color core + 16 status/UI colors + 16 environmental) = 256-color global palette** | LoSpec-quality; supports faction recolor; readable at small scale. |
| Sprite sizes | Infantry = 16×24 px; Powered armor = 24×32 px; Light mech = 48×64 px; Medium mech = 96×128 px; Heavy mech = 160×192 px. Devices = 8-32 px. | Matches DR-021 chassis scale ladder. |
| Animation frame count | Hero chassis 8-12 frames per action (walk cycle 8; idle 4; fire 2; reload 6; death 6). Non-hero 4-8 frames. | AI generation budget; readable motion. |
| Lighting model | **2D dynamic lighting via normal maps + radial point lights + ambient + light volumes** (per spec/lighting-and-shadows). | Tactical readability; chassis silhouette under spotlight; combat punch. |
| Style anchor | **Pixel-sim battlefield (Cortex/Liero/Soldat) + comic-noir UI (Mark of the Ninja) + tactical readability (Into the Breach)** | Per DR-019. |

## What This Locks In

| Spec Area | Implication |
|---|---|
| `tools/asset_gen/` | Tier 1 SVG/geometric placeholder generator scripts (Python). Run on `cargo build`. |
| `tools/comfyui_workflows/` | Tier 2 ComfyUI workflow `.json` files committed to repo. Versioned. |
| `tools/asset_gen/comfy_runner.py` | Python orchestrator; talks to ComfyUI API; deterministic seed per asset; logs to usage-ledger. |
| `cf-asset-pipeline` CLI | Master regeneration tool. `cf-asset-pipeline regen --tier 2 --asset weapons/ak47` works. |
| `references/usage-ledger.md` | Every AI-generated asset logged: prompt, seed, model, LoRA, license, regenerable Y/N. |
| `assets/<tier>/<category>/<id>.png` | Tier-suffixed output paths. Tier-3 replaces Tier-2 replaces Tier-1 by file-name swap. |
| `cf-mod validate --tier <1\|2\|3>` | Mod packages can declare which tier they target; validation reports inconsistencies. |
| `cf-render-2d` | Renders normal maps + diffuse + emissive + sub-pixel discipline + comic-noir UI overlay. |
| Modding | Modders can use the same Tier 1/2/3 pipeline; ComfyUI workflows are committed and reusable. |

## What This Does NOT Lock

| Non-Commitment | Why |
|---|---|
| Final art-direction LoRA hash | Open. Will lock once Tier 2 produces consistent output across factions. |
| Whether Aseprite is the only authoring tool | Open. Could add Pyxel Edit, Pixelorama, Krita pixel mode. |
| Which AI music provider set wins | Open. Suno/Udio/ElevenLabs/MusicGen/Stable Audio Open candidates are allowed for private prototypes once logged in the usage-ledger; public sale/release use requires cleanup or current license clearance. Non-AI music production is outside this direction. |
| Specific ComfyUI custom node versions | Tracked in `tools/comfyui_workflows/requirements.json`; updated per milestone. |
| Hardware floor for asset regeneration | Currently 32GB VRAM (RTX 4090 class). Tier 1 runs on any CPU; Tier 2 needs ≥12GB VRAM; Tier 3 only needs Aseprite. |

## Why This Direction

| Driver | Detail |
|---|---|
| AI-augmented solo dev | Project is "AI-augmented solo or small core" per DR-026. Hand-painting 60+ weapons + 18+ chassis + 4-6 factions × visual variants + animation sets is a multi-year stall risk. |
| 32GB VRAM available | User has 32GB VRAM; can run any ComfyUI workflow including Flux.1-dev, AnimateDiff, Stable Video Diffusion, Stable Audio Open locally. No cloud lock-in. |
| Determinism + regenerability | Every asset has a prompt + seed + model + LoRA. Re-runnable. Reproducible. Modders can extend with the same pipeline. |
| License safety without prototype drag | Every model/LoRA/tool has an explicit license row in usage-ledger. Private prototypes may use the best available generation tools; public sale/release assets require cleanup or clearance. Stable Audio Open and MusicGen/AudioCraft require special release gating: Stable Audio uses Stability AI Community License / commercial registration rules; AudioCraft code is MIT but released MusicGen weights are CC-BY-NC 4.0. Suno/Udio/ElevenLabs require TOS review before release use. |
| Quality gradient | Tier 1 looks intentional from M0; Tier 2 looks like a real game by M5; Tier 3 is shippable. No "bad placeholder" phase that blocks playtesting. |
| Style fit | SDXL+Pixel Art XL LoRA + PixelArt-Detector quantize is the proven 2026-state-of-the-art for AI-generated pixel art (per Civitai community evidence). |

## Why Not The Alternatives

| Alternative | Why Rejected |
|---|---|
| Pure hand-painted pixel art | Violates the AI-agent-authored pipeline and creates a bottleneck across 60+ weapons + 18+ chassis + factions × variants × animations. |
| Pure AI-generated with no hand polish | Hero assets need pixel-perfect cleanup; faction silhouette readability needs deliberate authoring. |
| Hire a pixel artist | Not feasible at solo-dev budget; also creates single-person bottleneck. |
| 3D-rendered pre-baked sprites | Loses pixel-sim grit; doesn't match DR-019 visual direction. |
| Vector/SVG only (no pixel) | Loses Cortex/Noita/Liero modding-friendly authoring + per-pixel terrain mutation visual coherence. |
| Cloud-only AI (no local) | License + cost + determinism risk. Local-first matches DR-013 backend posture. |

## Revisit Trigger

- ComfyUI/diffusion model pipeline produces unusable pixel art at chassis scale.
- AI-agent Tier-3 cleanup step balloons beyond solo capacity.
- Model licenses change in a release-blocking way (Suno/Udio TOS shift).
- A single-pixel-perfect hero asset takes >2 hours of AI agent work consistently.
- Generated content fails to maintain faction silhouette discipline.
