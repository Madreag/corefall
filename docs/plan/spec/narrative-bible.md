# Narrative Bible

## Setting Bible (10-page worldbuilding)

The post-collapse interstellar frontier (per DR-016): Old colony charters failing; corporate empires collapsing or feeding on corpses; alien biomes eating settlements; abandoned megastructures hold riches and horrors. Player runs a small merc / rescue / salvage outfit taking contracts. Some heroic, some corporate, most go wrong. Player anchored in command core (rooted = base power; uprooted = mobile avatar).

Worlds reachable per [[spec/celestial-bodies-and-worlds-model]]: Sol, Earth, Earth's Moon, Mars + Phobos + Deimos, Mimas, Europa, Vulcan, Venus, belt asteroids, orbital stations.

Factions per DR-045: Trade Star, Coalition, Browncoats, Ronin, Tek-Mart, Imperatus, Free Hold, Husks (anomaly).

## Faction Archives (1 page each)

### Trade Star (corporate mercenary)
- **Origin:** Spun off from a pre-collapse trade conglomerate; now mercs anyone with currency.
- **Doctrine:** Buy-rented loyalty; salvage-focused; clean energy weapons; no faction allegiance.
- **Visual register:** Chrome + glass; corporate logos; muted tan-blue.
- **Signature gear:** Blaster pistol, blaster rifle, flak cannon, light dropships.
- **Quirks:** Contract cancellation clauses; will betray for higher bidder.
- **Mission types:** Salvage, escort, escape, market raid.

### Coalition (military)
- **Origin:** Successor military to the largest pre-collapse government.
- **Doctrine:** Pincer + suppress; medic + engineer support; clean tactical professionalism.
- **Visual register:** Forest-green / khaki; numbered patches; clean lines.
- **Signature gear:** M4-style assault, designated marksman rifle, M249 LMG, jetpack power armor.
- **Quirks:** Strict ROE; no mercenary work; deeply hierarchical.
- **Mission types:** Defense, breach, hostage rescue, stronghold assault.

### Browncoats (heavy clone troopers)
- **Origin:** Clone-trooper program survivors of the Browncoat Wars; recruit anyone tough enough.
- **Doctrine:** Frontline grinder; super-soldier discipline; CCCP precedent.
- **Visual register:** Brown + red; weathered armor; uniform faceplates.
- **Signature gear:** Galil assault, combat shotgun, heavy power armor.
- **Quirks:** Loyalty over orders; bunker-defense specialty.
- **Mission types:** Frontline assault, bunker defense, salvage convoy.

### Ronin (frontier specialists)
- **Origin:** Loner mercenaries; no faction allegiance; "named operatives only."
- **Doctrine:** Stealth + duelist + signature kill; no formation.
- **Visual register:** Black + crimson; individualized; named operatives.
- **Signature gear:** Monomolecular katana, .44 revolver, .338 sniper, infiltrator gear.
- **Quirks:** Each operative has a story; respect strict.
- **Mission types:** Assassination, stealth infiltration, duel.

### Tek-Mart (techbro frontier rats)
- **Origin:** Modder analog faction; rebuilt-from-junk corporation.
- **Doctrine:** Improvised + modular + chaotic; modder analog.
- **Visual register:** Mismatched colors; visible wires; "rebuilt by hobby" aesthetic.
- **Signature gear:** Plasma pistol, modular weapons, jury-rigged mechs.
- **Quirks:** Will sell anything; no consistent doctrine.
- **Mission types:** Workshop raid, modder showcase, salvage marketplace.

### Imperatus (oppressive empire)
- **Origin:** Power vacuum filled by an autocratic conglomerate.
- **Doctrine:** Order + hierarchy + autocrat; legion formations.
- **Visual register:** Imperial gold + black; rigid geometry; uniform.
- **Signature gear:** Gauss rifle, pulse rifle, autonomous drones.
- **Quirks:** Crushing rule; technocrat elite; uses drones over humans.
- **Mission types:** Imperial siege, drone hunt, technocrat extraction.

### Free Hold (frontier independents)
- **Origin:** Frontier scrappers / homesteaders / mutual-aid commune.
- **Doctrine:** Asymmetric defense; bunker-first; CCCP Ronin/Coalition mix.
- **Visual register:** Earth tones; patched cloth; community-painted insignia.
- **Signature gear:** AK-47, pump shotgun, salvage-built gear.
- **Quirks:** Defensive specialists; "hold the homestead."
- **Mission types:** Bunker defense, raid response, supply run.

### The Husks (post-anomaly biological-mechanical hybrids)
- **Origin:** Post-anomaly contamination; biological-mechanical fusion.
- **Doctrine:** Antagonist faction; swarms + biotoxin; corruption.
- **Visual register:** Sickly green + flesh-pink; oozing armor; mismatched limbs.
- **Signature gear:** Chemical injector, chainsaw, swarming mutants.
- **Quirks:** No language; no surrender; spread by infection.
- **Mission types:** Containment, anomaly extraction, finale boss.

## AI Authoring Pipeline

1. Project-owner provides faction seed prompt + tone anchors.
2. AI agent (Claude Sonnet 3.7 or GPT-4o) drafts copy.
3. AI agent reviews for tone consistency + factional voice.
4. Project-owner reviews + edits.
5. Translation pass per Tier-A language via AI translation per [[spec/localization-plan]].
6. Community review per locale (Discord channels).
7. Commit to `content/narrative/` + `content/i18n/<lang>/`.
