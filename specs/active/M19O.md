# M19O — Sleep Need + Bed Quality + Per-Actor 24h Schedule + Insomnia + Bedroom Assignment + Roommate Effects

## Status

`active`

## Intent

RimWorld-grade per-actor sleep need + 24h schedule grid + bed quality + bedroom assignment + roommate effects + insomnia + nap zones. After M19O, every actor has a per-tick sleep_need that drains over time, sleeps in a bed they're assigned to, can be scheduled with a 24h grid (Work / Rest / Recreation / Eat), and suffers measurable penalties for missed sleep.

## Canonical ownership

Owns sleep need, bed quality, 24h schedule grid, roommate friction, insomnia, nap zones. M19H morale consumer; M19P trait consumer (compatibility); M14A walking → bedroom paths.

## Player-facing behavior

### Per-actor sleep need

- Every actor has `sleep_need` (0.0-1.0; 0=fully rested, 1=collapse).
- Drains at `0.04/hr` (24/hr cycle for max 1.0 across awake period).
- Restored at `0.125/hr` while sleeping (8hr sleep restores fully).
- At sleep_need > 0.6: -10% work speed.
- At sleep_need > 0.8: -25% work + -15% accuracy + can fall asleep at work.
- At sleep_need = 1.0: actor collapses; mandatory sleep.

### Bed objects (5 launch tiers)

| Bed | Quality | Sleep recovery rate | Mass | Notes |
|---|---|---:|---:|---|
| `bedroll_floor` | 0.3 | 0.08/hr | 1.2 kg | Survival; portable |
| `sleeping_bag` | 0.4 | 0.10/hr | 1.4 kg | Survival item; deployable |
| `cot_simple` | 0.5 | 0.12/hr | 8 kg | T0 base |
| `bed_standard` | 0.7 | 0.15/hr | 25 kg | T1 base |
| `bed_luxury` | 1.0 | 0.20/hr | 40 kg | T2 base; +morale |
| `medical_bed` | 0.8 | 0.18/hr + healing | 30 kg | T2 base; medical procedures |
| `cryo_bed` | n/a | suspended animation | 80 kg | T3; mission stasis |

### Bedroom assignment

- Player can assign a bed to a specific actor via M19O cfctl `act.player.assign_bed`.
- Unassigned actors sleep in the nearest bed.
- Per-bedroom mood bonus: solo bedroom > shared > barracks.

### Roommate effects

- Two actors sharing a bedroom: chance of friction per night based on M19P trait compatibility.
- Friction events: snoring (loud actor wakes other), nightmare (stress accumulator boost for roommate), pillow-fight (positive social event), romantic encounter (per M19P relationships).

### Per-actor 24h schedule grid

- Per RimWorld: 24 horizontal slots per actor; each slot assigned `Work`, `Rest`, `Recreation`, `Eat`, `Anything`, `Skip`.
- Default schedule: Work 8h / Rest 8h / Recreation 2h / Eat 3h / Anything 3h.
- Player can override per-actor + save presets.
- Per-role schedule presets: "Soldier", "Engineer", "Medic", "Scientist", "Drone Operator".

### Curfew enforcement

- Per-room curfew zones: at curfew time, actors not in their assigned bedroom get -morale.

### Nap zones

- Chair / couch / armchair: actors can nap (× 0.5 sleep recovery rate); useful for short breaks.
- M19H recreation chair: doubles as nap zone + recreation.

### Insomnia

- Stress > 60 + recent trauma → insomnia trait (temporary 3 days).
- Insomniacs wander base at night; produce morale events for roommates.
- Treatment: medical bed + therapy session (M19P).

### Sleep deprivation afflictions

- 4+ hours missed sleep → `sleep_dep` affliction per M16 + M43 PvE list.
- Effects: vision tunneling + reaction time +50% + hallucination risk.

### Sleep scheduling for non-human origins

- Robots: no sleep need; can be assigned "Charge" instead of Rest (M29 battery recharge).
- Androids: half sleep need (0.02/hr drain).
- Heavy biomech: sleep optional; can run continuously but degrades slowly.

## Acceptance criteria

```gherkin
Scenario: Sleep need drains over time
  Given actor awake 16 hours
  Then sleep_need ≈ 0.64
  And work speed × 0.9

Scenario: Sleep recovery via assigned bed
  Given actor with sleep_need=0.8 assigned to bed_standard (0.15/hr recovery)
  When actor sleeps 6 hours:
    Then sleep_completed fires
    And sleep_need = 0.8 - 0.9 → clamped 0 (fully rested)

Scenario: Bed quality affects recovery
  Given bedroll_floor (0.08/hr) vs bed_luxury (0.20/hr)
  Then bed_luxury recovers 2.5× faster

Scenario: Bedroom assignment
  Given player invokes act.player.assign_bed { actor_id, bed_id }
  Then bed_assigned fires
  And actor's "owned_bed" field set
  And at sleep time, actor paths to owned bed

Scenario: Roommate friction
  Given 2 actors sharing a bedroom
  When night begins:
    Then roommate_friction rolled per trait compatibility (M19P)
    And snoring / nightmare / romance event possible

Scenario: 24h schedule grid
  Given player sets actor schedule: Work 6am-2pm, Rest 10pm-6am, Recreation 2pm-4pm, Eat 4pm-5pm
  When current_time = 7am:
    Then actor in Work slot; takes work tasks
  When current_time = 11pm:
    Then actor paths to assigned bed

Scenario: Insomnia diagnosis
  Given actor stress > 60 + trauma event yesterday
  When sleep attempted:
    Then insomnia_diagnosed fires
    And actor stays awake; wanders base

Scenario: Sleep deprivation affliction
  Given actor missed 4+ hours sleep
  Then sleep_dep_affliction fires
  And aim_accuracy × 0.7
  And reaction_time × 1.5

Scenario: Robot Charge instead of Rest
  Given robot actor assigned schedule slot "Charge"
  When current_time hits slot:
    Then robot paths to charger (M29)
    And battery recharges per M29 charge rate
```
