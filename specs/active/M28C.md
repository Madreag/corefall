# M28C — Vehicle Bay + Loading Dock

## Status

`active`

## Intent

Vehicle bay base module + loading dock for actor-vehicle-cargo transfer + Stationeers-style drive-up-and-unload UX — closes the M44 "vehicles have cargo capacity but no loading UX" gap.

## Player-facing behavior

- Build a `vehicle_bay` (16×8 tile module) attached to airlock; vehicles drive in; bay seals + pressurizes; actor can disembark in atmosphere.
- Build a `loading_dock` (8×4 tile module) outside the airlock; deposit-only or transfer; auto-routes cargo crates from vehicle to attached storage.
- Drive an electric ATV (M44A) onto the loading dock; press [E] → cargo manifest UI opens; player drags ore from ATV crate to base storage in 1-second-per-crate animation.
- Vehicle-attached crate (refrigerated / sealed / armed variant) maintains its sub-circuit power from vehicle battery while on dock; switches to base power when locked.
- Forklift (M44A T1) auto-loads from loading dock → storage room when in `auto-load` mode; uses M22 pathfinding + IC10 chip for route.
- HUD shows per-vehicle inventory manifest + capacity-percent meter at dock proximity.

## Acceptance criteria

```gherkin
Scenario: ATV docks at vehicle bay; bay pressurizes
  Given a base with vehicle_bay attached to airlock
  And an electric ATV approaching from exterior
  When the ATV drives onto the bay's parking footprint + presses [E]
  Then vehicle_bay_docked event fires
  And the bay's exterior door closes + interior pressurizes (M19 + M28 cycle)
  And the driver actor can exit the ATV in atmosphere

Scenario: Player opens cargo manifest at loading dock
  Given an ATV at the loading dock with 12 ore crates in cargo
  When the player presses [E]
  Then cargo_manifest_drawer opens showing 12 crates with per-crate composition
  And HUD shows "Cargo: 12 / 20 capacity (60%)"
  And player can drag a crate slot → base storage slot

Scenario: Manual cargo transfer takes 1s per crate
  Given a player at loading dock with cargo manifest open
  When the player drags 5 crates to base storage
  Then cargo_transfer_started fires per drag
  And each crate animates over 1 second + cargo_transfer_completed fires
  And total elapsed = 5 seconds + 1 tick for each crate
  And vehicle inventory + base inventory both update deterministically

Scenario: Refrigerated cargo crate maintains power during dock
  Given a refrigerated cargo crate (medical samples) in the ATV
  When the ATV docks at the bay
  Then the crate's sub-circuit power source switches from vehicle battery to base power
  And the cooling sub-circuit remains active
  And no spoilage events fire

Scenario: Forklift auto-loads from dock → storage silo
  Given a base with loading_dock + cargo_storage_silo + idle forklift on charging_pad
  And 8 ore crates arrive at the dock
  When the player issues "auto_load" command to the forklift via M22 squad UI
  Then the forklift's AI doctrine plans a path: dock → silo → dock loop
  And each crate transfers in ~6 seconds (drive + load + drive + unload)
  And the forklift returns to charging_pad when storage is full OR when dock is empty
  And per-trip cargo_transfer_completed events fire

Scenario: Vehicle bay refuses oversized vehicle
  Given a vehicle_bay_t1 (capacity: ATV, light mining hauler)
  When a large cargo freighter attempts to dock
  Then docking is rejected with reason="vehicle_too_large_for_bay"
  And caption shows "Bay too small — needs T2 vehicle bay"
  And the freighter must dock at exterior loading_dock instead
```

## Out of scope

- Multi-vehicle bay (parking 2+ vehicles simultaneously) — M48+ base expansion.
- Cargo crate auto-routing across multiple bases via inter-base conveyor — M48+ logistics.
- Drone-based cargo transfer (autonomous drone fleet) — M45A endgame ambition.
- Vehicle wash + decontamination (radiation removal) — M16 hazard integration; future.

- M28 base atmospherics (active): airlock + room detection

## Notes for the implementer

- Vehicle bay seal cycle is 5 seconds (exterior door close + 3s pressurize + interior door open); matches M28 airlock cycle.
- Cargo crate "slot" is a virtual container with `[contents: Vec<(MaterialId, kg)>]` and `[max_kg: f32]`. M44A defines per-vehicle crate count; M28C provides the routing.
- Auto-load AI for forklift uses standard M22 pathfinding with cost_modifier `prefer_loading_dock_path: 0.5×` to bias the planner.
- Loading dock can be unsealed (exterior; no atmosphere) OR sealed (interior, M28-compatible); player chooses at place-time.
- The cargo_manifest_drawer reuses M27A Tetris inventory grid widget; M28C adds the per-vehicle scoping.
