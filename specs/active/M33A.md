## Intent

**M33A is the tutorial lab production milestone** — 8 modular tutorial labs implemented (per M8 + M33 reservation + DR-023) with scripted scenarios + tutorial player widget + adaptive hints engine. After M33A, new players have a 12-15 minute "First Contract" onboarding (per DR-046) followed by 8 optional modular labs covering every major mechanic.

**Canonical-ownership cross-ref:** M33A ships the 8 standalone tutorial labs + the First Contract scenario + lab-player widget + adaptive hints engine + FRE wizard *mockups* (the FRE step screens baked at Tier 1). The **deep FRE wizard kernel** (5-step state machine + accessibility-preset bundles + difficulty recommender + calibration arena + skill-rating bot + per-tooltip-verbosity resolver + progressive-disclosure unlock graph + sandbox mode + 8 in-game system mini-tutorials) is owned by **M33D**, which extends M11A's FreStep state machine and consumes M33A's labs from step 5 ("tutorial offer"). M33A is the lab content + tutorial player; M33D is the deep new-player-experience layer above and around it.

**Why after M33 (mod workbench):** by M33 close, the scenario editor + Lua scripting + IC10 + photo + replay tools all exist. Tutorial labs are scenarios authored against the M33 editor; they CONSUME M33 infrastructure.

**Why this milestone exists at all:** the user said "minimal human interaction once milestones are set". A new player downloading the game on Steam needs onboarding to understand the depth (chassis, atmospherics, power, factions, etc.). Without M33A, the game is impenetrable. M33A produces ALL onboarding content via LLM-driven scenario authoring + M37A voice-over.

M33A promise: **"a new player can pick up the game and learn every major mechanic in 30-45 minutes of optional tutorial labs — narration voice-acted, captions ACC-A compliant, scenarios bite-sized, adaptive hints surface when player stumbles."**

## Player-facing behavior

### First Contract — 12-15 minute introductory mission

Per DR-046 — the canonical onboarding mission that introduces:
- Movement (WASD + jump + crouch)
- Aim + fire (mouse + click)
- Reload + ammo management
- Material affordance (dig dirt; refuse metal)
- Basic enemy combat (M2 ReactiveGuard)
- Objective completion + mission outcome

Plays as a guided scenario with on-screen hints + voice narration (M37A). Skippable for veterans.

### 8 modular tutorial labs

Each lab is 2-5 minutes; standalone; covers one mechanic; player can play any/all in any order:

| Lab | Topic | Mechanics covered | Duration |
|---|---|---|---|
| 1 | **Movement Mastery** | Sprint / crouch / lean / vault / slide / climb / dive | 5 min |
| 2 | **Weapons + Fire Modes** | 6 weapons + 3 fire modes + suppressor + bipod | 4 min |
| 3 | **Grenades + Arc Preview** | 4 grenades + cook + throw arc | 3 min |
| 4 | **Tools + Terrain** | 7 tools + material affordances + tool degradation | 5 min |
| 5 | **AI + Cover Seeking** | 5 enemy archetypes + cover + suppression + retreat | 5 min |
| 6 | **Mission Objectives + Branching** | Multi-objective + branching paths + storyteller pacing | 4 min |
| 7 | **Squad Commands + 4 Verbs** | Follow / Hold / Defend / Push | 4 min |
| 8 | **Stealth + Perception** | Stealth meter + sound propagation + per-material footsteps | 5 min |

### Tutorial player widget

- Per-lab HUD shows: lab title + step counter (e.g. "Step 3/8") + objective text + hint area
- Next / Previous / Skip / Replay buttons
- Pause + resume support
- Lab completion tracking (per profile)
- All accessible via Tab + Enter (DR-012 ACC-A-04 keyboard navigation)

### First-run-experience (FRE) wizard

On first launch after install:
1. **Welcome screen** — game intro + branding (M48B marketing pipeline assets)
2. **Profile setup** — display_name + preferred_origin + accessibility presets (per M11/M38 settings)
3. **Calibration** — text scale + audio levels + key bindings preview
4. **Tutorial offer** — "Want to play First Contract? (~12 min)" — Y/N
5. **Recommendation** — based on origin choice, suggests starter PvE world (per M43 race-world matrix)

After FRE, player lands in main menu; tutorial labs accessible from menu.

### Adaptive hints engine (M11 forward-compat → M33A fills)

Per DR-023 — adaptive hints monitor player state via M20 EnvironmentSignal + M11 HUD focus:

- Player stuck at low HP for 30s → hint "Press M to open material overlay; find healing tile"
- Player dying repeatedly to same enemy → hint "This enemy archetype is <Sniper>; try flanking"
- Player not using a tool → hint "Press G to use digger; try carving cover"
- Player struggling with M19 atmospherics → hint "Press F4 for material overlay → hazard mode"
- Hints respect Settings.objective_help = Minimal / Standard / Verbose per M11
- Hints can be dismissed (don't show again per player per session)

### Hint text source = M25A

M25A narrative pipeline produced the tutorial_narration content. M33A consumes those scripts + per-lab structure.

## Tutorial lab scenario schema (locked v1)

```ron
TutorialLab (
    id: "lab_01_movement",
    title: "Movement Mastery",
    description: "Learn sprint, crouch, lean, vault, slide, climb, dive.",
    estimated_duration_min: 5,
    
    steps: [
        TutorialStep(
            step_id: "step_01_sprint",
            title: "Sprint",
            hint_text: "Hold SHIFT while moving to sprint. Sprinting depletes stamina.",
            target_action: "act.player.sprint",
            completion_condition: ActorVelocityExceeds(walk_threshold_x_2),
            voice_synth_pair: "lab_01_step_01_voice",  // M37A produces voice-over
            success_caption: "Sprint achieved!",
            fail_caption_after_30s: "Try holding SHIFT while moving with WASD.",
        ),
        TutorialStep(
            step_id: "step_02_crouch",
            ...
        ),
        ... 8 steps total
    ],
    
    scenario_ref: "content/scenarios/tutorials/lab_01_movement.ron",
    
    completion_reward: AchievementUnlock("tutorial_movement_complete"),
    
    package_source: PackageRef(vanilla, version: "1.0.0"),
)
```

## Notes for the implementer

### Architecture rules

- **Tutorial = scripted scenarios** — each lab is a scenario .ron + a cfctl script for AI Self-Test grading
- **Step machine** — per-lab step state + completion conditions + advance triggers
- **Adaptive hints non-blocking** — never pause game; surface via HUD ticker per M11 caption strip
- **Voice synth integration** — M33A consumes M37A; voice + caption + hint fire together
- **Replay determinism** — labs must replay deterministically for AI Self-Test grading

### Decision-record alignment

- **DR-023 (tutorial / onboarding) — CLOSES at M33A** with 8 modular labs + adaptive hints + FRE
- **DR-046 (player-facing surfaces)** — M33A is the canonical onboarding surface
- **DR-044 (audiovisual production pipeline)** — M33A consumes M9A/M12A/M18A/M24A/M25A/M37A outputs

### Pitfalls

- **Lab pacing drift** — labs that take >5 min lose players; LLM-grade per-lab target duration
- **Hint spam** — adaptive hints must not over-fire; cooldown per-hint
- **Skip + replay state** — completion tracker handles skip / replay / restart per profile
- **AI Self-Test grading flakiness** — labs must be deterministic for grading

### Closure procedure

1. Reference bundle: M33A self-test (AI plays all 8 labs + First Contract; bundle archived).
2. Self-play sweep rows: `m33a_first_run_wizard`, `m33a_first_contract_complete`, `m33a_8_labs_complete`, `m33a_adaptive_hints`, `m33a_acc_a_calibration`, `m33a_origin_recommendation`, `m33a_modder_authoring`. All PASS.
3. Update DR-023 + DR-046 closure note.
4. Move M33A → done/.
