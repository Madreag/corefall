# M43A — Map + Mission Select + Campaign + Travel Planner UX

## Status

`active`

## Intent

**M43A is the map + mission + campaign UX milestone** — full UX for navigating the multi-world Corefall universe: world map (per-world geography + waypoints + bases + ore deposits + faction territory + hazards), solar system map (per DR-039 12 worlds + travel time + comms latency + orbital positions), mission select screen (campaign tree + side missions + endgame modes), campaign progression visualizer (unlock graph + branching paths + completion %), mission briefing screen (full text + voice + comic panels per M48B), travel planner UI (dropship/rocket/teleporter per M44).

**Why after M43 (PvE survival + procgen):** by M43 close, the 3 launch survival worlds + procgen are complete. M44 adds inter-planet transport + 12 worlds via post-launch unlock. M43A polishes the navigation UX so players can plan + travel + select missions seamlessly.

**Why this milestone exists:** without M43A, the player can't navigate the multi-world universe. M11 reserves world_map + orbital_map widgets; M43/M44/M25 features build the underlying systems; M43A is the dedicated UX that ties it all together.

M43A promise: **"navigating Earth + Mars + Mimas (M43 launch) + 9 post-launch worlds + 30+ campaign missions + 5 endgame bosses + asteroid mining outposts + orbital stations + cross-world supply chains feels intuitive — world map per Civilization VI quality; solar system map per Stellaris quality; mission select per Hades quality."**

## Player-facing behavior

### World map UX

Per-world (current planet):
- **Geography view** — height map + biomes per M31 + per-region terrain features
- **Layer toggles:**
  - Bases (player + faction)
  - Ore deposits (per M30 + M35; per-tier visualization)
  - Hazard zones (per M16: fire / electric / acid / radiation / etc.)
  - Faction territory (color-coded per M26 8 factions)
  - Weather (per M31; current weather state + forecast)
  - AI raider settlements (per M43 procgen)
  - Geysers (per M19 + M43 ONI parity)
  - Anomaly clusters (per M16 STALKER)
  - Pre-existing structures (per M43 procgen: ruined outposts / pirate bases / ancient artifacts)
  - Trade routes (per M26 trader NPCs)
  - Quest markers (per M26 quests)
  - Player waypoints (custom; player-placed)
- **Click + drag** to pan; mousewheel to zoom; per-tier zoom levels (continent / region / area / location)
- **Mini-map (bottom-right)** — current player position + nearby waypoints
- **Per-tile inspection** — click tile to see: material / ore content / hazard / faction control / pre-existing structures
- **Per-tier visibility** — fog-of-war per M43 procgen (unexplored areas dim); exploration reveals
- **Waypoint placement** — click "Place Waypoint" + name + symbol + color; persistent per-base
- **Travel route planning** — click destination → preview route (per pathfinding + atmospheric / hazard impact / fuel cost)
- **Per-faction territory visualization** — color overlays + faction emblems
- **Per-weather forecast** — 24h ahead per M31 weather kernel
- **Mini-map zoom-to-overview** — Tab to switch world map → solar system map

### Solar system map (per DR-039)

12 launch worlds + orbital mechanics:
- **Orbital view** — top-down solar system with all 12 worlds in current positions
- **Per-world icon** — planet/moon/asteroid + per-world emblem (M9A SVG)
- **Per-world status** — colonized / explored / unexplored / unlockable
- **Travel time to each world** — per-craft (dropship / rocket / teleporter); ETA
- **Comms latency per DR-039** — Earth ↔ Mars 6-44 min; Earth ↔ Vulcan 12-24 hr; etc.
- **Orbital position over time** — drag time-slider to see future positions
- **Per-world recommended race** — per M17 + M43 difficulty matrix (e.g. Methane breather on Mimas = native)
- **Per-world atmosphere preview** — gas composition / temperature / pressure / gravity
- **Per-world ore distribution** — per M30 + M35 visualization
- **Per-world faction presence** — color-coded per M26
- **Pin destinations** — bookmark worlds for quick-travel planning
- **Travel planning overlay** — drag from world A to world B → route preview with ETA + fuel + tank requirements
- **Anomalous events (per M45 storyteller)** — solar flare / mass attack / mysterious signal markers visible

### Mission select screen (Hades-quality + Civ-level depth)

- **Per-mode tabs:**
  - Campaign (per M25 30+ missions)
  - Side missions (per M26 procedural quests)
  - PvE Survival (per M43)
  - Endgame Modes (per M41 10 endgame modes)
  - Boss Hunts (per M45 5 bosses)
  - Tutorial Replays (per M33A)
  - Player-Made Scenarios (per M33 mod workshop)
- **Per-mission card:**
  - Title + brief description
  - Per-mission preview clip (per M40A capture)
  - Reward preview (credits + loot + reputation + cosmetics)
  - Recommended tier + race + faction
  - Difficulty rating (1-5 stars)
  - Completion status + best record (time + rating)
  - Friends who have played + their rating (per M36A Steam)
  - Available + locked status
- **Filter** — by mode / difficulty / completion / faction / world / boss / mod-supplied
- **Search** — keyword
- **Sort** — Newest / Most-played / Highest-rated / Recently-played / Difficulty
- **Per-mission briefing preview** — hover shows M25A intro text + M37A voice preview

### Campaign progression visualizer (per M25 + DR-048)

Per M25 30+ campaign missions:
- **Tree layout** — branching campaign tree
- **Per-mission node** — icon + title + status (locked / available / completed / failed)
- **Per-mission prereqs** — visual lines connecting prereqs to current node
- **Per-mission rewards** — preview of credits / loot / cosmetics / codex unlocks
- **Per-mission branching** — visible alternate paths
- **Boss encounters** — highlighted nodes
- **Endgame mode unlocks** — visible at tree end
- **Hidden missions** — locked + obscured ("Complete X to discover")
- **Per-mission completion %** — community-wide completion rate (M36B telemetry)
- **Per-mission character spotlight** — per-NPC dossier link (per M25A + M26)
- **Storyline summary** — current arc + next arc preview
- **Multi-playthrough tracking** — per-playthrough progress visible

### Mission briefing screen

Per M25A mission briefings + M37A voice + M48B comic panels:

- **Layout:**
  - Top: Mission title + objective summary
  - Center-left: M48B comic panel illustration (LLM-generated; per-mission unique)
  - Center-right: Mission text (M25A; intro 300-400 words)
  - Bottom: Objective list + reward preview + boss intro (if applicable)
- **Voice-over** — M37A voice plays per intro + boss intro
- **Briefing skip** — Press [Space] to skip; voice continues in background (Settings.briefing_skip=Always / Manual / Never)
- **Loadout recommendation** — auto-suggest per-mission gear (per M25A + M27A)
- **Faction reputation impact** — preview of choices' impact
- **Mission timer preview** — if timed
- **Briefing replay** — replay briefing from main menu / mission history

### Travel planner UI (per M44 inter-planet)

Per M44 dropship/rocket/teleporter:

- **Per-craft options** — Dropship / Rocket / Teleporter (per-availability)
- **Per-route preview** — origin → destination + ETA + fuel cost + comms latency
- **Per-craft cargo capacity** — actors + materials + weapons
- **Per-craft tank requirements** — fuel + O2 + N2 per M44 vehicle tank slots
- **Per-craft risk assessment** — crash chance + pirate intercept chance + solar flare interruption
- **Pre-flight checklist** — fuel ≥20% / engine integrity / heat shield / cargo mass / passengers
- **Per-flight phase visualization** — Take-off / Orbital insertion / Inter-planetary cruise / Mid-course correction / Deceleration / Re-entry / Landing
- **Multi-leg planning** — Earth → Mars → Belt asteroid → Mimas
- **Teleporter pair selection** — pick paired endpoints (per M44)
- **Travel-time accelerated playback** — fast-forward through inter-planetary cruise per M44 long-duration flights
- **Per-platform booking** — Steam Friends in destination zone visible

### Orbital station overview (per M44)

Per-orbital-station UX:
- **Station layout view** — top-down of station modules
- **Per-module status** — solar arrays / mining drone bay / defensive turrets / habitation / hangar / comm relay / living quarters / research lab
- **Per-module power state** — per M29 power overlay integration
- **Per-module atmospheric state** — per M28 + M19 integration
- **Dock + undock UX** — per-arrival dropship docking; cargo unloading
- **Per-station defense** — turret + shield state per M9 + M25
- **Asteroid mining drone status** — per M35 + M44 auto-extraction
