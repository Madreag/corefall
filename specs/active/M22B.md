# M22B — Hierarchical A* Pathfinding Deep + Cover-Finder + Per-Team Path Cost

## Status

`active`

## Intent

Take M22's three-grain Hierarchical Pathfinding A* sketch and ship it as a real, profiled, per-team, M3B-aware pathing kernel with a first-class **cover-finder** that reads M3B's per-tile element model to score cover tiles by occluder thickness, material mass, and line-of-fire from known threats. After M22B, a flanker actually flanks (routes region → chunk → tile through cover-rich corridors), a sniper finds high-ground occluder cover (queries `cover_state=Full + LOF_blocked_to_known_threats`), and a hazmat squad routes *through* a hazard its gear ignores while the unprotected squad routes *around*.

M22B promise: **"the pather sees three grains, the cover-finder sees M3B element-by-element, and every team has its own opinion about which tile is worth stepping on."**

## Player-facing behavior

- **Three grains auto-picked by Manhattan distance.** ≤32 tiles → tile-only (per-pixel A* over collision + M3B element solidity). 32-512 tiles → chunk-grain A* over the 256×256 chunk graph + tile refinement on entry / exit chunks. >512 tiles → region-grain (regions = connected-chunk clusters) → chunk inside each region → tile inside entry / exit chunks. Recorded in `ai.path_built_hierarchical`.
- **Per-grain heuristic.** Tile: Manhattan + diagonal-corrected (`max(dx,dy) + 0.414·min(dx,dy)`). Chunk: Euclidean on chunk centroids + material-aware base cost. Region: Euclidean on region centroids + team-affinity bias.
- **Per-team cost-vector weighting** — `TeamCostProfile { material_costs, hazard_overrides, friendly_actor_cost, enemy_actor_cost, unknown_tile_cost }`. Hazmat team has `Radiation = 1.0` (normal); unprotected team has `Radiation = INFINITY`. Scouts have `friendly_actor_cost = +20`, `unknown_tile_cost = -2` (max-explore). Loaded from `game/content/ai/team_cost_profiles/<team_id>.ron` at scenario boot.
- **Cover-finder reads M3B element mass, not legacy hardness.** `CoverQuery { from, threats, max_radius, min_occluder_thickness_kg }` returns scored `CoverTile { pos, cover_state, occluder_thickness_kg, lof_blocked_to_threats: BitMask, score }`. Scorer rewards: full LOF block from *all* threats > thicker occluder mass > shorter detour > BotMemory pain-angle avoidance (M23B). Budget ≤2 ms per query (Steam Deck floor).
- **Dynamic re-pathing on M3 dirty-rect** — `terrain.terrain_dirty_region_batch` triggers the invalidator; cached paths intersecting affected chunks are marked stale; `ai.path_invalidated_dirty_chunk { actor_id, chunk_id }` fires; per-grain edge caches auto-drop.
- **Stuck recovery escalates grains.** Velocity ~0 for 60 ticks → drop tile segment, refall to chunk path. Another 60 → drop chunk, recompute region. Third failure → `ai.path_stuck_terminal` + BT receives `pathfinding_failed`.
- **Formation-slot pather hook (M7B integration)** — slot world position fed as goal via `RepathToMovingGoal { goal_provider, max_stale_ms: 300 }`. Slot vector recomputed every 2s relative to commander facing; pather updates smoothly without per-tick re-A*.
- **Per-team LOF predicate** — `cover_finder::lof_blocked(from, to, profile) -> bool` walks the tile line, returns true if any tile's `mass_kg ≥ min_occluder_thickness_kg`. Used by M7B `Overwatch` + `Suppress` to filter valid sectors. Penetration math (low-mass tile + high-energy round) is M14, not here.
- **Sleeping AI never enqueues path requests** (M22 invariant preserved); invalidator skips them on dirty-rect events.
- **Replay-deterministic** — requests processed in stable actor-id order on M8A's `par_iter` scheduler; team-cost + cover-finder are pure functions of replay-recorded state; no `thread_rng()`.

## Acceptance criteria

```gherkin
Scenario: Hierarchical grain auto-selected by request distance
  Given an AI request from A to B
  When Manhattan(A,B) ≤32 tiles, ai.path_grain_picked = "tile"
  When 32..=512 tiles, ai.path_grain_picked = "chunk" with tile refinement on entry + exit chunks
  When >512 tiles, ai.path_grain_picked = "region" with chunk inside each region + tile on entry + exit chunks
  And ai.path_built_hierarchical records the full grain trace

Scenario: Per-team path cost diverges through a hazard
  Given a radiation tile and two teams: team_enemy_default (hazard_overrides[Radiation]=INFINITY), team_enemy_hazmat (=1.0)
  When both request a path through that corridor
  Then default routes around, hazmat routes through
  And ai.team_cost_applied fires per request with the resolved cost vector

Scenario: Cover-finder reads M3B per-tile mass and scores occluders
  Given an actor at A and one known threat at T
  When the cover-finder runs with min_occluder_thickness_kg=20
  Then CoverTile entries report cover_state=Full only when occluder mass ≥20 kg
  And the top-scored tile maximizes occluder mass among tiles with full LOF block from T
  And ai.cover_finder_result records the top-N scored tiles

Scenario: Dynamic re-pathing on M3 dirty-rect
  Given an actor traversing a cached chunk-grain path
  When terrain.terrain_dirty_region_batch fires on a chunk on that path
  Then ai.path_invalidated_dirty_chunk fires, the per-chunk cache evicts, and the actor re-requests next AI tick

Scenario: Stuck recovery escalates tile → chunk → region
  Given velocity ~0 for 60 ticks while a tile-segment is active
  Then ai.path_stuck_escalation fires (tile→chunk)
  After another 60 ticks stuck, it fires again (chunk→region)
  After a third 60-tick window, ai.path_stuck_terminal fires and the BT receives pathfinding_failed

Scenario: Formation-slot moving goal does not per-tick re-A*
  Given an M7B formation slot assigned to actor A and the commander rotates 90°
  When 2s pass, the slot vector recomputes and the pather receives a moving-goal update
  And no per-tick A* request is issued (max one re-A* per 2s under stationary commander)

Scenario: LOF predicate respects M3B element mass
  Given a Steel wall with mass_kg=80 per tile between A and B
  When lof_blocked is called with min_occluder_thickness_kg=20, it returns true
  When the wall is breached to mass_kg=5 per tile, it returns false
  And ai.path_invalidated_dirty_chunk fires for any cached path that depended on the LOF block

Scenario: Sleeping AI is skipped by invalidator
  Given an actor in IdleSleeping with a cached path
  When terrain.terrain_dirty_region_batch fires on its path
  Then no ai.path_invalidated_dirty_chunk fires for that actor; the cached path is left alone until wake

Scenario: 50-actor pathing meets Steam Deck p99 budget
  Given 50 active actors with mixed-grain requests
  When the per-tick pathfinder runs on the Steam Deck reference, total work ≤80 ms p99
  And the same workload ≤8 ms p99 on the 9950X3D reference
  And no `thread_rng` is invoked anywhere in the kernel

Scenario: Replay determinism across hierarchical paths
  Given a recorded mission with mixed tile + chunk + region paths and one cover-finder volley
  When replayed on a different machine, every ai.path_built_hierarchical and ai.cover_finder_result fires bit-exactly
```

## Out of scope

- Penetration math for the LOF predicate (low-mass tile + high-energy round actually punches through) — M14 ballistic owns this.
- 3D / multi-layer pathfinding (Z-stacked rooms) — M19 atmospherics has 3D; M22B pather stays 2D.
- Path-segment reservation + collision-avoidance steering — already owned by M22.
- Squad-cohesion pathing (squad moves as one entity) — covered by M7B formation slot pather; M22B only ships the per-actor moving-goal hook.
- AI commander-level strategic pathing (which region to attack next) — M23B `tactical_planner` owns.
- Per-tile element transition / phase change as path-cost input — M3B `tile_phase_transitioned` is read-only here; pather just uses the current mass.
- LLM-driven path proposals — M23 / M23B mind layer; M22B never blocks on LLM.

## Notes for the implementer

- Three grains share one A* core — implement `AStar<Node, Heuristic, CostFn>` once + parameterize. Do NOT copy the inner loop three times.
- Chunk-edge + region-edge cache key = `(chunk_id, team_profile_id, terrain_revision)`. Bump terrain_revision on `terrain_dirty_region_batch` so caches auto-drop.
- Cover-finder is a hot path. Pre-sort threats by distance, short-circuit the LOF walk on first solid tile, bit-mask LOF accumulation (not `Vec<bool>`).
- Team cost profiles are RON, not Rust. Adding a team MUST NOT require a recompile.
- Per-team material cost = `Vec<f32>` indexed by interned u16 `MaterialId`, NOT `HashMap`.
- hierarchy_glue picks grain by Manhattan, not Euclidean — matches the tile heuristic.
- Moving-goal updates use a per-actor `path_revision: u32`; the pather drops requests stamped with a stale revision.
- All path events include `grain` + `team_profile_id` + `path_revision` for replay grading.
- No `unwrap()` on user-controllable inputs; bounds-check cover-finder args against the chunk grid.
- `cf-ai` is a sim crate — inherit M8A invariants exactly (no `thread_rng()`, no default-hashed `HashMap`, no `f64` in cost / heuristic math).
- 80 ms Steam Deck budget is for 50 actors *combined*. Per-actor floor ≤1.6 ms; profile any single request >4 ms.
- Commit one grain at a time: tile_grain → chunk_grain → region_grain → hierarchy_glue → team_cost → cover_finder → dirty_invalidator. Commit subject `M22B: <imperative summary>`.
