# M25B — Narrative Tier 2 LLM Expansion + 80k Word Bible + 600 Codex

## Status

`active`

## Intent

Close the M25A "future milestone" deferral by shipping the actual LLM-driven narrative-expansion production pipeline that takes M25A's Tier 1 seed corpus (83 files; 24 NPC dossiers; 12 mission briefings; 300 codex starts) and expands it to README's promised 80k word bible + 600 codex entries + full mission briefing pass for all 30+ campaign missions.

## Player-facing behavior

- **Codex unlock progression**: as the player progresses, codex entries unlock per faction / world / NPC / event / item. By M49 GA, 600 entries are available; the bible reads as a coherent setting.
- **Mission briefings**: every campaign mission has a 200-500 word briefing in-mission terminal style (Helldivers-flavor) + lore-rich codex links.
- **24 named NPCs** have full dialog trees (8 options per encounter) + per-NPC backstory + voice (M37A baked) + sprite (M32A baked).
- **8 faction lore documents** read as historical / political / economic / cultural deep-dives; influence quartermaster dialog + diplomacy options (M26).
- **5 storytellers** have their full mid-mission interjection libraries (Cassandra dread / Phoebe quirk / Randy chaos / Ironman challenge / Sandbox open).
- **Per-world lore** for all 12 worlds: history / native species / climate / past disasters / faction territory / mission hooks.
- **75 achievements** have lore-rich titles + descriptions tying to the bible.
- **60 loading screen tips** are extracted lore-friendly callouts from the bible.

## Out of scope

- Player-generated narrative content via mod tools (player writes own codex) — M33 modding workbench owns.
- Per-language translation (i18n) — M38A handles.
- Real-time LLM generation during gameplay (no live LLM calls in runtime sim) — design constraint.
- Adaptive narrative that changes based on player choices in-mission — M48+ branching narrative.

## Notes for the implementer

- LLM choice: project-owner-configurable; default to ElevenLabs / OpenAI / local model per BYOK config. Pipeline should not lock to a specific provider.
- Determinism: pipeline outputs are baked OFFLINE (not per-tick LLM calls); runtime reads RON. Seed + prompt hash recorded in narrative_ledger.jsonl for reproducibility.
- Review_loop quality gates: enforce style consistency + no factual contradictions + length bounds + sensitive-content filtering.
- 80k word total is the README floor — implementer should aim higher (~100k) to provide slack for editing.
- Per-section budget split: codex (300×100 = ~30k words) / NPC bios (24×500 = ~12k) / briefings (30×400 = ~12k) / factions (8×1200 = ~10k) / worlds (12×600 = ~7k) / storytellers (5×1200 = ~6k) / achievements (75×50 = ~4k) / loading tips (60×80 = ~5k) = ~86k baseline.
- The pipeline is a build-time tool (lives in `tools/` not `game/`); only the baked RON files ship in `game/content/`.
