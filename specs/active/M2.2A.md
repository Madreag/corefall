
## Status

`active`

## Intent

**M2.2A** is the **first bridge slice** between M2 (chunked terrain, closed) and M2.5 (reactor defense). It closes the **actor controller + equipment + inventory + sound + squad-of-two** gap left after M1 + M1.5 + M2. M2.2A is followed by **M2.2B** (AI archetypes + mission director) and **M2.2C** (camera + UX + debug + localization + accessibility). The full M2.2 ladder must be closed before M2.5 reactor defense gets its full surface.

M2.2A's player-facing promise: **"a single actor in a single scenario already feels like a modern tactical shooter."**

## Player-facing behavior

### Actor controller depth (M1: 9 actions → M2.2A: 36 actions)

The actor controller becomes near-vertical-slice quality. New actions on top of M1's 9 baseline:

- **Sprint** — faster than running, no aim; depletes `stamina` (0..1; -0.2/s while sprinting; +0.3/s recovery when not)
- **Crouch** — reduced silhouette + 40% bloom reduction + better aim
- **Prone** — lowest silhouette + slowest move + bipod-deployable
- **Slide** — sprint-to-crouch transition (600ms; reduces silhouette mid-motion + invuln frames)
- **Vault** — over low cover (800ms animation; transitions actor to other side)
- **Climb up** / **climb down** — ledge (1200ms) / ladder (1500ms)
- **Dive** — forward-roll evasive (600ms; brief i-frames)
- **Lean left** / **lean right** — -45° to +45° around corners (aim extends past wall; collision body shifts)
- **Stealth kill** / **takedown** — sneak melee from behind (only available when `stealth_meter < 30%`)
- **Knife throw** — throw equipped melee as projectile
- **Rope / pipe / ladder climbing** — climbable terrain features
- **Damage falloff** — projectiles lose damage over distance (per-weapon falloff curve)
- **Weapon swap 1-8 (hotbar)** — 300ms smooth transition between any inventory slot
- **Drop item** (Q) / **pickup** (E) / **signal_friendly** / **signal_enemy_spotted** / **mark_waypoint**

`Stance` state machine: `Stand, Walk, Run, Sprint, Crouch, CrouchWalk, Prone, ProneWalk, Slide, Vault, Climb, Dive, Lean, KnockedDown, Downed, Dying, Dead` + `RopeClimb / LadderClimb / PipeClimb / StealthAttack / KnifeThrow / Swim (reserved M5.7+)`.

### Equipment depth (M1: 1 rifle → M2.2A: 6 weapons + 4 grenades + 4 melee + 7 tools)

**6 launch weapons** with multi-fire modes + magazine system + tracers + shells + attachments:

| Weapon | Fire modes | Magazine | Range | AI summary | Recoil pattern |
|---|---|---|---|---|---|
| Rifle (M1) | Single / Burst-3 / Auto | 30 / regular + 1:3 tracer | 320u | Mid-range balanced | up-right zigzag |
| SMG | Single / Burst-3 / Auto | 40 / regular + 1:5 tracer | 160u | Close-range suppressor | sharp up-right |
| Shotgun | Single / Pump-action | 8 / 8 pellets per shot | 80u | Close-range crowd control | strong upward |
| Sniper | Single / Charge | 5 / regular + 1:1 tracer | 800u | Long-range high-damage | minimal but slow recovery |

| Grenade Launcher | Single / Arc | 4 / explosive rounds | 200u | Arcing explosive | strong upward |

**Magazine system** per CCCP `Magazine::PopNextRound`: regular + tracer rounds with `RTTRatio` (1 tracer per N rounds, deterministic). **Shell casing ejection** as cosmetic `MovableObject` per CCCP `Round::Shell`. **Suppressor attachment** reduces `loudness` by 60%. **Bipod attachment** (deployable when crouched/prone) reduces recoil 70% + bloom 50%.

**4 grenade types** with throw-arc preview (translucent ghost path):
- `Frag` — 5s fuse + radius damage
- `Smoke` — 5s fuse + smoke hazard tile spawn
- `Flash` — 1.5s fuse + deafen + blind afflictions
- `Stick` — adheres to actor/surface + 4s fuse

**Cook grenade** (held trigger) for shorter fuse on throw.

**4 melee weapons**: Rifle bash (blunt + knockdown) / Knife stab (piercing + bleed chance) / Hatchet (heavy chop) / Baton (high knockdown chance) + Kick (close-range knockdown) + Shoulder check (during sprint).

**Knife throw**: throw equipped melee as projectile (50% damage; can be retrieved from wall).

**7 tools** (extending M1's digger):

| Tool | Action | Effect |
|---|---|---|
| Digger (M1) | dig | Carve dirt/concrete |
| Repair tool | repair_apply | Restore terrain integrity (`repair_fill` tiles) + repair equipment |
| Foam gun | foam_spray | Spawn `loose_fill` material in air space |
| Concrete gun | concrete_spray | Spawn hardened `concrete` material |
| Welder | weld_cut | Slow cut through `metal_nohook` |
| Drill | drill_carve | 2× faster than digger; generates heat (jams when overheat) |
| Multi-tool | probe | Inspect material affordances + reveal HUD tooltip |
| Beacon | beacon_drop | Place persistent map marker (visible to squad) |
| Sensor pulse | sensor_pulse | Reveal enemies + hazards in radius for 5s |

**Tool degradation**: each tool has durability (0-100%); degrades with use; repair tool restores; broken tool emits `equipment.tool_broken` event.

### Inventory: 8 slots + weight + drop/pickup

**8-slot inventory** (`primary / secondary / sidearm / tool1 / tool2 / grenade / medical / special`) with:
- **Weight system**: total weight affects movement speed (`>30kg` forces Walk; sprint disabled)
- **Hotbar**: 1-8 keys select slot (300ms swap transition; visible weapon-swap overlay)
- **Drop item** (Q): drops to ground at hand position with toss velocity; gets stable `RecordId`
- **Pickup** (E): action prompt within `pickup_radius`; goes into first empty slot
- **Backpack capacity** (small extra inventory for spare ammo/items)

### Centralized sound propagation + perception kernel (NEW cf-perception crate)

Replaces M1.5's per-AI perception with a unified kernel:
- **Per-surface footstep loudness** (metal louder than dirt; configurable in `MaterialDef.loudness_modifier`)
- **Distance attenuation** (loudness × (1 - distance/max_hearing_range))
- **Occlusion** (walls partially block sound; `occlusion_factor` per material)
- **Echo** behavior in enclosed areas
- **Stealth meter** per actor (detection probability 0-100%); visualized via eye icon near reticle
- **Suppressor effect** reduces alarm propagation
- Events: `perception.footstep_emitted`, `perception.occlusion_applied`, `perception.stealth_meter_changed`

### Stealth kill / takedown depth

- Sneak up behind enemy + melee → **instant kill** (only when undetected; `stealth_meter < 30%`)
- Sound minimal (only nearest enemy hears)
- Visible 1.2s animation
- Per DR-018 death-meaning ladder

### 1 friendly bot + 4 squad commands (basic squad surface)

Reserved at M2.2A; full AI archetype behaviors land in M2.2B.

**4 commands** via `act.squad.issue_command`:
- `FollowLeader` — bot follows player
- `HoldPosition` — bot stops + holds current pos
- `DefendPoint(pos)` — bot moves to waypoint + holds + uses cover
- `PushToWaypoint(pos)` — bot moves to waypoint while engaging en route

Bot HP visible in HUD squad strip. Bot uses M1.5's `ReactiveGuard` baseline at M2.2A; M2.2B replaces with 5 archetypes.

### Side-view facing direction + limb-loss action restrictions (M5 forward-compat)

The user demand: **"limbs can also be lost/blown off, cut, etc... that doesn't kill outright, but it does lose what the limb does"**. M2.2A enforces **action restrictions when limbs are lost** + tracks **Actor::facing direction** for side-view sprite + hit routing.

**Actor::facing field (side-view orientation):**

- `Actor::facing: FacingDirection { Left | Right }` (default = Right at spawn)
- Updated on `act.player.aim` direction (mouse position relative to actor)
- Sprite flips per facing change (instant; cosmetic)
- M5 chassis adds armor zone visibility per facing direction (front zones exposed when facing toward enemy; back exposed when facing away)
- Replay events: `actor.facing_changed { from, to, cause }`

**Limb-loss action restrictions (M5 chassis fills full; M2.2A reserves the surface):**

When limbs are lost (per M5 chassis):

| Limb lost | Action restriction at M2.2A | Reason label |
|---|---|---|
| Both arms | All weapon-fire intent REJECTED | `"no_arms_for_weapon"` |
| Single arm | Two-hand weapons REJECTED (rifle/sniper/shotgun); pistol allowed at reduced accuracy | `"single_arm_two_hand_weapon_rejected"` |
| Both legs | Stance forced to `Crawl`; sprint REJECTED; jump REJECTED; vault REJECTED; climb REJECTED | `"no_legs_for_movement"` |
| Single leg | Stance forced to KneelStance OR limp; speed × 0.4; sprint REJECTED; jump REJECTED | `"single_leg_reduced_mobility"` |
| Both hands | Cannot grip ANY weapon — weapons drop on attempt; tools rejected | `"no_hands_for_grip"` |
| Backpack lost | Jet disabled; battery disabled; inventory storage = 0 | `"backpack_lost_no_jet"` |
| Head destroyed | Instant DEAD (M5 chassis instant state change) | `"head_destroyed_instant_death"` |
| Torso destroyed | Instant DEAD | `"torso_destroyed_instant_death"` |

**Action rejection events fire** when action requested but limb prevents:

- `actor.action_rejected { action, reason: <limb_loss_reason> }`
- HUD captions surface the reason ("Cannot fire — both arms lost; use pistol if one arm")

**Stance forced transitions on limb loss:**

- Both legs lost → Stance::Crawl (1500ms transition; per CCCP)
- Single leg lost → Stance::KneelStance (transition with limp)
- Both arms lost → Stance::Stand (no change but weapons disabled)
- Limb loss banner: "LIMB LOST: <which> — capability degraded"

**Physics-driven limb damage triggers (M5.5 forward-compat):**

- Falling damage routes to legs (per M5.5 impulse routing)
- Ramming damage routes to facing-direction limbs
- Explosion proximity severs limbs at joint threshold
- Heavy melee can sever limbs (chainsaw, katana, hatchet)
- High-velocity projectile (sniper/APFSDS) can sever joints

### Preservation rules from M1 (DO NOT regress)

M1's architectural rules are inherited by M2.2A without exception:

1. **Same sim path for human input + cfctl + replay** — non-negotiable. cf-app keyboard input goes through cf-control JSON-RPC; no shortcut path. Adding new actions (36 total) does NOT bypass this rule.
2. **`IntentSource::{Player, Replay, Ai, Script}` enum**: Player + Replay emit at M1; M1.5 fills Ai; M2.2A keeps the surface; M5+ fills Script.
3. **Update order per CCCP `Actor::FullUpdate`**: PreControllerUpdate → Controller::Update (consume player/AI/replay/script intent) → Actor::Update → Movement/equipment → Device → Terrain. M2.2A's 36 actions all respect this ordering.
4. **NaN/Inf guards on ALL floating-point inputs** — engine MUST `is_finite()` check before applying. NaN poisons the checksum.
5. **Edge-trigger discipline** — `clear_edges()` runs after consumption per tick. Press+release within one tick still registers one consumed press.
6. **Sim numbers locked from M1**: stability cost = recoil_impulse / 200; knockdown threshold = stability < 0.1 + impulse > 100; DYING dwell = 1000ms (60 ticks @ 60Hz); loudness_radius = 480 × (damage/10).clamp(1,3); reticle bloom multipliers (standing=1×, running/jumping/jetting=7×, airborne=3×).
7. **AI Self-Test Report required at closure** (per DR-056 Universal Done-Criteria): scripted 5-minute scenario + matching headless replay + LLM-graded verdict.
