# M37B — Per-Equipment Radio Power Draw + Range Curve + Antenna Mast

## Status

`active`

## Intent

Surface the per-equipment radio power-draw table + range curve + antenna mast as a base module + tethered repeater + EMP-protected backup so M37's ACRE2-tier voice + radio simulation has concrete numeric backing for personal battery loop integration + base-level comm infrastructure gameplay.

## Player-facing behavior

- **Handheld radio** (5W idle / 25W transmit; range ~3 km LoS): personal squad comm.
- **Squad radio** (12W idle / 60W transmit; range ~10 km): platoon-level coordination.
- **Long-range radio** (50W idle / 500W transmit; range ~50 km): inter-base / inter-team coordination.
- **Antenna mast** (base module; T2; 200W draw; multiplies range × 3): place on base roof; player's long-range radio works in mountainous terrain.
- **Tethered repeater drone**: deploy a drone with comm relay; extends squad radio range; drone has its own T2 battery; runs ~2 hours.
- **EMP-protected backup**: Faraday-cage handheld radio (T3; survives EMP grenades + solar flare blackouts); slower transmit; expensive.
- **Per-equipment power draw integration**: NVG + radio + IR scope + heated suit total budget = ~250W; player must trade-off (run cold without heater, or accept reduced range).
- **Solar flare + EMP cascade**: M45 world event drops all radios offline 2-15 minutes; Faraday-cage variant only one that survives.
- **Audio model integration with M37**: radio range × atmospheric attenuation × antenna height = signal_db.
- **Range visualization in M29A power overlay**: per-radio range circle on world map.

```gherkin

  Given a deployed tethered repeater drone at base outskirts
  When squad squadmate transmits from 15 km out
  Then signal hops repeater → base (no direct line needed)

Scenario: Squad radio range matches expected curve
```

## Notes for the implementer

- Radio range curve: at full antenna height (mast), use Friis path-loss formula: `signal_db = transmit_power_dbm + antenna_gain_dbi - path_loss(distance, freq)`. Without mast, use ground-reflection model that's per-actor-height aware (per M14A walk_angle).
- Antenna mast height integration: mast at 8 m above ground → multiplies effective range × 3 vs no mast.
- Faraday cage adds +20 dB shielding to the radio's EMP-induced surge model; reduces signal sensitivity by 10 dB (worse reception in normal conditions, but immune to disruption).
- Signal_db is integrated with cf-net packet-loss simulation: signal_db > 70% = 0 packet loss; 50-70% = occasional loss; <30% = unusable.
- Per-equipment power draw integration with M29B is the canonical lookup; M37B only authors the SKU rows.
