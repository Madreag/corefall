# M20 — EnvironmentSignal Aggregator

## Status

`active`

## Intent

**M20 is the EnvironmentSignal aggregator** — per DR-040. Per-tick per-actor bundle aggregating atmospheric (DR-037), gravitational (DR-038), thermal, radiation, photic, EM, weather, water, acoustic, day/night, and comms slices into one source of truth. Every consumer (AI / HUD / accessibility / replay / audio / mission director) reads from the bundle.

M20 promise: **"AI never gets stale views; HUD never gets parallel queries; one bundle, many subscribers."**

## Player-facing behavior

### EnvironmentSignal struct (locked v0.1)

Per `spec/environmental-conditions-model`:

```rust
struct EnvironmentSignal {
  actor_id, tick, world, pos, cell_id,
  atmospheric: AtmosphericExposure,    // from M19
  gravitational: GravityVec,           // from DR-038
  thermal: ThermalExposure,
  radiation: RadiationExposure,
  photic: PhoticExposure,
  em: EmExposure,
  pressure: PressureExposure,
  weather: WeatherExposure,            // M31
  water: WaterExposure,
  acoustic: AcousticExposure,          // M37
  day_night: DayNightExposure,         // M31
}
```

Per-tick: `EnvironmentSignal::for_actor(actor, tick)` computed ONCE at deterministic point in tick schedule. All consumers read from bundle. Kernels write via typed adapter.

### Per-race environmental resistance matrix (canonical owner)

The 10-race × per-environmental-factor resistance matrix. Referenced by M17 (origin definitions), M24 (AI environmental competence), M43 (PvE survival difficulty), M29 (per-world power generation modifiers).

Each row is a race; each column is an environmental factor. Cells show baseline resistance / behavior **without gear**, plus per-tier suit mitigation.

### Hazard taxonomy (closed-enum)

`hypoxic, combustible_atmosphere, toxic_atmosphere, breach_decomp, hyperthermic, hypothermic, radiation, low_visibility, glare, em_disruption, wind_force, drowning_hazard, vacuum_no_voice, comms_blackout, gravity_shift`

Origin gating happens at consumer (humans concuss; robots don't) per `spec/origin-reaction-and-resource-model`.

### Replay records deltas (bandwidth-friendly)

- Bundle changes = events; static signals = snapshots
- M20 adds `environment` event category to M4 taxonomy (already reserved)
- Replay reproduces full env state from event stream

### Performance bounds

- SoA actors; SIMD-friendly
- Sleeping actors skip aggregation
- Per-tick budget bounded (target: <2ms for 50 actors)
