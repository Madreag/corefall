# M32C — Per-Actor Crafting Skill + Quality Output Tiers + Auto-Restock + Linked Storage + Recipe Discovery

## Status

`active`

## Intent

RimWorld-grade crafting depth: per-actor skill ladder (0-20 per category) + 7 quality output tiers (Awful → Legendary) + auto-restock from linked storage + recipe permutation discovery.

**Naming disambiguation (vs M27 loot rarity):** M27 owns the loot **rarity** ladder (Common / Magic / Rare / Legendary / Unique — drop-pool tier). M32C owns the craft **quality** ladder (Awful → Poor → Standard → Good → Excellent → Masterwork → Legendary — output-grade tier). Both ladders end with the word "Legendary." Player-facing UI strings MUST disambiguate: rarity uses **"Legendary Drop"** (orange border per M27); quality uses **"Legendary Quality"** (gold border + animated aura per M32C). Item tooltips display both axes separately (`Rarity: Rare` + `Quality: Masterwork`).

## Canonical ownership

Owns per-actor crafting skill, quality tiers, linked storage, recipe permutation. M32 ships 150 recipes + 5-tier ladder; M32C adds per-actor depth.

## Player-facing behavior

- **Per-actor crafting skill** (0-20 ladder): every actor has `crafting_skill_level` per category (`Weaponcraft`, `Armorcraft`, `Cookery`, `Medicraft`, `Tailoring`, `Sculpting`).
- **Skill XP gain**: completing a craft awards XP. Skill cap per origin (humans 20, androids 18, robots 16, heavy_biomech 12, drone 8).
- **Quality output tiers** per craft: Awful → Poor → Standard → Good → Excellent → Masterwork → Legendary (7 tiers per RimWorld).
- **Quality probability table per skill**:

| Skill | Awful | Poor | Standard | Good | Excellent | Masterwork | Legendary |
|---|---:|---:|---:|---:|---:|---:|---:|
| 0-4 | 30% | 40% | 25% | 5% | 0% | 0% | 0% |
| 5-9 | 10% | 25% | 40% | 20% | 5% | 0% | 0% |
| 10-14 | 0% | 10% | 30% | 35% | 20% | 5% | 0% |
| 15-19 | 0% | 0% | 15% | 30% | 35% | 18% | 2% |
| 20 (master) | 0% | 0% | 0% | 20% | 40% | 30% | 10% |

- **Quality affects stats**: quality_tier multiplies base stats per category (Awful 0.6×; Standard 1.0×; Legendary 1.6×).
- **Auto-restock from nearby storage**: crafting station auto-pulls materials from linked chests within 8-tile radius.
- **Linked storage** (Terraria parity): chests can be "linked" to a station via cable / wireless logistic network.
- **Recipe permutation discovery (Noita)**: combining materials in alchemy table can produce new recipes.
- **Inspector tool**: pre-craft simulation preview ("Atlas skill 18 → 35% Excellent / 18% Masterwork / 2% Legendary").
- **Recipe scrolls as tradeable items**: per M48 — gift / sell / drop scrolls.

## Acceptance criteria

```gherkin
Scenario: Per-actor crafting skill
  Given actor "Atlas" with crafting_skill_level=18 in Weaponcraft
  When Atlas crafts rifle_m1:
    Then craft_started_with_skill fires
    And quality rolled per skill 15-19 row
    And craft_quality_rolled fires with rolled quality

Scenario: Quality affects stats
  Given masterwork plasma_rifle (quality=Masterwork)
  Then damage = base × 1.45
  And tooltip shows quality border + multiplier

Scenario: Skill XP gain
  Given Atlas completes rifle_m1 craft
  Then crafting_skill_xp_gained fires with delta XP
  And eventually skill 18 → 19

Scenario: Auto-restock from linked storage
  Given workbench + linked chest 5 tiles away (8-tile range)
  And chest contains 30 iron + 10 wood
  When player queues 3× iron rifle:
    Then auto_restock_pulled fires per material pull

Scenario: Recipe permutation discovery
  Given alchemy table + 2 unknown reagents combined
  When recipe rolled (low chance):
    Then recipe_discovered fires
    And player's recipe_book updated

Scenario: Recipe scroll trade
  Given recipe_scroll for "ancient_plasma_rifle"
  When player gifts scroll to NPC quartermaster:
    Then trade.scroll_given fires

Scenario: Inspector pre-craft preview
  Given player opens craft inspector for plasma_rifle
  Then UI shows: "Atlas skill 18 → 35% Excellent / 18% Masterwork / 2% Legendary"

Scenario: Drone craft cap
  Given drone actor with crafting_skill_level=10 cap
  Then drone CANNOT exceed skill 8 (origin cap)
  And tooltip warns "Drone skill ceiling"
```

## Notes for the implementer

- Quality roll uses seeded RNG; deterministic.
- Per-actor skill XP curve: `xp_to_next_level = base × (level + 1)^1.5`.
- Linked storage discovery uses BFS within 8-tile radius; deterministic order.
