# M45C — 12 Dynamic World Events Deep Catalog (Solar Flare / Pirate Raid / Trader / Anomaly / Volcanic / Asteroid / Signal / Famine / Plague / Faction War / Eclipse / Mineral Rush)

## Status

`active`

## Intent

**M45C is the per-event deep design milestone.** M45 ships the 12-row dynamic-world-event summary against M25's `cf-storyteller` registration API. M25 owns the storyteller runtime, registry, intensity curve, and cooldown enforcement. M16 owns hazard tiles. M31B owns weather catalog. M26 owns factions. None of them owns the deep, per-event authored content: trigger conditions (per-tick probability OR storyteller-scheduled OR world-state-gated), player response options (engage / avoid / negotiate / sabotage / exploit), reward (loot / reputation / codex / story / recipe), consequence (faction shift / world state / hazard tile / actor affliction / weather change), per-storyteller integration (Cassandra dread vs Phoebe quirk vs Randy chaos vs Ironman vs Sandbox), per-difficulty scaling, OR per-world variant (a solar flare on Mars knocks out comms but on Vulcan superheats the atmosphere into a kill zone; a pirate raid in the asteroid belt is a 6-ship skiff, on Earth is a 2-truck convoy with mech support).

After M45C, every one of the 12 events — **solar_flare / pirate_raid / trader / anomaly / volcanic / asteroid / signal / famine / plague / faction_war / eclipse / mineral_rush** — has a deterministic, replay-exact event-state machine, authored response trees, ledgered rewards, deterministic consequence application, storyteller pacing integration, difficulty tuning, and per-world content rows for every one of the 12 launch worlds (Earth / Mars / Moon / Phobos / Deimos / Mimas / Europa / Vulcan / Venus / Belt / Orbital / Sol Zone).

M45C's player-facing promise: **"every world session has its own incoming texture. On Mars you learn to fear the dust-storm pirate raids. On Vulcan a solar flare is a death sentence if you're outside. On Mimas a passing trader is suspicious — pirates pose as traders in low-population systems. On Europa an anomaly storm summons artifact drops worth the wreckage. On Earth a plague event is a 14-day mission spine. Every world has its own event mix, its own response palette, its own loot, and its own consequences."**

### Per-event content rows (data shape)

Every event authored in M45C ships:

- **Trigger conditions** — `per_tick_probability_base` (e.g. 0.0001 per minute base), optional `storyteller_schedule_hook` (Cassandra can pre-schedule), `world_state_gate` (e.g. requires player has built base > 0 modules), `weather_gate` (some events only fire under specific M31B weather states), `time_gate` (some only fire after Day-N in mission).
- **Response options** — 3-5 mutually-exclusive response branches per event (engage / avoid / negotiate / sabotage / exploit). Each response has its own resolution flow + reward + consequence row.
- **Reward** — per-response rolled deterministically against event-seed; loot drop / reputation delta / codex unlock / story-flag set / recipe unlock.
- **Consequence** — per-response applied to world state: faction-relation shift / hazard-tile spawn / actor affliction / weather transition / persistent flag.
- **Per-storyteller integration** — Cassandra dread cadence, Phoebe gentle pacing, Randy chaos (can roll a second event during the first), Ironman permanence, Sandbox banked-reward.
- **Per-difficulty scaling** — chill 0.6×, tough 1.0×, extreme 1.4×, nightmare 1.8× — applied to event severity (raid party size / flare duration / asteroid radius / etc.).
- **Per-world variant rows** — for each of the 12 launch worlds, the event takes a tuned form. Solar flare on Vulcan is lethal in 6s; on Mimas is lethal in 18s; on Earth knocks out comms only.
- **Replay-exact event sequence** — every event emits a typed `event.<id>.{started, response_chosen, resolved, consequence_applied}` event chain; replay reproduces bit-exact.

### Event-by-event deep content

#### 1. solar_flare

**Trigger:** `per_tick_probability_base = 0.00004 /tick` (≈ 1 per 25 min at default), `storyteller_schedule_hook=true`, `world_state_gate = sun_facing_world`. Cassandra increases probability ×1.5.

**Phase machine:** `Warning (90s) → Onset (immediate radiation + comms blackout) → Peak (durability burn + lethal radiation on exposed) → Decay (residual radiation tile) → Gone`.

**Response options:**

| Response | Requirement | Reward | Consequence |
|---|---|---|---|
| **Shelter** | Sealed base module OR vehicle interior | survival; 5 codex unlocks | full radiation dose avoided; comms blackout still applied |
| **Faraday Hub** | Built T2 Faraday-rated comms hub (M28F) | survival + comms preserved + +5 reputation w/ Scientist Order | 30% durability burn on exposed gear |
| **Exposed Endurance** | Vacuum-rated radiation suit (M16) | 1 unique recipe: Flare-Plate Armor | suit durability reduced by 40% |
| **Push Forward** | None | high-risk loot from the open arena (events.solar_flare.loot_table) | sustained radiation tick = 1.5%/s; afflictions stack |

**Per-world variants:**

- **Earth** — 18 min warning, comms blackout 12 min, no lethal radiation, but durability burn on outdoor gear ×1.5.
- **Mars** — 6 min warning, comms blackout 8 min, lethal radiation outdoor (TTD 60s without suit).
- **Mimas** — 30 min warning (eclipse cycle helps), comms blackout 6 min, minor radiation.
- **Europa** — under ice; warning 4 min only (ice attenuates signal); no radiation; comms blackout 18 min.
- **Vulcan** — 90 s warning; lethal radiation outdoor TTD 6 s; the most dangerous variant; only Vulcan-rated armor survives.
- **Venus** — atmospheric scattering reduces flare damage; warning 8 min; durability burn only.
- **Belt** — orbital exposure; lethal radiation in EVA TTD 15 s; ship interior is full shelter.
- **Orbital** — sun-facing platform; lethal TTD 8 s if outside; warning 10 min.
- **Sol Zone** — flare is a constant baseline radiation already; the event manifests as a +50% spike.
- **Moon / Phobos / Deimos** — gas-world atmospheres absent; mid-severity per Mars rules.

**Storyteller variants:** Cassandra ×1.5 probability + warning -2 min; Phoebe ×0.7 probability + warning +3 min; Randy ×1.3 + 25% roll to also trigger eclipse during peak; Ironman survives are permanent flags; Sandbox banked-reward — shelter response gives bonus codex unlock even if player retreated.

**Codex unlocks** (M25A `solar_flare.lore.ron`): solar dynamics / heliophysics origin / shelter doctrine / radiation suit history / flare-plate armor schematic.

#### 2. pirate_raid

**Trigger:** `per_tick_probability_base = 0.00008 /tick` (≈ 1 per 12 min), `storyteller_schedule_hook=true`, `world_state_gate = base_value > 1000 credits OR reputation_w/Pirates < 0`. Raids escalate over the mission as the player accumulates loot.

**Phase machine:** `Detection (long-range radar paints) → Approach (visible incoming dot) → Engagement (raid party at base perimeter) → Resolution (kill all, flee, broker, or be looted) → Aftermath (faction reputation update)`.

**Response options:**

| Response | Requirement | Reward | Consequence |
|---|---|---|---|
| **Fight** | Combat capacity ≥ raid party | full loot of raid party (weapons, ammo, vehicle, captured intel) + +5 reputation w/ Allied Resistance | base damage during engagement |
| **Hide** | Hidden base (camo netting M28) OR distance > 30 tiles from raid party | loot lost (raid party takes ~10% of base storage) | -2 reputation w/ Mercenary Guild (they were on patrol) |
| **Broker** | Bribe ≥ raid party value × 0.4 OR offer faction-trade | survive; -3 reputation w/ Allied Resistance (they consider you weak) | loot lost = bribe amount |
| **Trap** | Pre-laid mines OR turret killbox | full loot + minor base damage | -10 reputation w/ Pirates (vengeance flag set) |

**Per-world variants:**

- **Earth** — raid party = 2 trucks + 6 pirates + 1 mech. Variant: "Highway raid".
- **Mars** — raid party = 4 dust-walkers + 8 pirates + 1 sandcrawler. Dust storm modifier increases pirate stealth.
- **Moon** — raid party = 3 microgravity-fighters + jetpack squad. Low-g combat preferred.
- **Phobos** — orbital pirates; raid = 1 skiff + boarding party of 4.
- **Deimos** — same as Phobos but +1 sniper.
- **Mimas** — 6-pirate boarding party from cryo-skiff; gravity inversion mid-fight possible.
- **Europa** — under-ice raid through service tunnel; 4 pirates + thermal cutter.
- **Vulcan** — heat-armored raiders; 3 elite pirates with heat-resist + plasma.
- **Venus** — gas-world variant; raid arrives via floating skiff; 5 pirates + acid-resistant rifles.
- **Belt** — 6 skiff convoy; pirates engage at 100+ tile range; ship-to-ship fight.
- **Orbital** — platform boarding; 4 pirates teleport via pod.
- **Sol Zone** — solar pirates; 3 elite + plasma + heat-resist; rarest + most dangerous variant.

**Storyteller variants:** Cassandra ×1.6 probability + raid party +1 mech; Phoebe ×0.6 probability + telegraphs +1 min approach; Randy 30% roll to also spawn a second raid mid-fight; Ironman raid loss = permanent base damage; Sandbox raid is banked — player can choose to skip the encounter at -2 reputation cost.

**Codex unlocks:** pirate origins / raid tactics doctrine / faction history (Pirates) / negotiated peace history / raid-defeat trophy schematic.

#### 3. trader

**Trigger:** `per_tick_probability_base = 0.00006 /tick` (≈ 1 per 17 min), `storyteller_schedule_hook=true`, `world_state_gate = base_built AND reputation_w/Mercenary_Guild ≥ -5`. Phoebe ×1.4 probability.

**Response options:**

| Response | Requirement | Reward | Consequence |
|---|---|---|---|
| **Trade** | Credits ≥ asking price | rare loot (T1-T3 mods, recipes, materials) at -30% market price | -credits = trade value |
| **Authenticate** | Signal-decoder rig (M30) | reveals fake-trader pirate raid OR confirms legit; +2 reputation w/ Mercenary Guild | none on legit; cancels trade if fake |
| **Reject** | none | no trade | -1 reputation w/ Mercenary Guild |
| **Ambush** | Combat capacity ≥ trader escort | take all cargo without paying | -15 reputation w/ Mercenary Guild + faction-wide bounty flag |
| **Refer** | Faction quest active | trader fulfills a faction quest item | +3 reputation w/ associated faction |

**Per-world variants:**

- **Earth** — trader convoy of 2 trucks + 4 guards. Cargo: food + medical + standard mods.
- **Mars** — sand-crawler convoy + 3 guards. Cargo: dust-rated mods.
- **Moon** — jetpack courier + 1 guard. Cargo: light tech mods + cryo cells.
- **Phobos / Deimos** — orbital skiff. Cargo: orbital mods + EVA suits.
- **Mimas** — cryo-skiff. Cargo: ice-walker boots + cryo recipes.
- **Europa** — under-ice tunnel trader. Cargo: thermal mods + Europa-specific recipes.
- **Vulcan** — heat-rated convoy. Cargo: plasma forge components + Vulcan-rated armor.
- **Venus** — atmospheric trader on cloud platform. Cargo: acid-resistant mods.
- **Belt** — orbital convoy of 4 skiffs. Cargo: rare materials + asteroid intel.
- **Orbital** — platform-to-platform trader. Cargo: orbital tech + comms gear.
- **Sol Zone** — Starlight-faction trader; rare codex + final-tier mods.

**Trader-vs-disguised-pirate roll:** 15% base chance the "trader" is a pirate raid disguised; on Belt + Mimas + Sol Zone, chance bumps to 30%; Cassandra +5% to chance; Phoebe -5% to chance; Randy ×2 to chance.

**Storyteller variants:** Cassandra ×0.8 probability + raised fake-trader chance; Phoebe ×1.4 probability + lowered fake-trader chance; Randy 35% roll to trigger faction-war during trader visit; Ironman trader-betrayal is permanent; Sandbox banked rewards.

**Codex unlocks:** Mercenary Guild origins / trade economy / fake-trader doctrine / black-market history / rare-recipe origin.

#### 4. anomaly

**Trigger:** `per_tick_probability_base = 0.00003 /tick` (≈ 1 per 33 min), `storyteller_schedule_hook=true`, `world_state_gate = world_has_anomaly_zone OR random_position_outside_base`. Per M16 the 6 STALKER anomaly kinds (gravity / electric / time / chemical / bloodsucker / psy_storm) seed at the event location.

**Phase machine:** `Detection (anomaly field appears on radar) → Field Expansion (radius grows over 60s) → Artifact Spawn (artifacts spawn at field edge) → Stabilization (field becomes persistent terrain) → Decay (optional, 30 minutes later)`.

**Response options:**

| Response | Requirement | Reward | Consequence |
|---|---|---|---|
| **Enter & Collect** | Anomaly-rated gear (M16) | rare artifacts (4-8 drops; T2-T4 rolls) | risk of affliction stack (electrical, time-dilation, chemical) |
| **Sweep Map** | Signal scanner (M30) | maps anomaly anchors → unlocks faster artifact runs | -1 scanner durability |
| **Avoid** | none | -2 codex unlocks (you don't see the lore) | none |
| **Stabilize** | Stabilizer device (T3, M32) | converts field into safe-mining terrain over 5 in-game days; unlocks T4 material vein | requires 1 stabilizer (consumed) |
| **Cull Bloodsuckers** | Combat capacity | unique artifact: "Bloodsucker Trophy" cosmetic | +2 reputation w/ Scientist Order |

**Per-world variants:**

- **Earth** — gravity + electric anomalies common; psy_storm rare.
- **Mars** — chemical + dust-amplified anomaly variants; time anomalies (legacy alien tech) rare.
- **Moon** — gravity-amplified (already low-g); electric rare.
- **Phobos / Deimos** — orbital anomaly fields; chemical + psy variants.
- **Mimas** — cryo-amplified anomalies; bloodsucker spawns in caves.
- **Europa** — under-ice anomaly; chemical (sulfur) + psy variants; the densest artifact world.
- **Vulcan** — heat-amplified anomalies; bloodsucker variants resistant to heat.
- **Venus** — acid-amplified chemical + psy; the highest-payoff but highest-risk.
- **Belt** — gravity + electric in zero-g; floating anomaly fields.
- **Orbital** — platform-bound anomalies; chemical variants from leaked fuel.
- **Sol Zone** — psy_storm dominant; the entire zone is one slow anomaly.

**Storyteller variants:** Cassandra ×1.2 probability + bloodsucker spawn +1; Phoebe ×0.9 + warning radius +5 tiles; Randy 40% roll to spawn multiple anomalies simultaneously; Ironman artifacts are permanent build flags; Sandbox banked-rewards on partial collection.

**Codex unlocks:** STALKER-style anomaly genesis / 6 anomaly kinds origin / artifact taxonomy / bloodsucker biology / stabilizer schematic.

#### 5. volcanic

**Trigger:** `per_tick_probability_base = 0.00002 /tick` (≈ 1 per 50 min), `storyteller_schedule_hook=true`, `world_state_gate = world_has_volcanic_biome`. Only Earth / Vulcan / Mars-dune-with-vent / Mimas-cryovolcanic.

**Phase machine:** `Tremor (audio + screen shake) → Vent Crack (specific tile cracks open, lava begins flowing) → Lava Flow (advancing wall, 1 tile/14s) → Cooling (after 14 in-game minutes, lava begins to crust over) → Geological Reset (new terrain layer)`.

**Response options:**

| Response | Requirement | Reward | Consequence |
|---|---|---|---|
| **Evacuate** | jetpack OR vehicle | survival; salvage 30% of base storage | base destroyed; rebuild required |
| **Dam It** | Construction T3 + 8 obsidian | redirects lava flow around base | obsidian consumed; +5 reputation w/ Engineer-class NPC |
| **Mine Vent** | Drill T3 + heat-resist suit | rare ore (obsidian + magma cells); unique recipe: Pyroclastic Drill | heat affliction stack; -1 drill durability/min |
| **Cool with Water** | Water reservoir + dam | converts vent to standard rock + steam aftermath | water depleted |
| **Ignore** | none | none | base destroyed if downstream; -5 reputation w/ NPCs lost to lava |

**Per-world variants:**

- **Earth** — vent flows ~14 min; obsidian + magma cells; the canonical version.
- **Mars** — dust-vent + reduced lava + ash storm (M31B weather transition triggered).
- **Mimas** — cryovolcanic; "lava" is liquid methane; -180 °C reverse hazard (freezing instead of burning).
- **Vulcan** — pyroclastic; 8 in-game minutes only; lava flow rate ×2.5; the most lethal variant.
- (Other worlds: event does not fire on Moon / Phobos / Deimos / Europa / Venus / Belt / Orbital / Sol Zone)

**Storyteller variants:** Cassandra ×1.3 probability + lava flow rate ×1.2; Phoebe ×0.8 + telegraphs +2 min; Randy 30% roll to also fire asteroid impact; Ironman base destruction is permanent for the campaign; Sandbox banked-rewards on partial mining.

## Notes for the implementer

- **Per-event content lives in `content/world_events/<id>/*.ron`.** The Rust modules under `cf-storyteller/src/content/events/` are thin wrappers that load the RON files at registry init. Do not hardcode response trees in Rust.
- **Per-world variants are tunings, not new events.** The base event row in `def.ron` is canonical; `per_world/<world_id>.ron` applies deltas (TTD, party_size, telegraph_ms, etc.). If an event does not fire on a world, omit the per-world file — do not author a "disabled" stub.
- **Event-resolution RNG must seed off the engine's deterministic RNG.** `thread_rng` is banned per AGENTS.md. The same event-seed produces the same `trader_class=pirate_disguise` outcome across replays.
- **Storyteller registration happens at boot time.** Each event module exposes `pub fn register(reg: &mut StorytellerRegistry)`. M25's `cf-storyteller` is the canonical owner of the registry.
- **`per_tick_probability_base` is per-tick, not per-second.** Convert to per-minute or per-hour intuitions at authoring time via the tick rate. Do NOT hardcode 60 Hz.
- **Player response selection MUST emit `world_event_response_chosen` BEFORE applying any consequence.** Determinism + replay-exact requires the player decision to be the deterministic input; the consequence is a pure function of (event-seed, world-state, response-branch).
- **Consequences are applied atomically at resolution.** Do not stream consequence-effects across multiple ticks unless the consequence is explicitly time-extended (e.g. Stabilize's 5-day timer). Atomic application keeps replay correct.
- **Per-difficulty scaling matrix lives in `difficulty.ron` per event.** The storyteller runtime reads this at event-fire time, not at scheduler-tick time. Difficulty is mission-scoped, not tick-scoped.
- **Per-storyteller variants are deltas.** The base event is authored once; the Cassandra / Phoebe / Randy / Ironman / Sandbox files apply probability ×, telegraph ±, and extra-spawn flags. Avoid duplicating the full row per storyteller.
- **Co-op `second_target` logic for raid parties is mirrored from M45B.** Where a response branch is targeted at a single player, multi-player coop adds a `second_target` parameter. Coordinate with M48.
- **Per-world variants are NOT all 12 worlds × 12 events.** Many events do not fire on many worlds (volcanic only on 4 worlds; eclipse on 11; signal on 12; etc.). The expected per-world file count is ~120, not 144.
- **Event interaction rules:** some events can chain (Randy's "spawn second event during first" mechanic). The storyteller runtime owns interaction guardrails; M45C authors only the per-event slot. If two events fire simultaneously, their consequences apply in priority order: hazard > weather > faction > affliction.
- **The signal-decoder rig affordance (`act.player.event_respond` with `response_branch="decode"`) needs the rig to be built AND powered.** Author the requirement in `responses.ron` as a precondition; the cfctl action validates and returns an error event if the precondition fails.
- **All event-related codex unlocks reference M25A's `content/narrative/world_events/<id>.lore.ron`.** If a lore file is missing for an event, codex unlocks are stubbed; do not block event implementation on lore-text completion. M25A owns the LLM-driven authoring pipeline.
- **Watch out for AWAW Rule 60 interaction:** if the host server has `enable_faction_resistance_levels=true` (per M45's faction resistance system), the `faction_shift` consequences in `faction_war`, `pirate_raid`, `trader`, `mineral_rush`, `signal`, and `eclipse` events feed into resistance-level transitions. The faction-resistance machinery is owned by M45's grand strategy module; M45C only emits the deltas.
