# M36B — Telemetry + Crash + Bug-Report Pipeline

## Status

`active`

## Intent

**M36B is the observability + bug-reporting milestone** — `cf-telemetry` crate (opt-in privacy-respecting in-process metrics + crash reporting) + in-game bug-submit UI + per-DR-031 anti-pay-to-win audit dashboard + per-server-shard analytics aggregation for M49 MMO.

**Why after M36A (platform integration):** Steam handles crash reports for Steam builds, but for non-Steam (itch.io / direct / EOS) we need our own crash pipeline. Plus per-DR-031 anti-pay-to-win audit needs continuous monitoring of cosmetic-vs-gameplay impact across player base.

**Why this milestone exists:** without telemetry, we can't measure: brown-out cascade frequency (M29), per-faction win rates (M26 balance), affliction-by-affliction lethality (M16), per-origin survivability (M17), per-mission difficulty curve (M43 PvE), per-anti-cheat profile cheater detection (M36). M36B ships the observability surface.

M36B promise: **"every bug is reportable from in-game; every crash surfaces a structured report; every gameplay-balance signal is queryable; players opt in to anonymized analytics; we never collect PII; the dashboard tells us when M16 affliction.bleeding is overtuned across 1000 players."**

## Player-facing behavior

After M36B, the player experiences:

- **In-game bug-submit UI** — Press [Esc] → "Report Bug" → form with: bug description + reproduction steps + last 100 events auto-attached + run-bundle reference + screenshot attached
- **Opt-in telemetry** — first-run wizard (M33A FRE) asks: "Allow anonymized gameplay analytics? Y/N (default N)"
- **Crash report submission** — on crash, the cf-app crash handler captures stack + last 100 events + scenario state; offers to submit (default OFF for opt-in users; ON for Steam VAC compliance)
- **Privacy-respecting** — no PII collected; no IP logged; no player name; only: anonymized session id + event counts + crash stacks + performance percentiles
- **Per-mission balance feedback** — players can rate missions 1-5 stars + leave optional comment
- **Anti-cheat outlier alerts streamed to admins** — server admins see suspicious-input alerts via `cfctl admin observe.admin.alerts`
- **Per-server-shard analytics** — M49 MMO shard health dashboard (player count, lag, brown-out frequency, cheater alerts)

## Telemetry event categories (privacy-respecting; opt-in)

```rust
pub enum TelemetryCategory {
    GameplayBalance,                        // weapon win-rate, faction win-rate, mission completion rate
    AccessibilityUsage,                     // % using high_contrast, captions, hold_to_confirm; per-flag opt-in
    ModLoadFailures,                        // mod versioning conflicts; helps modders
    PerformancePercentiles,                 // p50/p95/p99 tick time; per-scenario perf
    CrashStacks,                            // anonymized stack traces; for fixing crashes
    AntiCheatOutliers,                      // suspicious input patterns for admin review
    SessionDuration,                        // play time per session (no individual identification)
    OnboardingFunnel,                       // % completing First Contract + per-lab completion
    ChurnSignal,                            // session-quit triggers + last-event-before-quit
}

pub struct TelemetryEvent {
    pub category: TelemetryCategory,
    pub anonymized_session_id: u64,         // random per session; NOT linked to player identity
    pub timestamp_unix: u64,                // server-local time
    pub payload: serde_json::Value,         // category-specific payload; NEVER contains PII
}
```

pub struct CrashReport {

}

## Notes for the implementer

### Architecture rules

- **Opt-in by default OFF** — privacy-first; player must explicitly enable
- **No PII ever** — code review enforces; anonymizer.rs filters all uploads
- **Anonymized session id rotates per session** — prevents cross-session player tracking
- **Self-hosted dashboard** — no SaaS dependency; community can run their own analytics
- **Crash handler captures + caches + submits on next launch** — works offline
- **Bug-submit UI keyboard-reachable per ACC-A** — Tab + Enter navigable

### Decision-record alignment

- **DR-031 (anti-pay-to-win audit)**: M36B telemetry drives the audit
- **DR-013 (backend service scope)**: self-hosted
- **DR-049 (cross-platform CI)**: telemetry per-platform percentiles
- **DR-056 (universal done-criteria)**: telemetry surfaces all done-criteria signals

### Pitfalls

- **Telemetry upload blocking sim thread**: NEVER; batched + uploaded on separate thread
- **Mod-supplied telemetry rate-limited**: prevents mod abuse
- **Storage retention policy**: default 90 days; configurable per server admin
- **GDPR + CCPA compliance**: per-session id rotation; player can delete data; documented

### Closure procedure

1. Reference bundle: M36B self-test with anonymized telemetry + bug submit + crash report flow.
2. Self-play sweep rows: `m36b_opt_in_telemetry_off_default`, `m36b_no_pii`, `m36b_bug_submit`, `m36b_crash_report`, `m36b_anti_cheat_alert_stream`, `m36b_anti_pay_to_win_audit`, `m36b_per_shard_dashboard`, `m36b_mod_telemetry`. All PASS.
3. Update DR-031 closure note.
4. Move M36B → done/.
