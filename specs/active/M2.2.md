
## Status

`active`

## Intent

**M2.2 is the mega-bridge catch-up milestone** that fills every actor-controller / weapons / equipment / AI / sound / UX / mission director / camera / debug / forward-compat gap left after M1 (closed) + M1.5 (closed) + M2 (active). It is NOT a new feature direction — it is the **integration milestone** that takes the M1 baseline (1 actor + 1 rifle + dig + reactive guard + chunked terrain) and ladders it up to a **near-vertical-slice gameplay surface** worth handing into M2.5 (reactor defense) and M5 (chassis) without leaving holes that M5+ would have to retrofit.

M2.2 lands BEFORE M2.5 and BEFORE M3A/M3B closure. It expands:
- **Actor controller** from 9 actions to 32 actions (crouching, sprinting, prone, sliding, vault, climb, dive, lean, grenade throw, melee, drop, pickup, swap, signal, …)
- **Weapons** from 1 rifle to 6 launch weapons (rifle, SMG, shotgun, sniper, pistol, grenade launcher) with multi-fire modes, magazine system, suppressors, bipod, tracers, shell casing
- **Thrown weapons** — frag/smoke/flash/stick grenades with throw-arc preview
- **Melee combat** — bash/stab/kick/shoulder check
- **Tools** from 1 digger to 7 (digger, repair, foam, concrete, welder, drill, multi-tool, beacon, sensor pulse)
- **AI** from 1 reactive guard to **5 enemy archetypes** (rifleman / sniper / assault / engineer / spotter) with cover seeking, suppression, retreat, squad communication, patrol routes, personality traits
- **Sound propagation** — footstep loudness per surface, distance attenuation, occlusion, echo
- **Inventory** from 4 slots to 8 slots with weight + backpack capacity + drop/pickup/swap actions
- **Squad command** — 1 friendly bot + 4 commands (Follow / Hold / Defend / Push)
- **Mission director v0.5** — multi-objective, branching, optional bonus, dynamic respawn, mission phases
- **Camera + game feel** — smooth follow, hit-stop, slow-motion, scope zoom, free-look, mini-map, compass
- **UX depth** — hotbar, mini-map, quick-time prompts, damage direction indicator, settings tree
- **Debug overlays** — AI state, pathfinding, collision shapes, material affordance, physics impulses
- **Localization** — keyed strings table (Tier-A 11 languages reserved)
- **Forward-compat surfaces** — weather (M7.7), day/night (M7.7), voice/radio (M9.5), multiplayer (M9-M11), mod manifest (M8), workshop (M8+)

After M2.2 closes, the M1 actor controller becomes a **vertical-slice-ready surface**. M2.5 (reactor defense) builds on M2.2's squad command + multiple enemies + better mission director, NOT on M1.5's bare reactive guard. M5 (chassis) builds on M2.2's 32 actions + 6 weapons + 7 tools, NOT on M1's 9 actions + 1 weapon.

## Player-facing behavior

### Information priority — what the player gains from M2.2

| Layer | Player attention | M2.2 surface | Source |
|---|---|---|---|
| **L0 — Survival** | 0-500 ms | Damage direction arrow + reticle bloom + footstep loudness + threat awareness + ammo countdown + grenade incoming + low-health warning | Reticle / edge / paired sound + caption + haptic |
| **L1 — Action state** | 0.5-2 s | 8-slot hotbar + ammo + reload + sharp-aim + weapon-swap UI + scope zoom (sniper) + bipod state + suppressor state + stance pip (stand/crouch/prone/sprint/slide/vault/climb/lean) + tool readiness | HUD around actor/reticle |
| **L2 — Tactical state** | 2-5 s | Squad strip (4 actors) + mini-map / radar + compass + cover-state + AI doctrine + threat awareness + material legend + objective progress + phase strip | Squad / quick-detail / overlay |
| **L3 — Planning** | 5-60 s | Loadout panel (8 slots + weight + backpack) + inventory swap + drop / pickup / signal + waypoint placement + difficulty preset | Full panels |
| **L4 — Learning** | After-action | Death recap cause chain + AI debug overlay + replay scrubber + material affordance probe | Viewer / overlays |

### Player narrative flow (extended micro_breach + new scenarios)

- Player spawns with **8-slot loadout** (primary weapon + secondary + sidearm + 2 tools + grenade slot + medical kit + special)
- Player can **sprint** (faster than running but no aim), **crouch** (reduced silhouette, better aim), **prone** (lowest silhouette, slowest, bipod-allowed), **slide** (sprint-to-crouch combo), **vault** over low cover, **climb** ledges, **dive** (forward roll evasive), **lean** left/right around corners
- Player can **swap weapons** (1-8 hotbar) with smooth ~300ms transition
- Player can **throw grenades** with on-screen arc preview (M2.5 hazard surface forward-compat)
- Player can **melee** (rifle bash, knife stab, kick, shoulder check on sprint)
- Player can **use tools** — repair, foam, concrete, welder, drill, multi-tool, beacon, sensor pulse
- Player can **command 1 friendly bot** with 4 commands (Follow / Hold / Defend / Push to waypoint)
- AI presents **5 enemy archetypes** in mixed-squad scenarios: rifleman, sniper, assault (grenade thrower), engineer (digs/repairs/sets traps), spotter (calls reinforcements)
- AI uses **cover-seeking + suppression + retreat + squad communication** instead of M1.5's simpler perception-shoot loop
- Mission director runs **multi-objective** with branching paths (kill vs sneak) + optional bonus + dynamic respawn waves + 4-phase pacing
- HUD shows **mini-map / radar** + **compass** + **damage direction indicator** + **8-slot hotbar** + **squad strip**
- Camera includes **smooth follow** + **hit-stop on impact** + **scope zoom** + **free-look**
- Settings tree exposes Graphics / Audio / Controls / Accessibility / Gameplay / Language tabs
- Replay viewer (M3B forward-compat) gets new debug overlays: AI state, pathfinding, collision shapes, material affordance

### Actor controller — 32 actions

```gherkin

  Given an actor
  When the player performs sequence: stand → walk → run → sprint → crouch → prone → slide → vault → climb → dive → lean_left → lean_right

  And each transition has reason label (input, fall, knockdown, etc.)

Scenario: Sprint depletes stamina; recovery during walk
  Given Stance::Stand with stamina=1.0
  When the player sprints for 5 seconds
  Then stamina decreases at -0.2/s (0.0 at t=5s)
  And actor.stamina_changed fires N times
  When stamina=0.0
  Then sprint mode auto-cancels to Run (stamina exhausted)
  When the player walks for 3 seconds
  Then stamina recovers at +0.3/s

Scenario: Crouch reduces silhouette + improves aim
  Given Stance::Stand with reticle_bloom_factor=1.0
  When crouching
  Then Stance::Crouch active
  And reticle_bloom_factor=0.6 (40% bloom reduction)
  And actor's collision height reduced (smaller silhouette for cover)

Scenario: Prone has bipod deploy
  Given Stance::Prone with a rifle that supports bipod
  When act.player.deploy_bipod fires
  Then bipod state = Deployed
  And recoil_impulse scaled by 0.3 (70% reduction)
  And reticle bloom factor scaled by 0.5
  And equipment.bipod_deployed fires

Scenario: Slide is a sprint-to-crouch transition
  Given Stance::Sprint
  When the player presses crouch
  Then Stance::Slide initiated (transitions through 600ms)
  And actor.slide_initiated fires
  When slide completes
  Then Stance::Crouch active

Scenario: Vault over low cover
  Given the player approaches a 1.5m wall
  When act.player.vault fires
  Then Stance::Vault initiated (800ms animation)
  And actor.vault_initiated fires
  When vault completes
  Then actor is on the other side of the wall

Scenario: Climb up a 2m ledge
  Given the player at a ledge edge
  When act.player.climb_up fires
  Then Stance::Climb initiated
  And actor.climb_started fires
  When climb completes (1200ms)
  Then Stance::Stand on top
  And actor.climb_completed fires

Scenario: Dive evasive (forward roll)
  Given Stance::Run
  When act.player.dive fires
  Then Stance::Dive initiated (600ms)
  And actor's invulnerability frames active during dive (per M5+ rules)
  And actor.dive_initiated fires

  Given Stance::Stand near a wall corner
  When act.player.lean_left fires
  Then lean_angle = -30° (lean out left)
  And actor.lean_angle_changed fires
  And actor's aim cone extends past the corner (visible to enemies)

  Then actor.cover_state_changed fires with state="full"
  And cfctl observe.actor.cover_state returns "full"
  When the player stands up
  Then cover_state="partial" OR "none" depending on wall height
```

## Notes for the implementer

### Architecture rules

- **32 actions are the public surface; the implementation can use fewer state machines.** The 32 actions enumerate the cfctl surface + the `act.player.*` API. Underlying state machines (Stance, weapon_state, etc.) handle transitions deterministically.
- **5 enemy archetypes share `BaseEnemyState` + archetype-specific behaviors.** Inheritance via composition: `Archetype { rifleman_data, sniper_data, ... }` enum + shared methods.
- **Mission director is a single state machine.** Multi-objective + branching + phases all flow through one director. NEVER create per-scenario custom directors at M2.2.
- **Squad command is just 1 friendly bot at M2.2.** M5+ multi-squad command ladders up using the same `Command` enum + Squad state.
- **Localization is data-driven keyed strings.** Loaded once at scenario start; lookup is O(1) per key. NEVER bake English literals into HUD widgets.
- **Debug overlays are dev-build-only by default.** Production builds require `debug.enabled=true` setting to render overlays (avoid runtime cost in shipped builds).
- **Sound propagation is per-surface.** Material registry's `loudness_modifier` field feeds the per-surface footstep loudness. NEVER hardcode footstep loudness per actor.
- **Stamina is the simplest resource.** M2.2 stamina = 0..1; depletes during sprint; recovers when not sprinting. M5.8 origin model ladders up power/battery/oxygen/heat with the same value range pattern.

### Design rules (M2.2 enforces these for the next bridge milestone)

1. **Actor controller depth > flat HP simulation.** Movement choices (sprint / crouch / prone / lean / vault / climb / dive) create tactical depth without adding stats.
2. **Weapons differ by terrain consequence + handling commitment, not raw damage.** Per DR-007: rifle vs SMG vs shotgun vs sniper vs pistol vs grenade-launcher each answer a different "how does this change the map?"
3. **AI is a doctrine + archetype + personality stack, not just a behavior tree.** Per DR-008: hybrid utility + scripted layered.
4. **Cover seeking is mandatory for any rifle-equipped AI.** Per CCCP `AHuman.cpp` AI patterns: shoot-from-cover is the baseline, never camp-in-open.
5. **Mission director phases drive pacing.** Per Warframe-style 4-phase pacing: Setup / Buildup / Climax / Debrief.
6. **Sound is a first-class gameplay signal.** Per CCCP `MovableMan::RegisterAlarmEvent`: visualize it in debug + propagate it through hearing + occlusion + suppression rules.
7. **Stealth meter is a learning hook.** Per DR-023 onboarding: show the player WHY they were spotted before they die.
8. **8-slot inventory + 1-8 hotbar.** Common across CCCP / Soldat / Noita / most FPS games. Don't reinvent.
9. **Mini-map + compass are L2 surfaces.** Per ux-overlay-screen-brief: dense tactical state in fixed corners, not full-screen overlays.
10. **Hit-stop + camera punch + scope zoom are accessibility-toggleable.** Per DR-055 + DR-012: every juice rule has a `reduce_*` setting.
11. **Localization is data-driven, never baked.** Per DR-046: every visible string is a keyed lookup.
12. **Debug overlays are toggleable, never auto-shown.** Per ux-overlay-screen-brief: production builds default to off.
13. **Squad command is 4 verbs at M2.2.** Per DR-009: Follow / Hold / Defend / Push. M5+ ladders up; the surface name is locked.
14. **All M2.2 events carry parent_event_id.** Per M3A locked envelope: full cause-chain walking is the contract.
15. **Forward-compat surfaces are reserved at M2.2; producers come later.** Atmosphere / weather / voice / multiplayer / mod: schemas locked, producers ladder up.
