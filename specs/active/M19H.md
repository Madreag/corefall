# M19H — ONI Decor + Morale + Stress + Germs + Light + Disease Tracking

## Status

`active`

## Intent

ONI-grade quality-of-life mechanics: per-tile decor score + per-actor morale + per-actor stress accumulator + per-tile germ tracking + per-tile light level + per-room decor average + per-room aesthetic class — the layer of mechanics that makes ONI's colonies feel alive + creates emergent gameplay (cramped/dirty colony = stressed crew = breakdowns).

## Player-facing behavior

- Each tile carries a **decor score** (-30 to +40 typically); placing pleasing items raises it; ugly items lower it.
- Each actor has a **morale level** (0-100); affected by recent room decor, food quality, sleep, work outcomes.
- Each actor has a **stress accumulator** (0-100); rises from negative events, drops from positive ones. Above 80 = mental breakdown (Stationeers/ONI parity).
- Each tile carries a **germ count** for one germ kind (slimelung / food poisoning / radiation poisoning per ONI). Germs spread to neighbor tiles + via touch + via breathing.
- Per-tile **light level** (0-50000 lux ONI scale); plants need light to photosynthesize; actors get morale bonus from brightness; vampires (origin) penalized.
- **Per-room decor average** drives "Bedroom Worth", "Kitchen Worth", "Workshop Worth" — Stationeers/ONI room-grading.
- **Disease system**: contact a germ → maybe contract disease → maybe transmit to others → eventually recover via Sickbay or remedy.
- **Stress responses**: yelling fit (drop morale of nearby allies), binge eating (consume food), aimless wandering (lose work hours), crying fit (drop stamina).
- **Mood + uniform + work-shift integration**: actor in a high-morale state works faster + better; low-morale actor refuses orders eventually.

## Out of scope

- Per-actor unique personality traits (e.g., "loves messy" / "germophobe") — M48+ origin specialization.
- Disease epidemiology with R0 modeling — abstracted into per-tile germ count + spread.
- Per-disease genetic mutations + drift — M48+ realism.
- Multi-germ-coexisting tiles — one germ kind per tile per ONI rule.

## Notes for the implementer

- ONI light is 1/r² propagation; cf-environment::light_propagation does the BFS-style propagation per tick.
- Germ tracking: per-tile u32 germ_count + u8 germ_kind. 256 kinds total. Most tiles have 0 germs.
- Stress is a long-term system; small per-event nudges + per-tick decay accumulate slowly.
- Morale + stress have replay-stable accumulators; no thread_rng.
- Disease registry is data-driven (RON); mod authors add new diseases via schema.
