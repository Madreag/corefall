
## Status

`active`

## Intent

**M8.6 is the Mining And Extraction milestone** (per DR-041). Full mining-and-extraction pipeline runs end-to-end: sample → drill → extract → refine → smelt → use. Per-world ore deposits load from World catalog (DR-039). 12 launch ores ship. Mining tools with origin compatibility. AI miner doctrine passes AI-MINE-A 8-test acceptance suite. Server-authoritative resource ledger replicates per `spec/persistent-mmo-architecture`. Mining missions land in the mission director (M7).

M8.6 promise: **"mining is a first-class gameplay loop — survey ore deposits, drill, refine, smelt, build with the output, defend supply lines from raiders."**

## Player-facing behavior

### Mining tools (9 launch tools with origin compatibility)

Per `spec/mining-and-extraction-model`:

| Tool | Function | Origin compatibility | Power source |
|---|---|---|---|
| `Sampler` | Survey ore deposits (reveals composition + yield) | Human / Android / Robot | Hand-held / batteries |
| `LightDigger` | Existing M1 tool; can mine soft ores (dirt-grade) | All origins | (M1 baseline) |
| `HeavyDrill` | Drills harder ores (concrete/metal-grade); slow | All origins; recommends Heavy chassis | Battery / power |
| `CoreDrill` | Deep drilling for rare ores (uranium / titanium / lithium); chassis-mounted | Light mech / Heavy mech | Reactor power |
| `RefiningStation` | Process raw ore → refined material | Base station (not portable) | Power grid |
| `SmelterFurnace` | Smelt refined → metal alloys (steel, brass, hardened plate) | Base station (not portable) | Power + heat |
| `EnrichmentReactor` | Concentrate rare ores (uranium-enrichment) | Base station (rare; advanced) | Reactor power |
| `OreCargoBay` | Storage bin for raw + processed ore | Base station | (passive) |
| `ConveyorBelt` | Moves ore between stations | Base station | Power |

### Per-world ore deposit generator

Per `spec/celestial-bodies-and-worlds-model`:
- Per-world `ore_distribution` config (which ores, density, depth)
- Earth → all 12 ores (mostly surface)
- Mars → iron + gold + uranium + titanium (deep)
- Moon / Phobos → titanium + helium-3 (M7.7 forward-compat)
- Mimas → ice + ammonia (cryogenic)
- Vulcan → sulfur + iron + copper (volcanic)
- Belt asteroids → various rare ores (each asteroid has distinct profile)

### Server-authoritative resource ledger

- Per-shard ledger: `per_shard.ledger[<actor_id>] += amount`
- Replicated via M9 server protocol
- Audit-logged for anti-cheat (preventing duplicate gold farming)
- Persisted via M5+ save system (carries across missions)
- Ledger accessible via `cfctl observe --mining`

### Mining missions (M7 mission director integration)

- New objective kinds: `MineN { ore, amount }`, `BuildBaseStation { kind }`, `EscortConvoy { source, dest }`
- Extraction-under-fire scenarios (mine while enemy attacks)
- Deposit-collapse-eta events (terrain collapses; ore destroyed if not extracted in time)
- Mission director extension: mining objective authoring panel in M8 editor

### M8 scenario editor extension

- Mining objective authoring panel
- Ore deposit placement tool
- Per-deposit yield + distribution config
- Mission rewards: credits, refined ore, rare items, faction reputation

### Origin gating

- Robot mines vacuum belt without life-support warning (immune)
- Human refuses to mine without sealed suit + oxygen tank in vacuum
- Android needs suit + tank (organic side requirement)

## Acceptance criteria (AI-MINE-A 8-test suite)

```gherkin
Scenario: AI-MINE-A-01 — AI surveys ore deposit
  Given AI bot with Sampler tool + ore deposit
  When bot uses Sampler at deposit:
    Then mining.deposit_surveyed fires with composition + yield
  And bot has data for next decision

Scenario: AI-MINE-A-02 — AI drills with appropriate tool
  Given AI bot + iron deposit (concrete-grade)
  When bot chooses tool:
    Then bot selects HeavyDrill (per ore hardness)
  When drilling:
    Then mining.drill_started fires
    And ore extracted over time

Scenario: AI-MINE-A-03 — AI refines raw ore
  Given AI bot with raw iron + RefiningStation
  When bot interacts with station:
    Then mining.refining_started fires
    After cooldown: mining.refining_completed fires
    And refined_iron in output bin

Scenario: AI-MINE-A-04 — AI smelts refined
  Given refined iron + coal + SmelterFurnace
  When bot loads furnace + activates:
    Then mining.smelt_started fires
    After cooldown: steel produced
  Cross-DR: integrates with M5.9 atmospherics (smelter requires heat per Stationeers)

Scenario: AI-MINE-A-05 — AI hauls output
  Given smelted output + OreCargoBay
  When bot hauls:
    Then mining.hauled fires (bot moves output to bay)

Scenario: AI-MINE-A-06 — AI retreats when threatened
  Given AI mining + enemy detected in proximity
  When threat threshold crossed:
    Then ai.retreat_decision fires with reason="mining_threat"
    And bot retreats to cover; mining suspended

Scenario: AI-MINE-A-07 — AI reads EnvironmentSignal
  Given vacuum environment + human bot
  When bot considers mining:
    Then ai.environmental_decision fires with reason="needs_oxygen_tank"
    And bot refuses to mine
  Given robot bot in same vacuum:
    Then bot mines (immune)

Scenario: AI-MINE-A-08 — AI emits reason labels
  Given mining session
  Then every mining decision has reason label
  And reasons render in plain language via M3B viewer

Scenario: 12 launch ores load + smelt
  Given 12 ore types in registry
  When each ore mined → refined → smelted:
    Then all 12 produce expected output material
    And material.* events fire correctly

Scenario: Server-authoritative resource ledger replicates
  Given shard A with player_actor + 100 iron
  When shard restarts:
    Then ledger persists; player_actor still has 100 iron
  And cfctl observe.mining shows ledger consistent

Scenario: Mining mission authorable in M8 editor
  Given M8 scenario editor with mining objective panel
  When designer places ore deposits + sets objective:
    Then mission.objective_started fires for MineN
    And designer can save + share scenario

Scenario: Origin gating — robot mines vacuum belt
  Given Belt asteroid scenario (vacuum)
  When robot bot mines:
    Then no life-support warning
  When human bot mines without suit:
    Then ai.environmental_decision rejects mining
    And caption "Needs sealed suit + oxygen tank"

Scenario: Determinism replay across full mining mission
  Given mining scenario at seed N
  When replayed via cf-headless:
    Then result=ok; all checksums match
```
