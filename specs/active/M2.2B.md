## Intent

**M2.2B** is the **second bridge slice** between M2.2A (closed actor + equipment core) and M2.2C (UX + accessibility polish). It closes the **AI + perception + mission director + basic personality/faction** gap. After M2.2B, the game has multiple intelligent enemies with distinct archetypes, real mission pacing, basic personality traits that affect AI behavior, and a faction relationship surface — all the things M2.5 reactor defense and M5 chassis need to feel meaningful.

M2.2B's player-facing promise: **"the enemies feel intelligent and the mission feels dynamic."**

## Player-facing behavior

### 5 enemy AI archetypes (M1.5: 1 reactive guard → M2.2B: 5 archetypes + behaviors)

**Per DR-008 hybrid utility + scripted layered AI model.** All archetypes share `BaseEnemyState` (M1.5 ReactiveGuard) + archetype-specific behaviors:

| Archetype | Primary behavior | FOV / range | Reaction time | Health | Key trait |
|---|---|---|---|---|---|
| **Rifleman** | Cover seeking + suppression fire | 180° / 320u | 12 ticks | 80 HP | Bread-and-butter combat unit |
| **Sniper** | High-ground preference + scope settle (1.5s before fire) | 240° / 800u | 18 ticks | 60 HP | Flanker; positions on rooftops |
| **Assault** | Sprint toward player + grenade thrower | 120° / 200u | 6 ticks | 90 HP | Close-quarters specialist |
| **Engineer** | Digs cover + repairs squadmates + sets explosive traps | 180° / 280u | 12 ticks | 70 HP | Force multiplier (support role) |
| **Spotter** | Calls reinforcements + commands squad | 200° / 360u | 12 ticks | 50 HP | Mini-boss with multi-phase (see M2.2C) |

**Cover seeking**: each archetype searches for `cover_state=Full` within sight; crouches + repositions toward cover when fired upon (per CCCP `AHuman.cpp` AI patterns).

**Suppression fire**: rifleman in squad maintains low-accuracy high-rate-of-fire while a squadmate flanks; emits `ai.suppression_started`.

**Retreat decision**: any archetype with HP < 30% OR squad dead → retreats to safe distance + cover.

**Squad communication**: 0.5s delay for alarm propagation through squad (M1.5 has direct line; M2.2B adds latency for realism).

**Patrol routes**: waypoint following with 5-10s idle stops at waypoints; emits `ai.patrol_waypoint_reached`.

**Friendly fire awareness**: AI repositions if a friendly is in line of fire OR within blast radius of a grenade; emits `ai.friendly_fire_avoidance`.

**High-ground preference**: sniper + spotter actively move to elevated terrain before firing.

### Personality traits + nicknames (basic; affects AI)

**M2.2B ships the surface; M5+ retention/campaign fills the full system.**

- Per-actor `traits: Vec<Trait>` (3-5 traits per actor)
- 20+ launch traits affecting AI: `brave, coward, loyal, disloyal, merciful, cruel, careful, reckless, sharp_shooter, terrible_shooter, hot_headed, calm, fast_reflexes, slow_reflexes, gun_collector, peaceful, paranoid`
- Per-actor name (generated from culture/faction name list — 50+ name pool per faction)
- Per-actor 1-line backstory (M5+ extends; M2.2B has placeholder)
- **Mood/stress accumulator (0..1)**: affects aim accuracy + retreat threshold + sprint speed; events that affect mood: ally killed (-15), kill landed (+5), mission progress (+5), wounded (-10)

Trait effects:
- `brave` → retreat threshold lowered (won't flee until <15% HP vs default <30%)
- `coward` → retreat threshold raised (flees at <50%)
- `sharp_shooter` → aim_accuracy × 1.15
- `terrible_shooter` → aim_accuracy × 0.7
- `paranoid` → false sightings (occasional ai.target_acquired with no real target)
- `loyal` → defends squadmates more aggressively

### Squad doctrine (Defensive / Aggressive / Scout)

Per-squad assigned doctrine affects all members:
- `Defensive` → hold cover positions; suppression fire; retreat at threshold
- `Aggressive` → push toward player; less suppression; flanking
- `Scout` → one member explores ahead while others wait

Set via `act.squad.assign_doctrine` (forward-compat for player vs enemy squads).

### Faction relationship surface (basic 3-faction model)

- 3 factions: `Player`, `AI Allied`, `AI Enemy`
- Per-faction relationship matrix (-100 to +100)
- Dynamic shifts: friendly fire on allied faction → -30; saving enemy NPC → +20
- Faction-specific gear (cosmetic differentiation; placeholder M5+ expands)
- M5+ fills full faction simulation; M2.2B ships the surface

### Mission director v0.5 (multi-objective + branching + 4 phases)

Replaces M1.5's simple timer-and-objective with:

**Multi-objective `DiGraph<ObjectiveNode>`** with kinds:
- `ReachZone, KillActor, KillN, SurviveTimer, DefendActor, EscortActor, RetrieveItem, PlantItem, DetectAlarm, SneakStealth, RescueDowned, BreachContainer, Optional, Branching`

Sequential + parallel + branching support (e.g. `Breach → KillSpotter → Extract`, with optional `RescueDowned` as parallel).

**4-phase pacing** (Warframe-style):
- `Setup` (mission start; players orient)
- `Buildup` (early enemy encounters)
- `Climax` (main objective + reinforcement waves)
- `Debrief` (mission resolution)

**Dynamic respawn waves**: director spawns reinforcements based on phase + player progress; emits `mission.reinforcement_wave_spawned`.

**Mini-boss patterns** (per Diablo / Sea of Thieves design):
- 1 mini-boss per scenario (Spotter archetype as launch boss)
- Multi-phase HP thresholds (>75% phase 1; <75% phase 2 with shield ability; <25% enraged phase 3)
- Specific tactic required (e.g. break shield with electric weapon)
- Boss events: `boss.phase_changed`, `boss.special_ability_triggered`

## Acceptance criteria

### 5 AI archetypes

```gherkin
Scenario: Rifleman seeks cover when fired upon
  Given Rifleman + LOS with player
  When player fires
  Then ai.cover_seeking_started fires
  And rifleman moves to nearest cover within 5m
  When cover reached: rifleman crouches behind cover

Scenario: Sniper takes high ground
  Given Sniper + nearby high terrain
  Then ai.high_ground_preference_applied fires
  And sniper moves to elevated position before firing
  When in position: ai.scope_settle fires (settles 1.5s before fire)

Scenario: Assault sprints + throws grenade
  Given Assault + player visible
  Then ai.archetype_chosen=Assault fires
  When within 5m of player
  Then ai.tactic_chosen=throw_grenade fires
  And equipment.grenade_thrown fires
  And assault retreats while grenade detonates

Scenario: Engineer digs cover + sets traps
  Given Engineer + player approaching
  When player closes:
    Then engineer digs cover OR repairs ally armor
  When threat detected:
    Then engineer sets explosive trap at chokepoint
    And ai.tactic_chosen=set_trap fires

Scenario: Spotter calls reinforcements
  Given Spotter + alarm registered
  Then ai.tactic_chosen=call_reinforcements fires
  And mission.reinforcement_wave_spawned fires
  And 2-3 additional enemies spawn at dropship zone
```

### Cover seeking + suppression + retreat + squad comm + patrol

```gherkin
Scenario: AI suppresses while squadmate flanks
  Given 2 Riflemen in squad
  When Rifleman B engages player
  Then Rifleman A starts suppression fire (low accuracy + high rate)
  And ai.suppression_started fires
  When Rifleman B flanks
  Then ai.tactic_chosen=flank fires

Scenario: Retreat when HP < 30%
  Given AI with HP=25%
  Then ai.retreat_decision fires with reason="hp_low"
  And AI retreats to safe distance + cover

Scenario: Squad comm relays threat with 0.5s delay
  Given squad of 3 enemies
  When one detects player
  Then ai.squad_comm_relayed fires after 0.5s
  And other 2 enter Alert state without direct LOS

Scenario: Patrol route with idle stops
  Given enemy in Idle with patrol_route defined
  Then enemy moves between waypoints
  At each waypoint: 5-10s idle pause; ai.patrol_waypoint_reached fires

Scenario: Friendly fire awareness
  Given 2 squadmates in line of fire
  When one about to shoot the other
  Then ai.friendly_fire_avoidance fires
  And AI repositions before firing
```

Scenario: Multi-objective sequential graph
  Given 3 objectives: Breach → KillSpotter → Extract

  When skipped: mission still wins; bonus null

  Given scenario start
  Then mission.phase_changed fires for Setup (phase 1)
  After ~30s: phase=Buildup
  After main objective triggers: phase=Climax + reinforcement wave

### AI-H test harness preservation + extension (M1.5 closure carried forward)

Per M1.5's `ai-trust-harness-slice-a`, the **AI-H test runner** is the canonical AI testing infrastructure. M2.2B extends it from M1.5's AI-H-01 baseline to the full **AI-H-01..06 suite**:

| Test ID | What it proves |
|---|---|
| `AI-H-01` | Sentry hears threat without LOS (M1.5 baseline; carried forward) |
| `AI-H-02` | Cover seeking under fire (M2.2B; new) |
| `AI-H-03` | Suppression while squadmate flanks (M2.2B; new) |
| `AI-H-04` | Retreat decision at HP threshold (M2.2B; new) |
| `AI-H-05` | Squad comm propagation with 0.5s delay (M2.2B; new) |
| `AI-H-06` | Friendly-fire avoidance + repositioning (M2.2B; new) |

Runner: `cargo run -p cf-e2e -- --ai-harness ai_h_XX_<name>`. Each test loads a scripted scenario + sets seed + spawns actors → runs to timeout → emits `ai_test_result` with status + duration + replay_path. AI-H is **distinct from M6.6 AI-MAT** (which tests environmental competence per M5.10 EnvSignal).

### AI difficulty preset registry (M1.5 baseline → M2.2B extension)

M1.5 shipped 3 difficulty presets (`cakewalk`, `tough_crowd`, `veteran`). M2.2B extends to **5 archetypes × 3 difficulties = 15 preset entries** in `content/ai/difficulty.json`:

- Per-archetype preset includes `hp`, `aim_settle_ticks`, `miss_chance`, `sight_range`, `hearing_radius`, `memory_decay_ticks`, `reload_ms`, `cover_seek_radius`, `retreat_hp_threshold`, `squad_comm_delay_ticks`
- `cfctl observe.ai.<actor_id>.difficulty_preset` returns active preset
- `act.settings.set { ai_difficulty: "veteran" }` applies globally; per-actor overrides via `act.actor.<id>.set_difficulty`

### Engine-RNG (NOT thread_rng) per CCCP determinism

M1.5 enforces: all AI rolls (miss_chance, target_score variance, stuck_recovery action) use the **engine seeded RNG**, never `thread_rng()`. M2.2B's 5 archetypes preserve this rule. Same seed → same outcome (replay determinism per DR-052). CI gate (`grep -r thread_rng game/crates/cf-ai`) returns zero matches.
