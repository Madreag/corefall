# M41 — Online Co-op + Full Match Grammar

## Status

`active`

## Intent

**M41 is the Online Co-op (Self-Hosted Dedicated Servers) — Extended For Full Match Grammar Per DR-042 milestone**. A community member can host an internet-reachable `cf-server --mode coop_room` instance, register it with a `lobby_directory` (community or first-party), and friends in different cities can find it, join via NAT-traversal/relay, and complete a Breach Contract together. Plus full match grammar from DR-042 + 10 endgame modes + named-rival AI commanders persisting across missions + Multi-squad command (4+ squads) + War Thunder-style polished kill cam.

M41 promise: **"online co-op with self-hosted dedicated servers; full match grammar; AI rivals with persistent memory; 10 endgame modes; the game becomes a story engine."**

## Player-facing behavior

### Online co-op via self-hosted servers

- Community member runs `cf-server --mode coop_room` behind a NAT-able router
- Server registers with `lobby_directory` (M36 surface; either community-hosted or first-party)
- Server heartbeats periodically
- Friends in different cities discover via lobby browser
- Join via NAT punch-through or relay (per `cf-net` transport from M36)
- Steam Datagram Relay / EOS adapter optional (cargo features `net-steam`, `net-eos`)

### Lobby UI

- Code-based join (private; share 6-character code)
- Browse-list join (public; filter by scenario / mod / player count / ping)
- Friend invites via Steam Friends

### Latency masking

- Client-side prediction + server reconciliation for player actor
- Pure replication for AI bots
- Works at 50-150 ms RTT without obvious jitter
- Reconciliation rollback if mispredicted (smooth correction; not snap)

### Package hash sync (online-strict)

- Server checks client packages match
- Dev workflow: soft-fail with auto-download for testing
- Shipping: hard-fail with mismatch report (not soft-download)
- Trust tier respected (per DR-006): `vanilla` / `verified` / `community` / `experimental`

### Anti-cheat profile `competitive` (default for online)

- Server-side input validation (rate limits + capability gates)
- Rejects impossible inputs (super-speed, infinite ammo)
- Per-session ban list (persisted)
- Audit log appended per session

### Multi-squad command (4+ squads per player)

- Player can lead up to 4 squads simultaneously
- Per-squad doctrine + commands (M7 baseline)
- 7 squad role types: Rifleman / Sniper / Engineer / Medic / Heavy / Recon / Tech
- Squad strip HUD shows all 4 squads
- Hotkey: 1-4 selects active squad; 5-8 issues commands to active squad
- Per-squad commands: FollowLeader / HoldPosition / DefendPoint / PushToWaypoint (M6) + Suppress / Flank / Cover_That_Position / Retrieve_Target / Treat_Wounded / Demolish / Stealth_Approach / Coordinated_Push

- Each campaign has 1-3 named AI commanders (M25 baseline; M41 extends with online persistence)

- Commander dossier visible (kills, defeats, signature tactics, dialog snippets)
- Defeating commander = unique reward (artifact + lore unlock + perk slot)
- Commander persists across online sessions (per-server-shard memory)
