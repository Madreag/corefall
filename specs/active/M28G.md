# M28G — Production Supply Chain + Resource Budget Accounting + Factorio-Style Throughput

## Status

`active`

## Intent

Closes the gap that bases consume + produce many resources (power M29, atmosphere M28, thermal M28B/D, refrigerant M28E, food, ore M30, refined M32) but have no unified accounting. M28G adds a single per-base budget table — power_in/out, water_in/out, atmosphere_in/out, food_in/out, ore_input/output, byproduct_disposal — driven by a Factorio-style Sankey throughput diagram. When any column runs deficit for >60s, an auto-bottleneck detector identifies the upstream pinch. IC10 chips (M29A) consume the budget and execute conditional routing. Each resource has an over-production alarm when downstream storage saturates.

## Player-facing behavior

### Per-base resource budget table

- **F9 toggle** opens a single-pane per-base table with 6 resource pairs:

| Resource | In/min | Out/min | Net | Buffer | Days remaining |
|---|---:|---:|---:|---:|---:|
| Power (kW·min) | 145 | 132 | +13 | 80% | ∞ |
| Water (L) | 12 | 18 | -6 | 47% | 2.3 |
| Atmosphere (mol O2) | 4.2 | 5.1 | -0.9 | 92% | 3.1 |
| Food (kcal) | 2400 | 3200 | -800 | 60% | 1.4 |
| Ore (kg) | 220 | 180 | +40 | 75% | ∞ |
| Byproduct (kg) | 60 | 50 | +10 unmanaged | 88% | 1.1 to overflow |

- **Net color**: green (surplus), yellow (-5% to 0%), red (deficit >5%).
- **Buffer**: current storage / reservoir / battery fill.
- **Days remaining**: deficit drain (or fill) projection on current buffer.
- **Cell click** drills into per-station contribution sortable by rate.

### Per-station consumption + production rates

- Every powered base station has `production_rates` + `consumption_rates` tables in its RON (e.g. smelter_t1: `power: 4.0 kW`, `iron_ore: 1.0 kg/sec`, `coal: 0.2 kg/sec`, `heat_output: 8.0 kW`; produces `refined_iron: 0.5 kg/sec`, `slag_byproduct: 0.1 kg/sec`).
- **Aggregation**: cf-supply-chain sums all station rates → updates per-base budget; stalled stations (empty input buffer) register as stalled badge.
- **Variable curves**: solar (M29) reads M31 weather + day/night; budget shows current contribution, not nameplate.

### Sankey throughput diagram

- **F10 toggle** — Factorio-style ribbon flow visualization, left-to-right.
- **Nodes**: source (ore vein, solar, scoop, condenser) → intermediate (smelter, fabricator, refinery, hydroponics, scrubber) → sink (storage, consumer, vent, fuel tank, byproduct disposal).
- **Edges**: thickness proportional to throughput (kg/sec, kW, mol/sec).
- **Bottleneck highlight**: any edge >95% capacity pulses red.
- **Hover tooltip**: source, sink, current flow, capacity, % util, eta-to-empty/eta-to-full of downstream buffer.
- **Layer filter**: single-resource or all-overlaid.

### Bottleneck auto-detection

- Sliding 60s window; flags any resource with consumption > production AND buffer < 30%.
- Walks Sankey upstream from deficit consumer to find pinch (most-loaded edge / most-stalled source / disconnected segment); fires `supply.bottleneck_detected { resource, root_cause_station_id, suggested_action }`.
- HUD: amber chevron in F9 + voice line ("Refined iron throughput insufficient — smelter T1 stalled on coal") + optional klaxon.
- Suggestions are text-only ("add 1 more smelter", "route additional power to refinery"); player decides.

### Conditional routing via IC10

- Per-station IC10 slot (M29A ABI) reads supply-chain DB:
  - `db pi/po/pn/pb` → power in/out/net/buffer_pct
  - `db ri/ro` → refined_iron in/out (auto-assigned 2-char per resource)
  - `db bd <station_id>` → bottleneck flag
- Player programs divert flow: `if pb < 30 then halt smelter`, `if water_buffer < 20 then halt hydroponics`, `if refined_iron_buffer > 95 then halt smelter`.
- **No-IC10 preset dropdown** per station: "Halt when input empty", "Throttle to 50% when buffer >80%", "Always on", "Manual only".

### Over-production alarms

- Configurable threshold per resource (default 95%); crossing fires `supply.overproduction_alarm { resource, current_buffer_pct }`.
- Auto-stop policies: `halt_on_full`, `vent_excess` (atmosphere, opens M28B emergency vent), `dump_to_byproduct` (slag/ash/CO2), `redirect_to_secondary_storage`, `continue` (waste accepted).
- Byproduct channels: CO2 → vacuum vent / carbon-recovery (M28E) / algae feed; slag → recycler / external dump; ash → fertilizer / vent.

## Out of scope

- Inter-base supply-chain accounting (one base's smelter feeding another base's fabricator via inter-planet cargo) — M48+ logistics ambition; M28G is per-base only.
- Predictive supply-chain ("in 4 hours your iron will run out at current consumption") beyond the simple linear "days remaining" projection — M48+ AI/ML feature.
- Market-price-driven supply chain (cost of goods optimization, profit-maximizing production scheduling) — M48+ economy layer.
- Per-actor labor budget (treating actor-hours as a resource) — RimWorld parity; M28G does not model this.
- Visual scripting of conditional routing (drag-and-drop logic instead of IC10) — modder territory; M28G ships IC10 + preset dropdowns only.
- Custom resource types created by modders (modder defines new "exotic_isotope" resource) — supported by content RON schema but no new launch-default resources beyond the 6 pairs in this spec.

## Notes for the implementer

- 6 launch resource pairs are the registered set; modders add via `content/resources/<id>.resource.ron`.
- Per-station rates schema-validated at mod load: non-negative + registered resource; cf-mod emits load-time error, never runtime crash.
- Budget aggregation runs once per second (not per-tick) — cache per-tick deltas. Tick rate is configurable per AGENTS.md; never hard-code 60.
- Sankey layout: left-to-right hierarchical, topological-order placement, cubic Bézier ribbons; <2ms for ~200 nodes + ~600 edges.
- Bottleneck root-cause: BFS upstream; first node with `consumption > production` or `input_buffer = 0` wins.
- IC10 DB keys are 2-char codes (M29A ABI): `pi/po/pn/pb`, `wi/wo`, etc. Modder resources auto-assigned at load; collision = fail load.
- `vent_excess` reuses M28B emergency vent — single mechanism.
- Voice cues in `content/audio/supply_voice/<resource>_{low,critical}.ogg`; missing files fall back to text HUD.
- All cf-supply-chain numerics are `f64` — `f32` accumulator drift observable at >10⁶ ticks.
- Days remaining: `buffer_current / (consumption_rate - production_rate)` clamped `[0, ∞)`; `∞` symbol when net positive.
