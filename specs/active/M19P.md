# M19P — Per-Actor Traits + Recreation Activities + Social Interactions + Romantic Relationships + Pet Behavior + Mood Breakdown Variants

## Status

`active`

## Intent

RimWorld + Dwarf Fortress personality + relationships layer: trait sheets, recreation needs, social bonds, romantic pairings, pet bonds, mood-breakdown variants. After M19P, every actor has a trait sheet (Optimist / Pessimist / Lazy / Hard-worker / Jealous / Kind / Pyromaniac etc.), seeks recreation activities (chess / TV / books / music / arcade), forms social bonds (friend / rival / lover), and when stress > 80 breaks down in a variant matching their personality.

## Canonical ownership

Owns traits, relationships, recreation, pets, breakdown variants. M19H stress consumer; M16C trigger producer (PTSD); M19O roommate consumer.

### Social interactions

- Two actors within 4 tiles trigger random social roll per 1 in-game hour.
- Interaction types: `friendly_chat` (+2 morale both) / `argument` (-3 both; rival++) / `joke` (+3 / -1 if pessimist) / `flirt` (romance progression) / `insult` (-5 / rival++++) / `praise` (+4 / friend++).
- Per-trait modifier: `silver_tongue` actors win more positive rolls; `intimidating` actors win more negative.
- Per-relationship tracking: every actor pair has `friendship_score` (-100 to +100) + relationship type (Stranger / Acquaintance / Friend / Best Friend / Rival / Enemy / Lover / Spouse).
- Hostile rival pairs avoid bedrooms together; lover pairs prefer to share.

### Romantic relationships

- Friendship score > 60 + trait compatibility → flirt chance.
- Flirt success → relationship advances (Friend → Crush → Dating → Lover → Engaged → Spouse).
- Per-stage events: "Engaged" triggers wedding ceremony (M25 mission); spouses share bedroom + bed quality bonus.
- Breakups + jealousy events drive morale swings.
- Per-origin compatibility: human-android possible (per M17 lore); human-robot platonic only.

### Pet behavior (M26 integration)

- 4 launch pet types (per M26): dog / cat / colony_lizard / hatch.
- Per-pet stats: HP / hunger / loyalty / training.
- Per-pet personality (mini-trait sheet: playful / shy / aggressive / lazy).
- Bonding: actor + pet repeated interaction → bond.
- Pet death → severe morale hit for bonded owner (esp `dog_lover` / `cat_lover` traits).
- Pets can be trained: come / sit / attack / haul / guard.

### Mood breakdown variants

When stress > 80 (per M19H), break down per trait + random roll:

| Variant | Trigger trait | Behavior | Duration |
|---|---|---|---|
| `berserker_rage` | bloodthirsty / pyromaniac | Attacks nearest hostile (or ally if no hostile) | 3 in-game hrs |
| `sad_wandering` | pessimist / introvert | Wanders aimlessly; refuses orders | 6 hrs |
| `binge_eating` | gourmet / fast_metabolism | Eats all available food | 2 hrs |
| `pyromania` | pyromaniac | Sets fires to base structures | 1 hr |
| `kleptomania` | kleptomaniac | Steals items from chests | 2 hrs |
| `crying_fit` | nervous / fragile | Cries; -stamina + -morale for nearby | 3 hrs |
| `aggressive_outburst` | intimidating | Yells at random actor; -morale for victim | 30min |
| `catatonia` | iron_willed → snapped | Stops all activity | 6 hrs |
| `binge_drinking` | addict_alcohol | Drinks all available alcohol | 2 hrs |
| `withdrawal_symptoms` | addict_alcohol no alcohol | Stress accumulator × 2; -accuracy | until alcohol or treatment |

Treatment: medical bed (M19O) + therapy session (1hr; actor with high social skill required) + drugs (mood stabilizers; M19N).

## Acceptance criteria

```gherkin
Scenario: Trait assigned at spawn
  Given new actor spawned via M25 narrative
  Then trait_assigned fires × 2-3 traits per actor
  And trait_sheet visible in UI

Scenario: Pyromaniac sets fire on breakdown
  Given pyromaniac actor with stress=85
  When breakdown rolled:
    Then mood_breakdown_started fires variant=pyromania
    And actor paths to flammable structure + ignites (per M15)

Scenario: Social interaction roll
  Given 2 actors within 4 tiles
  When 1 hour elapses:
    Then social_interaction fires
    And random roll: friendly_chat / argument / etc.
    And friendship_score updates

Scenario: Relationship advancement
  Given friend pair with friendship=72
  When 50+ flirt rolls succeed over weeks:
    Then relationship_advanced fires
    And type transitions Friend → Crush → Dating

Scenario: Recreation activity
  Given actor with recreation_need=0.7 + chess_table available
  When actor chooses chess:
    Then recreation_completed fires after 30min
    And morale += 12
    And recreation_need drops to 0.2

Scenario: Pet bond formation
  Given actor + dog within 4 tiles for 7 in-game days of interaction
  Then pet_bond_formed fires
  And dog "owner" field set
  And actor gets +5 morale near pet

Scenario: Lover roommate bonus
  Given lover pair assigned same bedroom
  Then per-night roommate_friction → positive event (no friction)
  And morale + 5 both

Scenario: Jealous actor + friend's lover
  Given jealous actor's friend pairs with lover
  Then jealous actor → -morale event fires
  And friendship_score with friend drops

Scenario: Breakdown recovery via therapy
  Given actor in catatonia breakdown
  When ally with social_skill > 10 performs therapy (1hr at medical bed):
    Then breakdown_recovered fires
    And stress -30
```
