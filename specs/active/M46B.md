# M46B — Mercenary Contracts + Bounty Boards + Taxes + Tariffs + Tribute + Faction-Specific Trade Routes + Caravan Escort

## Status

`active`

## Intent

**M46B is the geopolitical-economy milestone** — the layer above M46's upkeep drain that ties money to *action*. After M46B, players can hire NPC mercenaries on signed contracts, collect posted bounties on named targets, pay (or evade) taxes and tariffs at faction ports, send or receive tribute to keep rivals at bay, route caravans along faction-restricted trade lanes, and run escort missions whose payout scales with risk.

M46B splits this out of M46 because M46 is the *passive* drain (upkeep) and M46B is the *active* economy (hire, hunt, tax, route, escort). The two together complete the grand-strategy economy stack on top of M26C's currency + market kernel.

**M46B respects M46's opt-in flag.** When `grand_strategy.enable_upkeep_economy=false`, M46B's tribute and tax systems also disable (mercenary contracts + bounty boards + caravan escorts remain available because they are mission content, not periodic drains). When `grand_strategy.enable_upkeep_economy=true`, the full stack engages.

M46B promise: **"hire a mercenary on a per-day contract; chase a bounty board for 5000 CC; pay tariff at the port or run the customs gauntlet; send tribute or get raided; escort a caravan through hostile lanes and pocket scaling reward."**

## Player-facing behavior

### Mercenary contracts (per-NPC, signed terms)

Mercenary NPCs (M26 Mercenary Guild quartermasters + named NPCs at faction bases) offer themselves for hire via the dialog tree `recruit_mercenary` branch. Each contract has explicit signed terms:

```rust
pub struct MercenaryContract {
    pub contract_id: ContractId,
    pub mercenary_npc_id: NpcId,
    pub employer_actor_id: ActorId,
    pub payment_terms: PaymentTerms,
    pub duration: ContractDuration,
    pub combat_rules_of_engagement: RoE,
    pub loyalty_modifiers: LoyaltyConfig,
    pub breach_penalty: BreachPenalty,
    pub signed_at_cycle: Cycle,
    pub expires_at_cycle: Cycle,
}

pub enum PaymentTerms {
    PerCycle { amount: u64, currency: CurrencyId },
    LumpSumUpfront { amount: u64, currency: CurrencyId },
    LumpSumOnCompletion { amount: u64, currency: CurrencyId },
    SharePerKill { share_pct: f32, currency: CurrencyId },
    SplitLootShare { share_pct: f32 },
}

pub enum ContractDuration {
    UntilMissionComplete(MissionId),
    FixedCycles(u32),
    AtWill,                                    // either party can dissolve with 1-cycle notice
    UntilBountyCollected(BountyId),
}

pub struct RoE {
    pub fire_at_will: bool,
    pub no_friendly_fire: bool,
    pub no_civilian_harm: bool,
    pub stand_ground_only: bool,
    pub follow_leader_within_m: f32,
}

pub struct LoyaltyConfig {
    pub base_loyalty: f32,                     // 0.0-1.0
    pub on_missed_payment: f32,                // delta per missed cycle
    pub on_high_risk_no_payment: f32,          // delta per perilous order
    pub on_share_bonus: f32,                   // delta per profitable share
}

pub enum BreachPenalty {
    Walkout,                                   // mercenary leaves; nothing else
    WalkoutPlusReputationLoss(i32),
    WalkoutPlusStolenGoods,                    // grabs visible loot on exit
    Hostility,                                 // turns hostile immediately
}
```

**Loyalty drift** — each cycle, loyalty updates based on payment history + RoE adherence + share quality. When loyalty < 0.2 the mercenary breaches per `breach_penalty`. M48 inter-faction intel can flip mercenaries via bribes; the contract carries an opt-in `bribery_immune` flag (more expensive contract, harder to flip).

Events: `mercenary.contract_signed`, `mercenary.payment_paid`, `mercenary.payment_missed`, `mercenary.loyalty_changed`, `mercenary.breach`, `mercenary.contract_completed`.

### Bounty boards per faction

Each faction-controlled base hosts a `BountyBoard` widget (accessed via `act.player.open_bounty_board`). Boards list active bounties; bounties expire on cycle, on target death, or when claimed.

```rust
pub struct Bounty {
    pub bounty_id: BountyId,
    pub poster_faction: FactionId,
    pub target: BountyTarget,
    pub reward: BountyReward,
    pub expires_at_cycle: Cycle,
    pub proof_required: BountyProof,
    pub min_reputation_to_accept: i32,
}

pub enum BountyTarget {
    NamedNpc(NpcId),
    AnyOfFaction(FactionId, u32),              // collect N kills of faction
    NamedBoss(BossId),
    EquipmentValue(ChassisLoadoutHash),        // target carrying a specific high-value rig
}

pub struct BountyReward {
    pub base_amount: u64,
    pub currency: CurrencyId,
    pub per_target_hp_modifier: f32,           // scales with target max HP
    pub per_target_reputation_modifier: f32,   // scales with target's notoriety
    pub per_target_equipment_value_modifier: f32, // scales with sum of M27 item values
}

pub enum BountyProof {
    DogTag,                                    // pick up + return tag
    HeadTrophy,                                // visible loot drop
    KillEventTimestamp,                        // replay event suffices
    CapturedAlive,                             // bring target back to questgiver alive
}
```

**Reward computation** at claim time:

```text
reward = base_amount
       + (target.max_hp / 100.0) * per_target_hp_modifier
       + max(0, target.notoriety) * per_target_reputation_modifier
       + sum(target.equipment.value_bp) * per_target_equipment_value_modifier
```

Bounties on *named NPCs* propagate via M26 narrative (NPC may have voice line + cosmetic flag indicating they are wanted). Anonymous-faction bounties stack across mission cycles.

Events: `bounty.posted`, `bounty.accepted`, `bounty.target_killed`, `bounty.claimed`, `bounty.expired`.

### Taxes per faction (income + transaction + property)

Each faction declares a `TaxPolicy` applied to actors within its territory:

```rust
pub struct TaxPolicy {
    pub faction_id: FactionId,
    pub income_tax_pct: f32,                   // applied to mission rewards earned in territory
    pub transaction_tax_pct: f32,              // applied to Trading Post purchases (M26C)
    pub property_tax_per_cycle: ResourcePool,  // applied per building owned in territory
    pub exemptions: BTreeSet<FactionId>,       // factions exempt from this tax
    pub minimum_reputation_for_exemption: i32, // threshold for ally exemption
}
```

Per-cycle tax events fire `taxation.assessed`, `taxation.paid`, `taxation.evaded` (if player has Smuggler perk + insufficient declared income).

**Evasion path** — players can attempt to under-report mission rewards (Smuggler perk required + roll vs tax-authority audit). Failed audit = `taxation.audit_failed`; penalty = 3× owed tax + reputation -20.

### Tariffs (cross-border goods)

Tariffs apply to specific item categories crossing faction borders:

```rust
pub struct TariffPolicy {
    pub origin_faction: FactionId,
    pub destination_faction: FactionId,
    pub item_category: ItemCategory,
    pub rate_pct: f32,                         // 0.0-1.0
    pub flat_fee: Option<(CurrencyId, u64)>,   // alternative to pct
}
```

When a player crosses a faction border carrying inventory or a caravan crosses with cargo, tariffs are assessed per item category. Player pays at the border or routes through a smuggling path (per M26C contraband concealment).

Launch tariffs: weapons (15%), ammunition (10%), narcotics (banned outright — see M26C contraband), refined-ore (5%), food (0% — most factions waive food tariffs to keep famines from spreading), luxury (20%).

Tariff-evasion is distinct from contraband: tariff items are *legal* but *taxed*; contraband is *forbidden*. Failing a tariff check yields a fine + item *retained* (not confiscated, unless escalated).

### Tribute mechanics (pay-or-be-attacked)

Stronger factions (or factions with grievance — relationship < -30) can demand tribute from the player or from weaker factions. Tribute is a per-cycle drain — failure to pay triggers raid escalation.

```rust
pub struct TributeDemand {
    pub demanding_faction: FactionId,
    pub paying_actor_or_faction: TributePayer,
    pub amount_per_cycle: ResourcePool,
    pub duration_cycles: u32,                  // 0 = permanent
    pub escalation_on_failure: TributeEscalation,
}

pub enum TributePayer {
    PlayerActor(ActorId),
    Faction(FactionId),
}

pub enum TributeEscalation {
    RaidSmall,                                 // 5-actor raid at random base
    RaidLarge,                                 // 15-actor raid at HQ
    DeclareWar,                                // M26 faction.war_declared
    Confiscate { resource: CurrencyId, amount: u64 },  // direct wallet drain (limited to once)
}
```

Tribute can be negotiated (lower amount in exchange for reputation gain), refused (triggers escalation), or transferred to a *patron* faction (a stronger ally agrees to absorb the demand in exchange for service-debt).

Events: `tribute.demanded`, `tribute.paid`, `tribute.refused`, `tribute.escalated`, `tribute.absorbed_by_patron`.

### Faction-specific trade routes

The world has a set of `TradeLane` edges. Each lane has an *operator* faction; only operator-allied or operator-licensed caravans may transit. Hostile traffic gets fired upon by lane wardens.

```rust
pub struct TradeLane {
    pub lane_id: LaneId,
    pub from_port: PortId,
    pub to_port: PortId,
    pub operator: FactionId,
    pub min_reputation_for_transit: i32,
    pub transit_fee: (CurrencyId, u64),
    pub warden_response_on_violation: WardenResponse,
    pub base_throughput_per_cycle: u32,
}

pub enum WardenResponse {
    Warn,                                      // verbal hail; +1 violation count
    Intercept,                                 // patrol ships block + force return
    Engage,                                    // open fire
}
```

Launch lanes (illustrative):

- **Coalition Trunk** (Coalition port A ↔ Coalition port B) — operated by Allied Resistance; min reputation +0; fee 50 CC.
- **Ronin Run** (Mercenary Guild HQ ↔ Marauder market) — operated by Mercenary Guild; min reputation -50 (most welcome); fee 20 RM; smuggling-friendly.
- **Hive Conduit** (Insectoid hive ↔ Insectoid satellite hives) — Insectoid only; non-Insectoid traffic refused.
- **Crystal Caravan** (Crystalline foundry ↔ trading post) — Crystalline; fee 5 CS; pacifist lane (no military cargo).
- **Methane Cryo-Lane** (Methane Breather frigid ports) — Methane Breather; cryogenic cargo only.
- **Aqueous Tide-Route** (Aqueous reef ↔ Aqueous trench) — Aqueous; submarine-only transit.
- **Photosynth Sun-Trail** (Photosynth orchard ↔ sun-aligned port) — Photosynth; transit only during local "day" cycle.
- **Biomech Vector** (Heavy Biomech foundry ↔ depot) — Heavy Biomech; high-fee but high-throughput.

Violating a lane (transit without license / hostile cargo / crossing during embargo) triggers `lane.violation_logged` + the warden response.

### Caravan escort missions (scaling reward)

Caravans are NPC-owned cargo movements along trade lanes. Players can accept escort contracts via M26 quartermasters or via the bounty board:

```rust
pub struct CaravanEscortMission {
    pub mission_id: MissionId,
    pub caravan_id: CaravanId,
    pub lane: LaneId,
    pub cargo_value_bp: u64,
    pub expected_threat_level: ThreatLevel,
    pub reward_base: (CurrencyId, u64),
    pub reward_scaling: EscortScaling,
    pub failure_penalty: (CurrencyId, u64),   // partial cargo-loss liability
}

pub struct EscortScaling {
    pub per_cargo_value_pct: f32,             // 0.0-0.05; reward grows with cargo value
    pub per_threat_level_multiplier: f32,     // multiplier per ThreatLevel step
    pub per_lane_hostility_multiplier: f32,   // multiplier per -10 reputation along lane
    pub bonus_zero_casualty_pct: f32,         // bonus if 0 caravan casualties
    pub bonus_zero_cargo_loss_pct: f32,       // bonus if cargo intact
}

pub enum ThreatLevel { Calm, Restless, Hostile, Warzone }
```

**Reward computation** at completion:

```text
threat_mult     = 1.0 + (threat_level_steps × per_threat_level_multiplier)
hostility_mult  = 1.0 + (lane_hostility_steps × per_lane_hostility_multiplier)
cargo_bonus     = cargo_value_bp × per_cargo_value_pct
zero_cas        = if no_caravan_casualty then reward_base × bonus_zero_casualty_pct else 0
zero_loss       = if cargo_intact then reward_base × bonus_zero_cargo_loss_pct else 0
final_reward    = reward_base × threat_mult × hostility_mult + cargo_bonus + zero_cas + zero_loss
```

Caravans take damage from raiders along the lane (M26 marauders + M48 covert sabotage + M49 PvP players); escort actors must intercept. Failed escort = partial reward + liability penalty.

Events: `caravan.escort_accepted`, `caravan.cargo_damaged`, `caravan.caravan_destroyed`, `caravan.escort_completed`, `caravan.partial_failure`.

## Acceptance criteria

```gherkin
Scenario: Sign per-cycle mercenary contract; payment drains on cycle
  Given a Mercenary Guild NPC offered for hire at 50 RM per cycle, AtWill duration
  And the player wallet has 500 RM
  When the player signs the contract via act.player.sign_mercenary_contract
  Then mercenary.contract_signed fires
  And the mercenary joins the player squad with RoE.fire_at_will=true
  When 1 in-game cycle elapses
  Then mercenary.payment_paid fires; wallet drained by 50 RM
  And loyalty unchanged (payment honored)

Scenario: Missed payment drops loyalty; breach at zero
  Given an active per-cycle contract at 50 RM, base loyalty 1.0, on_missed_payment -0.3
  And the player wallet has 0 RM
  When 4 consecutive cycles elapse with no payment
  Then mercenary.payment_missed fires 4 times
  And loyalty drops to approximately 0.0 at the 4th miss
  And mercenary.breach fires with breach_penalty=Walkout
  And the mercenary leaves the squad and ceases combat

Scenario: Share-per-kill contract pays on engagement
  Given a contract with PaymentTerms::SharePerKill { share_pct: 0.30, currency: RM }
  When the mercenary kills 3 enemies worth 100 RM total bounty
  Then mercenary.payment_paid fires with amount=30 RM after each completion event
  And loyalty rises by on_share_bonus per share collected

Scenario: Bounty reward scales with target HP + equipment value
  Given a bounty with base_amount=1000 CC, per_target_hp_modifier=2.0, per_target_equipment_value_modifier=0.1
  And the target has max_hp=500, equipment_value_bp=4000
  When the player kills the target and presents dog-tag proof
  Then bounty.claimed fires
  And reward_paid = 1000 + (500/100 × 2.0) + (4000 × 0.1) = 1410 CC
  And the wallet credits 1410 CC

Scenario: Anonymous-faction bounty stacks across kills
  Given a bounty BountyTarget::AnyOfFaction(Pirates, 5) at 500 CC reward
  When the player kills 5 Pirate NPCs across 3 missions
  Then bounty.target_killed fires 5 times
  And on the 5th kill, bounty.claimed becomes available
  And the reward is paid in full

Scenario: Per-cycle income tax assessed and paid automatically
  Given the player is in Coalition territory with income_tax_pct=0.10
  And the player earned 1000 CC in mission rewards this cycle
  When the cycle reconciliation runs
  Then taxation.assessed fires with amount=100 CC
  And taxation.paid fires; wallet drained by 100 CC
  And no audit triggered (declared income matches recorded events)

Scenario: Tax evasion attempted and caught by audit
  Given the player has Smuggler rank 2 and earned 1000 CC, declares 500 CC
  And the tax authority audit chance = 0.40 with deterministic seed=7
  When the cycle reconciliation runs and the audit roll succeeds
  Then taxation.audit_failed fires
  And the wallet drains by 3 × 50 CC = 150 CC penalty
  And Coalition reputation drops by 20

Scenario: Tariff applied at border crossing
  Given a caravan carrying 10 units of weapons (category=Weapons) crosses Coalition → Marauder border
  And tariff Weapons Coalition→Marauder = 0.15
  And per-unit base value = 100 CC
  When the border crossing event fires
  Then taxation.tariff_assessed fires with amount=150 CC
  And the caravan owner's wallet is debited 150 CC
  And the cargo is retained (not confiscated)

Scenario: Tribute refused triggers raid escalation
  Given the Hostile Corp demands 200 BT per cycle from the player for 5 cycles
  And the escalation_on_failure = TributeEscalation::RaidSmall
  When the player invokes act.player.refuse_tribute
  Then tribute.refused fires
  And within 2 in-game cycles a 5-actor raid spawns at the player's nearest base
  And tribute.escalated fires with escalation=RaidSmall

Scenario: Tribute absorbed by patron faction
  Given the Hostile Corp demands tribute from the player
  And the player has a +90 alliance with the Allied Resistance
  When the player invokes act.player.request_tribute_patron(Allied Resistance)
  Then tribute.absorbed_by_patron fires
  And the Allied Resistance wallet drains the tribute amount
  And the player owes the patron a service-debt flag (tracked for one downstream mission hook)

Scenario: Trade-lane license required for transit
  Given the Hive Conduit lane has Insectoid-only transit policy
  When a non-Insectoid player caravan attempts transit without license
  Then lane.violation_logged fires
  And the warden_response triggers WardenResponse::Engage
  And lane wardens open fire on the caravan within 5 in-game seconds

Scenario: Caravan escort reward scales with threat + hostility
  Given a caravan escort mission with reward_base=1000 CC, threat_level=Hostile (steps=2), lane hostility=-30 (steps=3)
  And per_threat_level_multiplier=0.5, per_lane_hostility_multiplier=0.2
  And cargo_value_bp=10000, per_cargo_value_pct=0.01 (cargo_bonus = 100 CC)

  And bonus_zero_casualty_pct=0.20, bonus_zero_cargo_loss_pct=0.20
  Then caravan.escort_completed fires

Scenario: Caravan partial failure pays liability penalty
  Given an active escort mission with reward_base=1000 CC, failure_penalty=500 CC
  When raiders kill the caravan mid-route
```

## Out of scope

- **Player-issued bonds + loans** — credit-instrument trading deferred.
- **Inter-shard caravan routing** — single-shard scope; cross-shard convoy is M49.
- **Mercenary squad-level command (10+ hires)** — M46B handles individual NPC contracts; squad-tier contracts deferred.
- **Custom-built trade lanes** — player can't draw new lanes in M46B; lane editor deferred to a later milestone.
- **Per-faction central banking** — M46B has tax/tribute/tariff but no central-bank policy levers.
- **Dynamic bounty board generated from M48 intel** — bounties at M46B are author-curated + storyteller-injected, not yet AI-generated from intel signals.
- **Per-faction currency issuance + exchange rates** — that is M26C scope.
- **Per-vendor inventory rotation** — that is M26C scope.

## Notes for the implementer

- Mercenary loyalty drift MUST seed off engine RNG. Do NOT use `thread_rng` in `cf-mercenary::loyalty`.
- Wallet drains for tax / tribute / tariff / contract payment MUST be atomic with M26C transactions. Use a single transaction queue per cycle reconciliation tick to avoid race conditions when multiple drains fire simultaneously.
- Bounty proof verification must be observable in the replay event stream. A spectator replaying a stream must be able to see exactly which kill event satisfied the bounty (timestamp + actor IDs + weapon).
- Tariff assessment fires at *border crossing event*, not at *cargo-load event*. Players who pre-load cargo before declaring intent to cross still owe tariff on crossing.
- Tribute escalation timing: raids spawn within `[1, 3]` cycles of refusal — do NOT fire instantly (gives player a window to negotiate or pay a patron).
- Caravan escort reward computation MUST be deterministic. Two replays of the same mission with same seed + same player actions must yield identical reward (no `thread_rng` in the scaling pass).
- Trade-lane warden ships should respawn per-cycle so the lane retains its defended character even after player kills.
- The opt-in flag check: when `grand_strategy.enable_upkeep_economy=false`, the cf-taxation and cf-tribute tick handlers MUST short-circuit at the cycle boundary (no events fired, no wallet drain). Mercenary contracts + bounty boards + caravan escorts continue to function — these are mission content, not periodic drains. Document this clearly at the top of each crate's `lib.rs`.
- Do NOT couple mercenary loyalty to M48 morale yet (M48 hooks are forward-compat only; the `bribery_immune` field is reserved but the actual bribery action lives in M48).
