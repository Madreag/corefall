
## Status

`active`

## Intent

**M8 is the modding workbench milestone** — full scenario editor + Lua script editor + mod manifest + workshop integration + photo mode + replay browser + custom HUD editor + IC10 chip editor + 8 tutorial labs. After M8, modders can extend chassis, weapons, materials, atmospheres, missions, AI doctrines, audio, animations, scripts, factions, localization with the same schema-first pipeline as the base game.

M8 promise: **"every part of the game is a mod, written in plain data — players become creators."**

## Player-facing behavior

### In-game scenario editor

- Press `Esc → Editor` (or via mod workbench)
- Paint terrain materials with brush
- Place actors / weapons / waypoints / mission triggers
- Save scenario to local `.ron` file
- Test-play option (reload + start)
- Export to mod package (forward-compat for Steam Workshop)

### Lua script editor

- In-game text editor with syntax highlighting
- Per-actor / per-weapon / per-item callbacks (M2.2 reserved):
  - `OnUpdate(actor)`, `OnFire(weapon, target)`, `OnUse(actor, item)`, `OnDeath(actor, cause)`, `OnHit(projectile, target)`
- Sandboxed: no file I/O, no network, no `os.execute`
- Error reporting with line numbers
- Hot-reload during play (test changes immediately)

### Mod manifest + workshop integration

- Mod package format: `<mod_name>.cfmod` directory with manifest + content + scripts
- `cargo run -p cf-mod -- package <mod_dir>` packages mod
- Steam Workshop integration: upload + subscribe + auto-update
- Auto-generated docs from schemas (rustdoc-style for mods)

### Custom HUD editor

- Player can move HUD widgets (drag-drop full editor; M2.2C had basic)
- Save layout preset
- Multiple presets ("Default", "Tactical", "Minimal", "Streamer")
- Export preset to mod package

### IC10 chip editor

- In-game text editor for IC10 programs (Stationeers-inspired)
- BASIC-like script (subset)
- Read game state: enemy_count, mission_phase, sensor readings
- Trigger actions: waypoints, sounds, lights
- Sandboxed; deterministic execution

### Photo mode full UI (M2.2C had basic)

- Full filter palette (sepia, B&W, cyberpunk, noir, vintage, posterize, etc.)
- Color grading curves
- Depth of field control
- Camera path animation (keyframe + interpolation)
- Export to PNG / sequence / video

### Replay browser full

- Scrubbable timeline (M2.2C had mini-scrub)
- Multi-bundle navigation
- Filter + search across bundles
- Bookmark sharing
- Export clip → MP4 (forward-compat)

### 8 modular tutorial labs (per DR-023)

- Each lab 2-5 minutes; standalone
- Topics:
  1. Movement basics (sprint / crouch / lean / vault)
  2. Weapons + fire modes
  3. Grenades + arc preview
  4. Tools + terrain interaction
  5. AI + cover seeking
  6. Mission objectives + branching
  7. Squad commands + 4 verbs
  8. Stealth + perception
- Tutorial mode HUD reminders ("PRESS X TO CROUCH")
- Forward-compat for M7+ full onboarding

### Mod parity contract (per DR-045)

- Every base-game feature MUST be mod-reachable
- New gas, reaction, world, actor, weapon, tool, grenade, mission, archetype, doctrine, audio, animation, faction, localization → all data rows
- Lua escape hatches for affliction logic / device behavior
- AI-driven test runs validate mods don't break determinism

## Acceptance criteria

```gherkin
Scenario: Scenario editor saves + tests
  Given editor mode active
  When player paints terrain + places actors
  And saves scenario:
    Then editor.scenario_saved fires
  When player chooses "Test Play":
    Then scenario loads + simulation starts

Scenario: Lua script hot-reload
  Given Lua script attached to weapon
  When player edits script in editor + saves:
    Then script.hot_reloaded fires
    And new behavior applies immediately

Scenario: Mod package + workshop upload
  Given mod directory
  When cargo run -p cf-mod -- package <mod>:
    Then .cfmod file created
  When Steam Workshop upload:
    Then mod.published fires
    Other players can subscribe + auto-update

Scenario: Photo mode full UI
  Given F12 + photo mode active
  When player applies sepia filter + adjusts color grading + saves keyframe path:
    Then photo.shot_taken fires
    And exported PNG / sequence

Scenario: Replay browser scrub
  Given replay bundle loaded
  When player drags timeline:
    Then replay.scrubbed fires
    And scene plays at scrub position

Scenario: All 8 tutorial labs complete
  Given player runs each lab
  Then tutorial.lab_completed fires for each
  And all 8 marked complete in progression

Scenario: IC10 chip controls door
  Given IC10 chip with program "if sensor > 5 → open_door"
  When sensor reads > 5:
    Then script.chip_executed fires
    And door opens

Scenario: Mod parity — custom material
  Given mod with custom material "antimatter"
  When loaded:
    Then cf-material registry includes "antimatter"
    And cf-physics uses correct affordances
    And cf-render-2d shows correct color signature
    And replay events include "antimatter" identifier
    And determinism CI matrix PASSES with mod loaded
```
