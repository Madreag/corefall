# M40B — Online UX (Server Browser + Friends + Party + Lobby + Admin Panel)

## Status

`active`

## Intent

**M40B is the online UX milestone** — full UX for multiplayer-facing surfaces: server browser (LAN + online + lobby_directory; filterable + sortable + favorites), friends list (Steam + Discord cross-platform), party invite UI (invite + accept + ready-up), pre-game lobby (loadout select + role assignment + ready state + voice chat), server admin web panel (per M38 + M36A), mod hash sync UI (clean diff on mismatch), Workshop subscription browser, voice chat UI (push-to-talk + channel select).

**Why after M40A (spectator + streamer):** by M40A close, LAN co-op + spectator + streamer tooling all exist. M40B polishes the multiplayer-CONNECTING UX so players find each other + join sessions smoothly.

**Why this milestone exists:** Steam community + Discord + LAN play all live and die by lobby UX. Without M40B, players struggle to find servers + invite friends + join parties. With M40B, multiplayer feels seamless.

M40B promise: **"finding a server takes <30 seconds; inviting friends works instantly via Steam + Discord; party invites + ready-up + role assignment + loadout select all in lobby; admin panel webview accessible via browser; mod conflicts have clean diff UI; voice chat works out-of-box."**

## Player-facing behavior

### Server browser (LAN + online + lobby_directory)

Per M36 lobby_directory + M40 LAN + M41 online:

- **3 source tabs** — LAN / Online (lobby_directory) / Favorites
- **Filter sidebar:**
  - Mode (coop_room / pvp_arena / lan_room / mmo_shard / lobby_directory)
  - Scenario (per-scenario filter; campaign / PvE survival / endgame mode / specific scenarios)
  - Player count (1-2 / 3-4 / 5-8 / 8+ / not-full)
  - Region (auto-detect; or manual: NA/EU/APAC/SA)
  - Ping (best ping first; max ping filter)
  - Mods (vanilla / verified / community / experimental; per-mod whitelist)
  - Anti-cheat profile (casual / competitive / tournament_strict)
  - Server name search
  - Friends-only filter (only servers with friends in-session)
- **Server list:**
  - Per-row: name + scenario + players + ping + region + mods badge + anti-cheat badge
  - Per-row Steam friend indicators (badges showing friends in-session)
  - Per-row mod-compatibility badge (vanilla = green; mismatch = red)
  - Per-row sort: Name / Players / Ping / Mode / Scenario / Recently-played
  - Right-click context menu: Join / Favorite / Report / Block server
- **Per-row preview pane:**
  - Server description (from server admin)
  - Scenario thumbnail (from cf-asset-ledger)
  - Player list (with Steam friend highlights)
  - Active mods + version
  - Server uptime + tick rate
  - Recent player count graph (last 24h)
- **Refresh** — auto-refresh every 30s; manual refresh button
- **Quick-join** — one-click join via Steam invite or LAN discovery
- **Code-based join** — enter 6-character invite code (private servers; per M41)
- **Steam Big Picture mode** — controller-friendly layout

### Friends list (Steam + Discord cross-platform)

Per M36A platform integration:

- **Per-platform sources:**
  - Steam friends (per M36A Steam SDK)
  - Discord friends (per M36A Discord integration)
  - Corefall friends list (per M36A internal accounts)
- **Per-friend card:**
  - Avatar + nickname
  - Current status (Playing Corefall / In Lobby / Idle / Offline)
  - Current activity (scenario + role + party status)
  - Per-platform indicator (Steam / Discord / etc.)
  - Quick actions: Invite / Join / Message / Mute / Block / Unfriend
- **Filter** — by platform / status / recently-played / friend-of-friend
- **Search** — keyword
- **Recently-played-with** — auto-list of recent co-op partners; quick-invite
- **Friend invite via Steam invite link** — copy + share link
- **Friend invite via Discord** — embed Rich Presence (per M36A)
- **Block + unblock** — per M36 anti-griefing
- **Mute + unmute** — per-friend voice chat

### Party invite UI

Per M41 multiplayer + M36A platform:

- **Create party** — invite up to 8 players (max coop_room player count)
- **Per-party state:**
  - Current scenario (set by party leader)
  - Per-player ready state
  - Per-player role assignment (Rifleman / Sniper / Engineer / Medic / Heavy / Recon / Tech)
  - Per-player loadout preview
- **Invite via Steam friends** — Steam invite popup
- **Invite via Discord** — Discord invite link
- **Invite via 6-character code** — public party with code
- **Per-party voice chat** — automatic Push-to-Talk channel
- **Per-party text chat** — separate channel from public
- **Per-party leader privileges** — change scenario / kick player / promote new leader
- **Ready-up flow** — all players Ready → leader Confirms → match starts

### Pre-game lobby

Per M40 ready-up + M41 multi-squad:

- **Lobby layout:**
  - Left: player slots (up to 8) with per-player loadout previews
  - Center: scenario preview + briefing (from M25A + M48B trailers)
  - Right: chat + voice
- **Per-slot loadout select:**
  - Per-player gear selection from M27A
  - Per-player cosmetic loadout from M27A
  - Per-player role assignment (M41 7 squad roles)
  - Per-player ready state (Not Ready / Ready / Confirmed)
- **Per-player kick + report** — leader can kick disruptive players
- **Pre-match mod sync** — per-player mod-hash check; clean diff UI on mismatch
- **Per-mod auto-subscribe** — if mismatched mod is on Workshop, prompt to subscribe
- **Pre-match difficulty adjustment** — leader picks AI difficulty + storyteller
- **Pre-match world selection** (PvE survival) — leader picks world per M43 procgen seed
- **Confirm start** — all players must be Ready; leader confirms; match begins

### Server admin web panel

Per M38 admin CLI + M36A platform:

- **Accessible via browser** — `http://<server>:<admin_port>/`
- **Authentication** — admin token per M38 server.ron
- **Dashboard tabs:**
  - **Overview** — server stats (uptime / players / tick rate / load / crashes)
  - **Players** — real-time player list + ban + kick + mute
  - **Mods** — whitelist + version sync + Workshop integration
  - **Settings** — live edit server.ron settings per M38
  - **Logs** — server log stream per M38 admin CLI
  - **Alerts** — cheater alerts from M36B telemetry; real-time stream
  - **Backup + Restore** — save management; restore from snapshot
  - **Per-shard analytics** — M49 MMO dashboard
- **Per-action audit log** — all admin actions logged for compliance
- **Per-platform integration** — Steam VAC report; EOS abuse report
- **Web-friendly** — responsive layout; mobile-friendly for emergency admin

### Mod hash sync UI

Per M36 + M33 + M41 mod hash check:

- **On lobby join** — server checks client mod hashes
- **Match results:**
  - All match → join succeeds
  - Mismatch → clean diff UI shown
- **Clean diff UI:**
  - "Your client has: <mod1 v1.2>, <mod2 v0.9>"
  - "Server expects: <mod1 v1.3>, <mod2 v0.9>, <mod3 v1.0>"
  - Per-mod action: Subscribe + auto-download / Update existing / Disable / Cancel join
- **Auto-resolve option** — auto-subscribe missing mods + update outdated; one-click
- **Per-mod trust tier check** — server-allowed trust tiers respected

### Workshop subscription browser

Per M36A Steam Workshop integration:

- **Workshop browser in-game** — accessible from main menu + lobby
- **Browse by category** — Mods / Cosmetics / Scenarios / Tutorials / Languages / Asset Packs
- **Search** — keyword + tag filter
- **Sort** — Popular / Trending / Newest / Most Subscribed / Highest Rated
- **Per-item card:**
  - Title + author + preview image
  - Subscribers + ratings + last-updated
  - Per-item trust tier
  - Subscribe button (one-click)
  - Per-item description + screenshots + changelog
- **Per-server suggested mods** — when joining a server, suggested mods from server admin
- **Per-friend recommendations** — Steam friends' subscribed mods
- **Per-creator follow** — follow modder for new releases

### Voice chat UI

Per M37 voice + M37A voice synthesis:

- **Push-to-Talk** — hold [V] (remappable) to speak; release to mute
- **Voice activity** — auto-detect speech; per-player VAD threshold
- **Channel select:**
  - Squad (party-only)
  - Public (server-wide; per M37 propagation)
  - Faction (faction-only; if in mission)
  - Whisper (1-on-1; click player avatar)
- **Per-channel volume** — independent volumes
- **Per-player mute** — right-click player → mute (session-only)
- **Per-player block** — permanent mute across sessions
- **Voice-activity icon** — speech indicator near player nameplate
- **Text-to-speech accessibility** — Settings.tts_for_voice_chat reads voice as captions per M11 + M38A
- **Push-to-mute** — Shift+[V] mutes all incoming voice for 30s (anti-griefing)

## Notes for the implementer

### Architecture rules

- **Server admin web panel via embedded HTTP server** — cf-server-admin-web hosts on configurable port
- **Voice chat opt-in** — Settings.voice_enabled (default true; muted by default for safety)
- **Mod sync deterministic** — per-mod blake3 hash + version comparison

### Decision-record alignment

- **DR-046 (player-facing surfaces)**: multiplayer UX
- **DR-034 (dedicated server)**: admin web panel
- **DR-006 (mod parity)**: Workshop integration

### Pitfalls

- **NAT traversal failure**: M41 handles; M40B reports clearly
- **Voice chat latency**: target <100ms
- **Mod conflict resolution**: server admin policy varies
