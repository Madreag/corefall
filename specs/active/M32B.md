# M32B — Crafting Panel + Research Tree + Salvage UX

## Status

`active`

## Intent

**M32B is the crafting + research tree + salvage UX milestone** — full UX for the M32 fabrication chain: crafting panel (Stationeers/Terraria hybrid; 150 launch recipes), research tree visualizer (30 nodes across 5 tiers), recipe queue management, salvage panel (item breakdown), modification attachment UI (Noita-style mod slots; combinatorial preview), material refining flow visualization (M30 → M32 chain), per-station hot-bar.

**Why after M32A (Tier 2 ComfyUI):** by M32A close, all crafting station art + recipe icons are Tier 2 quality. M32B polishes the UX so players can navigate the 150-recipe ladder + 30-node research tree + per-station fabrication flow.

**Why this milestone exists:** crafting is the SECOND-most-used screen after inventory. Stationeers + Terraria + Factorio + Diablo all have crafting screens with rich UX. M32 spec sketches the UX at concept level; M32B fills in the production-quality UX.

M32B promise: **"crafting feels like Stationeers + Terraria + Factorio combined; 150 recipes navigable in seconds; research tree visualized at Factorio quality; modification slots Noita-style stackable; salvage breakdown clear; recipe queue Factorio-style drag-reorder."**

## Player-facing behavior

### Crafting panel (Stationeers/Terraria hybrid)

Per M32 concept; M32B fills:

**Layout (3-pane):**
- **Top bar** — tier filter (T0/T1/T2/T3/T4) + station filter + category filter (weapons / armor / chassis / tools / base / power / vehicles / consumables / mods / cosmetics)
- **Left pane (recipe list)** — scrollable; rarity-color borders; per-recipe icon + name + tier-icon
- **Center pane (selected recipe card)** — full recipe details:
  - Inputs (per-material count + have/need with color-coded bars)
  - Outputs preview (with rarity color)
  - Time bar (estimated craft duration)
  - Power requirement (live grid check via M29)
  - Station-availability check
  - Temperature + atmospheric requirements (per M32 / M19)
  - Success rate (with failure mode tooltip)
  - Per-recipe unlock condition (if locked)
- **Right pane (queue)** — multi-recipe queue; drag-reorder; pause/cancel/clear
- **Bottom** — CRAFT button + cost feedback + tooltip + station-walk indicator

**Recipe filtering:**
- **Search** — keyword + per-input filter (e.g. "uses iron" finds all iron recipes)
- **Per-tier filter** — T0 / T1 / T2 / T3 / T4 with locked-tier greyed-out
- **Per-station filter** — Workbench / Smelter / Fabricator / Assembly Line / Plasma Forge / Enrichment Reactor / Material Lab / Exotic-Matter Forge
- **Per-category filter** — Weapons / Armor / Chassis / Tools / Base / Power / Vehicles / Consumables / Mods / Cosmetics
- **Per-craftable filter** — "Show only craftable" hides locked + missing-material recipes
- **Sort** — Name / Tier / Time / Cost / Rarity / Recently-used

**Per-recipe context:**
- **Affordable preview** — green check if all materials present
- **Walking distance** — if station not at player location, show distance + ETA
- **Power preview** — live M29 check; warns if brown-out risk
- **Atmospheric preview** — temperature + pressure + atm composition requirements
- **Success probability** — T2: 95%; T3: 85%; T4: 70% per M32; with retry-bonus per perk

**Recipe queue management:**
- **Add to queue** — multi-add: Shift+click adds 5; Ctrl+click adds 10
- **Drag-reorder** — drag recipe in queue to reorder
- **Pause queue** — pause-all + per-recipe pause
- **Cancel + refund** — cancel returns 50% materials per M32
- **Per-queue capacity** — Workbench 5; Fabricator 10; Assembly Line 20
- **Auto-fabricate-when-materials-arrive** — set queue + walk away; auto-crafts as materials arrive

### Research tree visualization

Per M32 30 launch research nodes + tree structure:

**Tree layout (Factorio-style):**
- **Per-tier rows** — 5 horizontal rows (T1 / T2 / T3 / T4 / Cross-tier-bonus)
- **Per-node card** — icon + name + RP cost + unlocks (recipes / abilities / multipliers)
- **Per-node prereqs** — visual lines connecting prereq nodes
- **Per-node status** — Researched (green) / Available (blue) / Locked (greyed)
- **Hover tooltip** — full description + unlocked recipes preview
- **Pan + zoom** — drag canvas; mousewheel zoom; controller dpad navigation
- **Search** — find research node by name; canvas auto-centers
- **Per-node click** — opens full detail panel
- **Progress bar per active research** — current RP / required; ETA based on RP/cycle
- **Branch overview** — minimap shows where in tree you are
- **Per-faction unlock prereqs** — some nodes require faction reputation (per M26 quartermaster integration)
- **Boss-drop nodes** — some nodes require defeating bosses (per M45)
- **Material-lab nodes** — T4 requires Material Lab puzzles (per M34)

**Research panel UX:**
- **Active research display** — top of screen during gameplay; "Researching: Industrial Metallurgy (32/50 RP)"
- **Set active research** — click any Available node; if RP-poor, queue for when RP available
- **RP investment** — drag-slider; per-faction RP grants (per M26)
- **Per-node lore** — flavor text from M25A bible; ties research to story

### Salvage panel UX

Per M32 salvage system + M27 inventory:

- **Salvage station UX** — open at salvage station
- **Drag item from inventory** — material breakdown preview
- **Per-item recovery preview** — "Iron Rifle → 8 iron + 3 plastic + 1 motor (75% of placement cost)"
- **Specialist perk** — "Salvage Master" perk shows 90% recovery (per M27 perks)
- **Damaged-item modifier** — damaged items recover less (50% × damage_pct)
- **Byproducts** — some items produce unique byproducts ("scrap_chips" from electronics)
- **Time + power cost** — "30s + 1 kW per item"
- **Bulk salvage** — multi-select inventory items; queue salvage operations
- **Per-item warning** — "This is a Rare item; you'll lose Affixes"
- **Confirm hold-to-confirm** — destructive action per M11

### Modification attachment UI (Noita-style)

Per M27 modification system + M13 modifier slots:

- **Per-weapon mod slot panel** — visible when weapon equipped at workbench
- **Per-tier slot count** — T1 weapon 0-1 slots; T2 1-2; T3 2-3; T4 3-4 (per M13)
- **Drag mod from inventory** — drop onto slot
- **Combinatorial preview** — live preview of stacked mod effects ("homing + explosive + freezing" → bullets home, explode on impact, freeze)
- **30+ launch mods** — homing / explosive / freezing / electric / poisoning / bouncing / piercing / ricochet / bleed / stun / fire_chain / double_tap / triple_shot / fast_fire / slow_fire / slow_motion_on_kill / summon_minion / gravity_well / vortex / magnet / time_slow_on_hit / healing_burst / life_steal / mana_burst / shield_break / armor_piercing_random / knockback / weighted / magnetic / chain_lightning / frost_aura
- **Mod compatibility warnings** — "homing + ricochet may have unintended physics"
- **Mod cost preview** — placement consumes the mod (one-time)
- **Per-weapon save loadout** — save modded weapon as preset

### Material refining flow visualization (M30 → M32 chain)

Per the M30 + M32 fabrication chain:

- **Per-base material flow diagram** — Sankey-style; per-material flow arrows
- **Per-stage rate** — extraction → refining → smelting → fabrication
- **Per-station throughput** — per-recipe-per-station current rate
- **Bottleneck identification** — red highlights stalled steps
- **Auto-optimize suggestion** — "Add 2 more smelters to clear iron backlog"
- **Per-resource buffer state** — current stock levels per material
- **Recipe surge** — if player queues big crafts, show resource forecast

### Per-station hot-bar

- **8-slot hot-bar per station** — most-used recipes per station
- **Per-player customizable** — drag recipe to slot
- **Per-station defaults** — Workbench default: iron_pickaxe / iron_axe / etc.
- **Per-keyboard shortcut** — number keys 1-8 trigger recipe craft (when station selected)

### Tier-progression overview (extends M27A)

- **Per-tier completion** — % of recipes unlocked + % of materials accessed
- **Next-tier milestone** — "Research Plasma Engineering to unlock T3"
- **Per-tier visual flair** — Tier-up animation when crossing milestone (per M12 juice rules)

## Notes for the implementer

### Architecture rules

- **Crafting reads + writes sim state** — recipes consume materials + produce items deterministically per replay
- **Research tree state is per-faction** — multi-player per-faction RP pool (per M26)
- **Mod slot stacking is deterministic** — same mods + same weapon = same combined effect per replay

### Decision-record alignment

- **DR-046 (player-facing surfaces)**: crafting UX = Stationeers/Factorio quality
- **DR-031 (anti-pay-to-win)**: no recipe locked behind real money

### Pitfalls

- **Recipe list perf at 150 entries**: virtualize list rendering
- **Research tree layout for 30 nodes**: pre-compute layout per release; mods extend
- **Combinatorial mod preview accuracy**: pre-validate stacking rules per M13 + M27 mod system

### Closure procedure

1. Reference flow: player navigates crafting → research → salvage → mod attachment + queues 10 recipes.
2. Self-play sweep rows: `m32b_crafting_panel`, `m32b_recipe_filter_search`, `m32b_queue_management`, `m32b_research_tree`, `m32b_salvage_station`, `m32b_mod_slots`, `m32b_material_flow`, `m32b_station_hotbar`, `m32b_acc_a`. All PASS.
3. Move M32B → done/.
