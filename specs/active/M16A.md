# M16A — Atmospheric + Environmental Afflictions Depth Layer

## Status

`active`

## Intent

**M16A is the atmospheric + environmental affliction depth layer** between M16 (parent: 22 affliction roster) and M16B (diseases) / M16C (mental health). M16 ships the affliction *event surface* (`affliction.applied / escalated / cleared`) and the launch roster (hypoxic / hyperthermic / hypothermic / etc.); M16A ships the **per-condition consumer kernel** that turns M19/M28/M9 environment events into actor-side affliction state — accumulators, threshold transitions, race-aware TTD curves, and per-affliction clear conditions for the 11 environment-driven affliction kinds that M16 names but does not deep-implement.

M16A's player-facing promise: **"the environment doesn't just kill you — it wears you down through a dozen named, readable mechanisms you can plan around."**

## Canonical ownership

Canonical owner of the **environment-driven affliction kernel** — accumulator math, threshold transitions, per-origin susceptibility (atmospheric-affliction slice of the M17 matrix), per-affliction clear conditions, and the affliction-strip consumer hooks for the 11 affliction kinds listed below.

**Sibling-spec relationships:**

| Layer | Owner |
|---|---|
| Hazard tiles (fire / smoke / electric / wet / hot-cold) + 22-affliction event surface roster | **M16 (parent)** |
| Disease registry (slimelung / cholera / etc.) | M16B |
| Mental health (PTSD / depression / addiction / pain) | M16C |
| **Atmospheric + environmental afflictions (this spec)** | **M16A (this spec)** |
| Per-origin susceptibility matrix (10 races × all afflictions) | M17 (canonical) — M16A consumes the atmospheric slice |
| Hazard producers (atmosphere thresholds, room temperature, electrical contact) | M19, M19E, M19F, M19G, M28B, M28D, M28E, M9B, M9C |

M19 / M28 / M9 produce the *triggers*; M16A owns the *consumer-side state machine* per affliction kind.

## Player-facing behavior

### 11 launch environment-driven afflictions (deep mechanics)

M16's parent roster names these 11; M16A ships the consumer kernel.

| Affliction | Producer | Accumulator | Threshold for affliction.applied | Per-tick effect | Clear condition |
|---|---|---|---|---|---|
| **stuffiness** | M19F (humidity > 70% + CO2 > 0.4% + occupants ≥ 4) | `stuffy_seconds` (1.0 / tick when triggered) | 600s = mild; 1800s = moderate | stamina drain × 1.2; mild morale −1 / min | leave room OR ventilate (CO2 < 0.2%) |
| **heatstroke** | M19G / M28B / M28D (T_room > comfort_max per M17 origin) | `heat_load_celsius_seconds` (ΔT × dt) | 300°C·s = mild; 900°C·s = severe | speed × 0.85; aim wobble × 1.4; HP −1 / 30s | T_room back in comfort + 5 min cooldown OR cold-water immersion |
| **hypothermia** | M19G / M28B / M28D (T_room < comfort_min per M17 origin) | `cold_load_celsius_seconds` (ΔT × dt) | 300°C·s = mild; 900°C·s = severe | speed × 0.85; aim wobble × 1.4; HP −1 / 60s | T_room back in comfort + 5 min cooldown OR warm enclosure |
| **asphyxiation** | M28E (halon dump / CO2 flood without breathing apparatus) | `asphyxia_seconds` (1.0 / tick while in low-O2 ambient) | 30s = mild; 90s = lethal | HP −2 / s after threshold; vision tunneling | return to breathable atmosphere |
| **refrigerant_inhalation** | M28E (R-22 / ammonia / CO2 supercritical leak) | `refrigerant_partial_pressure_seconds` (PP × dt) | 50 kPa·s = mild; 200 kPa·s = severe | nausea + aim wobble × 1.6; HP −1 / 10s; lung damage (M16B chronic feed) | leave room + decontaminate suit + 10 min cooldown |
| **electrocution** | M9C (electrified fence) / M16 hazard `electric` tile contact | instant + `arc_count` (per shock event) | 1 shock = stunned 0.5s; 3 shocks = unconscious | actor.stance = Stance::KnockedDown for 5s per shock; HP per shock energy | wait OR insulator removes ongoing contact |
| **illuminated** | M9C (spotlight cone) | `illuminated_seconds` (1.0 / tick while in cone) | always-on while in cone; no escalation | reveal-on-AI flag (AI hearing range × 1.5); concealment removed | leave cone OR destroy spotlight |
| **laceration** | M9C (razor wire) / M14 swept_collision bladed hit | instant + `bleed_severity` per wound | tag stacks (M14G wound-list consumer) | HP −1 / 60s per stack; +bleed_stack toward M16 bleeding auto-triage | bandage + 30s tend per wound |
| **trench_foot** | M9B (wet duckboards / submerged feet) | `wet_duckboard_seconds` (1.0 / tick while feet submerged in cold liquid) | 7200s = mild; 21600s = severe | speed × 0.9; +infection-rate to M16B sepsis pathway | dry boots + 24 in-game hours warm + dry |
| **stamina_movement_cost** | M9C (MG portable, heavy weapon equipped) / encumbrance | `extra_kg_carried` × dt | always-on; severity proportional to load above baseline | stamina drain × (1 + load_factor); rest cooldown × 2 | drop heavy weapon OR reach base resupply |
| **panic_freeze_env** | M19E (analyzer combustible-mix alarm acknowledged but not addressed) / extreme breach event | event-driven (no accumulator; one-shot per trigger) | always fires on trigger | actor.stance = Stance::PanickedFreeze for 3-8s (M16C panic disorder shares FSM) | wait timer OR squadmate stabilize action (M22) |

### Per-origin susceptibility (atmospheric slice; M17 canonical)

M16A consumes the M17 origin matrix and exposes the atmospheric-affliction slice as a typed view:

```rust
pub struct AtmosphericSusceptibility {
    pub origin_id: OriginId,
    pub stuffiness_multiplier: f32,         // robot = 0; methane_breather = 0.5
    pub heat_comfort_max_k: f32,            // human = 322 (49°C); crystalline = 423
    pub cold_comfort_min_k: f32,            // human = 273 (0°C); aqueous = 263
    pub asphyxiation_ttd_s: f32,            // human = 30; methane_breather = IMMUNE in O2
    pub refrigerant_inhalation_multiplier: f32,
    pub electrocution_resistance: f32,      // robot tolerant; aqueous low
    pub trench_foot_multiplier: f32,        // aqueous = 0; human = 1.0
    pub stamina_cost_multiplier: f32,
}
```

M17 owns the full matrix; M16A reads it once per actor at spawn + caches.

### Auto-triage trigger hooks (M16 parent contract)

Each affliction above contributes to the M16 auto-triage threshold per its severity. M16A exposes the per-affliction `severity` field on the actor's affliction stack; M16 reads it to compute the Medic utility bonus per M16's auto-triage trigger contract. M16A does NOT own the trigger; it owns the severity producer.

### Affliction-strip HUD consumer

M16A populates the per-actor affliction icons + tooltips for these 11 kinds on the M16 affliction-strip widget. Each affliction has:
- icon ID (per `content/affliction_icons/*.png`)
- severity bar (0.0 — 1.0)
- tooltip text (cause + per-tick effect + clear hint)
- color-coded by severity (yellow / orange / red)

## Acceptance criteria

```gherkin
Scenario: Stuffiness affliction in crowded uncooled room
  Given 6 actors in a closed room with humidity 80% + O2 18 kPa + CO2 0.4%
  When 10 in-game minutes elapse (stuffy_seconds > 600)
  Then affliction.env_threshold_crossed fires with kind=stuffiness, severity=mild
  And each actor's stamina drain × 1.2
  And HUD affliction-strip shows yellow stuffiness icon
  When the room ventilates and CO2 drops below 0.2%
  Then affliction.env_cleared fires for all 6 actors

Scenario: Uninsulated room on Mimas accumulates hypothermia
  Given a sealed concrete room at 20°C with ambient -180°C and no heater (M19G consumer scenario)
  When T_room drifts toward ambient and crosses 0°C for a human actor
  Then per-tick cold_load_celsius_seconds accumulates
  And at 300°C·s, affliction.env_threshold_crossed fires with kind=hypothermia, severity=mild
  And speed × 0.85; HP −1 / 60s
  When the actor enters a heated airlock + 5 min cooldown
  Then affliction.env_cleared fires

Scenario: Halon dump asphyxiates unsuited actor (M28E consumer)
  Given a sealed server room with active fire + halon_dump triggered (M28E producer)
  And an unsuited human actor in the room
  When halon flood completes and O2 partial pressure < 16 kPa
  Then affliction.env_threshold_crossed fires with kind=asphyxiation, severity=mild within 30s
  And HP −2 / s after threshold
  When 90s elapse without rescue
  Then affliction.env_threshold_crossed fires with severity=lethal
  And actor.died fires (M14 lethality consumer)

Scenario: Refrigerant leak inhalation (M28E consumer)
  Given a base AC develops an R-22 leak in a sealed room (M28E producer)
  And an actor breathes the contaminated atmosphere
  When refrigerant_partial_pressure_seconds > 50 kPa·s
  Then affliction.env_threshold_crossed fires with kind=refrigerant_inhalation, severity=mild
  And the actor's aim wobble × 1.6 + HP −1 / 10s
  And M16B sepsis-feed flag set (chronic lung damage forward-compat)

Scenario: Electric fence shock applies electrocution affliction (M9C consumer)
  Given an electrified fence (M9C producer) with an actor touching it
  When the actor receives 80 J shock damage
  Then affliction.env_threshold_crossed fires with kind=electrocution
  And actor.stance = Stance::KnockedDown for 5s
  And arc_count increments
  When the actor takes 3 shocks within 10s
  Then severity escalates to unconscious; KO grace per M16 concussion contract

Scenario: Razor wire laceration stacks (M9C consumer)
  Given an actor crossing razor wire (M9C producer; 4 dmg/tick)
  When the per-tick env affliction pass runs
  Then affliction.env_threshold_crossed fires with kind=laceration

Scenario: Trench foot from wet duckboards (M9B consumer)

  When the env affliction pass runs
  Then affliction.env_threshold_crossed fires with kind=trench_foot, severity=mild
  And speed × 0.9
  And M16B sepsis-feed flag set (infection-rate elevated)
  When the actor dries feet + spends 24 in-game hours in warm + dry conditions
  Then affliction.env_cleared fires

Scenario: Spotlight illuminated status reveals concealment (M9C consumer)
  Given an actor in concealed posture entering a spotlight cone (M9C producer)
  Then affliction.env_threshold_crossed fires with kind=illuminated
  And AI hearing/spotting range × 1.5 against this actor
  When the actor leaves the cone OR the spotlight is destroyed
  Then affliction.env_cleared fires

Scenario: Heavy weapon stamina cost (M9C consumer)
  Given an actor equipping mg_tripod_portable (M9C producer; +400 kg weight)
  Then affliction.env_threshold_crossed fires with kind=stamina_movement_cost
  And stamina drain × (1 + load_factor)
  When the actor drops the weapon
  Then affliction.env_cleared fires

Scenario: Per-origin immunity (methane breather in O2 atmosphere)
  Given a methane-breather actor in Earth-standard atmosphere

  Then affliction.env_origin_immune fires with kind=asphyxiation, reason="oxygen_toxic_origin"

Scenario: Auto-triage hook surfaces severity to M16 Medic doctrine

  Then it sees heatstroke.severity=0.9 + hypothermia.severity=0.4

Scenario: Determinism across environment afflictions

  And SaveBlob.checksum identical at tick 600
```

## Notes for the implementer

- All 11 affliction accumulators share a single `cf-affliction::env::tick_all(actor, env_signals, dt)` entry point — runs at 1/N=5 ticks cadence (perf-bound; per-tick check expensive across all actors).
- The env-signal aggregator is M20's EnvironmentSignal slice; M16A reads atmospheric / thermal / em / electric slices.
- Per-origin immunity short-circuits the accumulator at function entry; no state mutation if `multiplier == 0`.
- Severity bands are tunable per affliction in `content/afflictions/env/*.ron`; mod-extensible.
- Cleared afflictions emit `affliction.env_cleared` but do NOT remove the actor's tolerance memory — repeated exposures escalate faster (forward-compat slot for M16A+1 adaptation curves).
- Determinism: accumulator order is per-actor-id ASC; tied with affliction-kind enum order. Never iterate by HashMap.
- The 11 RON files share a common schema; modders can add new env-driven affliction kinds via the same registry (M16A is the canonical schema authority).
