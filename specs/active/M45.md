# M45 — PvE Endgame Bosses + World Events

## Status

`active`

## Intent

**M45 is the PvE endgame milestone** — the 5 named bosses + 12 dynamic world events that give 100+ hour PvE Survival runs their narrative spine. After M45, every PvE world has 1-2 boss encounters, every session has dynamic storyteller events, and endgame progression unlocks unique recipes + artifacts + lore.

M45 splits this out of M43 because boss content + storyteller events are their own coherent scope. M43 ships the survival mechanics + procgen; M44 ships transport; M45 ships endgame challenge.

M45 promise: **"100 hours in, you face the Hollow King in Earth's volcanic core, the Frozen Heart in Europa's caverns, the Last Star on Vulcan — each kill rewriting your civilization."**

### Faction Resistance Levels (AWAW Rule 60 — Opt-In Graduated Collapse)

**Opt-in per server.** Default `server.ron` has `grand_strategy.awaw_rulesets.enable_faction_resistance_levels=false`. Hardcore PvE Survival / persistent MMO recommends ON.

Instead of binary "alive/collapsed", factions cascade through **5 resistance levels** based on cumulative losses + bankruptcy.

#### Resistance Level system

```rust
pub struct FactionResistance {
    pub faction_id: FactionId,
    pub current_level: ResistanceLevel,             // 0 / -1 / -2 / -3 / -4 / surrender
    pub cumulative_losses_bp: f32,                  // running total
    pub last_level_change_tick: Tick,
    pub recovery_possible: bool,                    // can the faction climb back?
}

pub enum ResistanceLevel {
    Level0,         // healthy faction; no penalties
    LevelMinus1,    // 20 BP of units lost OR 1-day deficit (per M46 cascade)
    LevelMinus2,    // 40 BP of units lost OR 3-day deficit (per M46 cascade)
    LevelMinus3,    // 60 BP of units lost OR 7-day deficit (per M46 cascade)
    LevelMinus4,    // 80 BP of units lost OR 14-day deficit (per M46 cascade)
    Surrender,      // 100+ BP of units lost OR 30-day deficit (per M46 cascade)
}
```

#### Deficit-day ↔ resistance-level mapping (canonical alignment with M46)

M46 owns the bankruptcy day-cascade canonical schedule (1 / 3 / 7 / 14 / 30 days). M45 owns the resistance-level state machine but synchronises the deficit-day axis to M46's schedule so the two systems advance in lockstep. The mapping below is the single authoritative table; any future change to either side must update both specs:

| M46 deficit-day milestone | M45 resistance level | Combined effect (M46 cascade + M45 modifiers) |
|---|---|---|
| Day 1 deficit | Level -1 | low-morale flag (-20% combat) + -1 DP/cycle + combat × 0.95 + defensive × 1.10 |
| Day 3 deficit | Level -2 | forced demobilization of lowest-priority assets + -2 DP/cycle + combat × 0.85 + defensive × 1.20 + production × 0.9 |
| Day 7 deficit | Level -3 | buildings auto-shut (factories pause, smelters stop) + -3 DP/cycle + combat × 0.70 + defensive × 1.30 + production × 0.8 |
| Day 14 deficit | Level -4 | cascading defections, named NPCs leave + -5 DP/cycle + combat × 0.50 + defensive × 1.40 + production × 0.6 |
| Day 30 deficit | Surrender | faction collapses or surrenders per AWAW Rule 54; per-faction surrender variant applies |

#### Per-level effects

| Level | Combat dmg | Defensive bonus | Production | Diplomatic | Effects |
|---|---|---|---|---|---|
| **0** | 1.0× | 1.0× | 1.0× | normal | healthy faction |
| **-1** | 0.95× | 1.10× | 1.0× | -1 DP/cycle | minor decline; defensive bonus |
| **-2** | 0.85× | 1.20× | 0.9× | -2 DP/cycle | visible weakness; allies hesitate |
| **-3** | 0.70× | 1.30× | 0.8× | -3 DP/cycle | desperate measures; refugee crises |
| **-4** | 0.50× | 1.40× | 0.6× | -5 DP/cycle | near-collapse; rebellion risk |
| **Surrender** | 0× | 0× | 0× | banished | faction defeated |

**Recovery:** factions CAN climb back UP a level by:
- Winning major battles (per scenario reward)
- Receiving allied BP grants (per M46 Edit 5.1)
- Diplomatic alliances (per AWAW Rule 49 — diplomatic results)
- Tech breakthroughs (per M32 research tree)

Once at Surrender, recovery is impossible. Surrender is final per AWAW Rule 54.

#### Storyteller integration

Per-storyteller event weighting owned by M25C (see M25C event-kind weights table). M45 ships the per-resistance-level event-kind list below; M25C's storyteller decision algorithm consumes those event kinds and applies per-storyteller multipliers (Phoebe down-weights `aggressive_raid`; Randy up-weights chaos; Cassandra balances). The per-level escalation kinds:

- **Level -1**: occasional refugee events (player can help; +diplomatic)
- **Level -2**: rebellion in occupied territory (player can crush or pacify)
- **Level -3**: rival faction smells blood; aggressive raids
- **Level -4**: cascading defections; named NPCs leave; loyal followers desperate
- **Surrender**: faction-wide funeral event; allied factions mourn

#### Per-faction surrender variants

Per AWAW Rules 54-62 (faction-specific surrender):

- Hostile Corp surrender → all assets sold at firesale; player gets bonus equipment
- Allied Resistance surrender → player loses major ally; reputation -50
- Pirates surrender → fleet disbands; loot scattered
- Drone Collective surrender → drone hive shuts; mining operations stop
- ...etc per faction

### 12 dynamic world events

**Registration API:** All 12 events register via M25's `cf-storyteller::registry.register()` API at scenario load. M45 ships the event DATA + trigger logic + effects; M25 owns the registry + scheduling. See `specs/active/M25.md` § Storyteller event registration API for the canonical contract.

Per M25 storyteller integration — events registered via M25 storyteller registration API. Each event has typed severity + trigger + effect:

**1. Solar flare (severity: critical):**
- Triggers from astrography astronomical model
- Duration: 1 in-game hour
- Effect: all electronics offline; mass blackout cascade per M29
- Player must fall back to manual hand-crank generator OR battery reserves
- Replay event: `event.solar_flare_started/ended`

**2. Pirate raid (severity: high):**
- Faction forces attack player base
- Wave count: 2-5 waves; difficulty scales with player tier
- Reward: pirate gear + loot drops
- Mission-style event with objective markers

**3. Trader arrival (severity: low):**
- NPC trader ship docks at player base
- Offers gear / recipes / materials at fluctuating prices
- Player can trade or refuse
- Lasts 30 in-game minutes

**4. Anomaly storm (severity: medium):**
- Existing anomaly cluster expands temporarily
- New anomalies appear within 50m radius
- Artifact farming opportunity (rare drops)
- Lasts 15-30 in-game minutes

**5. Volcanic eruption (severity: high; volcanic biomes only):**
- Lava cascade affects surface
- New ore deposits revealed at lava cooling
- Player must evacuate zone
- Lasts 1 in-game hour; lava cools naturally

**6. Asteroid impact (severity: medium):**
- Random ore-rich asteroid lands on player's planet
- Massive ore deposit revealed at impact site
- Crater hazard zone (radiation + hot terrain)
- Mining opportunity

**7. Mysterious signal (severity: low):**
- Codex artifact + lore unlock; quest line begins
- Player must investigate signal source
- Reward: rare recipe + faction reputation

**8. Famine (severity: medium):**
- Low caloric resources globally
- Forces player to focus on M25 plant growing + cooking + scavenging
- Lasts 24 in-game hours

**9. Plague outbreak (severity: high; faction-specific):**
- Affliction risk; medical recipes needed
- Player can develop antidote (T3 research)
- Lasts 12 in-game hours

**10. Faction war declaration (severity: critical):**
- 2 factions declared war
- Mass attacks spawn on player territory if relevant
- Player can ally; reward depends on side

**11. Eclipse (severity: medium; bodies in alignment per DR-039):**
- Solar reduced to 0% on planet being eclipsed
- Battery management becomes critical
- AI uses darkness for stealth

**12. Mineral rush (severity: low):**
- Rare ore deposit reveals on world surface
- Player rush to claim; faction conflict possible
- Lasts 1 in-game hour
