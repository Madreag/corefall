# M27C — Identification UX + Magic Affix Prefix/Suffix Grammar + Naming + Reveal Pipeline

## Status

`active`

## Intent

Diablo identification pipeline: unidentified-item state + identification station + scroll-item flow + magic affix prefix/suffix grammar that turns flat `+15% damage` affixes into Diablo-grade item permutations ("Bloody Plasma Rifle of the Cosmos +damage +crit +piercing").

## Canonical ownership

Owns identification state machine, prefix/suffix grammar, affix name generator, unique-item registry. M27 declared rarity tiers + 30+ flat affixes; M27C adds the slot-based combinatorial grammar.

## Player-facing behavior

- **Unidentified state**: Rare / Legendary / Unique items drop as `"Unidentified Rare Rifle"` with `[?] [?] [?] [?]` affix slots hidden.
- **Identification station** (T1+ base module; M28A integration): drop item → 30s timer → identification.complete event → affixes revealed.
- **Identification scroll** (consumable; T0 alchemy craft): instant ID; one-time use.
- **Affix slot grammar**: every Rare+ item has 2 prefix slots + 2 suffix slots. Prefixes describe damage / stat modifiers ("Bloody", "Burning", "Razor", "Heavy"); suffixes describe magical effects ("of the Cosmos", "of the Voidlord", "of Salvation").
- **Per-item-class affix pool**: weapons / armor / chassis-module / consumables / containers each have separate prefix + suffix pools.
- **Affix tier within prefix**: affixes themselves have rarity (common prefix "Sharp" +5% sharpness; rare prefix "Razor" +20%; legendary prefix "Edged of the Reaper" +40% + life steal).
- **Naming convention**: `"<Prefix1> [<Prefix2>] <BaseName> [of <Suffix1>] [<Suffix2>]"` per Diablo.
- **Unique items** override naming with author-defined names ("Doombringer", "The Hand of God").
- **Affix re-roll** at identification station (consumable: rare_re_roll_scroll): re-rolls one prefix or suffix.
- **Affix transfer** (T3+ workbench): destroy item A to copy one affix to item B (one-time per affix).
- **Lore tied to affixes** per M25A bible.

## Affix grammar schema

```ron
PrefixAffix (
    id: "prefix_razor",
    display_name: "Razor",
    item_class: Weapon,
    affix_tier: Rare,
    stat_modifiers: [
        StatMod (target: SharpnessPenalty, op: Add, value: 0.20),
        StatMod (target: BleedChancePct, op: Add, value: 0.10),
    ],
    lore_tag: Some("ancient_smith_forged"),
    drop_weight: 5,
)
```

## Acceptance criteria

```gherkin
Scenario: Rare+ drops as unidentified
  Given rare plasma_rifle dropped
  Then item.is_identified = false
  And display_name = "Unidentified Rare Plasma Rifle"
  And affix slots show "[?]"

Scenario: Identification station reveals affixes
  Given unidentified rare rifle at identification_station
  When 30s timer elapses:
    Then item_identified fires
    And affix_revealed fires × 4 (2 prefix + 2 suffix)
    And display_name updates: "Bloody Razor Plasma Rifle of the Cosmos"

Scenario: ID scroll instant reveal
  Given unidentified item + id_scroll in inventory
  When player uses scroll:
    Then item_identified fires immediately
    And scroll consumed

Scenario: Affix re-roll
  Given identified item with "Bloody" prefix + reroll_scroll
  When player rerolls prefix1:
    Then affix_rerolled fires
    And "Bloody" replaced with new roll from pool

Scenario: Affix transfer
  Given item A (legendary "of the Cosmos" suffix) + item B (rare)
  When player uses affix_transfer_workbench:
    Then item A destroyed
    And affix_transferred fires
    And item B gains "of the Cosmos"

Scenario: Unique item named
  Given unique drop "Doombringer"
  Then unique_item_discovered fires
  And display_name = "Doombringer"
  And codex entry unlocks

Scenario: Lore unlock on first prefix encounter
  Given player first encounters "of the Voidlord" suffix
  Then codex.entry_unlocked fires id=voidlord_lore
```

## Notes for the implementer

- Affix grammar uses procedural name combiner: `"{prefix1} {prefix2_optional} {base_name} of {suffix1} {suffix2_optional}"`.
- 50+ prefixes + 50+ suffixes per item class = thousands of combinations.
- Re-roll uses seeded RNG; deterministic.
- Unique items: 20+ hand-authored with custom names + signature abilities.
