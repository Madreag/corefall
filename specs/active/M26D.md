# M26D — Prisoner + Captive + Interrogation + Ransom + Parole + Breakout

## Status

`active`

## Intent

Closes the captive-loop hole left open by M26 (factions + diplomacy declares "rescue captive → +20 relationship" but never specifies how a captive arrives, where they're held, what they eat, how the player extracts intel, or how they leave). M26D ships the full **prisoner lifecycle** end-to-end: non-lethal capture mechanic (knock-out vs kill via tranquilizer / stunbaton / fist + zip ties + handcuffs + per-actor knock-out threshold) → holding cells (M28F zone type + cell-bar walls + locked door + per-cell furniture) → per-prisoner Need profile (food / sleep / recreation / morale at degraded standards) → interrogation dialog tree (M26B integration) with 4 ethical styles (humane / coercive / drugs / torture) gated by DR-031 → ransom mechanic (per-prisoner faction value + negotiation curve) → parole / release / faction reputation deltas → execution + per-faction outrage → breakout AI (per-prisoner planning + tool acquisition + lockpick + guard distraction).

M26D promise: **"you can take prisoners alive, lock them in a cell with a bed and a toilet, walk in with a clipboard and ask questions, and decide whether to ransom them home, parole them out, or — if you're that kind of warden — break them."**

## Canonical ownership

This spec is the **canonical owner of the prisoner lifecycle, capture mechanic, binding tools, holding-cell zone type, prisoner Need profile, interrogation dialog tree, ransom + parole + execution + breakout subsystems**. M26 consumes the per-faction reputation deltas. M26B consumes the interrogation dialog tree as a specialization of its conversation runtime. M28F consumes the new `prison_cell` zone type. M14H consumes captive-on-arrival treatment routing. M48 consumes captured-spy outcomes (covert-ops extraction pipeline). M19O consumes prisoner sleep schedule overrides. M19N consumes prisoner-meal routing.

## Player-facing behavior

### Capture mechanic — knock-down vs kill

- Every melee strike / firearm hit / explosive in cf-actor + cf-physics now resolves a **lethal-vs-incapacitating fork** at hit-resolution time. Per DR-014 (consent of harm + non-lethal opt-in), the weapon's `damage_profile.lethality_mode ∈ {lethal, less_lethal, configurable}` decides which branch fires.
- **Knock-out threshold**: each actor carries `consciousness_threshold: f32` (default 0.35 of max HP for civilians, 0.18 for hardened soldiers, 0.05 for armored vehicles → ie. tanks don't go unconscious). When HP drops below the threshold but above 0, and the inbound hit's `lethality_mode != lethal`, the actor enters `Unconscious` stance instead of `Dead`.
- **Non-lethal weapon catalog** (5 launch):
  - `tranquilizer_dart` — ranged; injects 1 tranq dose; full unconsciousness in 8s; consumes 1 dart.
  - `stunbaton` — melee; per-strike electric jolt; 3 successful strikes → unconscious for 90s.
  - `fist_strike` / `unarmed_combatives` — melee; brawling check; per-strike concussion accumulator; KO when concussion ≥ actor's `consciousness_threshold`.
  - `gas_grenade_cs` — area; 6-tile radius; 10s exposure → unconscious if no respirator.
  - `bola_projectile` — ranged; restrains legs; not unconscious, but immobile + 80% accuracy debuff.
- **Lethal weapons can be holstered**: per-weapon UI toggle `[X]` cycles `lethal → less_lethal → off` for any firearm that supports rubber bullets (see M14H wound producer overrides). Less-lethal firearm hits route to `BruiseHeavy` / `Concussion` wounds (no `GunshotEntry`).
- **Binding tools** (must be applied within 30s of incapacitation or actor wakes and resists):
  - `zip_tie` — 1-use; 3s apply; breakable with `escape_strength ≥ 12`.
  - `handcuffs_steel` — reusable; 5s apply; breakable only with lockpick OR `escape_strength ≥ 25`.
  - `restraint_chair` — fixed-furniture; one-tile occupancy; immobilizes seated prisoner; required for `torture` interrogation style.
- **Capture event chain**: `actor.knocked_out { actor_id, by_weapon }` → `actor.bound { actor_id, binding_type, by_actor }` → `prisoner.transport_queued { prisoner_id, to_cell }`. If 30s elapses without binding, fires `prisoner.escaped_pre_bind`.

### Holding cells — M28F zone integration

- New zone type registered with M28F: `prison_cell { capacity: u8, security_level: 1..3 }`. Painted via the M28F zone painter ([Z] in build mode), same as `quarantine` / `security_clearance_*`.
- **Cell-bar walls** — new building tile `wall_cellbar` (60 steel / tile, blocks LOS only partially: vision through, projectiles blocked, atmosphere shared with corridor — used for cheap supervised cells). Solid `wall_steel` also valid for higher security.
- **Locked door** — `door_cell_locked` (existing `door_steel` re-skinned + permission gate). Default permission: `prisoner=deny, guard_role=allow`. Players + companions with the **Warden** role bypass.
- **Per-cell furniture requirements** (capacity-1 cell minimum):
  - 1× `bed_standard` OR `cot_simple` (M19O bed) — REQUIRED. Missing → -20 prisoner morale + "no bed" warning.
  - 1× `toilet_basic` (M19N waste system tie-in) — REQUIRED. Missing → -30 prisoner morale + hygiene need violation.
  - 1× `sink_basic` OR `water_dispenser` — REQUIRED for capacity-2+. Missing → +10% disease chance.
  - 1× `chair_simple` — OPTIONAL; required for `humane` interrogation seating.
  - Decorative items (paintings / plants / books) — OPTIONAL; +morale per M19O room-quality formula.
- **Cell security tier** decides breakout difficulty:
  - `tier_1` — bars + wooden door + basic lock. Lockpick DC 12.
  - `tier_2` — steel walls + steel door + tumbler lock. Lockpick DC 20.
  - `tier_3` — reinforced + electronic lock + IC10-monitored. Lockpick DC 30 + requires hacking tool.

### Per-prisoner Need profile (degraded standards)

Reuses M19O Needs scaffolding but with **prisoner-specific defaults**:

| Need | Free-actor target | Prisoner target | Threshold for "abuse" complaint |
|---|---|---|---|
| Food | 3 meals/day @ quality ≥ basic | 2 meals/day @ quality ≥ basic_gruel | <1.5 meals/day or quality = `nutrient_paste` for 7 days |
| Sleep | 8h @ bed_standard | 6h @ cot_simple acceptable | <4h or no-bed for 3 nights |
| Recreation | 2h/day | 0.5h/day in cell (reading / pacing) | 0h for 14 days |
| Hygiene | toilet + sink + shower | toilet only | no toilet for 24h |
| Morale | 50+ acceptable | 30+ acceptable | <15 for 7 days |

- **Prisoner meal**: M19N cooking outputs a new variant `meal_prisoner_gruel` (1 ingredient, 0.4 nutrition, 0 mood-modifier). Wardens may also serve `meal_basic` (+morale, +faction-relationship-on-release).
- **Abuse threshold breach** fires `prisoner.abuse_complaint { prisoner_id, factor }` → consumed by M26 faction relationship engine: -2 reputation per complaint per faction-week with the prisoner's faction.

### Interrogation dialog tree — M26B integration

- Triggered by `act.player.npc_interact { npc_id }` on a bound prisoner OR `act.player.start_interrogation { prisoner_id, style }`.
- Reuses M26B conversation runtime: portrait + name plate + dialog text + 4 choice buttons + voice playback. Specialization: **Interrogation Mode** flag on the conversation context unlocks the 4 interrogation styles as choice templates.
- **4 interrogation styles** (DR-031 ethical opt-in; coercive / drugs / torture require `server.ron::ethics.allow_coercion=true`):
  - `humane` — chair + conversation; 30s rounds; per-round intel reveal probability `0.15 + 0.02 × (interrogator.social_skill - 5)`; no reputation penalty; no wound; **always available**.
  - `coercive` — verbal threats + sleep deprivation + light slaps; 30s rounds; intel reveal `0.30 + 0.03 × social_skill`; -3 faction reputation per session; +Stress +10 per round; no wound; **opt-in via DR-031**.
  - `drugs` — sodium-thiopental injection (M14H consumable `truth_serum_v1`); 60s rounds; intel reveal `0.45 + 0.02 × medic_skill`; -5 faction reputation; +5% addiction risk per session (M16C); wound: `IVPunctureMinor`; **opt-in via DR-031**.
  - `torture` — restraint_chair + various; 60s rounds; intel reveal `0.55 + 0.04 × cruelty_skill` but with `lie_probability 0.30`; -15 faction reputation per session + flagged as `war_crime` in M26 narrative log; +Stress +50 per round; per-session wound: 1× `BurnT2` OR `LacerationModerate` OR `FractureSimple` (rolled); **opt-in via DR-031 + explicit "I'm sure" modal confirm**.
- **Intel currency**: successful interrogation yields one of `{ enemy_base_location, enemy_patrol_route, enemy_spy_ring_member (M48), faction_secret_project, named_npc_relationship_dossier }`. Per-prisoner intel pool is finite (3-7 items per dossier). Once depleted, further rounds yield only `repeated_or_useless` outcomes.
- **Lie probability**: torture-extracted intel has a 30% chance of being false. Fires `intel.acquired { prisoner_id, payload, lie_chance }` so M48 covert-ops + M26 faction engine know to discount.
- **Per-prisoner interrogation log**: persisted in save under `save.prisoner.<id>.interrogation_history[]` for narrative recall (e.g. NPC remembers "you broke my fingers" in a later dialog node).

### Ransom mechanic

- Per-prisoner **faction_value**: computed at capture-time as `base_value(role) + rank_bonus + relationship_bonus(captor_faction, prisoner_faction)`. Roles range from `grunt: 50 credits` → `named_npc_quartermaster: 2500 credits` → `faction_leader: 15000 credits + 1 unique unlock`.
- **Negotiation curve**: player opens ransom dialog via M26 `act.player.faction.negotiate { faction_id, topic: ransom, prisoner_id }`. The target faction's opening offer = `0.6 × faction_value`; player counter-offers via slider; per-round delta capped at ±15%; per-round acceptance probability = `sigmoid((offer - faction_value) × 2 - patience_decay)` where `patience_decay` increments each round.
- **Settlement outcomes**:
  - `accepted` — credits/items transferred → prisoner teleported to faction territory edge → `+10 faction reputation with prisoner_faction` → -2 with rival factions.
  - `rejected` — round limit hit (5 rounds default) → prisoner stays + faction reputation -3 with prisoner_faction (perceived insult).
  - `counter_terms` — faction demands non-credit payment (e.g. release of THEIR prisoner held by player). M26D supports prisoner-for-prisoner swaps.
- **Per-faction value modifier**: Mercenary Guild always +20% (they pay premium); Religious Order accepts non-monetary terms (relics, scripture); Drone Collective doesn't negotiate (auto-reject).

### Parole + release + execution

- **Parole** (`act.player.prisoner.parole { prisoner_id, terms }`):
  - Player sets terms: `{ no_attack_for_days: u32, exit_via: GateId, escort_to: HexCoord? }`.
  - Prisoner walks to exit; if escorted, guard escorts and returns.
  - On exit: `prisoner.paroled { prisoner_id, terms_hash }` → +5 faction reputation with prisoner_faction → -1 with rival.
  - If terms broken (prisoner attacks within `no_attack_for_days`): -10 reputation with prisoner_faction (they're embarrassed) + flagged in M26 narrative log.
- **Release** (`act.player.prisoner.release { prisoner_id, location }`) — unconditional; +8 reputation with prisoner_faction; no terms.
- **Execution** (`act.player.prisoner.execute { prisoner_id, method }`):
  - Methods: `firing_squad`, `hanging`, `lethal_injection`, `oubliette_neglect`.
  - Per-faction outrage: -25 reputation with prisoner_faction + cascading -5 with all allies of prisoner_faction + flagged as `war_crime` in M26 narrative log (irreversible).
  - Religious Order penalty doubled (-50) per faction doctrine.
  - Triggers M16C psych shock event for witnessing actors: +20 Stress per witness.
- **Recruitment** (alternative release; per M26 recruit pipeline): high-relationship prisoner can be offered membership in player faction. Per-prisoner recruitment chance = `0.05 + 0.02 × (humane_interrogation_count) - 0.05 × (torture_session_count)`. On success: -2 reputation with original faction (they consider it desertion).

### Breakout AI (per-prisoner planning)

- Every awake, bound, in-cell prisoner runs a per-tick `BreakoutPlanner` whose tick budget is gated by M22 AI scheduler (1Hz default, 0.2Hz when cell is under direct guard observation).
- **Plan phases**:
  1. **Observe** — record guard patrol patterns + cell door open/close cycles + nearby tool spawn locations. Per-tick observation roll: `0.1 × (1 - guard_supervision_strength)`.
  2. **Plan** — when observation accumulator ≥ 0.6, prisoner formulates a plan node: `{ target_tool: Option<ItemId>, distraction_plan: enum, escape_route: PathId, partner_prisoners: Vec<PrisonerId> }`.
  3. **Acquire tool** — attempt to swipe tool when guard is distant: lockpick / improvised shiv (crafted from cell furniture if M28F furniture damage allowed) / contraband from negligent guard.
  4. **Execute** — at next opportunity (guard out-of-LOS, distraction firing):
     - Pick lock (DC vs `lockpick_skill`).
     - Distract guard (loud noise / fake medical emergency / partner-prisoner riot).
     - Move to exit using `escape_route`.
- **Breakout tool acquisition** outcomes:
  - `success_lockpick_obtained` — prisoner now has lockpick item (hidden in cell).
  - `failed_caught` — guard catches the attempt; +1 prisoner suspicion (Warden alerted); +1 cell security upgrade recommended.
- **Lockpick DC** (per cell tier above): rolled per attempt; failure increments cell-door alert counter; alert ≥ 3 → guards summoned automatically.
- **Multi-prisoner coordination**: prisoners in adjacent cells with relationship `+30` form a `BreakoutCoalition`. Coordinated breakouts boost distraction efficacy +50% but raise alarm chance +20%.
- **Anti-breakout countermeasures**:
  - Frequent guard patrols (player-assigned `act.player.set_warden_schedule { actor_id, cell_zone_id }`).
  - Cell-camera tile + IC10 motion sensor (re-uses M28F IC10 readout `zone.unauthorized_count`).
  - Per-prisoner solitary-confinement zone (overrides recreation need to 0; -10 morale/day; reduces breakout planning rate to 0.1Hz).
- **Breakout success consequence**: prisoner escapes to nearest faction-friendly hex; -10 reputation with player faction from the prisoner's faction (they consider it weak warden practice); fires `prisoner.escaped { prisoner_id, route_used }` for M26 narrative log.

## Acceptance criteria

```gherkin
Scenario: Less-lethal hit incapacitates instead of killing
  Given an enemy grunt at full HP
  And a player wielding a stunbaton (lethality_mode = less_lethal)
  When the player lands 3 successful stunbaton strikes
  Then the enemy enters Unconscious stance
  And the enemy HP remains > 0
  And no Dead event fires
  And the player has a 30-second window to bind the target

Scenario: Unbound knocked-out prisoner wakes and escapes
  Given an enemy in Unconscious stance for 30 seconds
  And no actor has applied a binding tool within that window
  When the 30-second timer elapses
  Then the enemy wakes (stance returns to Aware)
  And event prisoner.escaped_pre_bind fires
  And the enemy attempts to flee to the nearest faction-friendly hex

Scenario: Cell zone requires bed + toilet to satisfy validation
  Given a player paints a prison_cell zone with capacity 1 via M28F zone painter
  When the cell contains only a wall_cellbar perimeter and a door_cell_locked
  Then the zone validation flags "missing required furniture: bed, toilet"
  When the player places a cot_simple and a toilet_basic inside
  Then validation passes and the zone is marked ready_for_occupancy

Scenario: Humane interrogation reveals intel without faction penalty
  Given a bound prisoner in a tier_1 cell with social_skill-5 interrogator
  When the player starts interrogation with style = humane
  And the player completes 4 conversation rounds
  Then at least 1 intel item is added to the player's intel ledger (probability ~25% per round)
  And no faction reputation delta with the prisoner's faction is applied
  And no wound is added to the prisoner

Scenario: Torture interrogation extracts intel with lie risk + war crime flag
  Given DR-031 ethics.allow_coercion = true in server.ron
  And a bound prisoner seated in a restraint_chair
  When the player confirms the "I'm sure" modal and starts torture interrogation
  And the player completes 2 sessions
  Then at least 1 intel item is added with lie_chance ≥ 0.30 on the item
  And faction reputation with the prisoner's faction drops by ≥ 30 (-15 per session)
  And the M26 narrative log records the event with tag war_crime
  And the prisoner receives 1 wound from {BurnT2, LacerationModerate, FractureSimple}

Scenario: Ransom negotiation accepted at fair price
  Given a captured Hostile Corp grunt with faction_value = 200 credits
  When the player opens ransom negotiation via faction.negotiate { topic: ransom }
  And the Hostile Corp opening offer is 120 credits
  And the player counter-offers 180 credits
  Then the acceptance probability is computed via sigmoid and the offer is accepted
  And the player receives 180 credits
  And the prisoner is teleported to the faction territory edge
  And player reputation with Hostile Corp increases by +10

Scenario: Parole respected gives reputation; broken parole hurts
  Given a paroled prisoner with terms { no_attack_for_days: 7, exit_via: gate_west }
  When the prisoner walks to gate_west and exits
  And 7 in-game days pass without the prisoner attacking the player faction
  Then player reputation with the prisoner's faction increases by +5
  When in a separate run, a paroled prisoner attacks the player faction within 7 days
  Then player reputation with that faction decreases by -10

Scenario: Execution triggers cascading faction outrage + war crime flag
  Given a captured named Religious Order officer
  When the player executes the prisoner via firing_squad
  Then player reputation with Religious Order drops by -50 (doubled per doctrine)
  And player reputation with every Religious Order ally drops by -5
  And the M26 narrative log records the event with tag war_crime (irreversible)
  And every witness actor receives +20 Stress per M16C

Scenario: Breakout planner acquires lockpick and escapes negligent cell
  Given a tier_1 cell with no guard within LOS for 20 minutes in-game
  And a prisoner with lockpick_skill = 8
  When the BreakoutPlanner observation accumulator exceeds 0.6
  And the prisoner formulates a plan with target_tool = lockpick
  And the prisoner successfully acquires a lockpick from a negligent guard's drop
  And the prisoner rolls 14 against lockpick_DC 12
  Then the cell door unlocks
  And event prisoner.escaped { prisoner_id, route_used } fires
  And the prisoner moves toward the nearest faction-friendly hex

Scenario: Solitary confinement suppresses breakout planning
  Given a prisoner flagged for solitary_confinement
  When 24 in-game hours pass
  Then the BreakoutPlanner runs at 0.1 Hz tick rate (vs 1 Hz default)
  And the prisoner's recreation need stays at 0
  And the prisoner's morale drops by -10 per day
  And the observation accumulator gains no more than 0.024 in that window

Scenario: Prisoner abuse threshold triggers faction complaint
  Given a prisoner held for 8 days with 0 hygiene access (no toilet present)
  When the threshold check fires on day 8
  Then event prisoner.abuse_complaint { factor: hygiene } fires
  And player reputation with the prisoner's faction decreases by -2 per faction-week
  And the prisoner panel UI displays an "abuse: hygiene" warning badge

Scenario: Recruitment offer succeeds after sustained humane treatment
  Given a prisoner held for 30 days with 6 humane interrogations + 0 coercive sessions
  And the prisoner's morale is ≥ 70 at offer time
  When the player issues act.player.prisoner.offer_recruitment { prisoner_id }
  Then the recruitment chance is computed as 0.05 + 0.02 × 6 = 0.17
  And on success, the prisoner joins the player faction
  And player reputation with the prisoner's original faction decreases by -2 (desertion penalty)
```

## Out of scope

- Sentencing system / criminal-justice court UI — never (this is a strategy game, not Phoenix Wright).
- Per-prisoner romantic-encounter mechanics inside cells — deferred forever.
- Per-jailer Stanford-Prison-Experiment psych decay — deferred to a future M16C extension if at all.
- Cross-faction prisoner exchange brokerage (third-party mediator) — picked up by a future M26 extension.
- Prisoner-of-war labor / forced-labor camps — explicitly NOT in this milestone for ethical-scope reasons (would require a separate DR-031 gate).
- Per-prisoner unique dialog backstory generation (procedural biography) — picked up by a future M26C extension.
- Cell-block riot AI (>3 prisoners coordinating mass uprising) — deferred to a later breakout-AI extension.
- Mass-prisoner camps (>20 prisoners on one base) — performance budget kept to 16 prisoners launch ceiling.

## Notes for the implementer

- **DR-031 gate is non-negotiable.** Coercive / drugs / torture interrogation styles MUST be hard-gated by `server.ron::ethics.allow_coercion`. If the flag is false, the cfctl returns `ErrEthicsForbidden` without side effect. The "I'm sure" modal on torture is a SECOND gate on top — both must pass.
- **Breakout planner determinism**: per AGENTS.md, all per-tick RNG inside cf-ai::breakout_doctrine MUST seed off the engine deterministic RNG (`cf-control::engine::tick_seed`), NEVER `thread_rng`. Same for the ransom negotiation acceptance roll.
- **Bind window timer**: implement the 30-second pre-bind escape window as a per-actor `unconscious_since_tick` field on `Stance::Unconscious`; checked on every tick when stance == Unconscious AND no binding has been applied.
- **Cell-bar vision semantics**: `wall_cellbar` blocks projectiles but not LOS. The M28F LOS solver already supports per-wall partial transparency; reuse `wall.los_block_factor = 0.0` + `wall.projectile_block = true`.
- **Intel pool depletion**: each prisoner's `intel_pool: Vec<IntelItem>` is generated at capture-time from faction + role + rank. Once depleted, further interrogation rounds emit `intel.repeated_or_useless` events; UI should grey-out interrogation options once the pool is dry.
- **Per-faction ransom modifier**: bake into `cf-faction::ransom::faction_modifier_table` keyed on FactionId; Mercenary Guild +0.20, Religious Order accepts non-cash, Drone Collective auto-rejects (return `ErrFactionRefusesNegotiation`).
- **Prisoner UI panel data flow**: subscribe to `prisoner.*` events from cf-replay; do NOT poll cf-prisoner state every frame.
- **Tracing**: all new prisoner lifecycle transitions MUST emit `tracing::info!(target: "cf-prisoner", prisoner_id, from_state, to_state, cause)`. No `println!` (AGENTS.md rule).
- **Warden role**: the warden is a new role in M7 doctrine but does NOT require an M7 spec extension — the role is purely a permission flag + AI doctrine, registered via the existing M7 role registry.
