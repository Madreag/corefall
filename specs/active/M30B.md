# M30B — Mining Tool Tier Ladder + Material-Aware Dig Speed

## Status

`active`

## Intent

Fill the missing 5+ mining-tool tiers (T0 BareHands → T-mech HeavyDrillArm) + wire material-aware dig speed into `try_carve` so the code comment "strength enters at M5+ when material hardness ladders" finally becomes reality + add the chassis-grade mech drill that turns a Cortex-Command-feel mining mech into something the player can actually build.

## Player-facing behavior

- **Bare hands (T0)**: dig dirt at painful speed (stamina drain; 1 px/sec); refuses concrete + metal_nohook. The "you lost your tool and must survive" emergency layer.
- **Iron shovel (T1)**: dig dirt + loose_fill fast; pickaxe for hard surfaces; both M32-craftable from base materials.
- **Iron pickaxe (T1)**: dig concrete + brick OK; slow on metal; both T1 tools share durability degradation curve.
- **Power jackhammer (T2)**: battery-powered concrete-and-reinforced-grade dig; loud hearing signal alerts AI; M29 personal battery drain (1.5 kW active).
- **Plasma cutter (T3)**: cuts metal_nohook (hardness 100); narrow beam; consumes plasma cells (separate from battery); vac-safe.
- **Mining laser (T4)**: long-range continuous cut; reactor-grade power (5 kW active); consumes `beam_cuttable` flag in M3 affordances; the endgame solo dig tool.
- **Heavy drill arm (T-mech)**: chassis-socket-mounted; mounts to mining_mech (M13 chassis grammar extension); routes power from chassis reactor; can dig at 5× hand-tool speed in a 32-pixel-radius arc.
- **Material-aware dig**: digging concrete with bare hands → impossible. With iron pickaxe → slow (8 sec per pixel). With power jackhammer → fast (1 sec per pixel). Plasma cutter → fast even on metal. Mining laser → continuous beam.
- Visual + audio: each tool tier has distinct dig animation + per-material SFX (concrete grinding / metal-cutting plasma whoosh / drill bit screech).

```gherkin

  And terrain.dig_progress fires per tick with progress_pct
  And the pixel is carved when progress reaches 100%

  Given the player has BareHands (dig_strength=8) facing concrete

  Then terrain.dig_blocked_by_hardness fires
```

## Out of scope

- Anti-grief tool-tier validation in PvP (preventing T4 tools from breaching faction walls without authorization) — M49 owns this.
- Tool-tier crafting recipes — M32 owns; M30B only declares the SKUs.
- Stationeers-style multi-tool that swaps modes — out for launch (each tool is single-purpose).
- Sound-suppressed mining (whisper drill) — M48+ stealth tech.

## Notes for the implementer

- `try_carve` becomes the canonical material-aware-dig API. Existing M2 dig + M3 carve callers route through it; signature: `try_carve(pos, tool_strength, radius, dt_ms) -> CarveResult`.
- BareHands has special-case stamina drain (per M6) — costs 1 stamina per pixel dug.
- HeavyDrillArm power consumption routes through chassis (M13 + M29), not personal battery — chassis-grade power source.
- Mining laser is endgame: requires Material Lab (M34) unlock + Plasma Forge (T4 crafting station).
- Plasma cells are a NEW consumable item — single-use cylinders carried in inventory slots; produced at T3 fabricator.
