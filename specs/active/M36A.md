# M36A — Platform Integration Pipeline (Steam + Discord + EOS)

## Status

`active`

## Intent

**M36A is the platform integration milestone** — Steam SDK (Cloud saves + Achievements + Steam Input + Workshop + Rich Presence) + Discord Rich Presence + Epic Online Services (EOS) adapter. All the platform glue that lets Corefall feel like a native Steam release while remaining compatible with itch.io / direct sales / future console.

**Why after M36 (dedicated server):** by M36 close, the `cf-server` foundation exists. Steam Workshop integration ties to M33 mod workbench. Steam Cloud sync ties to DR-029 save model. Steam Achievements ties to M27 achievements. Steam Input ties to M11 controller path. M36A integrates all the spokes.

**Why this milestone exists:** the user said "minimal human interaction once milestones are set". Shipping on Steam without the SDK integrations means players can't use Friends invite, can't sync saves across devices, can't see achievements pop, can't subscribe to mods. M36A wires it all up.

M36A promise: **"Corefall is a first-class Steam release — Cloud saves work, Friends invite works, Steam Achievements pop, Workshop mod subscription auto-installs, Discord Rich Presence shows current scenario, EOS adapter ready for cross-platform launch — and every adapter is feature-gated via cargo features so non-Steam users get a clean experience."**

## Player-facing behavior

After M36A, the player experiences:

- **Steam Friends invite + lobby browser** — friend list integration; quick-join via Steam invite link; lobby browser filtered by ping + region + scenario + mods
- **Steam Cloud saves** — profile.ron + per-mission saves auto-sync across devices on the same Steam account
- **Steam Achievements pop** — every M27 achievement triggers a Steam achievement notification + browser-side unlock
- **Steam Input** — controller config via Steam's controller config tool; per-game default templates; player can customize via Steam UI
- **Steam Workshop** — M33 mod packages publishable to Workshop; subscribers auto-download + auto-update; mod browser in-game (per M33A) browses Workshop + local
- **Steam Rich Presence** — shows player's current scenario + role + faction + party status on friend list
- **Discord Rich Presence** — shows player's current scenario + role on Discord profile + party invite via Discord
- **EOS adapter (optional)** — cross-platform play with non-Steam users (Epic Games Store / itch.io / direct)
- **Steam-friendly install path** — content/ directory + saves/ directory respect Steam's expected layout
- **Steam-compatible launch via Big Picture / Steam Deck** — controller-first UI verified on Steam Deck

## Notes for the implementer

### Architecture rules

- **PlatformAdapter trait** — every platform implements: `init() -> Result`, `user_id() -> UserId`, `cloud_save(bytes) -> Result`, `cloud_load() -> Result<Bytes>`, `achievement_unlock(id) -> Result`, `rich_presence_set(state) -> Result`, `friends_list() -> Vec<Friend>`, `friends_invite(friend_id) -> Result`
- **Feature-gated cargo features** — `platform-steam`, `platform-discord`, `platform-eos`, `platform-itch`; combinations valid
- **No platform-specific code in core crates** — only adapter crates depend on platform SDKs
- **Per-platform build script** — `steam_build.sh` enables `--features platform-steam,platform-discord`; `itch_build.sh` disables all platform features
- **Anonymous mode always works** — if no platform feature compiled in, local-only mode runs

### Decision-record alignment

- **DR-029 (save model)**: Cloud sync per-platform respects canonical save format
- **DR-031 (anti-pay-to-win)**: Steam DLC NOT used for gameplay items; cosmetics only
- **DR-034 (dedicated server)**: M36A platform tokens used by cf-server lobby directory
- **DR-035 (MMO architecture)**: per-shard player identity uses platform tokens
- **DR-049 (cross-platform CI)**: M36A enables cross-platform builds + verifies determinism

### Pitfalls

- **Steam SDK platform-specific FFI** — pin steamworks-rs version; cross-platform build matrix
- **Discord rate limits** — Rich Presence updates limited to 1/sec; respect API limits
- **EOS adapter immaturity** — eos-sdk-rs is community-maintained; test thoroughly
- **Cloud save conflict resolution** — if player edits saves on two machines offline, conflict; auto-resolution = latest mtime wins; UI warns
- **Steam Achievement granularity** — Steam achievements can't be unset programmatically (only by user via Steam UI); achievement design must respect this
- **Workshop content moderation** — Steam handles; report flow integrated

### Closure procedure

1. Reference Steam release build (signed, packaged); upload to Steam internal branch; verify all features work.
2. Self-play sweep rows: `m36a_steam_cloud_sync`, `m36a_steam_achievement_pop`, `m36a_steam_workshop_publish_subscribe`, `m36a_steam_rich_presence`, `m36a_discord_rich_presence`, `m36a_eos_cross_platform`, `m36a_itch_no_features_local_only`, `m36a_steam_deck_verified`. All PASS.
3. Move M36A → done/.
