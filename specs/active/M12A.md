## Intent

**M12A is the Tier 1 audio pipeline** — LLM-driven SFX generation via Stable Audio Open + AudioCraft (Meta) + OpenAI Audio + ElevenLabs Sound Effects produces 200+ placeholder sounds at the floor quality. Every gameplay event has a sound; caption metadata pre-authored for ACC-A captions; deterministic seed-based regeneration via cf-asset-ledger.

**Why after M12 (comic-noir):** by M12 close, the game has cinematic visual juice (camera shake, hit-stop, banners). Visual cues without audio cues are accessibility-broken. M12A ships the audio floor RIGHT after the visual floor so every juice rule has both visual + audio + caption simultaneously, satisfying DR-012 multi-channel accessibility.

**Why this is the BACKBONE:** like M9A for visual, M12A means human-authored audio is OPTIONAL forever. Every SFX in the game from M12A through M49 is regenerable from prompts + seeds via Stable Audio Open / AudioCraft / equivalents. M37A produces Tier 2 production-quality audio; M48A polishes; M12A bootstraps. Modders use the same pipeline.

M12A promise: **"every gunshot, every footstep, every reload click, every UI tick, every alarm, every impact has a sound — generated from text prompts + seeds + caption metadata + ledgered for regenerable + accessibility-friendly captions ship from day one."**

## Player-facing behavior

After M12A, the player hears:

- **Every gameplay event has audio** — fire / reload / impact / explosion / footstep / UI tick / banner alert / mission state / breach / alarm / drone / hazard contact / chassis movement / fluid leak / fire crackle / electric arc / atmospheric venting / craft engine
- **Per-material footstep variants** — metal clang / dirt thud / sand swish / concrete tap / ice crunch / wood creak / glass shatter / wet splash — 8 materials × 4 stances = 32 footstep variants
- **Per-material impact sounds** — ricochet ping / wood crack / dirt thud / concrete smash / glass shatter / metal spark / sand puff — 15 impact variants × 8 materials = 120 SFX (with material-state suffix: pristine/scratched/cracked/destroyed)
- **Per-weapon fire sounds** — 70+ weapons × 3 variants (single / burst / auto) = 210+ fire sounds (M9 LOAD-A rifle gets baseline; rest via M12A)
- **ACC-A captions for every audio event** — caption metadata pre-authored per SFX; auto-shows when captions_enabled=true; "GUNSHOT — left" / "BREACH — north" / "RELOAD click"
- **Origin-specific audio variants** — heart-rate audio mix per human concussion band (M17), robot servo whine (M17), android hybrid breathing (M17)
- **No silent events** — every event in the M4 envelope has either a real SFX OR a "no audio" tag with a caption fallback

## SFX manifest entry schema (locked v1)

```ron

    canonical_name: "Iron Rifle — Single Fire",
    category: WeaponFire,
    
    prompt: "Industrial rifle gunshot, sharp crack, brief muzzle blast, mid-range, slight metallic ring decay, 0.5s duration",
    negative_prompt: "music, voice, soft, gentle",
    duration_ms: 500,
    seed: 1234,
    target_loudness_lufs: -16.0,        // standardized loudness per EBU R 128
    
    envelope: (
        attack_ms: 1,
        decay_ms: 50,
        sustain_db: -6.0,
        release_ms: 400,
    ),
    
    caption_template: "GUNSHOT — {direction} ({weapon_kind})",
    caption_severity: "info",
    caption_categories: ["combat"],
    
    occlusion_curve: "linear",          // for M19 atmospherics propagation
    propagation_range_m: 50,            // hearing radius
    
    package_source: PackageRef(vanilla, version: "1.0.0"),
    license: CC0,
)
```

## Caption authoring (ACC-A integration)

Per DR-012 ACC-A-07: every audio event has a caption template. LLM authors the template from manifest metadata:

```
Input to caption_authorer.py:
  - sfx_id: "weapon_fire_iron_rifle_single"
  - category: WeaponFire
  - manifest_prompt: "Industrial rifle gunshot..."

LLM output:
  - caption_template: "GUNSHOT — {direction} ({weapon_kind})"
  - caption_severity: info
  - caption_categories: [combat]
  - per-language strings (M38A produces translations later)
```

Caption template variables resolve at runtime from event payload (direction = from where the sound came; weapon_kind = which weapon fired).

## Notes for the implementer

### Architecture rules

- **Stable Audio Open as primary** — open-source, deterministic with seed, runs locally on a modern GPU, no API cost. AudioCraft (Meta) as secondary. OpenAI Audio / ElevenLabs as fallback for special cases (voice grunts that need character).
- **OGG Vorbis as game format** — small file size, broad codec support, deterministic decode. Master WAV stored offline for re-baking.
- **Loudness normalization** — every SFX normalized to -16 LUFS short-term per EBU R 128. Prevents one weapon from being 10× louder than another.
- **Envelope shaping** — Stable Audio Open output trimmed to declared duration; attack/decay/sustain/release applied per manifest entry. No raw model output ships.
- **Caption per SFX is mandatory** — no audio event without a caption. ACC-A compliance non-negotiable.

### LLM provider abstraction

Same pattern as M9A: support Claude / GPT-4 / Llama for caption authoring; Stable Audio Open / AudioCraft / OpenAI Audio / ElevenLabs for SFX generation; adapter trait pattern in Python.

### Determinism

- Stable Audio Open: deterministic with pinned model + seed; same prompt + seed → same audio
- AudioCraft: deterministic with seed; verified per-machine
- Cloud APIs (OpenAI / ElevenLabs): non-deterministic across calls; use freeze-then-store; CI verifies stored output

### Replay parity

cf-audio events are flagged `cosmetic=true` by default (per M4 cosmetic flag). They don't enter the determinism checksum. BUT: every audio event MUST fire deterministically per replay tick — same input → same audio event sequence. The cosmetic flag means the audio CONTENT isn't checked against checksum, but the EVENT must fire in same order.

### Pitfalls

- **Audio thread blocking sim thread**: cf-audio is on its own worker thread; sim thread emits events to a queue; audio worker plays. NEVER block sim.
- **Spam-event audio pile-up**: 50 actors firing simultaneously = 50 gunshots playing at once. Audio engine must limit voice count + prioritize (closest first) per Steam Audio standard.
- **Caption pile-up**: cap caption queue at 4 visible per M11; oldest evicts.
- **Stable Audio Open model size**: 12+ GB download for high-quality model. CI uses smaller model (faster); release uses full quality. Document the model_version pin in pipeline.
- **OGG Vorbis decoder determinism**: libvorbis is deterministic; rodio + cpal handle correctly. Don't use MP3 (encoder non-determinism).
- **Loudness drift across mods**: per-mod SFX should normalize to same -16 LUFS target; pipeline enforces at generation; cf-audio does NOT do runtime normalization (would hurt determinism).
