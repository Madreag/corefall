# M38A — Localization Production Pipeline (19 Languages)

## Status

`active`

## Intent

**M38A is the localization production milestone** — LLM auto-translation for 19 launch languages (11 Tier-A + 8 Tier-B per DR-051) with ICU MessageFormat compliance, per-language consistency grader, per-language style guides, terminology dictionary, community contribution flow, and forward-compat for voice synthesis in target languages (M37A multilingual).

**Why after M38 (settings hierarchy):** by M38 close, the 200+ settings keys + the full M25A narrative + M11/M12/M27/M33A user-facing strings are all in keyed-string form (English baseline). M38A translates the entire string corpus to 18 additional languages.

**Why this milestone exists:** without M38A, the game ships English-only. M8 reserved the ICU MessageFormat keyed-string infrastructure; M11/M12/M25A/M33A populated it with English. M38A is the LLM-driven translation pipeline that fills the other 18 languages.

M38A promise: **"every player-facing string in the game (HUD labels, banners, captions, settings, tooltips, weapon/tool names, command labels, achievement names, error messages, codex entries, NPC dialog, mission briefings, tutorial narration, voice synthesis prompts) is professionally translated to 19 launch languages via LLM auto-translation + per-language consistency grader + community contribution flow."**

## Player-facing behavior

After M38A, the player experiences:

- **19 supported languages**:
  - **Tier-A (11 launch)**: English / Spanish / French / German / Japanese / Chinese (Simplified) / Chinese (Traditional) / Korean / Portuguese (Brazil) / Russian / Italian
  - **Tier-B (8 launch)**: Polish / Turkish / Arabic / Dutch / Swedish / Hindi / Vietnamese / Indonesian
- **Language selection at first-run wizard (M33A FRE)** — detects system language; default suggests local; player can override
- **Live language switch** — without restart; setting changes immediately apply per M38 hot-reload
- **Per-language style guides applied** — formal Spanish vs informal; honorific Japanese; gender-aware German
- **ICU MessageFormat plurals + gender** — "1 enemy spotted" vs "3 enemies spotted" with correct per-language pluralization
- **Faction names + character names consistent across languages** — Sgt. Marcus Reyes stays Marcus across all 19 languages (transliterated correctly for non-Latin scripts)
- **Per-language fonts** — Latin / Cyrillic / CJK / Arabic / Devanagari fonts loaded; per-language font hinting
- **Right-to-left layout for Arabic** — HUD mirroring + text direction reversal per ICU bidi
- **CJK input methods** — Steam Input + Steam Big Picture compatible
- **Community contributions accepted** — players can submit translation improvements via GitHub PR or in-game submit
- **Voice synthesis target language** — M37A produces voice in target language when language selected

## Per-language style guide

```markdown
# Spanish (es) Style Guide

## Register
- Formal "usted" form throughout the game
- NEVER tutear (no "tú")
- HUD labels: imperative or noun phrases preferred ("DISPARAR" not "Dispara")

## Faction-specific tone
- Hostile Corp: terse, military jargon
- Religious Order: archaic, liturgical Spanish
- Pirates: rough, colloquial, port-vocabulary
- Drone Collective: technical, dispassionate

## Gender
- Default to gender-neutral where possible
- For character pronouns: respect canonical gender from M25A

## Pluralization
- ICU MessageFormat plurals: zero / one / many / other
- "1 enemigo detectado" vs "{count} enemigos detectados"

## Number formatting
- Decimal separator: comma (e.g. "1,5 kg" not "1.5 kg")
- Thousands separator: period (e.g. "1.000 créditos")

## Date/time formatting
- DD/MM/YYYY HH:MM (24-hour)

## Specific terms to keep in English
- "Steam" (brand name)
- "Discord" (brand name)
- Item codes (e.g. "T1", "T2")
```

19 style guides total, one per language.

## Translation algorithm

```text
For each English key:
  1. Look up per-language terminology dictionary
  2. Look up per-language style guide
  3. Compose LLM prompt:
     - Source English text
     - Per-language style guide (full)
     - Terminology dictionary (relevant terms)
     - Context (which UI element, which faction, which NPC if applicable)
     - ICU MessageFormat constraints (preserve placeholders + plural categories)
  4. LLM translates (Claude-3-opus, temperature=0.3 for translation accuracy)
  5. icu_validator.py checks: placeholders preserved? plural categories valid?
  6. consistency_grader.py runs:
     - Score against terminology dictionary (used correct terms?)
     - Score against style guide (right register?)
     - Score against context (right meaning?)
     - If < 0.85: regenerate with adjusted prompt (max 3 retries)
  7. Write to content/localization/<lang>.json
  8. Ledger entry via cf-asset-ledger (category=Localization_Strings; tier=Tier1_LLM)
```

## Notes for the implementer

### Architecture rules

- **English is the source of truth** — all translations derive from English; English baseline ships first
- **Per-language style guide enforces register** — formal/informal/honorific per language
- **Terminology dictionary preserves brand consistency** — faction names + character names + place names + technical terms locked
- **ICU MessageFormat for plurals + gender** — language-specific plural rules
- **Per-language fonts loaded conditionally** — only load fonts needed per current language
- **Community contributions accepted via PR + in-game submit** — but auto-merge requires grader >= 0.95

### Decision-record alignment

- **DR-012 (accessibility)** — per-language fonts + RTL bidi + text_scale 200% reflow
- **DR-051 (localization)** — 19 launch languages = 11 Tier-A + 8 Tier-B
- **DR-044 (audiovisual production)** — translation = production track
- **DR-053 (asset ledger)** — every translation entry ledgered

### Pitfalls

- **Per-language plural rules** — Russian has one/few/many/other; Polish has one/few/many/other; English has one/other; ICU MessageFormat handles
- **CJK font size**: Japanese/Chinese fonts ~20 MB each; lazy-load
- **RTL layout bugs**: test Arabic thoroughly; HUD widgets may need explicit RTL variants
- **Cloud LLM translation cost**: 380,000 strings × per-call cost = nontrivial; batch + cache aggressively
- **Translation drift across LLM versions**: pin LLM model_version per ledger entry

### Closure procedure

1. Reference bundles: M9 + M25 + M45 scenarios played in 19 languages; per-language QA reviewer signs off.
2. Self-play sweep rows: `m38a_19_languages_translated`, `m38a_icu_plurals`, `m38a_rtl_arabic`, `m38a_per_language_fonts`, `m38a_live_switch`, `m38a_terminology_consistency`, `m38a_community_pr_validator`, `m38a_voice_synth_target_language`. All PASS.
3. Update DR-012 + DR-051 closure note.
4. Move M38A → done/.
