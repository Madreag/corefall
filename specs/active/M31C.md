# M31C — Multi-Day Calendar + Seasons + Per-World Year Length + Holidays + Birthdays + Crop Seasons + Per-Cycle Statistics

## Status

`active`

## Intent

Stardew Valley + RimWorld + Dwarf Fortress calendar / seasons / multi-day layer. After M31C, every world has a deterministic monotonic **cycle counter** (Day-N of the run), a **per-world day-length-in-hours** clock (Earth 24h / Mars 24.6h / Moon 708h / Phobos 7.66h / Deimos 30.3h / Mimas 22.6h / Europa 85.2h / Vulcan 58.4 Earth-days / Venus 116.75 Earth-days), a **per-world year-length** that wraps the cycle counter into a calendar year (Earth 365 / Mars 687 / Moon 27 / Phobos 0.32 / Deimos 1.26 / Mimas 22.6 / Europa 3.6 / Vulcan 224 / Venus 117), and on Earth-like worlds a 4-season cycle (spring / summer / autumn / winter) that drives per-season temperature, weather, wildlife, and plant overrides. Cultures get 8 launch holidays per major faction with recipe / cosmetic / event unlocks; each of M25A's 24 named NPCs has a birthday with a social bonus; every M19I crop has a per-season growing window; and a **per-cycle persistent statistics ledger** tracks kills / deaths / crafted / mined / harvested / built / lost so the player can review "Day-37 of this run" the same way a Stardew player checks "Year 2 Summer 14 — best harvest day".

M31C promise: **"the run has a calendar — your birthday is a friendship hook, your harvest only blooms in summer, the faction throws a parade on Founding Day, and the Day-37 statistics screen tells you the whole story."**

## Player-facing behavior

### Monotonic cycle counter

- Every world session boots with `cycle_id = 0` and increments by **+1** when the world's local day-length clock wraps from 23:59 → 00:00 (per-world hours, NOT a global 24h fixed).
- `cycle_id` is a `u32` monotonic counter that persists across save/load and is replay-bit-exact.
- Mid-mission saves (M25) capture the current `cycle_id` + `time_of_day` + `season` + `year` + `day_of_year` and restore them on resume.
- HUD top-right widget reads `Day {cycle_id+1} · {hh:mm} · {season} · {faction_calendar_date}` (e.g. `Day 37 · 14:22 · Summer · 18 Heatwave, Y2`).
- Storyteller (M25) reads `cycle_id` for cooldown enforcement (e.g. solar_flare cooldown = "no flare in the next 5 cycles").

### Per-world day-length in hours (`day_length_hours`)

Per-world authored constant (data row in `content/worlds/<world>.ron`):

| World | `day_length_hours` (Earth hours) | Notes |
|---|---:|---|
| Earth | 24.0 | Reference baseline |
| Mars | 24.6 | "sol"; tiny offset from Earth |
| Moon | 708.0 | One lunar day ≈ 29.5 Earth-days; **HUD wraps to compressed display** |
| Phobos | 7.66 | Fast orbit; 3 sunrises per Earth day |
| Deimos | 30.3 | Slow; midnight lasts hours |
| Mimas | 22.6 | Saturn orbit; close to Earth-day |
| Europa | 85.2 | 3.55 Earth-day rotation; long nights |
| Vulcan | 1401.6 | 58.4 Earth-days; "tidally locked hellscape" |
| Venus | 2802.0 | 116.75 Earth-days; longer than its year |
| Sol Zone | 24.0 | Orbital station; synthetic clock |
| Belt | 24.0 | Synthetic clock |
| Orbital | 24.0 | Synthetic clock |

For worlds with `day_length_hours > 168` (Moon / Vulcan / Venus), the HUD displays a **compressed clock**: `Cycle 14 · Phase: Late Day (87%)` instead of `hh:mm`. The underlying `time_of_day` float still ticks deterministically; only the readout is compressed.

### Per-world year length (`year_length_days`)

Per-world authored constant (Earth-day-equivalent, NOT local-day-equivalent — so designers compare across worlds without unit confusion):

| World | `year_length_days` (Earth-day-equivalent) | Notes |
|---|---:|---|
| Earth | 365 | Reference year |
| Mars | 687 | ~1.88 Earth years |
| Moon | 27 | Lunar synodic month rounded |
| Phobos | 0.32 | Sub-day orbital year (compressed display) |
| Deimos | 1.26 | Just over an Earth day |
| Mimas | 22.6 | Saturn moon orbit |
| Europa | 3.6 | Jovian moon orbit |
| Vulcan | 224 | Authored; "Venus-like" |
| Venus | 117 | Pre-canon; 88 Earth-day orbit rounded to 117 for story-consistency |
| Sol Zone | 365 | Synthetic calendar mirrors Earth |
| Belt | 365 | Synthetic |
| Orbital | 365 | Synthetic |

`day_of_year` wraps via `cycle_id % year_length_days`; `year_count = cycle_id / year_length_days` (integer division). Both surface in HUD + replay events.

For worlds with `year_length_days < 7` (Phobos / Deimos / Europa), the calendar year is **collapsed** in the HUD — only `cycle_id` shows; the year-wrap fires as a `calendar.new_year` event but no quarterly seasons apply.

### 4-season cycle on Earth-like worlds

Authored per-world boolean `seasons_enabled: bool` in `content/worlds/<world>.ron`. Earth-likes (Earth + Mars + Mimas + Vulcan + Venus + Sol Zone + Orbital) get seasons; pure orbital / micro-orbital (Moon + Phobos + Deimos + Europa + Belt) do NOT.

Seasons evenly divide `year_length_days` into 4 quarters:
- `spring` — `[0, year_length_days × 0.25)` — temp_offset +5°C, rain_chance × 1.4, plant_growth × 1.3, wildlife_density × 1.2
- `summer` — `[0.25, 0.50)` — temp_offset +15°C, drought_chance × 1.5, crop_yield × 1.4, lightning_storm × 1.6
- `autumn` — `[0.50, 0.75)` — temp_offset 0°C, harvest_yield_modifier × 1.2, wildlife_density × 0.9, leaf_decay
- `winter` — `[0.75, 1.0)` — temp_offset -15°C, snow_chance × 2.0 (M31B), plant_growth × 0.3, wildlife_density × 0.4

Per-season override rows live in `content/seasons/<world>/<season>.ron` and are consumed by:
- `cf-atmos` — adds `temp_offset_c` to the ambient outdoor temperature.
- `cf-weather::catalog` (M31B) — multiplies per-state spawn probability by `season_weather_modifier`.
- `cf-environment::wildlife_spawn` — multiplies wildlife density.
- `cf-actor::critter` (M19I) — multiplies plant grow rate; gates per-crop seasonal eligibility.

Season transitions fire `season.changed { from, to, cycle_id }` events.

Holiday firing logic:
- On each `cycle_id` increment, iterate all loaded holidays; for each with `schedule_day_of_year == current_day_of_year` and `world_gate.contains(current_world)`, fire `calendar.holiday_started { holiday_id, faction, cycle_id }`.
- Holiday persists 1 cycle (24 in-world hours of current world).
- `calendar.holiday_ended` fires at the next day-roll.
- Storyteller event hooks (M25) consume `holiday_id` to schedule themed incidents.

### Per-NPC birthday (24 named NPCs)

M25A's 24 named NPCs each get an authored `birthday_day_of_year: u16` in their dossier (`content/npcs/<npc_id>.ron`). On the matching `cycle_id`:
- `calendar.npc_birthday { npc_id, cycle_id }` fires.
- Birthday NPC's morale +20 baseline for the day.
- All NPCs within 16 tiles get social interaction roll boosted by × 1.5.
- Player can `act.player.gift_npc { npc_id, item_id }` for ×3 reputation bonus on birthday (vs. ×1 normal).
- HUD calendar widget highlights upcoming birthdays in the next 7 cycles.
- Birthday NPC dialog tree has a "today is my birthday" branch (M25A dialog flag).

24 named NPCs each get a unique birthday spread across the Earth 365-day year (or compressed for shorter-year worlds via `day_of_year % year_length_days`).

### Per-crop growing season

Every M19I plant + hydroponics crop gets an authored `growing_seasons: Vec<Season>` row in `content/plants/<crop>.ron`. Examples:
- `hydroponics_wheat` → `[spring, summer, autumn]` (no winter growth outdoors)
- `hydroponics_lettuce` → `[spring, autumn]` (heat-sensitive)
- `algae_terrarium` → `[spring, summer, autumn, winter]` (indoor-only; ignores season)
- `mushroom_plant` → `[spring, summer, autumn, winter]` (indoor)
- `tomato` → `[summer]` only
- `pumpkin` → `[autumn]` only
- `winter_squash` → `[autumn, winter]` only

When planted outside its season window:
- Plant accepts placement but `growth_rate_modifier = 0.1` (effectively frozen).
- HUD plant widget shows "Off-season: 10% growth".
- Plant dies if temperature drops below per-plant `min_temp_c` (winter crops survive freezing; summer crops don't).
- `plant_died_off_season { plant_id, season, cycle_id }` fires when killed by season mismatch.

Hydroponics + indoor structures (algae terrarium, mushroom plant) bypass the season gate (they have authored `season_independent: true`).

### Seasonal-events catalog (M45C integration)

Per-season weighted-spawn table for storyteller incidents:

| Season | Boosted events | Suppressed events |
|---|---|---|
| Spring | trader (× 1.4), anomaly (× 1.2), signal (× 1.2) | volcanic (× 0.6) |
| Summer | solar_flare (× 1.6), volcanic (× 1.3), pirate_raid (× 1.2) | snowstorm-tagged events (× 0.0) |
| Autumn | mineral_rush (× 1.3), famine (× 1.4), faction_war (× 1.2) | (none) |
| Winter | plague (× 1.4), eclipse (× 1.3), famine (× 1.5) | volcanic (× 0.7), solar_flare (× 0.8) |

The storyteller (M25) reads the current season per cycle and multiplies M45C's `per_tick_probability_base` for each event by the season modifier.

### Per-cycle persistent statistics ledger

`cf-stats::CycleLedger` records 7 counters per `cycle_id`:
- `kills` — actors killed by player or owned NPC
- `deaths` — player + owned NPC deaths
- `crafted` — items crafted (M32)
- `mined` — blocks broken (M30)
- `harvested` — plants + critter outputs collected (M19I)
- `built` — structures placed
- `lost` — items dropped + chests lost + structures destroyed by hostile

Persisted as a `Vec<CycleStatsRow>` indexed by `cycle_id`. Replay-bit-exact.

HUD calendar widget tab "History" shows per-cycle table:
```
Cycle | Date         | Kills | Deaths | Crafted | Mined | Harvest | Built | Lost
   0  | Spring 1 Y1  |    3  |    0   |    12   |   45  |    8    |   2   |   0
   1  | Spring 2 Y1  |    1  |    1   |     5   |   20  |    3    |   0   |   4
  37  | Summer 12 Y1 |   18  |    0   |    44   |  103  |   22    |   9   |   1
```

Per-cycle row also surfaces via `cfctl observe.stats.cycle_ledger`.

### Replay-visible events

All calendar mutations emit typed events:
- `calendar.cycle_advanced { cycle_id, season, day_of_year, year_count, world }`
- `calendar.season_changed { from, to, cycle_id, world }`
- `calendar.year_advanced { year_count, cycle_id, world }`
- `calendar.holiday_started { holiday_id, faction, cycle_id }`
- `calendar.holiday_ended { holiday_id, cycle_id }`
- `calendar.npc_birthday { npc_id, cycle_id }`
- `calendar.crop_off_season_planted { plant_id, season, cycle_id }`
- `plant_died_off_season { plant_id, season, cycle_id }`
- `stats.cycle_ledger_finalized { cycle_id, kills, deaths, crafted, mined, harvested, built, lost }`

### Storyteller hook (M25 carry)

`cf-storyteller` registers a per-cycle tick: on `cycle_id` increment, the storyteller reads season + holidays + birthdays for the new cycle and feeds them into its weighting table. Cassandra Classic uses holidays as "themed cadence beats" (every faction holiday is a guaranteed light incident); Randy Random treats holidays as chaos amplifiers (× 1.8 event volume). Phoebe Chillax suppresses deadly events on birthdays.

## Out of scope

- Moon-phase / lunar-cycle visuals (M31 ambient-light extension)
- Per-faction calendar systems that differ from the Earth Gregorian baseline (e.g. Husks using a Bloodmoon-anchored calendar) — Husks use Earth day_of_year for holiday scheduling; non-Gregorian calendars deferred to M31D
- Per-NPC zodiac / astrology compatibility math (Stardew-style preference modifiers) — deferred to M19P social-bonus extension
- Per-holiday cooked food perishable mechanics (Founders' Pie spoils if not eaten) — handled by M19O food spoilage system
- Multiplayer time-sync across co-op players in different timezones (handled by M48 co-op)
- Real-world calendar (April Fools / Christmas / etc.) — explicitly NOT a goal; the calendar is per-world-fictional

## Notes for the implementer

- `cycle_id` is `u32`, NOT `u64` — a run capping at 4 billion cycles is fine; clamp + log if anyone reaches `u32::MAX`.
- Per-world `day_length_hours` is a float because Mars (24.6) and Phobos (7.66) are non-integer. Tick conversion: `ticks_per_cycle = round(day_length_hours × 3600.0 × tick_rate)`. **DO NOT** hardcode `tick_rate = 60` — read from sim config (AGENTS.md rule).
- Season transitions must fire **before** any per-tick consumer reads season-dependent rows that cycle. Run the season FSM in the first sub-stage of the calendar tick.
- All per-cycle ledger increments must use the deterministic event bus, NOT direct counter mutation, so replays reproduce.
- The `day_of_year` float for Phobos (year_length_days=0.32) wraps multiple times per single Earth-day; treat that as authored intent — Phobos has "fast years" and surfaces only `cycle_id` in HUD.
- For Vulcan + Venus (day_length > year_length), one local day spans MORE than one local year. In that edge case, `year_advanced` fires multiple times within a single `cycle_advanced`; emit them in order before the cycle_advanced event so the HUD updates coherently.
- Holiday `world_gate` MUST exclude worlds where the faction has no presence (e.g. Cult holidays do NOT fire on Orbital station unless authored).
- The `growing_seasons: Vec<Season>` on plants is sorted + de-duplicated at load to make replay comparisons deterministic.
- Per-cycle ledger persists in the scenario save blob, NOT a separate file — co-located with sim state to avoid save-load drift.
- All RNG for holiday-scheduled storyteller events MUST seed off `scenario_seed XOR cycle_id XOR holiday_id_hash`, NOT `thread_rng()` (AGENTS.md rule).
- 24 NPC birthdays: distribute evenly across Earth's 365-day year at load via the M25A dossier schema; don't hardcode here.
