M6 promise: **"AI navigates the destructible world like a human would — finds the path, adapts when terrain changes, doesn't get stuck."**

## Player-facing behavior

### Hierarchical Pathfinding A* (H-PA*)

- 3 levels: tile-level (per pixel; for short-range moves) → chunk-level (256-tile chunks; for mid-range) → region-level (multi-chunk; for cross-map)
- A* per level with appropriate heuristic (Manhattan for tile; Euclidean for chunk/region)
- Cache invalidation on `terrain.terrain_dirty_region_batch` (per affected chunk only)
- Per-tick budget: ~80ms for pathfinding across 50 actors (Steam Deck floor)

### Dynamic re-pathing

- AI rebuilds path when terrain dirties in current segment (M2 dirty-region tracker → M6 path recompute)
- Stuck-detection: if AI velocity ~0 for N ticks, force re-path (event `ai.path_invalidated`)
- Stale paths get "ignore stale costs" fallback (per DR-007 risk mitigation)

### Per-team path costs

- Per-team weight table per material (e.g. team_A treats hazard tile as path_cost=∞; team_B has hazmat suit, cost=normal)
- Material registry has 9 affordance flags + per-team_path_cost extension

### Multi-actor collision avoidance

- Spatial hashing for O(1) neighbor lookup
- Steering forces: separation (push away from neighbors), alignment (match velocity), cohesion (move toward group center)
- Reservation system: actors claim path segments; conflicts resolved by priority (lower-priority yields)

### Sleeping AI optimization

- AI in `IdleSleeping` state skip per-tick perception + pathfinding
- Wake when player within audible range OR vision range OR alarm radius
- Per `ai-sleeping-pattern` (M5.6 cells skip when sleeping; M6 same pattern for AI)

## Acceptance criteria

```gherkin
Scenario: H-PA* finds path through dynamic terrain
  Given AI at (X1,Y1) + target at (X2,Y2) + destructible terrain
  When act.ai.path_to fires
  Then ai.path_built fires with hierarchy=region→chunk→tile
  And path completes in ≤80ms (Steam Deck floor)

Scenario: Dynamic re-pathing on terrain dirty
  Given AI traversing path
  When terrain.terrain_dirty_region_batch fires on current path segment
  Then ai.path_invalidated_dirty_chunk fires
  And AI recomputes path
  And no stuck behavior

Scenario: Stuck recovery
  Given AI velocity ~0 for 60 ticks (stuck)
  Then ai.path_stuck_recovery fires
  And alternative path computed (or ignore-stale fallback)

Scenario: Per-team path costs
  Given team_A treats hazard tile as path_cost=∞
  And team_B has hazmat suit (normal cost)
  Then team_A routes around hazard
  And team_B routes through hazard
  And ai.path_built records team_specific_cost

Scenario: Multi-actor collision avoidance
  Given 10 actors in narrow corridor
  When all move toward exit
  Then ai.collision_avoided fires for conflicts
  And actors spread/queue without bunching

Scenario: Sleeping AI skips pathfinding
  Given AI in IdleSleeping state + no nearby threats
  When tick runs
  Then ai.sleeping_state_changed=Sleeping fires once
  Then no per-tick pathfinding for sleeping AI
  When player enters audible range:
    Then ai.sleeping_state_changed=Awake fires; pathfinding resumes
```
