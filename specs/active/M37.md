# M37 — Voice + Radio + Comms

## Status

`active`

## Intent

**M37 is the voice + radio + comms milestone** — ACRE2-tier voice + radio simulation per DR-043. After M37, players communicate with squad via voice chat with realistic radio propagation, interference, EMP failure, captions, accessibility fallbacks, and AI reason labels explain what bots believe is happening.

M37 promise: **"voice + radio are gameplay — proximity matters, interference is real, EMP cuts comms, and captions never lock out deaf players."**

## Player-facing behavior

### AI chatter — production voice replaces M7 placeholder TTS

M7 ships the **chatter scaffold** (placeholder TTS strings + cooldown table + captions). M37 closes the loop with **production-quality voice** generated through DR-053's AI audio pipeline (ElevenLabs / Bark / XTTS / MusicGen per `cortext_command_vault/decisions/dr-053`). The M7 chatter trigger logic + cooldown table + caption infrastructure is preserved unchanged; M37 just swaps the audio asset under each chatter event.

| Production layer | Notes |
|---|---|
| Per-actor voice line library | ~50-100 voice clips per named actor (Combat / Treating / Repairing / Spotted / Reloading / Falling Back / Acknowledge / etc.); generated via DR-053 pipeline + usage-ledger logged |
| Per-archetype voice library | ~20 generic clips per archetype (Medic / Engineer / Rifleman / Sniper / Assault / Spotter) for un-named actors |
| Per-faction accent / language | 8 factions × distinct vocal style (vault per-faction style.json sets pitch / pacing / accent) |
| Radio occlusion | Voice clips processed through M37 radio propagation pipeline (distance attenuation + occlusion + frequency band + antenna height). M7's clean caption text never degrades; only the audio degrades. |
| Caption parity | Every voice clip has its caption from M7. ACC-A: audio degradation NEVER reduces caption clarity. |

### Voice chat (proximity-based)

- Voice transmits at proximity (similar to ACRE2)
- 3 channels: Squad (encrypted) / Public (open) / Faction (faction-only)
- Push-to-talk default; toggleable to voice activity
- Per-player mute / volume per channel

### Radio propagation (ACRE2-inspired)

- Radio sets in inventory: short-range (5km) / medium (15km) / long (50km+)
- Propagation: distance attenuation + occlusion + frequency band
- Antenna height affects range
- Underground / through walls: signal degraded
- Cave / heavy terrain: blocked

### Interference + EMP

- EMP grenades (from M6) disable radio for 5-30s
- EMP from machines (generators, reactor breaches)
- Solar flares (Sol-zone scenarios) disrupt for minutes
- Comms blackout affliction (DR-040 hazard taxonomy)

### Subtitle system + captions

- All voice + radio captioned (per DR-012 accessibility)
- Subtitle modes: Off / Critical-Only / Standard / Expanded (per M11 caption modes)
- Per-actor identification in subtitles
- Speaker indicator (visual ring around current speaker)

### Vacuum no_voice

- In vacuum: no audio voice transmission (sound doesn't propagate)
- Radio still works (electromagnetic; not sound)
- HUD banner "VACUUM — radio only" surfaces

### AI radio chatter

- AI bots emit radio chatter on key events:
  - "Contact, west wall!"
  - "Reloading!"
  - "Down!"
  - "Need help over here!"
- Reason labels accompany (per DR-008 humanlike AI)
- Bots respond to player voice (via M23 MIND or scripted patterns)

### Comms HUD

- Voice channel indicator (which channel active)
- Per-speaker direction arrow (from where the sound came)
- Subtitle stream (top or bottom; configurable)
