# M26B — Dialogue UI + Conversation Trees + Speaker Portraits + Voice Playback + Per-NPC Dialog State

## Status

`active`

## Intent

Closes the UX hole M26 left open: M26 declared "8 factions / 24 named NPCs / 4 default dialog options / dialog branches drive faction relationship + reveal lore + unlock side missions" but never authored **how the player sees + hears + picks** a dialog line. M26B ships the **conversation runtime + dialogue UI** end-to-end — speaker portrait + name plate + dialog text panel + 4 choice buttons + voice playback hooked to M12A/M37A + skip + replay + per-NPC dialog state persisted in the save + per-faction dialog template + per-NPC personal tree + branching outcomes with per-choice morale/reputation deltas + the 8 launch quest templates from M26 wired into the conversation runtime so a quartermaster handing out a Scavenge quest actually plays as a conversation, not a popup.

M26B promise: **"every NPC you walk up to opens a real conversation — portrait, voice, four meaningful choices, branches that actually change faction reputation + party morale + quest state, and the game remembers what you said last time."**

## Player-facing behavior

### Dialogue UI shell

Triggered by `act.player.npc_interact { npc_id }` when the player is within interaction radius of a named NPC. The UI is a full-screen modal that pauses the local-area sim (`sim.local_pause` per M25 base mode; gameplay tick continues outside the conversation zone for multiplayer/M45 PvE consistency):

- **Speaker portrait** — left third of screen; M9A-baked portrait sprite scaled to 70% of viewport height; outlined in the speaker's faction palette; M12 ink-line styling applied selectively per `<npc_id>.dossier.ron` flag; expression frame chosen from `{neutral, smiling, angry, fearful, surprised, knowing}` per the active dialog node's `expression` field.
- **Name plate** — under the portrait: `<NPC display name>` + faction emblem (small) + relationship pip (-100..+100 colored slider) + role tag (`Quartermaster | Storyline | Quest Giver | Friendly Stranger | Recruiter | Captive | Storyteller Avatar`).
- **Dialog text panel** — right two-thirds, top half; speaker-relative line styled per faction (Hostile Corp = corporate sans, Marauder Tribes = handwritten brush, Religious Order = serif blackletter, etc.); typewriter reveal at 40 cps unless reduce-motion=true (then instant); subtitle ribbon always-on when captions_enabled.
- **Choice buttons** — right two-thirds, bottom half; up to 4 choices stacked vertically; per-choice icon (talk / trade / accept / threaten / sympathize / leave / etc.); per-choice hover-preview tooltip showing the **predicted reputation/morale delta** if knowable (otherwise `?`); disabled choices grayed with reason tooltip ("requires +50 relationship", "requires Recruit perk", "first meeting only").
- **Skip + replay controls** — `[Tab]` skips typewriter to instant reveal; `[Space]` after text complete advances to next node OR shows choices; `[R]` replays the current node's voice + text; `[Esc]` opens "leave conversation" confirm.
- **Voice playback indicator** — small waveform glyph next to portrait that pulses with playing voice clip amplitude (visual-only echo of the M12A audio mixer).

### Per-NPC dialog tree structure

Each named NPC ships a `<npc_id>.dialog.ron` under `content/dialog/`:

```ron
DialogTree(
    npc_id: "quartermaster_coalition_vega",
    faction: "coalition",
    role: Quartermaster,
    portrait_id: "portrait_npc_quartermaster_coalition_vega",
    voice_actor_id: "vo_coalition_quartermaster_female_warm",
    default_template: "faction_quartermaster",
    personal_root: "vega_first_meeting",
    nodes: {
        "vega_first_meeting": Node(
            line: "Another contractor. Hope you live longer than the last one.",
            expression: knowing,
            choices: [
                Choice(id: "ask_mission",  template: faction_quartermaster_ask_mission,  goto: "vega_mission_offer"),
                Choice(id: "trade",        template: faction_quartermaster_trade,         goto: "vega_trade_open"),
                Choice(id: "recruit",      template: faction_quartermaster_recruit,       goto: "vega_recruit_pitch", requires: Relationship(min: 50)),
                Choice(id: "leave",        template: faction_default_leave,                goto: END),
            ],
            on_enter_deltas: [Familiarity(+1)],
        ),
        ...
    },
)
```

- **Per-faction dialog template** — `content/dialog/templates/<faction_id>_<role>_<choice_id>.ron` provides the **shared line + outcome** for each `(faction, role, choice)` triple. A new Coalition quartermaster needs only a 10-line personal tree because all 4 default options (`ask_mission`, `trade`, `recruit`, `leave`) auto-inherit the Coalition-Quartermaster template. **Personal tree overrides template** when a node specifies a custom line.
- **Personal root** — first-meeting hook unique to each named NPC; subsequent meetings drop into the template chain.
- **Familiarity track** — `save.npc_dialog_state.<npc_id>.familiarity: u32` increments each meeting; `>=3` unlocks personal-history branches; `>=10` unlocks "old friend" voice lines.

### 4 default options (per DR-027 + M26)

Every named NPC has these 4 buttons available unless the per-node script overrides:

| Choice | Effect | Faction template anchor |
|---|---|---|
| `ask_mission` | Opens quest offer subtree; pulls 1-3 quests from the 8 quest templates | `<faction>_<role>_ask_mission` |
| `trade` | Opens M27 quartermaster inventory; closes dialog (returns on shop close) | `<faction>_<role>_trade` |
| `recruit` | Opens recruit-to-squad pitch (gated by relationship + perk + slot availability) | `<faction>_<role>_recruit` |
| `leave` | Closes dialog; familiarity +1; relationship +0 | `faction_default_leave` |

Per-node scripts can replace any of the 4 with custom choices (e.g., `threaten`, `sympathize`, `bribe`, `interrogate`, `confess`) — the **slot budget stays at 4**; never more, never fewer.

### Branching outcomes + per-choice morale/reputation deltas

Each choice declares zero or more deltas applied on selection:

| Delta kind | Effect |
|---|---|
| `Relationship(faction_id, delta: i32)` | Adjusts player ↔ faction relationship (-100..+100), fires `faction.relationship_changed` |
| `Morale(squad_member_id?, delta: i32)` | Adjusts squad morale (+ optionally per-actor); fires `squad.morale_changed` |
| `Reputation(scope: Global|Region|Faction, delta: i32)` | Adjusts the player's reputation score consumed by M25 / M41 / M45 |
| `Quest(action: Offer\|Accept\|Complete\|Abandon, quest_id)` | Drives the quest log via M26 quest events |
| `Item(action: Give\|Take, item_id, count)` | Player inventory delta |
| `Codex(unlock, codex_id)` | Unlocks a codex entry per M25A |
| `Familiarity(delta: i32)` | Per-NPC familiarity track |
| `Memory(tag)` | Adds a player-action memory tag to the NPC (consumed by future dialog branches) |

A single choice can stack multiple deltas; deltas resolve atomically on choice confirmation. The hover-preview tooltip surfaces the **player-visible deltas** (Relationship + Morale + Reputation + Quest); Item/Codex/Familiarity/Memory deltas are post-confirmation reveals.

### Voice playback via M12A / M37A

- Each dialog line has a baked voice clip at `content/audio/voice/dialog/<npc_id>/<node_id>.ogg`. Tier 1 placeholder bakes ship at M26B; Tier 2 production-grade bakes ship at M37A.
- The conversation runtime plays the clip via the existing `AudioCue::Voice { speaker, line_id, channel: DialogChannel }` cue from M12A's audio kernel, ducking music and SFX per the M12A LUFS mix profile.
- Word-level timestamps (when present in `<node_id>.line_track.json`) drive the typewriter cadence (text reveals in sync with voice) and the caption ribbon highlight per M12C narration sync.
- Missing voice clip = silent playback with full text + caption (never block on missing audio).
- Players can mute dialog voice independently via `settings.audio.dialog_voice_volume`; captions still display.

### Skip / replay / leave UX

- **Skip typewriter** — `[Tab]` instant-reveals the current line; voice clip continues. Second `[Tab]` jumps to choices.
- **Replay current line** — `[R]` re-emits the line text + restarts the voice clip from t=0 (`dialog.line_replayed { npc_id, node_id }`).
- **Skip whole conversation** — disabled by default. Pressing `[Esc]` opens a confirm popup: "Leave the conversation? You'll lose the offered options." Confirm → `leave` choice deltas applied (familiarity +1 only); no other branch consequences.
- **Replay past conversations** — `Codex → NPCs → <npc_id> → Conversation Log` shows the full text transcript of past meetings with timestamps; clicking a node re-plays its voice clip but never re-applies deltas.

### Per-NPC dialog state persisted in save

The save format gains a `npc_dialog_state: HashMap<NpcId, NpcDialogState>` field:

```rust
struct NpcDialogState {
    familiarity: u32,
    last_seen_tick: TickId,
    last_node_visited: Option<NodeId>,
    visited_nodes: HashSet<NodeId>,
    memory_tags: HashSet<MemoryTag>,
    mood: i32,                                // -100..+100, drifts toward faction relationship
    relationship_to_player: i32,              // -100..+100, per-NPC override of faction relationship
    offered_quests: HashSet<QuestId>,
    completed_quests_with_npc: HashSet<QuestId>,
    death_recorded: bool,                     // NPC is dead in current campaign
}
```

- **Greeting variants** — first-meeting greeting fires only when `familiarity == 0`; returning-visit greeting when `familiarity > 0`; old-friend greeting when `familiarity >= 10`.
- **Memory of past player actions** — choices can write `Memory("betrayed_at_first_meeting")`; future branches gate on memory tags (`requires: Memory("rescued_my_brother")`).
- **NPC death** — if the NPC is killed by player or another actor (M16 death event), `death_recorded=true`; subsequent attempts to interact route to `dialog.npc_dead` (no UI; ambient "they don't answer" line + leave).
- **Save migration** — schema version `npc_dialog_state.v1`; future schema bumps via M41 save migrator.

### Per-faction dialog templates

`content/dialog/templates/<faction>_<role>_<choice>.ron` — the matrix is:

- 8 factions × 4 roles (`Quartermaster | Storyline | Quest Giver | Recruiter`) × 4 default choices (`ask_mission, trade, recruit, leave`) = **128 templates** at launch.
- Each template authored in M25A faction-voice (Coalition formal-bureaucratic, Marauder tribal-aggressive, Religious Order doctrinaire-ornate, Drone Collective synth-disjointed, Pirate weathered-jovial, etc.).
- Per-template branching for relationship gates (allied vs hostile vs neutral lines).

### 8 quest templates wired to conversation runtime

The 8 M26 quest templates (`Scavenge | Defend | Eliminate | Rescue | Investigate | Voyage | Trade | Boss Hunt`) each ship a conversation sub-tree under `content/dialog/quest_templates/<template_id>/`:

- **Offer node** — questgiver describes the quest in a 2-4 line beat ("Pirates are running a black-ice op out of Mimas. Bring me three crates and I'll cut you in.").
- **Accept / decline / haggle** — 4 choice buttons (`accept | decline | haggle_reward | ask_details`); `haggle_reward` adds a `Relationship(-5)` delta and a `Reputation(-2)` delta to coerce the questgiver into a +25% reward bump (success gated by faction relationship + speech perk).
- **Mid-quest check-in** — re-talking to the questgiver during the active quest opens a check-in node with `ask_progress | request_help | abandon | leave`.
- **Completion node** — on quest objective complete + return-to-giver, the runtime fires a completion conversation: line + reward delivery + Relationship + Reputation + Codex unlocks.

Quest-template conversations are **inherited** by every faction questgiver via the template system; per-faction overrides for tone are applied as text-substitution patches.

| Event | When |
|---|---|
| `dialog.opened { npc_id, opening_node, source: NpcInteract\|QuestOffer\|StorytellerCallin }` | First node enters |
| `dialog.node_entered { npc_id, node_id }` | Each node transition |
| `dialog.choice_selected { npc_id, node_id, choice_id, applied_deltas }` | Player clicks a choice |
| `dialog.line_replayed { npc_id, node_id }` | Player presses `[R]` |

## Notes for the implementer

- Template merge is **node-level**, not file-level: if the NPC's personal tree has node `ask_mission`, that node wins entirely; the template's `ask_mission` is NOT spliced in. Keep merge logic dumb and predictable.
- Delta application MUST be atomic per choice — wrap in a single transaction in `delta_applier` and emit replay events in stable order (alphabetical by delta kind).
- The 4-choice slot budget is enforced at **load time** by `cf-mod`, not at runtime. Authoring more than 4 fails the bake.
- Typewriter cps is `40` by default and lives in a constant; reduce-motion settings collapse it to instant reveal (NOT a hardcoded tick assumption — convert via active tick rate where applicable).
- The "leave" choice is **always present** even when authored as omitted; the runtime injects a synthetic `leave` choice if the node script forgets it (player-out clause).
