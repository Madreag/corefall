# M35 — Advanced Mining + Extraction

## Status

`active`

## Intent

**M35 is the advanced mining + extraction milestone** (per DR-041). Builds on M30's basic mining foundation to ship the full extraction pipeline: deep drilling, advanced refining, server-grade ledger replication, conveyor-belt automation, and the full AI-MINE-A acceptance suite. After M35, mining is server-authoritative, mod-extensible, and accessible across all 12 launch worlds.

**M30 must close first** — M35 extends M30's surface; it does not replace it.

M35 promise: **"mining is a first-class server-authoritative gameplay loop — survey ore deposits, drill, refine, smelt, build with the output, defend supply lines from raiders, automate via conveyor belts."**

## M8A foundation

M35's persistent MMO sit on top of M8A's server architecture. Specifically:

- The Apple Mini Lab server tier (Mac mini M4 Pro 64 GB / 24 GB cluster, 3-5 nodes, 10 GbE switch) defined in M8A is the prerequisite shard-validation hardware for M35's persistent-world mesh. M35 doesn't ship the mesh; M35 inherits a `cf-net::server` (M8A) capable of running a single canonical shard, then the mesh layer (DR-035) builds the cross-shard merge protocol.
- M35's mining ledger MUST go through M8A's `cf-net::snapshot` envelope for cross-shard reconciliation. Per-shard checksums emit at M8A's locked cadence (every 64 ticks); cross-shard divergence detection is the M35 mesh layer's job.
- The "server-authoritative ledger" cited in M35 means: M8A's `cf-headless serve` is the source-of-truth process for every ore drop / smelter conversion / transmutation event in M35. Clients send inputs, server simulates, server emits semantic events (no bitmap deltas).
