# M30D — Geological Survey + Multi-Band Prospecting + Heatmap Overlay

## Status

`active`

## Intent

Surface Stationeers/ONI-grade geological survey: multi-band echo from Sampler (M30) + per-depth-band ore reveal (surface / subsurface / deep crust / core) + color-coded heatmap overlay on the world map (M43A) so players can prospect-before-dig instead of randomly carving.

## Player-facing behavior

- **Sample at the surface**: sampler emits a pulse → reveals ore types within a radius for the current depth band only.
- **Deeper sample**: surveyor on a deeper drill rig samples subsurface band → reveals deeper ore + risk warnings (e.g., "Methane pocket below at depth 32 px").
- **Heatmap overlay**: per-world map (M43A) shows ore density gradients per depth band; player switches band via [1/2/3/4] keys (surface/subsurface/deep_crust/core).
- **Veined / pocketed / streak / uniform**: the four ore distribution shapes show distinctly on the overlay (veins as lines; pockets as clusters; streaks as bands; uniform as low-amplitude noise).
- **Live updating**: as the player surveys more areas, the heatmap fills in (initially gray → colored after sample).
- **Risk warnings**: surveyor flags hazard pockets (lava chamber / gas seep / radiation hot zone) on the overlay with red icons.
- **Auto-prospecting drone** (T3): drone autonomously surveys a region; returns to base with map data after 10-30 minutes.
- **Server-authoritative claim**: in PvP/MMO, a player surveys an area → their faction is the first claim; sharing or competing surveys creates trade/strategy gameplay.

```gherkin
  When both surveys complete
  Then the first-to-arrive faction's results are claim-priority
  And the second faction sees partial data + "contested zone" warning

Scenario: Determinism across ore_generator
  Given a world_seed=12345 + chunk (10, 20)
  When ore_generator runs on two engines
  Then identical ore_pixel placement
  And identical reveal sequence on identical surveys
  And replay byte-identical

Scenario: Player surveys + then digs with M30B tool
  Given a survey reveals iron at deep_crust band (depth 64 px)

  And the survey-then-mine workflow is established
```

## Out of scope

- Sub-pixel resolution geology (per-pixel ore variants) — sample is per-cell (8×8 pixel resolution).
- 3D depth axis with continuous z-coordinate — depth_band is discrete (4 bands).
- Stealth-survey (drone invisible to enemy AI) — M48+ stealth tech.
- Survey forgery in multiplayer (faking results to deceive enemies) — M48+ social engineering.

## Notes for the implementer

- Real procgen for veined/pocketed/streak/uniform shapes uses Perlin worms / clustered Poisson disc / 1D-noise streaks / 2D-noise uniform — all seedable via `world_seed XOR chunk_xy`.
- Heatmap rendering uses M11 overlay patterns + per-band layer compositing.
- Sample pulse is single-shot (no continuous beam); cooldown 2s to prevent spam.
- Auto-prospector drone uses cf-perception + M22 path-planning + IC10 chip slot for route customization.
- Hazard pocket detection reads M16 hazard + M19 atmospheric pocket data; surveyor only "knows about" what M30D has scoped — methane / lava / radiation / cold-vent / hot-vent.
