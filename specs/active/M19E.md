# M19E — Atmospheric Analyzer + Combustible Gas Detection + Multi-Room Auto-Response

## Status

`active`

## Intent

Stationeers Atmospheric Analyzer module + per-room hazard detection (combustible mix / toxin / low-O2 / smoke / refrigerant leak) + IC10 alarm chip auto-response + multi-room consequence chain — turns the atmospheric kernel from "the game knows" into "the player sees + the system responds."

## Player-facing behavior

- **Atmospheric Analyzer module**: place in a room → reads PV=nRT composition + temperature + flammability ratio + O2 partial pressure + CO2 buildup + toxin levels. Displays on HUD per-room.
- **Per-room hazard thresholds**:
  - Combustible mix: Volatiles + O2 both above 5% threshold (per Stationeers DR-037).
  - Hypoxic: O2 < 16 kPa (Stationeers yellow); critical < 12 kPa.
  - Hypercapnic: CO2 > 0.5% partial.
  - Toxic: Pollutant > 0.1 mol (Stationeers threshold).
  - Refrigerant: R-22 / ammonia / CO2 supercritical present.
  - Smoke: smoke material density > 5%.
- **Alarm chain**:
  - L1 yellow: warning HUD banner per room.
  - L2 orange: caption + audio alarm + auto-vent triggered.
  - L3 red: emergency cascade (auto-airlock + HVAC shutdown + sprinkler if combustible + crew alert).
- **IC10 alarm chip**: programmable: "if Volatiles > 5% then close all airlocks + vent room + alert squad."
- **Per-actor hazard awareness**: actors in hazardous room receive HUD warning + automatic AI-driven retreat behavior.
- **Multi-room consequence chain**: smoke detection in one room → atmospheric analyzer in adjacent rooms reads contamination level → quarantine via M28D damper closure.

## Acceptance criteria

```gherkin
Scenario: Atmospheric Analyzer reads room composition
  Given a sealed living quarters with an Atmospheric Analyzer
  When the player opens the analyzer dashboard
  Then per-room composition shows: 75% N2, 25% O2, 0.1% CO2, temp 22°C, pressure 101 kPa
  And updates per tick

Scenario: Combustible mix alarm triggers
  Given a room with Volatiles 7% AND O2 12% (both above 5% threshold per DR-037)
  When the analyzer threshold check runs
  Then combustible_mix_detected fires
  And HUD displays "WARNING: COMBUSTIBLE MIX" red banner
  And audio alarm plays in the room

Scenario: Auto-vent on L2 hazard
  Given an Atmospheric Analyzer with default auto-vent rule
  And Pollutant > 0.1 mol in the room (toxin threshold)
  When toxin_alarm fires
  Then auto-vent triggers (M28B emergency_vent variant or M28D damper opens to outside)
  And quarantine_triggered fires (M28D dampers close to adjacent rooms)
  And HUD shows "QUARANTINE — ROOM <id> ISOLATED"

Scenario: IC10 chip programs custom threshold
  Given a player writes an IC10 chip: "if O2 < 14 kPa then alert squad + auto-evacuate"
  When O2 drops below 14 kPa
  Then chip fires alert
  And ai.squad_evacuation_initiated event fires
  And M22 squad doctrine moves all squad members to safer rooms

Scenario: Hypoxia alarm in vacuum-exposed room
  Given a sealed room that suddenly experiences a hull breach (vacuum exposure)
  When O2 partial pressure drops below 16 kPa
  Then hypoxia_alarm fires
  And HUD shows "OXYGEN LOW" (yellow) → "OXYGEN CRITICAL" (red)
  And actor receives in-suit warning (M19C consumer)
  And alarm cascades to repair priority queue (M28 + M28B)

Scenario: Multi-gas panel monitors multiple rooms
  Given a multi_gas_panel placed at base entry point
  When 5 rooms are surveyed by their atmospheric analyzers
  Then the panel displays all 5 rooms' status
  And player can filter / sort / acknowledge alarms

Scenario: Acknowledge alarm clears notification
  Given multiple alarm events have fired in the past 60s
  When the player acknowledges via UI
  Then alarm_acknowledged fires
  And HUD notifications hide
  And the actual hazard remains (acknowledge ≠ fix)
  And the player must address the underlying cause

Scenario: AI hazard awareness automated retreat
  Given an AI worker in a combustible-mix room (analyzer threshold crossed)
  When the AI hazard_awareness doctrine reads the threshold
  Then AI initiates retreat to safer area
  And cf-ai.reason_label="hazard_avoidance"
  And ai.retreat_under_hazard event fires

Scenario: Multi-room quarantine sequence
  Given a smoke event in Room A
  When smoke_detector triggers per M28E
  Then quarantine_triggered fires for Room A
  And M28D dampers close on all routes to adjacent rooms
  And atmospheric analyzers in Rooms B, C, D verify clean state
  And player must clear smoke before quarantine lifts

Scenario: Determinism across alarm chains
  Given two engines with same seed + identical hazard sequence
  When 600 ticks elapse with multiple alarms
  Then identical alarm event sequence
  And identical SaveBlob.checksum at tick 600
```

## Notes for the implementer

- Atmospheric Analyzer is the canonical readable surface — modders extend via RON; mod-defined hazards inherit from M19E producer surface.
- IC10 chip programming surface is exposed via M29A IC10 editor.
- Threshold values are configurable per-RON; defaults match Stationeers (16 kPa O2; 5% Volatiles; 0.1 mol Pollutant; 5% combustible mix).
- Quarantine cascade uses M28D damper closure ordering: outer rooms first, then inner; deterministic path-traversal.
- Per-room AI awareness flag propagates: AI reads analyzer; AI escalates to player if no human player in mission (per M22 commander AI doctrine).
