# M34 — Material Lab

## Status

`active`

## Intent

**M34 is the Material Lab milestone** — `cf-tools-editor --mode material_lab` workbench per DR-036. Designers + modders author tiny systemic-material puzzles in <10 minutes using brushes, material palette, recipe inspector, stamp save/load (Powder Toy pattern), snapshot/delta undo, test-run with replay capture, and AI puppet validation. M34 is the **modding stress test** for M15 active-material kernel + M16 hazard package + M19 atmospherics. After M34, the material lab is the proving ground for both designer authoring + AI material competence (M24 puppet test).

M34 promise: **"a designer authors an acid trap with water counter, an oil-fire chain reaction, and an electrified-water shock zone in minutes — then shares them as `.cfpkg` packages."**

## Player-facing behavior

### Material Lab workbench (cf-tools-editor --mode material_lab)

Per `spec/material-lab` + Powder Toy reference:

- **Brush tools**: paint per pixel (4×4 / 8×8 / 16×16 / 32×32 brush sizes) with selected material + temperature + state
- **Material palette**: 17 launch materials + 13 expansion materials (slime / brine / coolant / cryo / fuel_vapor / foam / nanogel / alchemic_precursor / Midas / biological variants — material lab unlock first)
- **Recipe inspector**: click any pixel → tooltip shows material id, temperature, state (solid/liquid/gas/plasma), density, last reaction parent cause, electricity charge if applicable
- **Stamp save/load**: select a region → save as `.cfstamp` file → place into another scenario / share via mod package
- **Snapshot/delta undo**: per-tick state snapshot; redo via delta replay (per Powder Toy pattern)
- **Test-run mode**: hit Space → simulate stamped scenario for 30s → capture replay events
- **AI puppet test**: `cfctl --bot puppet` plays the lab scenario; AI affordance reasoning visible in real-time
- **Recipe journal**: reactions discovered by the designer/player are recorded; UI shows reagents → byproducts; debrief cause chains link back

### Material pack format (`.cfpkg`)

Mod packs can declare:
- NEW materials (extends M15 50+ material registry)
- NEW reactions (extends M15 reaction table)
- NEW ingestion effects (per origin matrix — what happens when human/android/robot consumes a material)
- NEW pipe devices (extends M19 atmospheric devices)
- NEW AI affordances (per-material `ai_affordance_tag` — avoid/seek/use-as-weapon/extinguish-with/neutralize-with)

Validated by `cargo run -p cf-mod -- validate <mod>`.

### AI puppet test (M24 hazard perception integration)

When a designer runs the AI puppet test:
- `cfctl --bot puppet --scenario <lab-pkg>` plays the lab scenario
- AI bot reads `EnvironmentSignal` per M20 + per-material affordance tags
- AI doctrine reasons about hazards (avoid acid pool / seek water counter / use oil as trap)
- Replay event stream shows AI's reason labels ("avoid_corrosive_acid", "seek_extinguish_water_for_fire", etc.)
- Designer learns whether their puzzle is AI-readable

### Accessibility floor (DR-012 ACC-A)

- 200% UI scale support
- High-contrast overlays for material categories
- Color-independent state labels (text always present per category)
- Controller / keyboard / mouse parity

### Run-bundle integration

Lab session emits:
- `material.*` events (every paint, delete, brush stroke)
- `reaction.*` events (every reaction discovered)
- `atmospherics.*` events (every aperture / pressure change)
- `editor.*` events (every stamp save, load, package export)
