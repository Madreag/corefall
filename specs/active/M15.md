### Material state transitions (water → steam → cloud → rain)

Per material `phase_transitions: Vec<PhaseTransition>`:

- `water` solid at 0°C, liquid at 0-100°C, gas (steam) at >100°C
- `oil` liquid at -20-200°C, gas at >200°C
- `mercury` liquid at -38°C to 357°C
- `wood` solid; burns to ash at >500°C
- `iron` solid <1538°C, liquid at >1538°C, gas at >2862°C
- All transitions reversible (steam cools → water; obsidian heats → lava)
- Visual state changes when phase crosses threshold
- Phase change consumes/releases latent heat per material

Events: `material.phase_transition { material, from_state, to_state, pos, temperature }`.

### Preservation rules from M3 (DO NOT regress)

M3's architectural rules are inherited by M15 without exception:

1. **`AddUpdatedMaterialArea` is the ONLY dirty path** (per CCCP `SLTerrain.cpp:397-481`). Every place that mutates a pixel — CA step, reaction, phase change, GPU compute writeback — MUST call it. Code review checks this contract. Raw `set_material_pixel` without `add_updated_material_area` is a bug.
2. **9 affordance flags preserved** from M3 registry: `actor_passable, projectile_passable, diggable, drillable, blastable, anchorable, beam_cuttable, blocks_line_of_sight, damage_on_touch`. M15 may add new flags (e.g. `flow, breathability, water_creation`) but never removes M3's flags.
3. **Material reference hardness values from M3 baseline** carry forward (concrete=40, metal_nohook=100, dirt=10, loose_fill=5, anchor=60). M15 may add new materials but doesn't re-tune M3 launch set without DR.
4. **Active-region flag** on each Chunk (M3 always writes false; M15 sets true for chunks with falling materials). Per Noita pattern: most of world sleeping; only chunks with falling materials wake up.
5. **Penetration formula `impulse² > integrity²`** (per CCCP `SceneMan.cpp:571`). Squared comparison avoids `sqrt` in hot path.
6. **Stickiness rolls via engine RNG**, not `thread_rng()`. M3 enforces; M15 preserves.
7. **Debris cap per event** (M3 caps at 100). M15 may raise budget but `terrain.debris_capped` event still fires when threshold hit.
