# M19J — ONI Overlay UI System (F1-F12 Toggle Layers)

## Status

`active`

## Intent

The full ONI-grade overlay UI suite: 12+ toggle-able overlay layers (oxygen / temperature / pressure / electrical / liquid / gas / germ / light / decor / radiation / priority / pathing) that the player toggles via F1-F12 (mappable) — the "ONI survives complexity through overlays and meters" rule turned into a first-class Corefall feature.

## Player-facing behavior

- Press F1 → Oxygen overlay: per-tile O2 ppm + per-room O2 partial pressure + warning bands.
- Press F2 → Temperature overlay: per-tile temperature gradient (red hot, blue cold, white neutral).
- Press F3 → Decor overlay (M19H): per-tile decor score gradient.
- Press F4 → Germ overlay (M19H): per-tile germ count + variant.
- Press F5 → Power overlay (M29A): live electrical grid + cable health.
- Press F6 → Thermal Conductivity overlay (M28B + M3B): per-material heat flow.
- Press F7 → Pressure overlay: per-tile mass × pressure + per-room atmospheric pressure.
- Press F8 → Tile Inspect overlay (M3B): per-tile element + mass + temperature.
- Press F9 → Disease overlay (M19H): per-actor + per-tile disease state.
- Press F10 → Priority overlay (M19K-style mining priority queue).
- Press F11 → Light overlay (M19H): per-tile light level.
- Press F12 → Radiation overlay (M16): per-tile dose + ambient radiation.
- Per-overlay scrub: hovering shows numeric value; click for detailed panel.
- Overlay smart-stacking: F-key combos stack overlays (e.g., F1 + F2 = oxygen + temperature simultaneously).
- Accessibility: high-contrast mode + colorblind palette + text labels per DR-012.

## Acceptance criteria

```gherkin
Scenario: F1 toggle activates oxygen overlay
  Given the player presses F1
  When the per-frame overlay system runs
  Then oxygen overlay renders as gradient over the world
  And per-tile O2 partial pressure visible
  And per-room overlay shows aggregated value
  And overlay_toggled fires with layer="oxygen", active=true

Scenario: F-key cycling cycles overlays per layer
  Given the player holds F1 + presses Tab
  When the overlay system reads the cycle command
  Then overlay_layer_cycled fires
  And oxygen overlay sub-layer cycles: per-tile → per-room → per-actor → reset

Scenario: F1 + F2 stack overlays
  Given the player presses F1 and then F2 (no release)
  When the per-frame overlay system runs
  Then BOTH oxygen + temperature overlays render simultaneously
  And per-tile shows both colored data (per overlay_stacking composition rules)
  And player can see hot oxygen vs cold oxygen at a glance

Scenario: Overlay scrub shows numeric value on hover
  Given the F1 oxygen overlay active
  When player hovers tile (10, 20)
  Then HUD displays "O2: 18 kPa, mass: 5 kg, temp: 22°C"
  And click opens detailed panel with history graph

Scenario: Accessibility mode preserves overlay legibility
  Given the player has high_contrast + colorblind=protanopia
  When F1 overlay activates
  Then oxygen overlay uses colorblind-safe palette
  And per-tile shows text labels (e.g., "O2: 18kPa") rather than relying on color alone
  And M16 accessibility constraints are respected

Scenario: Per-room overlay surfaces room-aggregated data
  Given a sealed bunker (M19 PV=nRT atmosphere)
  When F1 oxygen overlay active
  Then the room is shown as a single tinted box
  And tooltip displays "Room <id>: O2 partial = 21 kPa, total pressure 101 kPa"
  And the per-room view is distinct from per-tile

Scenario: F10 priority overlay shows per-pixel mining priority
  Given a base with assigned dig priorities (per M30B/M30C)
  When F10 toggled
  Then per-pixel priority labels (1-9) render on the world
  And AI miners read priority + execute in order
  And player can drag-to-paint priority levels

Scenario: F12 radiation overlay shows real-time dose
  Given an M16 radiation zone + an actor within it
  When F12 toggled
  Then per-tile radiation dose rate visualized
  And actor's cumulative dose visible
  And player can plan around hot zones

Scenario: Determinism not affected by overlays
  Given two engines running same seed
  When player toggles overlays in engine A but not engine B
  Then sim state is identical between both engines
  And SaveBlob.checksum identical at tick 600
  (overlays are render-only; no sim impact)
```

## Out of scope

- Mod-defined custom overlays (player creates new layer) — M33 mod tools.
- Per-overlay data export to PNG for screenshots — M48A polish.
- Animated heat-flow arrows showing per-tile direction — visual fidelity; consider for M48A.
- 3D / isometric overlay views — Corefall is 2D; flat-grid overlays only.

## Notes for the implementer

- Each overlay is a separate Bevy plugin (additive composition); F-keys toggle visibility flags.
- Per-overlay color scheme is data-driven (RON); modders can override.
- Stacking rule: latter overlay's color overrides earlier in conflict; player can choose layering preference.
- Per-tile overlay rendering happens in a deferred pass; perf budget < 1.0 ms per overlay.
- Accessibility text labels render at all zoom levels; per-tile readability at zoom-out.
