# M27A — Player Game UI (Inventory + Loadout + Cosmetic + Codex + Achievements + Tutorial Menu)

## Status

`active`

## Intent

**M27A is the player-facing game UI milestone** — full UX for inventory management (grid Tetris), per-actor loadout (pre-mission gear selection), cosmetic loadout (50+ items per actor; per M45A), codex viewer (600 entries; categorized + searchable + cross-linked), achievement browser (75+; with progress + flavor), tutorial selection menu (8 labs + First Contract).

**Why after M27 (loot + progression):** by M27 close, all the DATA exists (loot affixes, inventory grid concept, 75+ achievements, perks, treasures). M27A polishes the UX for managing all that data. M11 reserved the loadout / codex / achievement panels as L3/L4 surfaces; M11A covers shell UI; M27A fills the player-facing game-data UI.

**Why this milestone exists:** players spend HOURS in inventory + loadout + codex screens. Stationeers + Terraria + Diablo all live and die by inventory UX. M27A produces best-in-class inventory + loadout + codex / achievement / cosmetic UX at the Terraria / Stationeers / Diablo / Path of Exile launch quality floor.

M27A promise: **"every minute the player spends in inventory + loadout + codex + achievement + cosmetic + tutorial-selection feels SMOOTH, RESPONSIVE, and INFORMATIVE — drag-drop perfect, tooltips rich, filters fast, comparisons clear, animations subtle, ACC-A first."**

## Player-facing behavior

### Inventory grid Tetris UX (M27 concept → full UX)

Per Stationeers + Tarkov + Diablo grid inventory:

- **Grid display** per-actor + per-chassis weight class (4×4 / 5×5 / 6×5 / 8×6 per M27)
- **Drag-drop perfect** — pick up item; ghost preview shows valid slots; drop validation
- **Auto-fit + rotation** — items rotate 90° on shift+click; auto-arrange button packs grid
- **Drag-to-equip** — drag item to loadout slot; auto-equip
- **Right-click drag** — split stack (for stackable items like ammo)
- **Item tooltips** — hover/focus shows: name + rarity color border + affixes (per M27) + stats + flavor (per M25A) + comparison vs equipped
- **Filters** — by type (Weapon / Armor / Tool / Consumable / Material / Cosmetic / Mod) + by rarity (Common → Unique) + by faction
- **Search box** — keyword + tag search; instant filter
- **Sort options** — by name / rarity / type / acquired / weight / value
- **Backpack capacity** — visible weight bar; per M27 carry_limit affects walk speed
- **Per-slot context menu** — Equip / Drop / Use / Sell / Examine / Compare
- **Multi-select** — Shift+click select range; Ctrl+click toggle; bulk actions
- **Per-cosmetic preview** — equipping cosmetic shows on actor portrait in real-time

### Per-actor loadout (pre-mission)

- **Loadout slot UI** — 8 active + 3 reserved tank slots (per M6); per-slot icon + tooltip
- **Per-slot category gating** — primary slot rejects melee; pistol slot rejects rifle
- **Pre-mission loadout** — pre-mission screen where player selects gear (per M11 L3 surface)
- **Quick-loadout presets** — save/load gear sets ("Stealth Loadout" / "Heavy Combat" / "Engineering")
- **Per-mission recommended loadout** — auto-suggest gear per mission (per M25 mission director recommended_counter)
- **Loadout cost feedback** — total weight + power requirement (per M17 personal power) + fuel + estimated mission viability
- **Loadout comparison** — preview "this vs that" gear with stat diff highlights
- **Per-faction loadout pool** — quartermaster (per M26) sells per-faction gear; filtered view
- **Loadout sharing** — export loadout as code/QR; share via Steam Workshop or Discord

### Cosmetic loadout UI (M45A integration)

- **Per-actor per-category** — Faction Skin / Veteran Scars / Achievement Badges / Boss Trophies / Seasonal / Career Arc / Mod_Custom
- **Equip one per category** (per M45A)
- **Full preview pane** — actor portrait with current cosmetic equipped; rotates 360°; per-action preview (idle / walking / firing)
- **Per-cosmetic unlock condition shown** — locked cosmetics greyed-out with unlock requirement text
- **Per-cosmetic rarity color** — Common / Uncommon / Rare / Legendary / Unique borders
- **Per-cosmetic flavor text** — from M25A bible (lore tie-in for each cosmetic)
- **Filter** — by category / rarity / unlocked status / seasonal availability
- **Search** — keyword
- **Cosmetic randomizer** — shuffle button; randomly equips from owned per category
- **Per-faction set bonuses** — wearing 6 items of same faction set highlights bonus (per M27)

### Codex viewer (600 entries)

Per M25A narrative pipeline + M27 unlock tracker:

- **Library layout** — left sidebar with category navigation; right panel with entry text
- **9 launch categories** — Lore / Equipment / Faction / Origin / World / Boss / Material / Achievement / Event
- **Per-category sub-categories** — Lore → World History / Command Core Mythology / Race Origins / Faction History / Technology
- **Search** — full-text search; highlights matched terms in entry text
- **Filters** — by category / unlock status (locked vs unlocked) / acquired-date / read status
- **Cross-link tooltips** — related entries linked; click cross-reference jumps to that entry
- **Read state tracking** — first-time-viewed mark; "New" badge until viewed
- **Per-entry related media** — illustrations (M32A), voice-over (M37A; play-on-click)
- **Bookmark system** — flag entries for re-reading
- **Reading progress** — per-category completion bar (e.g. "Lore: 45 / 80 unlocked")
- **Per-entry unlock condition** — locked entries show "Unlock by: Complete <mission> / Defeat <boss> / Talk to <NPC>"
- **Universal codex search** — global search across all 600 entries
- **Glossary** — hover any in-game term → tooltip with codex entry summary + "Read full" link

### Achievement browser (75+)

Per M27 achievements + M48B Steam integration:

- **Per-category grouping** — Combat / Exploration / Crafting / Social / Mastery / Hidden / Endgame
- **Per-achievement card** — icon (from M9A/M32A) + name + flavor text (M25A) + unlock condition + progress bar + completion %
- **Locked achievements** — show condition partially obscured ("Defeat X with Y under Z constraint" with X/Y/Z hidden until unlocked)
- **Hidden achievements** — show as "???" until unlocked (Steam-friendly hidden flag)
- **Filter** — by category / locked-vs-unlocked / progress (none / partial / complete) / rarity
- **Per-achievement rarity** — Common / Uncommon / Rare / Legendary based on global unlock % (from M36B telemetry)
- **Steam integration** — unlock pops Steam achievement notification (per M36A); browser links to Steam achievement page
- **Per-achievement timeline** — when unlocked; tied to which mission / replay bundle
- **Total progress bar** — "32 / 75 unlocked (43%)" + per-tier breakdown
- **Per-achievement reward** — most unlock cosmetics (per M45A); achievement → cosmetic mapping shown
- **Friend comparison** — Steam friends list shown with their achievement state (per M36A friends API)

### Tutorial selection menu

Per M33A tutorial labs:

- **Per-lab card** — title + duration + topic + completion status + last-played
- **8 launch labs** — Movement / Weapons / Grenades / Tools / AI Cover / Objectives / Squad / Stealth (per M33A)
- **First Contract** — featured tutorial mission (12-15 min; canonical onboarding)
- **Recommended order** — recommended path for new players (with override)
- **Per-lab preview** — short video clip (from M40A capture) showing what the lab teaches
- **Per-lab difficulty rating** — Beginner / Intermediate / Advanced
- **Completion rewards** — per-lab achievement + cosmetic unlock (per M27 + M45A)
- **Replay button** — re-play any completed lab
- **Modder labs** — community-contributed labs shown with mod tag (per M33A modder authoring)
- **Adaptive hints status** — current Settings.objective_help level visible

### Gear comparison tooltip (universal across inventory / loadout / quartermaster)

- **Side-by-side stat comparison** — current vs candidate gear
- **Color-coded deltas** — green = better; red = worse; yellow = trade-off
- **Per-stat tooltip** — hover stat shows full explanation
- **Affix breakdown** — per-affix bonus visible (per M27 30+ affixes)
- **Set bonus preview** — equipping this completes/breaks which set bonus
- **Weight + power-draw impact** — affects mobility + battery drain per M17 + M29
- **Per-faction reputation impact** — equipping faction gear changes how others react

### Per-tier-progression overview

- **Tier ladder visualization** — T0 → T1 → T2 → T3 → T4 (per M32)
- **Per-tier completion** — % of recipes unlocked + % of materials accessed + % of bosses defeated
- **Next milestone preview** — "Unlock T2 by researching Industrial Metallurgy (50 RP needed; currently 32 RP)"
- **Per-research-node hover** — full M32 research tree preview

## Acceptance criteria

```gherkin
Scenario: Inventory grid Tetris drag-drop
  Given player opens inventory in 5×5 chassis
  Then 25 cells visible
  When player drags 2×1 rifle:
    Then ghost preview shows valid placement cells
    Drop snaps to nearest valid grid position
    Auto-rotate (Shift+drag) rotates 90°
    Auto-arrange button packs grid optimally
    Drag to loadout slot equips item

Scenario: Inventory filters + search
  Given inventory with 50 items
  When player filters by "Weapon" + rarity "Rare+":
    Then only Rare+ weapons visible
  When player types "iron" in search:
    Then filters to items with "iron" in name OR description OR affixes
  When player sorts by Rarity:
    Then ordered Common → Uncommon → Rare → Legendary → Unique

Scenario: Item tooltip rich content
  Given hover over an iron rifle
  Then tooltip shows:
    Name + rarity color border
    Item type icon
    Stats (damage / fire rate / range / recoil / weight)
    Affixes (per M27)
    Flavor text (per M25A bible)
    Comparison vs currently equipped weapon (color-coded deltas)
    Acquisition source (mission / boss / quartermaster / craft)

Scenario: Loadout presets
  Given player creates "Stealth Loadout" preset
  When player saves:
    Then preset stored with: gear selection + cosmetic loadout + perks
  When player loads preset:
    Then gear auto-equips
    Cosmetic auto-applies
  Preset shareable via Steam Workshop

Scenario: Cosmetic loadout preview pane
  Given player opens cosmetic loadout for human soldier
  When player hovers Hostile Corp faction skin:
    Then preview pane shows actor with skin equipped
    Per-action preview cycles (idle → walking → firing)
    Per-stat impact = None (per M45A anti-pay-to-win)

Scenario: Cosmetic locked state visible
  Given a locked cosmetic
  Then cosmetic card shows greyed-out icon
  Unlock condition text below ("Defeat Hollow King to unlock")
  Hover shows full flavor text + lore tie-in

Scenario: Codex viewer 600 entries
  Given M25A produced 600 codex entries
  When player opens Codex:
    Then library layout with 9 categories
    Per-category sub-categories
    Search filters in real-time
    Cross-links navigate between entries

    Per-entry voice-over plays on click (M37A)

Scenario: Codex glossary integration
  Given codex contains entry "Command Core"
  When player hovers "Command Core" term anywhere in game (HUD / dialog / mission briefing):
    Then tooltip shows codex entry summary
    "Read full" link jumps to codex viewer at that entry

Scenario: Achievement browser
  Given M27 ships 75+ achievements
  When player opens Achievements:
    Then per-category grouping visible

    Per-lab preview clip (M40A)

    Modder labs distinguished with mod tag

  Given player hovers a new iron rifle
  Then comparison tooltip vs currently-equipped weapon
  Color-coded deltas (green/red/yellow)
  Per-stat tooltip explains stat
  Set bonus preview
  Weight + power-draw impact visible

Scenario: Per-tier progression overview
  Given player views tier progression
  Then T0 → T4 ladder visualized
  Per-tier completion % shown
  Next milestone highlighted
  Research tree preview accessible

Scenario: ACC-A floor for all screens
  Given Settings.high_contrast=true + Settings.text_scale=2.0
  When any M27A screen renders:
    Then all UI reflows correctly
    No tooltip clipping
    Color-independent state labels
    12-node focus ring works per screen
    Caption support for any audio cues (item-equip sound)

Scenario: Per-tier perf gate
  Given 100+ items in inventory + 600 codex entries + 75 achievements
```

## Notes for the implementer

### Architecture rules

- **Per-screen modular crates** — cf-ui-inventory + cf-ui-loadout + cf-ui-codex + cf-ui-achievement + cf-ui-tutorial-menu + cf-ui-cosmetic-loadout + cf-ui-comparison; each independent + composable
- **Tooltip rich content via M25A bible** — every item flavor text auto-pulled from cf-codex
- **Cosmetic preview uses M40A spectator director** — 360° preview pane via rendering pipeline
- **All ACC-A compliant** — per M11; 12-node focus ring per screen; text_scale 200% reflow

### Decision-record alignment

- **DR-006 (mod parity)**: mods can register custom screens
- **DR-012 (accessibility)**: all screens respect ACC-A
- **DR-031 (anti-pay-to-win)**: cosmetic UI shows gameplay impact = None
- **DR-046 (player-facing surfaces)**: M27A is canonical game-data UI

### Pitfalls

- **Drag-drop latency on Steam Deck**: aim <50ms
- **Tooltip pile-up**: cap to one tooltip at a time
- **Codex performance with 600 entries**: index for search; lazy-load entry text
- **Steam friends sync rate limits**: M36A handles
