# M11A — Shell UI Foundation (Title + Menu + Settings + Save/Load + Pause)

## Status

`active`

## Intent

**M11A is the shell-UI foundation milestone** — every screen the player sees OUTSIDE of in-mission HUD: splash screen + title screen with attract mode + main menu + pause menu + save/load slot UI + full settings tree (6 tabs auto-generated from M38 schema) + credits screen + loading screens + first-run-experience polish. M11 covers in-mission HUD; M11A covers the meta layer wrapped around it.

**Why after M11 (HUD readability):** M11 explicitly defers settings menu full tree + hub + lobby + mod manager + photo mode UI to "M33+/shell UI work". M33 then ships modder tools (editor + Lua + IC10) but NOT the player-facing shell. M11A fills the gap before M12 visual juice polishes everything.

**Why this milestone exists:** without a polished title screen + main menu + settings UI + save/load + pause menu, the game feels "alpha" no matter how good the in-mission HUD is. First impressions are made at the splash + title; daily flow happens in the pause + settings. M11A ships the shell at amazing-UX quality.

M11A promise: **"the moment a player launches Corefall — splash → title with attract mode → main menu → first-run wizard → loading screen → in-mission HUD → pause → settings → save → quit — every screen is polished, keyboard+controller-navigable, accessibility-first, brand-coherent, and feels like a $50 production not a Steam Early Access placeholder."**

## Player-facing behavior

### Splash screen (3s; skippable)

- Studio brand + game logo (M48B marketing assets)
- Subtle animated reveal (M12 juice rules; respects reduce_motion)
- Loading bar for engine init
- Press any key to skip
- Per-platform splash variants (Steam Deck = larger logo + brand; desktop = subtler)

### Title screen with attract mode

- Background: animated reactor scenario gameplay loop (M9 reactor defense playing at 0.5× speed; cinematic camera angles via M40A director; respects reduce_motion = static screenshot)
- Title art: full game logo at center
- Subtitle: tagline from M25A bible
- Menu options (vertical list; keyboard + controller + mouse navigable):
  - **Continue** (resumes last save; only shown if save exists)
  - **New Game** (opens FRE wizard or campaign select)
  - **Load Game** (opens save slot UI)
  - **Multiplayer** (opens server browser per M40B)
  - **Workshop** (opens mod browser per M48C)
  - **Tutorials** (opens tutorial menu per M27A)
  - **Settings** (opens full settings tree)
  - **Credits**
  - **Quit**
- Per-platform branding (Steam: shows Steam logo + Big Picture support; Discord: shows community link; itch: shows itch.io link)
- Particle effects (subtle; M24A)
- Per-faction music (M37A; rotates per session)

### Main menu (extends title)

After New Game or Continue clicked, player lands in main menu:
- Per-actor career arc summary (per M41 persistent veterans)
- "Last played" mission summary (cause-chain to last save state)
- Quick-action buttons (Resume Mission / Loadout / Mech Bay / Base / Workshop)
- Per-faction relationship summary (top 3 by reputation)
- News ticker (M48B marketing pipeline; community announcements)
- Daily quest notification (M26 dynamic quest generator; if active)
- Per-server status indicator (multiplayer connections; per M40B)

### Pause menu (in-mission)

- Press [Esc] in-mission → opens pause overlay
- Pause options:
  - **Resume**
  - **Settings** (live-edit; per M38 hot-reload)
  - **Save Game** (quick-save slot + named slot)
  - **Load Game** (warns about progress loss)
  - **Show Me Why** (M10 cause-chain handoff; only shown if mission_resolved=lost)
  - **Report Bug** (M36B form)
  - **Tutorials** (jump to tutorial selection)
  - **Quit to Main Menu** (warns about progress loss)
  - **Quit to Desktop** (warns)
- Pause behavior per M11 game_speed_assist (FullPause vs Slowdown75 vs Slowdown25)
- Per-platform input (Steam Deck = controller-first; desktop = mouse-first)

### Save / load slot UI

Per DR-029 save model + M27 progression integration:

- 10 named save slots + 3 auto-save slots
- Per-slot preview card:
  - Thumbnail screenshot (M40A clip export pipeline; auto-captured at save time)
  - Mission name + tick count + wall-clock duration
  - Last play timestamp (M/D/YYYY h:MM AM/PM per timezone)
  - Player actor portrait (M32A NPC dossier portrait if named veteran)
  - Faction relationship summary (top 3 factions + relationship score)
  - Achievements unlocked count (per M27)
  - Total play time (per M36B opt-in telemetry)
- Sort options: Last played / Created / Mission name / Difficulty
- Delete confirmation with hold-to-confirm (M11)
- Cloud sync indicator (Steam Cloud per M36A; ✓ Synced / ⏳ Syncing / ⚠ Conflict)
- Conflict resolution UI (per M36A Cloud save conflict)

### Full settings tree (6 tabs)

Per M38 schema (200+ keys); auto-generated UI; per M11 ACC-A floor:

**Tab 1 — Display:**
- Resolution (with current + supported list)
- Display mode (Fullscreen / Borderless / Windowed)
- VSync (On / Off / Adaptive)
- Quality preset (Low / Medium / High / Ultra / Custom)
- Render scale (50% / 75% / 100% / 125% / 150% / 200%)
- Per-tier perf preview (estimated FPS; per device class)

**Tab 2 — Audio:**
- Master volume slider
- SFX / Music / Voice / Ambient per-bus volume sliders
- Audio device selection
- Output mode (Stereo / 5.1 / 7.1 / HRTF)
- Voice priority ducking strength
- Subtitle category filter (per M11 caption_categories)

**Tab 3 — Controls:**
- Per-action key rebinding (18 launch actions; per M11)
- Per-action controller mapping (Steam Input integration per M36A)
- Hold-to-confirm toggle + threshold
- Mouse sensitivity + invert-Y
- Controller deadzone + curve
- Reset to defaults button (per group)
- Per-action conflict detection (warn on duplicate binding)
- Per-input-profile (Keyboard+Mouse / Controller / Keyboard-only / Custom)

**Tab 4 — Accessibility:**
Per M11 ACC-A floor + DR-012:
- Text scale slider (0.5 / 1.0 / 1.5 / 2.0 / Custom 0.5-4.0)
- UI density (Comfortable / Compact)
- Contrast mode (Standard / High Contrast Dark / High Contrast Light)
- Color cue mode (Default / Colorblind-safe / Monochrome-test)
- Caption mode (Off / Critical-only / Standard / Expanded)
- Caption background opacity (0% / 50% / 80% / 100%)
- Reduce motion + Reduce shake + Reduce flash
- Hold-to-confirm + Hold threshold (50-2000ms)
- Game speed assist (Off / Slowdown75 / Slowdown25 / Full pause)
- Screen shake scale (0% / 25% / 50% / 75% / 100%)
- Damage numbers toggle
- Killcam enabled
- Hit-stop enabled
- Aim assist (Off / Steady aim / Auto-aim with damage penalty)
- Adaptive hints engine (M33A; objective_help: Minimal / Standard / Verbose)
- Debug explainer level (Player / Designer / Raw)

**Tab 5 — Gameplay:**
- Difficulty preset (Cakewalk / Tough Crowd / Veteran / Custom)
- AI difficulty per-archetype override
- Permadeath toggle
- Friendly fire toggle (default per mode)
- Mission timer modifiers
- Storyteller (Cassandra Classic / Phoebe Chillax / Randy Random / Ironman / Sandbox)
- Difficulty modifiers (per M8): no_respawn / fog_of_war / limited_ammo / time_limit / no_minimap / hardcore_mode

**Tab 6 — Language + Privacy:**
- Language picker (19 launch languages per M38A)
- Per-language voice synthesis (M37A multilingual)
- Telemetry opt-in (default OFF; M36B)
- Crash reports opt-in (default ON for Steam VAC compliance)
- Mission rating prompts (Show after every mission / Disabled)
- In-game bug submit shortcuts

### Credits screen

Auto-generated from cf-asset-ledger + git contributors + AI model attribution:

- Sections: Engine / Gameplay / Production Track / Audio / Narrative / Localization / Modding Community / AI Models / Comparable Games (CCCP, Soldat, Stationeers, Noita, etc.) / Special Thanks
- Per-contributor entries (from git log)
- Per-AI-model attribution (SDXL / Flux / AnimateDiff / ElevenLabs / Bark / MusicGen / Stable Audio Open / Claude / GPT-4 / Llama)
- Per-mod-author attribution (from Workshop subscriptions)
- Scrolls per accessibility (respects reduce_motion = static; press [Space] to advance)
- Press [Esc] returns to main menu

### Loading screens

- Tips drawn from M25A story bible (random per load; LLM-authored tip pool of 50+ entries)
- Screenshot from M40A capture grid pool
- Per-tier loading time visualized (progress bar + ETA)
- Per-platform layout (Steam Deck = full-screen tip; desktop = bottom-tip)
- Music continues per M37A adaptive music engine (no audio break across load)
- Per-scenario context (loading micro_breach = mission-specific tip)

### First-run-experience polish (M33A integration)

M33A ships the FRE wizard logic; M11A polishes the visual presentation:

- Step 1: **Welcome** — game intro + brand reveal animation (M12 juice)
- Step 2: **Profile setup** — display_name input + preferred_origin selector (with per-origin lore preview from M25A)
- Step 3: **Accessibility calibration** — visual demos of text_scale + contrast + reduce_motion; player can preview effect live
- Step 4: **Controller calibration** — auto-detect; per-input-profile suggested
- Step 5: **Tutorial offer** — "Play First Contract (~12 min)?" with mini-trailer (M48B)
- Step 6: **Recommendation** — per-origin starter world recommendation (M17 + M43)

### Per-platform layout adaptations

- **Steam Deck (800p, controller-first)**: large touch targets + simplified menu + controller-icon prompts
- **Desktop (1080p+, mouse-first)**: dense layout + mouse-hover tooltips + keyboard shortcuts visible
- **4K (high-DPI)**: scale 2x or 3x via M11 text_scale
- **Ultrawide (21:9 / 32:9)**: HUD respects safe-zone; main menu centered

## Notes for the implementer

### Architecture rules

- **Shell UI is OUTSIDE in-mission sim** — cf-shell runs without cf-sim-core active for title/menu; integrates with sim for pause/save/load
- **Auto-generated UI from M38 schema** — settings tree reads schema at startup; never hardcoded
- **Per-platform layout via Settings.ui_density** — Compact vs Comfortable; Steam Deck defaults Compact
- **Attract mode plays a real M9 bundle** — not pre-recorded video; uses M40A spectator director on a pre-shipped run bundle
- **All shell UI ACC-A compliant** — 12-node focus ring + per-action captions + reduce_motion respect
