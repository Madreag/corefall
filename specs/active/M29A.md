# M29A — Power Grid + IC10 Chip Editor UX

## Status

`active`

## Intent

**M29A is the power grid + IC10 chip editor UX milestone** — full UX for the M29 electrical engineering kernel: Factorio-style live grid topology + Wire routing preview (with live validation) + per-device priority drag-drop + IC10 chip editor (BASIC-like; syntax highlighting; debugger; breakpoints; register inspector; live state monitor; hot-reload) + per-generator dashboard + battery management widget + brown-out cascade visualization + three-phase load balancing UI.

**Why after M29 (electrical kernel):** by M29 close, the deep electrical simulation exists (8 generators / 6 cable tiers / 6 storage types / 4 turret tiers / IC10 chips / per-actor personal-power). M29A polishes the UX so players can MANAGE the deep simulation visually.

**Why this milestone exists:** the user said "I live electricity!" — M29 ships the deep sim; M29A makes managing it feel like Factorio + Stationeers + IC10 simulator combined. Without M29A, players have a deep sim they can't navigate. With M29A, they have a delightful electrical engineering puzzle.

M29A promise: **"managing a 500-cable / 50-generator / 200-load base feels like Factorio's electric stats + Stationeers' IC10 + Powder Toy's logic circuits combined; brown-out cascades are debuggable; IC10 chips have a proper editor with breakpoints; three-phase power balance has a clear UI."**

## Player-facing behavior

### Power overlay full UX (F5 toggle; Factorio-style)

Per M29 concept; M29A fills:

- **Live grid topology** — every cable + node rendered at runtime
- **Cable thickness ∝ amperage** — thicker = higher current
- **Voltage class color** — blue (LV 24V) / cyan (LV 120V) / yellow (MV 480V) / orange (HV 4 kV) / red (HV 35 kV) / white (Critical superconductor)
- **Per-room load percentage** — room tinted by load / capacity
- **Power deficit warning band** — top of screen pulses red when supply < demand
- **Per-generator output curves** — live wave per generator (solar sine / wind cubic / chemical steady / RTG flat / kinetic spike)
- **Per-tick load graph** — bottom-of-screen chart (Factorio "electric stats" style); last 60s; supply (green) + demand (blue) + battery (yellow) + brown-out (red)
- **Per-cable hover tooltip** — current / amperage cap / voltage / length / loss / temperature / health
- **Per-node hover tooltip** — incoming + outgoing connections / breaker state / fuse state
- **Per-device hover tooltip** — power state (Powered / Shed / Brown-out) / draw / priority band / shed reason
- **Per-overlay accessibility** — color-independent text labels per DR-012; mono palette + patterns for high_contrast
- **Pause + slowdown** — overlay viewable in pause; M11 game_speed_assist=Slowdown75 preferred for tweaking

### Wire routing preview UX

When player selects a cable from M28A palette:
- **Live cable placement** — drag cable end from device to power source; cursor follows
- **Per-segment validation** — green = valid; yellow = warning (near amperage cap); red = invalid (voltage class mismatch / over-capacity)
- **Length feedback** — total cable length shown in real-time
- **Transmission loss preview** — "Loss: 1.2% over 12m at 5 kW load"
- **Auto-route option** — auto-route from device to nearest power source via shortest valid path
- **Bridge mode** — cables can cross via dedicated bridge module (per Stationeers)
- **Wire-cutting** — middle-click cable midpoint to split; player can re-route
- **Cable tier upgrade** — Shift+click cable upgrades to next tier (insulated_copper → shielded_cable etc.)

### Per-device priority drag-drop

For brown-out cascade management:
- **Priority panel** — open via [P] when building
- **4 priority bands** — Critical / Important / Utility / Luxury (per M29)
- **Per-device drag** — drag any device into any band
- **Auto-shed visualization** — live preview of which devices shed at 90%, 120%, 150%, 200% load
- **Per-band color** — Critical red / Important orange / Utility yellow / Luxury green
- **Save priority configs** — per-base default priority + per-mode override (e.g. "Combat Priority" / "Power Saver")
- **Drag from palette directly to priority** — set priority while placing device

### IC10 chip editor (Stationeers MIPS-style)

Full developer-friendly chip editor:

- **Code editor pane** — Monaco-equivalent editor with:
  - Syntax highlighting (per IC10 instruction set per M29)
  - Auto-complete (per registered device variables + instructions)
  - Line numbers + ruler
  - Indent guides
  - Match-bracket highlighting
  - Per-error squiggles + tooltip
- **Per-chip variable inspector** — sidebar shows: 16 registers (r0..r15) + 5 device pins (d0..d4) + per-tick state
- **Live execution monitor** — current PC (program counter) + last 10 instructions executed + cycle count
- **Breakpoints** — click line number to toggle breakpoint
- **Step-through execution** — Step / Step-Over / Step-Out / Continue
- **Per-tick step** — single sim-tick execution; useful for race conditions
- **Per-instruction help** — hover instruction → tooltip with M29 documentation
- **Sample chip library** — 20+ launch sample chips (LoadShed / GridSurplusCharge / BrainAwarePower / TurretFireControl / AtmosphericsManager / RoomTemperatureManager / CropAutoIrrigator / etc.)
- **Hot-reload** — apply edits without restart (per M33 mod hot-reload pattern)
- **Multi-chip view** — split-screen to view multiple chips simultaneously
- **Per-chip wiring** — visual editor for chip's d0..d4 connections to devices

### Per-generator dashboard

For each generator type (8 launch generators):
- **Per-generator panel** — generator id / type / location / current output / max output
- **Output curve graph** — last 60s output (solar = sine; wind = cubic; chemical = step; RTG = flat; etc.)
- **Per-generator efficiency factor** — current efficiency × per-world modifier (per DR-039)
- **Per-generator fuel state** — for chemical/nuclear: current fuel vs capacity
- **Per-generator heat output** — for chemical/nuclear: heat → cf-audio thermal pip + M19 atm integration
- **Per-generator maintenance** — degradation %; replace prompt at 80%

### Battery management widget

For each battery bank:
- **Per-battery panel** — battery id / type / charge state
- **Charge curve graph** — last 30 min charge/discharge
- **Time-to-empty estimate** — at current load
- **Time-to-full estimate** — at current charging rate
- **Health % + cycle count** — replace prompt at 80% health
- **Per-battery temperature** — warning if thermal runaway risk
- **Battery balancing** — for multi-battery banks; shows per-battery state-of-charge mismatch

### Brown-out cascade visualization

When cascade detected:
- **Cascade graph overlay** — red-flashing sequence on affected nodes/breakers
- **Per-tripped-breaker indicator** — visible red icon
- **Cascade timeline** — list of trips with timestamps; click jumps to event detail
- **Recovery suggestion** — auto-suggest: "Reduce load by 2 kW OR add 3 kW solar"
- **Per-room offline indicator** — room dims; ux.banner_raised "Power lost: <room>"
- **Hold-to-restore** — manual breaker reset via hold-to-confirm

### Three-phase load balancing UI (T3+ endgame)

For three-phase circuits:
- **Per-phase load visualization** — Red phase / Yellow phase / Blue phase
- **Per-phase load percentage bars** — visualize imbalance
- **Balance score** — perfectly balanced = 100%; visible as a meter
- **Auto-balance suggestion** — "Move device X to phase Yellow to balance"
- **Harmonic distortion warning** — if imbalance high; suggested fixes

### Personal power widget (per-actor; per M17 + M29)

In-mission HUD widget (extends M11):
- **Per-actor battery state** — charge % + time remaining
- **Per-actor equipment power-draw list** — per-equipment with priority drag-drop
- **Hot-swap UI** — F5+B opens battery hot-swap radial menu (per M11 pie menu pattern)
- **Charging pad proximity indicator** — "Charging pad nearby (8m); plug in?"
- **Solar trickle indicator** (robots) — "+50W from body solar (daylight)"

### Modder-friendly features

- **IC10 sample library extensible** — modders add custom samples via mod packs
- **Custom device-variable registration** — mods can register custom devices with custom IC10 variables
- **Power overlay extensions** — mods can add custom power categories (e.g. magic energy for fantasy mods)

## Notes for the implementer

### Architecture rules

- **Power overlay reads sim state; never affects** — pure-read
- **Wire placement modifies world** — placement event per replay determinism
- **IC10 editor edits chip data; chip execution is sim-side** — separation of edit (UI) and execute (sim)
- **All ACC-A compliant** — color-independent state labels per DR-012

### Decision-record alignment

- **DR-027 (combat-base)**: power management is core base experience
- **DR-046 (player-facing surfaces)**: power UX = electrical engineering puzzle quality

### Pitfalls

- **Cable rendering perf at 500+ cables**: GPU-instanced rendering
- **IC10 editor execution loop**: ensure editor doesn't slow sim; per-chip throttle per M29
- **Live graphs render budget**: cap to 60 samples × 5 graph types

### Closure procedure

1. Reference flow: player builds 50-generator + 200-load base; uses IC10 chips; debugs cascade; survives 24h sim.
