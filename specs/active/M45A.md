# M45A — Cosmetic Production Pipeline

## Status

`active`

## Intent

**M45A is the cosmetic production milestone** — 50+ cosmetic items per actor via Tier 2 ComfyUI pipeline + faction skins (8 factions × per-actor variants) + war-veteran scar variations (per M41 persistent veterans) + achievement-unlock cosmetics (per M27) + boss-defeat cosmetics (per M45) + seasonal cosmetics (per M31 weather/seasons) + mod-contributed cosmetics. **All earnable through play** per DR-031 anti-pay-to-win audit.

**Why after M45 (PvE endgame bosses):** by M45 close, all gameplay content for cosmetic-earning is defined — bosses, achievements, factions, seasons, veteran progression. M45A produces the cosmetic art via M32A pipeline + ties them to play-time unlocks via M27 progression system.

**Why this milestone exists:** without M45A, the game has zero personalization. M27 ships achievements but no visual rewards. M41 ships persistent veterans but no scars. M49 final roster lists "50+ cosmetic items per actor" but no milestone owns production. M45A produces them all.

**Why anti-pay-to-win matters:** DR-031 requires that NO cosmetic affects gameplay. Cosmetics are pure visual + audio variants. Per-cosmetic gameplay-impact audit runs continuously via M36B telemetry. Steam DLC for cosmetics is OPTIONAL (cosmetics-only DLC); no DLC ever provides gameplay advantage.

M45A promise: **"50+ cosmetic items per actor × 44+ actors = 2200+ launch cosmetics; all earnable through play; per-faction skins distinct; war-veteran scars persistent across sessions; mod-contributed cosmetics work via same pipeline; zero pay-to-win impact verified by automated audit."**

## Player-facing behavior

After M45A, the player experiences:

- **50+ cosmetic items per actor** spanning categories:
  - **Faction skins** — Hostile Corp / Allied Resistance / Marauder Tribes / Religious Order / Scientist Order / Mercenary Guild / Pirates / Drone Collective variants per actor archetype = 8 × per-actor = 350+ skins
  - **War-veteran scars** — per persistent veteran's wound history, visible scar texture variants per zone (per M13 chassis 15 zones + per M14 limb-loss); 14 zones × 4 severity levels = 56 scar variants per actor
  - **Achievement-unlock cosmetics** — per M27 achievements (75+ achievements) × decorative cosmetic (badge, banner, weapon-skin, helmet-detail) = 75+ cosmetics
  - **Boss-defeat cosmetics** — per M45 5 bosses × 5 trophies = 25 boss trophies
  - **Seasonal cosmetics** — per M31 weather + seasons (12 worlds × 4 seasonal variants = 48) — winter skins / summer skins / etc.
  - **Mod-contributed cosmetics** — per M33 mod workshop; modders ship cosmetic packs
  - **Career-arc cosmetics** — per M41 persistent veterans + named NPCs (24+ × per-mission unlock = 100+)
- **Cosmetic loadout system** — equip per actor per cosmetic category via Loadout UI (per M27 inventory grid + M33 workbench)
- **Earnable through play** — every cosmetic has a play-time-based unlock condition (kill count / achievement / boss defeat / faction reputation / scenario completion / season participation / mod contribution)
- **Cosmetic preview** — in-game preview of unowned cosmetics with unlock condition shown
- **Per-actor cosmetic display** — chassis silhouette + per-zone armor + helmet + weapon-skin + decals + emblem + banner
- **Visible during play** — cosmetics render in real-time per cf-render-2d (no separate "menu only" cosmetics)
- **In capture grids + screenshots + clips** — cosmetics show per M40A replay export
- **Steam Workshop sharing** — modders publish cosmetic packs to Workshop

```ron
    actor_archetype: "human_soldier",
    category: FactionSkin,                              // FactionSkin / VeteranScar / AchievementBadge / BossTrophy / Seasonal / Career / ModCustom

    upstream_assets: ["m32a_human_soldier_base", "hostile_corp_palette"],
    
    auditor_signature: "no_gameplay_impact_verified_2026_01_15",
```


## Out of scope

- **Real-money cosmetic transactions** — Steam DLC for cosmetics is OPTIONAL (post-launch); play-unlock alternative always available; cosmetics ONLY (no gameplay DLC)
- **Cosmetic crafting / combining** — cosmetics are not craftable; only earnable
- **Cosmetic trading between players** — Steam Inventory adapter post-launch
- **Per-cosmetic music / voice variants** — M37A audio cosmetics are out of scope; M45A is visual + decal only
- **Animated cosmetic effects (e.g. glowing trails)** — M48A Tier 3 polish

## Notes for the implementer

### Architecture rules

- **Per-cosmetic gameplay impact = None ALWAYS** — code review enforces; audit verifies
- **Per-cosmetic ledger entry** — every cosmetic ledgered with auditor_signature
- **Per-cosmetic unlock condition required** — zero cosmetics auto-unlocked; all earnable
- **Per-cosmetic render at runtime** — cf-render-2d composites; no offline-baked variants per cosmetic

### Decision-record alignment

- **DR-031 (anti-pay-to-win)**: M45A is the canonical anti-pay-to-win surface
- **DR-044 (audiovisual production)**: M45A is cosmetic production
- **DR-053 (asset ledger)**: every cosmetic ledgered

### Pitfalls

- **Per-zone cosmetic alignment**: cosmetic textures must align with M18A animation frames + M13 chassis zones
- **Mod cosmetics + vanilla cosmetics conflict**: handle via priority (vanilla > mod) + ID collision detection
- **Pay-to-win audit false positives**: if a cosmetic appears to affect gameplay (e.g. faction emblem grants "+5 reputation"), it's NOT a cosmetic; flag + refactor
- **Per-cosmetic memory budget**: 2200 cosmetics × multi-zone textures = ~5 GB texture data; lazy-load per-actor

### Closure procedure

1. Reference bundle: M41 + M45 sessions re-played with cosmetics equipped.
2. All PASS.
