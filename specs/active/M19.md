### Real ideal gas law (PV=nRT)

- Every atmosphere unit tracks `n` (moles per gas type), `V` (liters), `T` (kelvin)
- Pressure computed: `P = n*R*T/V` (R = 8314.46 J/(kmol·K) — Stationeers convention)
- Liquids co-exist with a gas (any gas can be the pressurant)
- Latent heat consumed on evaporation, released on condensation

### Combustion stoichiometry (6 deterministic reactions)

| Reaction | Formula | Energy Release | Min Temp |
|---|---|---|---|

| Volatiles + N2O → CO2 + Pollutant + heat | combustion | 1.4 MJ/mol | 323 K |
| Volatiles + Ozone → CO2 + Pollutant + heat | combustion | 1.6 MJ/mol | 423 K |
| Hydrogen + O2 → Steam + heat | combustion | 2.3 MJ/mol | 700 K (cleanest) |
| Hydrogen + N2O → Steam + Pollutant + heat | combustion | 2.1 MJ/mol | 423 K |
| Hydrogen + Ozone → Steam + Pollutant + heat | combustion | 2.4 MJ/mol | 373 K |

Each reaction: fixed mole equation, energy release in J/mol, autoignition temperature, minimum ratio thresholds for ignition.

### Pipe networks as first-class atmospheres

- Connected pipe segment graph = one atmosphere
- Pumps, valves, regulators, filtration units, condensation chambers split networks
- Each piece of network state: volume, total moles, partial moles per gas, temperature
- Pipe rupture / freeze / overpressure events emit replay
- Wire interaction: pipes can be tapped, vented, sealed

### Room atmospheres + apertures

- Connected sealed-volume graph = one atmosphere
- Walls/floors/ceilings = barriers (sealed)
- Doors/windows = barriers with state (open/closed/breached)
- Apertures: bullet holes, blast breaches, pipe ruptures, suit punctures, terrain cracks
- Gas/liquid flow reads aperture: a hole is NOT just a decal
- Vacuum dissipates atmosphere within "a few large grid atmospheres of distance"

#### Electrolyzer + closed-loop life support backbone

Per ONI: water (H2O) split via electrolysis into O2 + H2; basic closed-loop life support backbone:

**Electrolyzer** (T2 base module; per M28 + M29):
- Input: 1 kg/s water; output: 0.888 kg/s O2 + 0.112 kg/s H2 (stoichiometric)
- Power: 240 W per Stationeers parity
- Output temperature: input_temp + Joule heating
- Min input pressure required (else doesn't run)
- Max output pressure (auto-stops if backpressure too high)
- Routes O2 → breathing supply; H2 → fuel for chemical generator OR Stirling engine
- Events: `atmos.electrolysis_started/stopped/throttled`

**Closed-loop diagram:**
```text
[Water reservoir] → [Electrolyzer + power] → [O2 supply line + filtered breathing] → [Crew breathes O2]
                                            → [H2 supply line] → [Stirling engine / fuel]
                                                                ↓
[Toilet / sewage] ← [CO2 + waste] ← [CO2 scrubber + atmospheric mix] ← [Crew exhales CO2]
[Water purifier / boiler] ← [Polluted water from sewage / shower / sink]
[Algae / plants] ← [Sunlight + CO2 + grow lamps] → [Food + O2 (photosynthesis)]
[Carbon-skimmer (T3+)] ← [CO2 from atmos] → [Carbon + O2 (less efficient than plants)]
[Liquid CO2 storage (T3+)] ← [Compressed gas] → [Stored for sale OR cooling refrigerant]
```

**Polluted oxygen + polluted water:**

Per ONI parity:
- Polluted oxygen forms from rotting biomass / sewage / certain plants
- Crew breathing polluted oxygen develops affliction.coughing (per M16)
- Air filter / CO2 scrubber modules clean polluted O2 → clean O2 + waste
- Polluted water from showers / sinks / sewage; runs through Water Sieve → clean water + polluted dirt
- Polluted dirt fertilizes plants
- Cycle: sewage → water sieve → clean water → electrolyzer → O2 + H2 → crew → polluted O2 / CO2 → scrubber → clean O2 → ...

This makes a self-sustaining colony possible (with sufficient power + plants + water sources).

#### Per-tile thermal conductivity + heat flow (ONI tile system)

Per ONI: heat flows through tiles based on per-material thermal conductivity. M19 implements this for all terrain + base modules:

```rust
pub struct TileThermal {
    pub material_id: MaterialId,
    pub thermal_conductivity_w_per_m_k: f32,    // ONI-style
    pub specific_heat_j_per_kg_k: f32,
    pub thermal_mass_j_per_k: f32,              // capacity to absorb heat
    pub current_temperature_k: f32,
    pub temperature_history: VecDeque<f32>,     // for graphing in HUD overlay
}
```

**Per-material thermal conductivity table (W/(m·K)):**

| Material | Thermal conductivity | Specific heat | Insulation use |
|---|---|---|---|
| Steel | 50 | 470 | High flow; conducts heat fast |
| Iron | 80 | 450 | High flow |
| Aluminum | 237 | 897 | Very high; not for insulation |
| Copper | 401 | 385 | Very high; cables conduct heat too |
| Tungsten | 173 | 130 | High; resistant to deformation |
| Concrete | 1.0 | 880 | Standard wall material; medium flow |
| Brick | 0.8 | 840 | Lower flow; better insulation |
| Ceramic | 1.5 | 850 | Medium |
| Insulite (T2+) | 0.01 | 800 | Excellent insulation |
| Wood | 0.15 | 1700 | Lower flow + high specific heat |
| Glass | 0.8 | 753 | Medium |
| Vacuum | 0 (radiation only) | 0 | Best insulation (only radiative loss) |

**Per-tick heat exchange:**

```text
For each tile pair (A, B) in contact:
  delta_T = temperature_A - temperature_B
  delta_t = tick_dt
  k = min(conductivity_A, conductivity_B)
  Q = k × delta_T × area × delta_t                       // heat transferred
  
  new_temp_A = temperature_A - (Q / thermal_mass_A)
  new_temp_B = temperature_B + (Q / thermal_mass_B)
  
  Emit thermal.heat_exchanged { from_tile, to_tile, joules }
```

**Insulated tiles** (T2 building block):
- Use Insulite material; 0.01 W/(m·K) conductivity
- Block heat flow effectively for thermal-managed bases
- Required for: cryogenic storage / hot reactor rooms / acid-resistant Venus rooms
- Player builds with `act.player.place_insulated_tile`
- Pure vacuum tile = zero conductivity (radiation only); ultimate insulation but harder to build
