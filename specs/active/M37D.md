# M37D — Adaptive Music Engine + Per-Scenario Intensity Scoring + Transition Rules + Music-Per-World

## Status

`active`

## Intent

Turn Corefall's static music catalogue into a **per-tick reactive score** — a deterministic intensity score (0.0-1.0) computed from enemies in sight, damage taken, bullets fired, and mission-critical state drives a 3-band variant selector (calm / buildup / climax) across the 120 baked tracks (12 worlds × 4 variants + 8 factions × 4 + 5 storytellers × 4 + 5 bosses × 4). Cross-fade transition rules enforce minimum hold times, beat-aligned cuts, and layer priority (boss > faction > storyteller > world). After M37D, **the music tells the player what's happening before they see it**.

## Player-facing behavior

- **Combat intensity scoring per tick** — every tick, a deterministic `intensity_0_to_1` is computed from 6 weighted signals: enemies-in-sight (35%), damage-taken-in-last-10s (25%), bullets-fired-in-last-5s (10%), mission_critical state flag (15%), boss-arena-active (10%), storyteller-event-active (5%). Values blend smoothly via a 60-tick low-pass so single events don't spike the score.
- **3-band variant selector** — intensity drives the music variant: `[0.0, 0.3)` → **calm**, `[0.3, 0.6)` → **buildup**, `[0.6, 1.0]` → **climax**. The `music_variant_for(track_id, intensity)` selector from M37A is the canonical lookup. Hysteresis: a 0.04 dead-band around each boundary prevents thrashing when intensity hovers on a threshold.
- **Per-world music palette** — every world (12 launch worlds — Earth, Mars, Moon, Phobos, Deimos, Mimas, Europa, Vulcan, Venus, Belt, Orbital, Sol_Zone) has 4 variants already baked in M37A. Loading into a world swaps the base palette; the active variant is then selected by intensity.
- **Per-faction music palette layered on top of world** — when a faction-aligned mission begins (8 factions: Coalition, Frontier, Ronin, Synth, Collective, Husks, Collegium, Starlight), the faction theme overlays the world ambient at a 0.4 mix weight. Player hears "world ambient + faction motif" simultaneously.
- **Per-storyteller music palette** — the active storyteller (5: Cassandra, Phoebe, Randy, Ironman, Sandbox) contributes a 0.25-weight layer that shapes the score's character. Cassandra leans dramatic orchestral; Randy leans chaotic glitch; Sandbox leans sparse ambient.
- **Per-boss theme** — entering a boss arena (5 bosses: Hollow King, Frozen Heart, Crimson Tide, Eclipse Walker, Last Star) **overrides** lower layers entirely. Boss theme priority = highest; world/faction/storyteller layers fade to 0.0 during the boss fight.
- **Beat-aligned cross-fades** — track transitions wait for the next bar boundary (per-track BPM metadata; e.g., Mars Ambient = 80 BPM → bar = 3 s; transition queues until the next bar). Cross-fade duration is 1 bar; logarithmic curve.
- **Minimum-hold rule** — once a variant starts, it holds for ≥ 12 seconds before another transition can fire. Prevents whiplash from intensity micro-spikes (e.g., a single grenade thrown by an offscreen actor).
- **Debrief variant on mission end** — when mission_phase transitions to `Debrief`, the active track cross-fades to the world's `debrief` variant (which exists in the M37A palette but was never explicitly wired). 8-second fade.
- **Determinism** — intensity scoring + selector + transitions are pure math on sim state; no `thread_rng`, no frame-time. Two engines with the same seed produce identical `audio.music_variant_changed` event streams.
- **Accessibility-compliant** — caption bridge surfaces `MUSIC: <track_name> [<variant>]` for deaf-mode players whenever the variant changes. The mission director's intensity readout is available as an HUD debug overlay (toggleable).

## Intensity formula (locked)

Per-tick deterministic score, computed by `cf-audio::intensity::score`:

```rust
pub fn score(snap: &EngineSnapshot) -> f32 {
    let enemies_in_sight = clamp(snap.hostiles_visible_to_player as f32 / 6.0, 0.0, 1.0);
    let damage_recent    = clamp(snap.damage_taken_last_10s_hp / 50.0, 0.0, 1.0);
    let bullets_recent   = clamp(snap.bullets_fired_last_5s as f32 / 30.0, 0.0, 1.0);
    let mission_critical = if snap.mission_critical { 1.0 } else { 0.0 };
    let boss_active      = if snap.boss_arena_active   { 1.0 } else { 0.0 };
    let story_active     = if snap.storyteller_event   { 1.0 } else { 0.0 };

    0.35 * enemies_in_sight
  + 0.25 * damage_recent
  + 0.10 * bullets_recent
  + 0.15 * mission_critical
  + 0.10 * boss_active
  + 0.05 * story_active
}
```

A 60-tick (1 s at 60 Hz; rescales at other tick rates) low-pass IIR smooths the raw score before it reaches the selector:

```
intensity_smoothed_t = α * raw_t + (1 - α) * intensity_smoothed_{t-1}
where α = 1.0 / smoothing_ticks  (default smoothing_ticks = 60)
```

## Variant selector + hysteresis (locked)

```
band(intensity) =
    if intensity < 0.30 - 0.02:                 "calm"
    elif intensity < 0.60 - 0.02:               "buildup"
    elif intensity < 1.00:                      "climax"
    else:                                       "climax"

if band(intensity) == current_band:             stay
elif intensity is within ±0.04 of band boundary AND elapsed_since_last_change < 12s:
                                                stay (hysteresis dead-band)
else:                                           schedule transition to new band
```

The `debrief` variant is selected explicitly when `mission_phase == Debrief`; it does not enter the band selector.

## Layer stack + priority (locked)

```
LayerStack {
    world:      Layer { track: world_palette[active_world], weight: 1.0,  priority: 1 },
    faction:    Layer { track: faction_palette[active_faction], weight: 0.4, priority: 2 },
    storyteller:Layer { track: storyteller_palette[active_storyteller], weight: 0.25, priority: 3 },
    boss:       Layer { track: boss_palette[active_boss], weight: 1.0,    priority: 4 },
}
```

Resolution rule:
1. Boss layer present → boss layer ONLY (lower layers crossfade to 0 over 4 s).
2. No boss → world + faction + storyteller mixed at their weights, total normalized to 1.0.
3. All layers play the SAME variant (calm/buildup/climax/debrief) per the selector.

## Cross-fade scheduler (locked)

```rust
struct ScheduledTransition {
    from_variant: VariantId,
    to_variant: VariantId,
    bar_tick: u64,          // tick at next bar boundary
    duration_bars: u32,     // default 1 bar
    curve: FadeCurve,       // Logarithmic by default
}
```

- `bar_tick` = `current_tick + bars_until_next_bar(bpm, current_tick) * ticks_per_bar(bpm)`.
- Boss override is the ONE exception: it cuts at the next beat (¼ bar), not bar.
- Debrief is an 8 s linear fade (not bar-aligned) so mission-end timing always feels right.
- Maximum one in-flight transition per layer; new transitions queued behind it.

## Per-difficulty intensity weight overrides

`game/content/ai/difficulty.json` adds an optional `audio_intensity_weights` block per difficulty:

```json
{
  "id": "hardcore",
  "audio_intensity_weights": {
    "damage_recent": 0.35,
    "enemies_in_sight": 0.40,
    "smoothing_ticks": 30
  }
}
```

Higher difficulties weight damage + enemies higher and smooth faster → music spikes harder + sooner. Default (Normal) uses the locked formula above. Missing fields fall back to defaults.

## Out of scope

- Procedural music composition at runtime (per-tick generative tracks via local MusicGen/ACE-Step) — M37D plays the M37A-baked 120 tracks; runtime generation deferred to M48B audio polish + post-launch experimentation.
- Per-player music personalization (preferred genre, learned listening patterns) — same palette for every player. Personalization is post-launch.
- Stinger / one-shot music cues (e.g., "kill stinger" + "boss-phase-2 stinger") — M37D ships continuous-track-with-variants only. Stingers land in M48B.
- Vertical-remix layering (separate stems for drum / bass / lead muted per intensity) — current tracks are pre-mixed loops. Stem-based vertical remix is M48B.
- DJ-style tempo-matching cross-fades (beat-grid synchronization across tracks of different BPMs) — bar-aligned suffices for M37D; cross-BPM beat-matching is post-launch polish.
- Per-equipment / per-weapon musical motifs (Witcher 3 sword-of-virtue cues) — single-character + faction motifs only.
- User-supplied custom music drops (mod-supplied music) — M37A modder authoring will pick up custom tracks; M37D respects whatever the registry exposes but does not author modder UX.
- Music ducking for voice/radio chatter — M37A's voice-priority duck handles this; M37D defers to that bus configuration unchanged.

## Notes for the implementer

- **Intensity scoring is sim-pure**: `cf-audio::intensity::score(snap)` takes an immutable `EngineSnapshot` slice and returns `f32`. No state, no allocation, no `thread_rng`. This is the cornerstone of the M12B + M37D determinism contract.
- **Smoothing IIR state lives in `MusicState`**: one `f32` per layer; serialized in SaveBlob. Resuming a save mid-firefight keeps the smoothed intensity at its pre-save value (no calm-music-while-bleeding-out edge case).
- **Track metadata defaulting**: missing BPM in `track_metadata.ron` defaults to 90 BPM (~2.67 s bar). Log once per missing track; never crash. Adaptive music must keep playing even if metadata is incomplete.
- **Layer stack normalization**: when a layer is absent (no active faction, no active storyteller), redistribute its weight proportionally to remaining layers, NOT to silence. World ambient always gets the residual.
- **Boss override is a hard transition**: the only place where a transition fires faster than the bar grid. Boss-arena-enter MUST be deterministic (M45 boss-arena-enter event is the trigger).
- **Cross-fade implementation lives in cf-app**: `cf-audio::transitions` produces `ScheduledTransition` descriptors; the actual sample-mixing happens in `cf-app::audio_backend::music_player` against `bevy_audio`. Determinism stays in `cf-audio`.
- **Track-not-found fallback chain**: if `phobos_climax` is missing, try `phobos_buildup` → `phobos_calm` → `earth_ambient_calm` (the universal fallback). Never silence the music; never crash.
- **Replay event classification**: `audio.intensity_computed` fires every 12 ticks (not every tick — bandwidth) with the smoothed value. `audio.music_variant_changed` + `audio.music_layer_changed` fire on actual change only. All three are cosmetic.
- **No `println!`**: per AGENTS.md, all logging via `tracing`. Use `tracing::debug!` for per-tick intensity values when an opt-in span is enabled.
- **No hardcoded tick rate**: smoothing_ticks + minimum_hold_ticks both scale with the active tick rate; read from `cf-control::TickRate` rather than baking 60 in.
- **HUD debug overlay is opt-in**: bound to F8 by default in cf-ui keybinds (subject to player rebind). Off in production builds unless `--debug-music` flag.
- **Caption frequency throttle**: a music-variant-change can fire up to once per 12 s under min-hold; the caption bridge can show all of them without overwhelming. No throttle needed beyond min-hold.
