## Intent

**M12 is the visual direction closure** — per DR-019 + DR-046 + DR-055. After M12, the **vivid-illustrated comic aesthetic** is fully layered on top of M11's HUD: hand-drawn ink-accent UI / panel-bordered banners / dramatic impact particles / dynamic color grading / animated UI panels / juice rules applied per-surface. M11 is readable; M12 is *cinematic*.

M12 promise: **"the game looks like a high-budget studio production — vivid color-rich illustrated aesthetic with selective ink accents and deep tactile feedback."**

## Visual direction (per DR-019; NOT pure noir)

**Reference aesthetic**: closer to **Hades / Streets of Rage 4 / Into the Breach / Cuphead / Hyper Light Drifter** than pure black-on-white noir. Corefall is a **color-rich + detail-rich** game with **selective comic / ink-line accents** — NOT a flat noir game.

| Element | Direction |
|---|---|
| **Palette** | Per-faction 8-color palettes (primary + secondary + accent + dark + light + 3 tints) — saturated, expressive, ON. Faction-coherent. Origin-coherent. Material-coherent. **No "all black" minimalism.** |
| **Linework** | Ink-line OUTLINES on key elements (actor silhouettes, UI panel borders, faction emblems, comic panel frames) — like Hades or Streets of Rage 4 — accent treatment, not the dominant style |
| **Fill** | Rich gradients + dithered shading + per-material texture details. Not flat. Every sprite has internal detail (rivets, plating seams, weathering, faction insignia, lighting). |
| **Detail density** | High — players see weapon iron sights, chassis joint articulation, armor plate seams, faction patches. Inspired by Into the Breach's mech sprites + Cortex Command's busy-but-readable pixel art. |
| **Color grading** | Dynamic per-scene + mission mood — daylight scenes are bright + saturated; nighttime / hazard scenes get atmospheric color shift but never flatten to monochrome |
| **Comic accents** | Comic-book speech bubbles + onomatopoeia stamps (BOOM / CRACK / KCHK) + comic-panel mission briefings + graphic-novel death recap — **applied to specific moments, not the whole HUD** |
| **Lighting** | Per-tile thermal glow (hot tiles glow orange, cold tiles glow blue, hazard tiles strobe), per-weapon muzzle flash, per-explosion radial bloom. Color carries information. |
| **Faction differentiation** | Every faction's units immediately distinguishable by palette + silhouette + insignia + decal language. Hostile-Corp = sterile blue / silver / red accents; Frontier = rust orange / dark green / leather brown; Marauder Tribes = bone white / blood red / fur trim; Scientist Order = lab white / electric cyan / brass accents; Drone Collective = chrome silver / electric magenta / black; Mercenary Guild = mottled olive / desert tan / scuffed brass; Religious Order = deep purple / gold / cream; Pirates = weathered teal / brass / driftwood gray. |

What M12 does NOT do:
- ❌ Drop colors in favor of black/white minimalism (we're not Limbo or Inside)
- ❌ Force every scene into the same noir filter
- ❌ Simplify silhouettes to the point of losing detail

What M12 DOES do:
- ✓ Add ink-line outline accents on heroic moments (death cam, slow-mo kill, mission briefing)
- ✓ Layer comic-panel transitions for narrative beats
- ✓ Apply impact-particle juice with INK style for emphasis (sparks from metal, blood splatters)
- ✓ Use dynamic color grading per scene-mood (NOT a static filter)

### Vivid color-rich aesthetic (per DR-019) — supersedes prior "comic-noir" framing

- Hand-drawn ink-accent UI elements (HUD borders, panels, banners) — accent layer ON TOP of color-rich panel fills, not REPLACING fills
- Comic-book-style speech bubbles for AI chatter (M37 forward-compat) — used selectively for narrative + chatter moments
- Dramatic impact particles (sparks, dust, blood, plasma, smoke) — color-coded per damage type, NOT all ink-black
- Per-actor outline shaders (selective; emphasized actors get heavier ink halo) — applied to player + key NPC + boss + killcam target only
- Dynamic color grading per scene (per mission mood — never flattens to monochrome)

### Juice rules (per DR-055 + DR-046)

- Button hover juice (scale 1.0 → 1.05 over 80ms ease-out + glow halo + tick SFX)
- Click punch juice (scale 1.0 → 0.95 → 1.0 over 120ms + click SFX)
- Banner slide-in juice (slide from edge over 200ms ease-in-out)
- Critical-hit punch (hit-stop + screen flash + chromatic aberration)
- Reload completion ding (subtle SFX cue)
- Weapon swap whoosh (audio + brief light streak)
- Pickup glow (item pulses on hover)

### Animation system

- UI panel transitions (slide + skew + ease per DR-046)
- Per-element animation hooks (entry, exit, hover, focus, click, drag)
- Animation system respects `reduce_motion` setting (instant transitions)

## Acceptance criteria

```gherkin
Scenario: Comic-noir UI renders
  Given M12 active + any scenario
  Then HUD borders use ink-line shader
  And impact particles use ink-style brushes
  And per-actor outlines (selective)

Scenario: Button hover juice
  Given a focusable button
  When cursor hovers:
    Then scale animates 1.0 → 1.05 over 80ms ease-out
    And glow halo appears
    And tick SFX plays
  When reduce_motion=true:
    Then animation skipped (instant 1.05)

Scenario: Click punch juice
  When button clicked:
    Then scale 1.0 → 0.95 → 1.0 over 120ms
    And brighter flash + click SFX
  When reduce_motion=true: skipped

Scenario: Banner slide-in
  Given new banner pushed
  Then banner slides from right edge over 200ms ease-in-out
  When reduce_motion=true: instant appear

Scenario: Mission briefing comic panel
  Given mission start
  Then comic_panel mission_briefing renders (hand-drawn art + text)
  And player can dismiss (Space) or auto-advances after 5s

Scenario: Death recap as graphic novel
  Given player death
  Then death recap renders as 4-panel comic with cause chain
  And player can navigate panels (Left/Right arrows)

Scenario: All juice respects accessibility
  Given Settings.reduce_motion=true + reduce_flash=true + reduce_shake=true
  Then every juice rule respects the flags
  And no juice violates the accessibility floor
```
