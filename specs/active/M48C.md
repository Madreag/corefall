# M48C — Endgame + Workshop UX Polish (Debrief + Replay + Mech Bay + Dossier + Faction + Quest + Hub + Mod Manager)

## Status

`active`

## Intent

**M48C is the endgame + workshop UX polish milestone** — the FINAL UX polish before M49 launch. End-of-mission debrief screen (full L4 surface integrating M10 cause-chain + capture grids + replay handoff), replay browser (multi-bundle navigation + scrub + bookmark), photo mode full UX (filters + color grading + keyframe + export), spectator UX polish (per M40A), mech bay (chassis configuration + module slots + repair queue + cosmetic preview), pilot dossier (per-pilot history + traits + relationships + scars), commander dossier (named AI enemies + persistent rivalry), faction diplomacy panel (relationship matrix + alliance + war + treaties), quest log (active + history + voyage tracking), NPC dialog UX polish (per M26 trees + M37A voice + animated portraits), hub UI (the meta layer between missions), mod manager UI (browse + subscribe + load order + conflicts).

**Why before M49 (final launch):** by M48B close, all production-track milestones close. M48C is the LAST UX polish pass — every L4 (after-action) surface gets dedicated treatment. Then M49 ships.

**Why this milestone exists:** L4 surfaces (debrief / replay / mech bay / dossiers / faction / quest) are RICH content but lack dedicated UX in current spec. M11 reserved them as forward-compat slots; M48C fills them at launch quality.

M48C promise: **"every L4 'after-action' screen feels like a deep meta game — debrief screens like a Sea of Thieves war room; mech bay like an Armored Core garage; pilot dossier like a Diablo character sheet; faction diplomacy like a Crusader Kings court; quest log like a Witcher 3 journal; mod manager like Stationeers' workshop — all in one game."**

## Player-facing behavior

### End-of-mission debrief screen (M10 + M11 + M40A integration)

Full L4 surface after mission_resolved:

- **Layout (full-screen):**
  - Top: Mission outcome banner (WIN / LOSS / ABORT) + result text
  - Center-left: Capture grid (M40A; auto-generated summary) showing 8-16 mission highlights
  - Center-right: Cause-chain rendering (M10) in plain language
  - Bottom: Reward summary + per-objective completion + faction reputation changes
- **Per-section interactive:**
  - **Outcome banner** — animated reveal (M12 juice; respects reduce_motion); WIN gold glow / LOSS red dim
  - **Capture grid** — click any image to view full-resolution; play replay from that point
  - **Cause chain** — interactive (click any event to see context); per M10 plain-language rendering
  - **Reward summary** — animated counter for credits / loot / XP / faction reputation
  - **Per-objective** — checkmarks for completed; X for failed; per-objective time-to-complete
  - **Achievement unlocks** — per M27 toast notifications during reveal
  - **Cosmetic unlocks** — per M45A; new cosmetics highlighted
- **Action buttons:**
  - **Continue Campaign** (next mission per M25)
  - **Show Me Why** (only on LOSS; M10 cause-chain expanded view)
  - **Replay** (re-play same mission)
  - **Export Clip** (M40A clip export)
  - **Rate Mission** (1-5 stars + optional comment; per M36B)
  - **Report Bug** (per M36B)
  - **Share Replay** (Steam Workshop)
  - **Back to Hub**
- **Per-platform layout:**
  - Steam Deck (800p): vertical scroll layout
  - Desktop (1080p+): two-column horizontal layout
- **Voice-over** — M37A produces per-outcome voice-over: "Mission complete. <faction> reputation +15."

### Replay browser (full UX; M33 + M10)

Per M33 replay browser reservation:

- **Layout (3-pane):**
  - Left: bundle list (per-mission per-date per-tag)
  - Center: bundle preview (capture grid + summary + cause-chain summary)
  - Right: timeline scrubber + per-event detail
- **Bundle list:**
  - Sort: Most-recent / Most-played / Highest-rated / Most-bookmarked
  - Filter: per-mission / per-faction / per-result / per-tag
  - Search: keyword
  - Per-bundle preview: thumbnail (from M40A capture grid) + title + duration + outcome
- **Center preview:**
  - Capture grid scrollable
  - Outcome banner
  - Cause-chain summary
  - Stats (kills / accuracy / objectives completed)
  - Per-bundle ratings + comments (community + own)
- **Timeline scrubber:**
  - Full-mission timeline (1 hour mission = 1 hour bar)
  - Per-event markers (combat / objectives / faction-changes / boss-encounters)
  - Per-marker tooltip
  - Click marker → jump to that tick in replay
  - Scrub left-right to fast-forward / rewind
- **Bookmark system:**
  - Hold [B] during replay → bookmark current tick
  - Bookmarks listed in right panel
  - Per-bookmark note (LLM-suggested OR custom)
- **Export options:**
  - **Export to MP4** (per M40A; with overlay theme)
  - **Export to Steam Workshop** (per M36A)
  - **Export to Discord** (per M36A webhook)
- **Per-replay friends-played-this:**
  - Steam friends who played same scenario
  - Compare ratings + best times

### Photo mode full UX (M8 basic + M33 stub + M48A polish)

- **Per-tier filter palette** — 10+ launch filters: Sepia / B&W / Cyberpunk Neon / Noir / Vintage / Posterize / High-Contrast / Saturated / Desaturated / Tilt-Shift
- **Color grading curves** — Highlights / Midtones / Shadows; per-channel (RGB)
- **Depth of field** — focal distance + aperture + blur amount

  - Auto-tween between keyframes
- **Export:**
  - PNG (still)
  - Image sequence (MP4 via M40A FFmpeg)
  - Sticker pack (per-platform Steam Community + Discord)
- **Per-photo metadata** — tags + caption + location-coords + timestamp
- **Photo mode tutorial** — first-time photo mode shows quick tour
