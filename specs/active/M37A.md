## Intent

**M37A is the Tier 2 audio production pipeline** — production-grade SFX via Stable Audio Open + voice synthesis via ElevenLabs / Bark / Mimic3 + music composition via MusicGen / Stable Audio + adaptive music engine + dynamic radio chatter generation. Every M12A Tier 1 placeholder SFX gets a production-grade replacement; 80+ voice lines per archetype across 8 archetypes generate dialog audio; 30+ music tracks compose across worlds + factions + bosses + storytellers + UI.

**Why after M37 (voice + radio + comms):** by M37 close, the voice + radio + comms subsystem ships (proximity audio + radio interference + EMP + captions). M37 needs voice clips; M37A produces them. Same with music tracks for ambient + boss + faction themes.

**Why this is the BACKBONE:** the human stops authoring audio FOREVER at M37A. Voice synth produces dialog from M25A narrative text; music composition produces 30+ tracks via MusicGen prompts + per-faction LoRAs; adaptive music engine cross-fades per scenario state; dynamic radio chatter generates per-faction lines at runtime.

M37A promise: **"every voice line in the game (mission briefings, boss intros, NPC dialog, radio chatter, AI bot comms, tutorial narration) is voice-synthesized + per-character voice-consistent; every music track (12 world ambients + 8 faction themes + 5 storyteller themes + 5 boss themes + adaptive variants) is MusicGen-composed + per-scenario adaptive — and nothing requires a human composer or voice actor."**

```rust
pub struct AdaptiveMusicState {
    pub current_track: TrackId,
    pub current_variant: VariantId,
    pub cross_fade_in_progress: Option<CrossFade>,
    pub intensity: f32,                              // 0.0-1.0; from mission_phase + storyteller + combat density

// 3. Compute target_variant per intensity
```

## Notes for the implementer

### Architecture rules

- **Voice synth offline-friendly** — Bark / XTTS / Mimic3 run local; ElevenLabs requires API (use for premium quality where needed)
- **Per-NPC voice caching** — once a voice clip is synthesized, cached; runtime never re-synthesizes
- **Dynamic chatter combines pre-synthesized phrases** — runtime concatenates "Engaging" + "{direction}" + "{weapon}" from pre-synth pool; deterministic per-event
- **Adaptive music as state machine** — cross-fade engine is deterministic per intensity input
- **Per-bus mix respects ACC-A** — voice priority ducking + per-bus volume + reduce_flash-no-strobe equivalents

### Decision-record alignment

- **DR-043 (realistic comms)** — M37A voice + radio chatter integrate with M37 propagation
- **DR-044 (audiovisual production pipeline)** — M37A is audio Tier 2
- **DR-053 (asset ledger)** — every audio entry ledgered
- **DR-006 (mod parity)** — mods author via same pipeline

### Pitfalls

- **Voice synth cost (ElevenLabs)** — API costs add up; use local Bark/XTTS for bulk; ElevenLabs only for premium voices (named characters)
- **Voice consistency across NPCs**: same NPC across all clips must sound identical; pin voice_id per NPC
- **Music memory budget**: 120 music files × 4 min × 320kbps = ~720 MB; OGG Vorbis brings to ~500 MB; lazy-load per-scenario
- **Adaptive music latency**: cross-fade must feel responsive; not exceed 3s
- **Multilingual voice consistency**: same NPC's voice across 19 languages must be recognizable; multilingual TTS preserves per-voice characteristics

### Closure procedure

1. Reference bundle: M25 + M45 scenarios re-played with full Tier 2 audio + voice + adaptive music.
2. Self-play sweep rows: `m37a_tier2_sfx_regen`, `m37a_npc_voice_synth_all_npcs`, `m37a_mission_voice_synth`, `m37a_music_composition_30_tracks`, `m37a_adaptive_music_cross_fade`, `m37a_per_faction_chatter`, `m37a_voice_priority_ducking`, `m37a_acc_a_captions`, `m37a_modder_authoring`. All PASS.
3. Update DR-043 + DR-044 closure note.
4. Move M37A → done/.
