# M24A — VFX + Particle Production Pipeline Tier 1

## Status

`active`

## Intent

**M24A is the Tier 1 VFX + particle production pipeline** — particle effects (impact / spark / smoke / ember / fluid splatter), animated VFX sequences (explosion / ignition / chain reaction / muzzle flash / reactor venting / atmospheric breach), environmental atmospherics (dust / fog / rain / snow / acid mist / volatile haze), authored from data via LLM-prompted particle config generation + ComfyUI texture generation + emitter parameter authoring.

**Why after M24 (AI environmental competence):** by M24 close, BP5 (atmospherics + AI env) closes. M16 hazards + M19 atmospherics + M20 env aggregator + M21 pressure-hold + M22 path + M23 mind + M24 env competence all need rich VFX to look + feel right. Plain colored squares for fire / smoke / electric arcs are insufficient.

**Why this is the BACKBONE:** the human stops authoring VFX FOREVER at M24A. Particle textures + emitter configs + per-damage-kind impact variants — all generated. M48A polishes via cinematic VFX + post-process; M24A is the Tier 1 floor.

M24A promise: **"every explosion, every spark, every wisp of smoke, every splatter of blood / oil / coolant — generated, ledgered, regenerable; the simulation has visceral visible feedback."**

## Player-facing behavior

After M24A, the player sees:

- **30+ impact variants** — per damage kind (kinetic / thermal / electric / chemical / radiation / kinetic-AP / HEAT / APFSDS) + per material (8 launch materials) = 64+ impact configurations
- **Per-material spark variants** — metal hit = bright sparks; concrete hit = dust + chips; wood hit = splinters; glass hit = shards
- **Explosion size variants** — small (grenade, 1m radius) / medium (HE shell, 3m) / large (reactor breach, 8m) / catastrophic (ammo rack, 15m + chain reaction)
- **Per-origin fluid splatter** — blood (red, human) / oil (black, robot) / coolant (green, robot) / fuel (amber, vehicle) / synth-blood (purple, android) / bio-fluid (white, heavy_biomech) / electrolyte (cyan, robot/android)
- **Environmental atmospherics** — dust storm particles (M31 weather), smoke clouds (M16 hazard fire), steam plumes (M19 atmospherics), fog banks (M31), rain (M31), snow (M31), acid mist (Venus per DR-039), volatile haze (Vulcan per DR-039)
- **War Thunder-style penetration spalling** — when AP round penetrates, 2-5 spalling fragment particles spawn into chassis interior (per M9 + M14 + M41 forward-compat)
- **Chain ignition cascades** — oil ignites with fire → larger fire VFX (per M15 reactions)
- **Reactor venting** — pressure_state=Venting fires continuous steam + spark VFX (M9)
- **Muzzle flash variants** — per weapon type (pistol / rifle / sniper / shotgun / plasma / railgun)
- **Bullet tracers** — per ammo type (1:3 rifle tracer ratio per M1; 1:1 sniper)
- **Wound emitters** — per CCCP MOSRotating::AddWoundExt: entry-point sparks + exit-point sparks per shot through actor
- **Health-damage tint** — actor sprite tints red on damage (cosmetic; respects reduce_flash)
- **Camera-punch debris** — gibs from explosions fly across screen + decal on terrain (M14)
- **VFX respect accessibility** — every VFX has `reduce_flash` + `reduce_motion` variants

## VFX manifest entry schema (locked v1)

```ron
VfxManifestEntry (
    id: "impact_kinetic_metal_pristine",
    canonical_name: "Kinetic Impact — Metal (Pristine)",
    category: Impact,
    
    damage_kind: "kinetic",
    target_material: "metal",
    target_material_state: "pristine",                  // pristine / scratched / cracked / destroyed
    
    emitter: (
        particle_count: 12,
        emit_duration_ms: 80,
        particle_lifetime_ms: 250,
        initial_velocity_min_px_per_s: 60,
        initial_velocity_max_px_per_s: 200,
        spread_radians: 1.05,                           // 60° cone
        gravity_affected: true,
        gravity_strength: 0.5,                          // 0..1 multiplier
        rotation_speed_min_rad_per_s: -3.0,
        rotation_speed_max_rad_per_s: 3.0,
        scale_curve: "shrink_to_zero",                  // shrink_to_zero / steady / grow / pulse
        color_curve: "bright_yellow_to_orange",         // per damage kind palette
        alpha_curve: "fade_out_quadratic",
        texture_ref: "spark_small",                     // ComfyUI-generated; small SDXL crop
        blend_mode: "additive",                          // additive / alpha / multiply
    ),
    
    accessibility_variants: (
        reduce_flash: (
            particle_count: 8,                          // fewer particles
            color_curve: "muted_yellow_to_orange",       // less saturation
            alpha_curve: "fade_out_quadratic",           // no flash spike
        ),
        reduce_motion: (
            particle_lifetime_ms: 150,                   // shorter; less motion
            initial_velocity_max_px_per_s: 80,           // slower
        ),
    ),
    
    sfx_pair: "impact_kinetic_metal_pristine",          // M12A SFX ID; auto-played
    caption_pair: "Metallic ping",                       // ACC-A caption
    
    seed: 1234,
    texture_blake3: "<computed>",
    config_blake3: "<computed>",
    
    upstream_assets: ["spark_small_texture"],
    
    package_source: PackageRef(vanilla, version: "1.0.0"),
    license: CC0,
)
```

## Notes for the implementer

### Architecture rules

- **Particles are pure cosmetic** — never affect sim state; cosmetic=true flag set on all VFX events
- **Particle pool reuse** — pre-allocate 5000 particle slots; recycle; no per-frame allocation
- **GPU-instanced rendering** — single draw call per VFX texture; per-particle instance data
- **Seeded per-event RNG** — same event + same tick = same particle spawn pattern across replays
- **Accessibility-aware** — every VFX has 3 variants: full / reduce_flash / reduce_motion
- **Frame-budget bounded** — max 2ms particle update + 2ms render per tick

### Pitfalls

- **Particle count explosion**: large explosions can spawn 1000s of particles; cap per emit (per M3 debris cap pattern)
- **GPU-instance memory**: per-particle instance data must fit in GPU constant buffer; cap per-VFX at 500 particles
- **Replay parity for particle RNG**: use cf-replay seeded RNG, NOT thread_rng
- **Per-tier perf**: Steam Deck must handle 500 particles at 60Hz — measured + gated
- **Texture atlas size**: 80 particle textures × multiple resolutions = ~20 MB texture atlas; load lazily
