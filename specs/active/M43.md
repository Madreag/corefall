# M43 — PvE Survival Mode + Procgen

## Status

`active`

## Intent

**M43 is the PvE Survival game mode + procgen milestone** — the Terraria / Stationeers / Minecraft / Cortex-Command hybrid PvE mode preset and procedural world generation. After M43, players can spawn on a procedurally-generated planet, survive across all 5 crafting tiers (M32), build/sustain race-specific colonies (ONI parity), face acclimatization to harsh worlds, and run solo or 2-8 player coop.

**Sister milestones in BP10:**
- M44 — Inter-Planet Transport + Stations (dropship / rocket / teleporter / orbital stations / asteroid mining)
- M45 — PvE Endgame Bosses + World Events (5 bosses + 12 storyteller events)

M43 is the mode + procgen spine; the others fill specific scopes.

M43 promise: **"if you survive 100 hours, you've built a multi-world civilization with your own bunker, your own avatar, and your own race-specific colony design."**

- **Surface terrain**: per-world surface_template + biome variations (3-5 biomes per world per M31)

### Procedural world generation algorithm (per-world)

Per-world generator runs deterministically from `world_seed + world_id`:

**Generation pipeline:**

```text
1. Surface topology pass
   ├─ Heightmap noise (Perlin + simplex; seeded)
   ├─ Tectonic faults (long jagged ridges)
   ├─ Volcanic regions (Vulcan / Earth volcanic biomes)
   ├─ Crater placement (Moon / Phobos / Deimos / asteroids)
   ├─ River system (Earth + Mars + Europa subsurface)
   └─ Coastline formation

2. Biome assignment pass (per M31 biome catalog)
   ├─ Tundra zones (cold worlds; Mimas/Europa)
   ├─ Desert zones (Vulcan + Mars equatorial)
   ├─ Forest zones (Earth temperate)
   ├─ Mountain zones (Earth + Mars + Vulcan)
   ├─ Swamp zones (Earth tropical)
   ├─ Cave zones (subsurface; per world)
   ├─ Urban zones (player-built; pre-placed ruins)
   ├─ Industrial zones (faction settlements; abandoned)
   ├─ Ocean zones (Earth + Europa subsurface)
   ├─ Ice zones (cold worlds + ice deposits)
   ├─ Volcanic zones (Vulcan + Earth + Europa)
   └─ Abandoned_lab zones (corp ruins; lore drops)

3. Ore deposit placement (per DR-039 world.ore_deposits)
   ├─ Surface scatter (T0/T1 ore; iron, copper, coal, dirt)
   ├─ Subsurface veins (T1/T2 ore; iron, gold, copper)
   ├─ Deep-crust pockets (T2/T3 ore; uranium, titanium)
   ├─ Core (T3/T4 ore; superconductor materials, rare earths)
   └─ Anomalous regions (T4 exotic ore; near anomalies)

4. Hazard zone placement (per M16 hazards + M31 weather)
   ├─ Radiation zones (per uranium-rich deposits + surface radiation)
   ├─ Anomaly clusters (gravity / electric / time / chemical / bloodsucker / psy_storm)
   ├─ Combustible atmosphere pockets (Vulcan; some Earth volcanic)
   ├─ Toxic atmosphere pockets (Vulcan industrial; cave systems)
   ├─ Cryogenic zones (Mimas/Europa; some Earth tundra)
   └─ Weather-zone biomes (per M31 weather variation table)

5. Pre-existing structure placement
   ├─ Ruined outposts (codex + lore drop; player can salvage)
   ├─ Pirate bases (4-8 per world; loot caches + bosses)
   ├─ Ancient artifacts (per M16 anomaly proximity; T4 rare drops)
   ├─ Trade routes (NPC trader patrol; player can hijack)
   ├─ Faction settlements (8 factions per M25 + per-world distribution)
   ├─ Mission objective markers (per scenario manifest + procgen quests)
   └─ Secret bunkers (hidden by terrain; lore unlock)

6. AI raider settlement seeding
   ├─ Per-faction territory map
   ├─ Settlement density per world danger rating
   ├─ AI commander placement (1-3 per world)
   ├─ Raid trajectory + raid frequency multiplier
   └─ Per-faction tech tier (T1 starter raiders; T3 endgame raiders)

7. Validation pass
   ├─ Connectivity check (player can reach all zones)
   ├─ Resource scarcity check (each world has all 12 ores accessible)
   ├─ Spawn safety check (initial spawn zone clear of hazards)
   ├─ Performance check (chunk count within Steam Deck budget)
   └─ Save schema check (per DR-029)
```

Determinism: same seed = byte-identical world per replay determinism contract.

### Industrial Center Evacuation (AWAW Rule 37 — Opt-In)

**Opt-in per server.** Default `server.ron` has `grand_strategy.awaw_rulesets.enable_industrial_center_evacuation=false`. Hardcore PvE Survival recommends ON.

#### Industrial Center placement

Per procgen pass: each world has 3-8 **Industrial Centers** (depending on world size + faction count). ICs are large named production hubs:

```rust
pub struct IndustrialCenter {
    pub ic_id: IndustrialCenterId,
    pub name: String,                               // e.g. "Magnitogorsk Steelworks"
    pub world_id: WorldId,
    pub position: Vec2,
    pub kind: ICKind,                               // factory / smelter / reactor / etc.
    pub bp_value: f32,                              // economic value (50-500 BP)
    pub current_owner: FactionId,
    pub evacuation_state: EvacuationState,
}

pub enum ICKind {
    Factory,            // produces parts / units
    Smelter,            // produces steel / refined metal
    Reactor,            // produces power (per M29)
    ResearchLab,        // produces RP/cycle
    Refinery,           // produces fuel
    Workshop,           // produces tools
}

pub enum EvacuationState {
    Operational,
    Evacuating { progress_pct: f32, target_region: BaseId },
    Evacuated { value_retained_pct: f32 },         // typically 30-70%
    Captured { by_faction: FactionId },             // lost forever
    Destroyed,                                      // scorched-earth
}
```

#### Per-IC defensive characteristics

Each IC has:
- **BP value**: economic worth (50-500 BP)
- **Defensive HP**: 100-1000 (lots of fortifications around it)
- **Evacuation time**: 3-7 in-game days (per IC value)
- **Evacuation BP cost**: 20-50% of IC value (cost to move materials + workers)
- **Materials carried**: 30-70% of original value (varies)

#### Evacuation mechanic

When enemy threatens IC + player decides to save value:

1. Player invokes `act.faction.evacuate_ic { ic_id, target_region }`
2. IC enters Evacuating state
3. Per-day progress accumulates (depending on player labor + transport)
4. During evacuation: IC produces 0 (workers transferring)
5. When complete: IC at target_region produces 30-70% of original value
6. Original IC location becomes empty (no value left)

#### Evacuation failure

If enemy captures IC during evacuation:
- Evacuation halts
- Materials in transit go to enemy (per AWAW Rule 37.6)
- Player loses BP + reputation

#### Scorched-earth option

Alternative: player destroys IC instead of letting enemy capture it.
- IC kind=Destroyed; produces 0
- BP value to player = 25% of original (salvaged scrap)
- Reputation -5 with player's faction
- Enemy gets 0
- Per AWAW Rule 37.5

### Acclimatization + adaptation mechanics

Per Stationeers + Subnautica Below Zero patterns:

- Player races have **acclimatization curve** per environment
- New environment = 100% exposure stress (full damage)
- Spending time in new environment slowly adapts body (per race biological speed)
- After ~10 in-game hours: 50% exposure stress (half damage)
- After ~50 hours: 10% exposure stress
- After ~200 hours: native (0% additional stress)
- Acclimatization is **lost** if player leaves environment for long; gradual fading

Per-race acclimatization speed:
- Human: slow (50 hours full acclimatize); evolutionary cost
- Robot: instant (no biology); just suit adjust
- Insectoid: fastest (chitin reflexes); 10 hours full
- Crystalline: very fast on radiation/thermal; slow on impact
- Photosynthetic: slow biological (light + CO2 adaptation)
- Methane breather: medium; instant on cryogenic, slow on warmth
- Aqueous: instant in water; very slow in air

UI shows acclimatization progress bar per environment per actor.
