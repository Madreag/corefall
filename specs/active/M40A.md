# M40A — Spectator + Streamer + Replay-to-MP4 Polish

## Status

`active`

## Intent

**M40A is the spectator + streamer tooling polish milestone** — Twitch/YouTube Live integration forward-compat + clean HUD mode (no nameplates over enemies + branded overlays) + multi-actor camera director + replay export to MP4 via FFmpeg + auto-cinematic kill cam director + 10+ launch streamer overlay themes + Discord stream integration + clip-export workflow.

**Why after M40 (LAN co-op):** by M40 close, LAN co-op sessions emit per-client run bundles. M40A polishes the spectator surface (M8 had basic spectator; M41 ships networked; M40A polishes both single-player and co-op spectator UX for streamer-friendly broadcast).

**Why this milestone exists:** competitive PvP streaming + Let's Play streaming + Twitch viewer engagement require professional spectator tooling. Steam Big Picture + Steam Deck broadcasting work out-of-box; M40A adds the polish that makes Corefall a streamer's favorite broadcast game.

M40A promise: **"streamers can broadcast Corefall professionally — clean HUD mode hides spoilers, branded overlay templates ship, replay export to MP4 enables clip culture, auto-cinematic kill cam director makes every kill cinematic, Twitch + YouTube + Discord integrations seamless."**

## Player-facing behavior

After M40A, the streamer experiences:

- **Clean HUD mode** — toggleable via Settings + per-server enforced; hides enemy nameplates (no spoilers); hides sensitive info (anti-cheat flags, server admin); shows player branding overlay
- **Multi-actor camera director** — auto-cycles through interesting actors during co-op + PvP matches; per-actor "interesting" score based on combat density + objective proximity + life count
- **Auto-cinematic kill cam director** — chains kill cams from M41 (War Thunder-style polished) into highlight reels
- **Replay export to MP4** — via FFmpeg / libav; per-replay export with custom start + end + audio mix + overlay
- **10+ launch streamer overlay themes** — branded templates: stream-tournament / let's-play / racing / co-op / pvp / docs-style / minimal / retro-2D / sci-fi-grimdark / drone-style
- **Twitch + YouTube + Discord integrations** — stream events emit via Twitch IRC bot + YouTube Live chat + Discord webhook
- **Clip export workflow** — Press F11 → "Clip Last 30 Seconds" → MP4 saved + optional auto-upload to Steam Community / Discord / Twitch
- **Spectator camera presets** — 5 launch presets: free-cam / follow-actor / objective-cam / overhead-tactical / dramatic-3rd-person
- **Per-stream-platform broadcast plug-in** — OBS Studio compatible (Windows Capture / Display Capture work out-of-box); StreamLabs templates ship
- **Tournament mode** — locked spectator camera + admin controls (per M41 tournament endgame mode)
- **Streamer mode** — Settings.streamer_mode=true hides: sensitive info, friend names, IP, Discord usernames; respects DR-031 anti-pay-to-win

## Notes for the implementer

### Architecture rules

- **Spectator camera reads sim state; never affects** — pure-read; no determinism impact
- **Multi-actor director scores deterministically** — same bundle + same director config = same camera cuts
- **Clip export non-blocking** — runs on background thread; player can keep playing
- **Overlay themes data-driven** — RON files; modder authoring via Workshop

### Decision-record alignment

- **DR-031 (anti-pay-to-win)**: streamer mode hides any DLC-bought items (cosmetics-only; no gameplay impact)
- **DR-046 (player-facing surfaces)**: streamer + spectator UX polished
- **DR-048 (endgame retention)**: clip culture extends retention via shared highlights

### Pitfalls

- **FFmpeg licensing**: GPL/LGPL; check distribution; use rust-ffmpeg or invoke ffmpeg binary
- **Audio mix sync to video frames**: ensure per-frame audio aligned in MP4
- **OBS scene template versioning**: pin per-version

### Closure procedure

1. Reference bundle: PvP arena + co-op campaign sessions streamed via OBS with M40A overlay themes; broadcast verified.
2. Self-play sweep rows: `m40a_spectator_camera_modes`, `m40a_director_multi_actor`, `m40a_cinematic_kill_cam`, `m40a_replay_export_mp4`, `m40a_overlay_themes_10`, `m40a_twitch_bot`, `m40a_youtube_live`, `m40a_discord_webhook`, `m40a_clip_export_f11`, `m40a_streamer_mode_pii`. All PASS.
3. Move M40A → done/.
