
## Status

`active`

## Intent

**M7 is the campaign + base + commander mega-milestone** — the gameplay vertical-slice anchor for BP7. After M7, players can run a campaign with multi-mission progression, build/defend/uproot bases with command core identity (DR-029), face an AI commander with persistent rivalry, use stratagem call-ins, encounter loot rarity drops, gain XP + perks, complete branching narratives with NPC dialog + investigation events, fight named mini-boss + boss encounters, manage pet companions, and consume the full faction system with quartermaster vendors.

M7 promise: **"this is the whole game" — campaign feels alive, bases feel meaningful, AI commanders feel like rivals, and emergent stories happen every session.**

## Player-facing behavior

### Campaign architecture (per DR-027 + DR-048)

- **Multi-mission progression**: 30+ launch missions tracked
- **Mission unlock graph**: completed missions unlock new branches
- **Mission rewards**: credits + loot drops + XP + reputation
- **Mid-mission saves** (M7-only feature; rest of game uses scenario.reset)
- **Replay export** per mission

### Storyteller / incident director (Rimworld-inspired)

**5 storytellers** with distinct pacing:
- `Cassandra Classic` — medium escalation; balanced events
- `Phoebe Chillax` — slow escalation; player-friendly
- `Randy Random` — chaotic events; unpredictable
- `Ironman` — no respawn; permadeath
- `Sandbox` — no escalation; pure exploration

Storyteller events: weather change, ally arrival, enemy raid, mass revolt, supply drop, mission extension.

Events: `director.incident_chosen`, `director.escalation_triggered`.

### Base + command core identity (per DR-029)

- Player has a designated **base** (built at scenario start or campaign progression)
- **Command core**: the brain that anchors the base
- **Bunker building**: place floors / walls / ceilings / doors / ramps / ladders / windows (per CCCP `Bunkers`)
- **Power grid**: generators + distribution + reserve power
- **Module slots**: shield, turret, sensor, repair, door
- **Avatar mode**: command core can uproot into avatar body (mobile risk; base undefended)
- **Reroot**: avatar returns to base (must travel to base + interact)
- **Salvage**: defeated enemy chassis become salvageable in base

### Buy menu + delivery craft (CCCP signature; M2.2 deferred)

- Mid-mission buy menu via `act.economy.open_buy_menu`
- Buy actors / weapons / chassis (loadout)
- Delivery craft (drop pod / dropship / rocket) — risk + capacity + crash chance
- Craft states: incoming → standby → landing → hatch_open → unloading → hatch_close → takeoff
- Anti-air defenses can shoot down dropships
- Gold/credit economy with material drops

### Stratagem call-ins (Helldivers; M2.2 deferred)

**8 launch stratagems** with D-pad combo input + cooldown timers:
- airstrike (orbital bombardment)
- drop_reinforcements (drops 2 bots)
- sentry_turret (auto-firing turret)
- supply_drop (ammo + medkit crate)
- smoke_screen (large smoke zone)
- EMP_grenade (disables electronics)
- repair_drone (friendly drone repairs)
- extraction_call (evac dropship)

Per-stratagem cool-down 30-180s. Friendly-fire risk highlighted.

### AI commander persona

- Each campaign has 1-3 **named AI commanders** (persistent across missions)
- Commander personality: aggressive / strategic / patient / sadistic
- Commander makes high-level decisions (where to attack, what reinforcements to call, what missions to attack player on)
- Persistent **rivalry**: commander remembers player tactics from previous missions
- Commander dossier visible to player (kills, defeats, signature tactics)
- Defeating commander = mission reward (artifact, gear, lore unlock)

### Faction system full mechanics

- **8 factions** (per README content target): Hostile Corp / Allied Resistance / Marauder Tribes / Religious Order / Scientist Order / Mercenary Guild / Pirates / Drone Collective
- Per-faction relationship matrix (-100 to +100)
- **Quartermaster vendors**: per faction, NPC sells faction-specific gear
- **Faction-specific gear** (cosmetic + functional differentiation)
- **Faction territory**: regions claimed by faction (M12 MMO inherits)
- **Faction wars** trigger when relationship < -50
- **Diplomacy**: truce, surrender, alliance, attack

### NPC dialog system + branching narratives

- Friendly NPCs in scenarios with dialog branches
- 4 dialog options per NPC: ask_mission / trade / recruit / leave
- NPCs offer side missions (kill X bandits, deliver Y, escort Z)
- Mission rewards: credits, gear, perks
- Forward-compat for M9.5 voice dialog

### Investigation + hidden lore + collectibles

- **Crime scene** scenarios: examine clues to solve mystery
- **Multi-clue chains** (5-10 clues per mystery)
- **Hidden lore items**: lore_log_X scattered in scenarios
- **Codex** unlocks per-clue (`docs/plan/spec/codex-tree`)
- ~600 codex entries cumulative

### Hostage / captives mechanics

- Mission objective: rescue captive OR capture target
- Captives are NPCs tied to scenery
- Player frees → captive follows player as weak NPC
- Captive can be killed by stray fire (mission fails)
- Captured enemy NPCs handcuffed + follow

### Mini-boss + boss patterns (Diablo + Sea of Thieves)

- **Mini-bosses**: Spotter archetype (M2.2B baseline) → expanded
- **Bosses** (full multi-phase):
  - Faction Boss: 3 phases with shield ability + summon reinforcements
  - World Boss: cross-mission shared; coordinated takedown required (M11+ multi-squad inherits)
  - Hidden Boss: secret arena unlocked by collectible chain
- Boss events: `boss.phase_changed`, `boss.special_ability_triggered`

### Pet / companion animals (Rimworld)

- 4 launch pet types: dog (alert + attack) / cat (small + stealthy) / wolf (combat-capable) / war-bear (heavy melee)
- Each pet has own HP + traits
- Pet follows player; can defend; can fetch items
- Pet training: feed + walk + commands
- Pet death = permanent (campaign-only)

### Perk + curse system stackable (Noita; M2.2 deferred)

- 20+ launch perks (vampire / berserker / explosive_immunity / fast_reload / sharp_aim_faster / sprint_speed+15% / etc.)
- 10+ launch curses (slow_reload / no_jet / vulnerable_to_fire / etc.)
- Perk altars in scenarios offer 3 perks; player picks 1 perk OR 1 curse for bonus
- Perks/curses persist across campaign (M7-only feature)

### Loot rarity + affixes + set bonuses (Diablo)

- 5 rarity tiers: Common (70%) / Magic (25%) / Rare (4%) / Legendary (1%) / Unique (0.1%)
- 30+ affixes per item type
- Set bonuses at 2 / 4 / 6 set items
- Loot drops from enemies + treasure chests + bosses

### XP + level + achievements

- XP from kills (more for higher-tier enemies), objectives, missions
- Level threshold: 1.5× more XP per level
- Per-level: +1 perk point
- 30+ launch achievements
- HUD toast on unlock

### Inventory grid Tetris (Stationeers; M2.2 deferred)

- Inventory displayed as 4x4 grid (configurable per chassis weight)
- Items occupy grid cells per shape (pistol 1x1, rifle 2x1, sniper 3x1, medical 2x2)
- Heavy items can't fit in small backpack

### Manufacturing + cooking + plant growing (Stationeers; M2.2 deferred)

- Manufacturing recipes (10+ launch) at workstations
- Cooking station: combine raw ingredients → cooked food
- Plant growing: seeds → grow → harvest
- Feeds caloric_energy resource (per M5.8)

### Treasure maps + voyages (Sea of Thieves)

- Treasure maps drop from rare enemies
- Map shows region with X marking treasure + rotational clues
- Player travels to X → digs → finds treasure (rare item + gold)
- Voyage system: multi-step missions with sequential clues (5-10 steps)

## Acceptance criteria

```gherkin
Scenario: 30+ launch missions accessible
  Given M7 closure
  Then 24 missions exist + accessible via campaign progression
  And M11+ adds 6 more to reach 30

Scenario: Campaign progression with mission unlocks
  Given player completes "First Contact" mission
  Then progression.mission_completed fires
  And 3 follow-up missions unlock per progression graph

Scenario: Storyteller event escalation
  Given Cassandra Classic storyteller + mid-session
  When player too comfortable for 5 minutes:
    Then director.escalation_triggered fires
    And mission.reinforcement_wave_spawned fires OR weather changes to storm

Scenario: Base building + power grid
  Given player at base + credits + materials
  When player builds turret + connects power:
    Then base.module_placed fires
    And base.power_connected fires
    And turret auto-fires at hostile entries

Scenario: Buy menu mid-mission
  Given mid-mission + credits=1000
  When player presses B:
    Then sim slowdown75 + buy menu opens
  When player buys rifle + 2 ammo + medkit (cost=200):
    Then economy.purchase_committed fires
    And delivery.craft_spawned fires (drop pod inbound)

Scenario: 8 stratagems with cooldowns
  Given player in scenario
  When player executes D-pad combo Up-Down-Left:
    Then stratagem.requested fires kind=airstrike
    And HUD shows targeting cursor
  When player confirms target:
    Then orbital strike inbound (3s delay)
    And after delay: stratagem.delivered fires

Scenario: AI commander rivalry
  Given player defeated Cmdr_Black on Mission 3
  When player encounters Cmdr_Black on Mission 8:
    Then commander.dossier_updated fires
    And commander employs different tactics (learned from previous defeat)

Scenario: 8 factions + relationship matrix
  Given scenario with all 8 factions
  When player kills allied faction member:
    Then faction.relationship_changed fires with delta=-30
  When relationship < -50:
    Then faction war declared

Scenario: NPC dialog with side mission
  Given friendly NPC approached
  When player chooses "ask_mission":
    Then dialog.mission_accepted fires
    And new mission added to quest log

Scenario: Crime scene investigation
  Given crime scene scenario
  When player examines 5 clues:
    Then investigation.mystery_solved fires
    And lore codex entries unlocked

Scenario: Mini-boss + boss patterns
  Given mini-boss in scenario
  When boss HP > 75%: phase 1 (ranged attacks)
  When HP < 75%: phase 2 (shield ability)
  When HP < 25%: phase 3 (enraged final stand)

Scenario: Pet companion fetches item
  Given dog companion + item dropped
  When dog detects item within range:
    Then pet.fetches fires
    And dog brings item to player

Scenario: Perk altar offer
  Given perk altar in scenario
  When player approaches:
    Then progression.perk_offered fires (3 perks shown)
  When player picks:
    Then progression.perk_acquired fires (perk modifier applies)

Scenario: Loot rarity drop
  Given enemy killed
  When loot.dropped fires:
    Then rarity rolled (common 70% / magic 25% / rare 4% / legendary 1% / unique 0.1%)
    And item has rarity-specific border + glow

Scenario: XP + level + perk point
  Given player kills with xp_value=50
  Then progression.xp_gained fires
  And player_xp += 50
  When level threshold crossed: progression.level_up fires (+1 perk point)

Scenario: Achievement unlocked
  Given player kills 10 enemies with grenades
  Then achievement.unlocked fires id="grenade_master"
  And HUD toast notification

Scenario: Inventory grid Tetris
  Given 4x4 backpack with 12 cells used
  When player adds 3x1 sniper:
    Then inventory.item_placed fires (fits)
  When player adds 2x2 medical:
    Then inventory.item_rejected fires (not enough space)

Scenario: Manufacturing recipe
  Given workstation + iron + coal + heat
  When player initiates recipe:
    Then crafting.recipe_invoked fires
    After cooldown: crafting.recipe_completed fires (steel produced)

Scenario: Cooking station
  Given cooking station + raw ingredients
  When player cooks:
    After 30s: cooking.recipe_completed fires
    And food restores caloric_energy + small HP

Scenario: Treasure map + voyage
  Given treasure map dropped
  When player views map:
    Then map UI shows X + clues
  When player digs at X: treasure.discovered fires + rare loot drops

Scenario: Content roster verified at M7 closure
  Given M7 closure pending
  Then 35 weapons + 28 actors + 8 vehicles + 40 base objects + 8 factions + 24 missions + 9 worlds + 17 materials + 12 ores + 22 music + 320 SFX + 60,000 words + 450 codex + 30 achievements
  And all roster validates against content target
```
