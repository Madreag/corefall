# M7.8 — Crafting Tiers & Fabrication Chain

## Status

`active`

## Intent

**M7.8 is the crafting tier ladder + fabrication chain milestone** — the player's progression spine for building weapons / armor / chassis / base modules / power equipment / vehicles / mods from raw materials. After M7.8, the game has a **5-tier crafting ladder** (T0 primitive → T1 industrial → T2 advanced → T3 endgame → T4 exotic), a **deterministic fabrication chain** (raw ore → refined material → component → equipment → assembly), **research-gated recipe unlocks**, **fabrication-station hierarchy** (workbench → fabricator → assembly line → smelter → enrichment reactor → exotic-matter forge), and **survival-friendly crafting UX** (Stationeers/Terraria-inspired) for both campaign and PvE-survival modes.

M7.8 promise: **"every weapon, every armor plate, every turret in your hands was forged from materials you sourced. Tier up by surviving."**

## Player-facing behavior

### 5 crafting tiers — locked launch ladder

| Tier | Theme | Materials needed | Fabrication station | Power requirement | Time per recipe | Unlock condition |
|---|---|---|---|---|---|---|
| **T0 — Primitive** | Stone-age survival | Wood / dirt / stone / hide / bone | Player hands + camp fire | None (or fire heat) | Fast (5-30s) | Start of any PvE-survival scenario; no research |
| **T1 — Industrial** | Early metallurgy + electricity | Iron / copper / coal / wood / silica | Workbench (T0-built) + Smelter (M8.6 mining) | Low (1-2 kW) | Medium (30s-2min) | Research at workbench (10 iron + 5 wood); Stationeers parity |
| **T2 — Advanced** | Steel + composites + reactor power | Steel / aluminum / titanium / electronics / advanced composites | Fabricator (T1-built) + Assembly Line + Nuclear Reactor power | Medium (5-15 kW) | Slow (2-10 min) | Research at fabricator (50 steel + 20 electronics); Factorio-tier progression |
| **T3 — Endgame** | Exotic + reactive + plasma | Plasma cells / superconductor / nanocarbon / reactive armor | Enrichment Reactor + Plasma Forge + Quantum Lab | High (50-200 kW + capacitor burst) | Very slow (10min-2hr) | Defeat M11 boss / acquire artifact / mid-campaign research |
| **T4 — Exotic** | Material-Lab unlocked (M8.5) | Modder-defined + 13 expansion materials | Exotic-Matter Forge (Material Lab integration) | Critical (1 MW+) | Endgame (2hr+) | Material Lab puzzle completion / endgame world unlock (Venus / Vulcan / etc.) |

**Locked launch invariant:** every tier MUST have at least 1 weapon, 1 armor piece, 1 chassis module, 1 tool, 1 power-generator, 1 base-object per tier. Total: 5 × 6 = **30 launch core recipes** per tier × 5 tiers = **150 recipes** at M7.8 close.

### Fabrication chain — raw to assembled

The full chain from ore to finished item:

```text
1. Raw ore (M8.6 mining)
   ↓ [Smelter station + heat from M5.9 atmospherics]
2. Refined material (iron, steel, aluminum, titanium, etc.)
   ↓ [Fabricator + power]
3. Component (electronics chip, motor, sensor, capacitor, armor plate, glass pane)
   ↓ [Assembly Line + IC10 program OR Lua script for complex items]
4. Equipment / weapon / chassis module
   ↓ [Player crafting station or Manufacturing Workbench (M8)]
5. Assembled product (chassis, vehicle, base structure)
```

**Per Stationeers parity:**
- Smelting + refining + alloying are real time + temperature + atmospheric reactions (per M5.9)
- Some recipes require specific atmospheric conditions (high-temp = volcanic; cryogenic = ice world)
- Cooling required for some endgame recipes (Mimas/Europa ambient bonus)
- Failure modes: wrong temperature = wasted material; impure ore = degraded output (rust / scrap)

### Recipe + research system

**Per Stationeers + Factorio + Terraria pattern:**

- Each recipe has: `recipe_id`, `tier`, `inputs` (per-material quantity), `outputs` (per-material quantity + condition), `station_required`, `power_required`, `time_seconds`, `temperature_k` (optional), `atmospheric_requirement` (optional), `research_required`
- Research unlocked via:
  - **Default unlocks**: T0 + basic T1 (no research needed; available at start)
  - **Workbench research**: spend research_points (earned by crafting, exploration, mission completion) on tech tree
  - **Faction unlocks**: per DR-031 faction quartermasters sell recipes
  - **Boss drops**: mini-boss + boss kills can drop rare recipe scrolls
  - **Codex archaeology**: hidden lore items grant recipe knowledge
  - **Material Lab puzzles**: M8.5 modder-authored puzzles unlock expansion recipes

### Code-Name Research Secrecy (AWAW Rule 41.5 — Opt-In)

**Opt-in per server.** Default `server.ron` has `grand_strategy.awaw_rulesets.enable_code_name_research_secrecy=false`. Competitive PvP / MMO recommends ON.

When enabled, factions assign **code names** to research projects. Other factions see allocations + die rolls but NOT what project each code name refers to.

#### Code-name mechanics

When a faction starts a research project:

```rust
pub struct ResearchProject {
    pub project_id: ResearchProjectId,
    pub home_faction: FactionId,
    pub actual_tech_id: TechTreeNodeId,             // PRIVATE — only home faction sees
    pub code_name: String,                          // PUBLIC — visible to all factions
    pub rp_allocated_per_cycle: f32,
    pub die_rolls_this_cycle: Vec<DiceRoll>,        // public; results visible
    pub current_progress_pct: f32,
}

pub struct DiceRoll {
    pub tick: Cycle,
    pub roll_value: u32,                            // 1-20 default; visible to all
    pub modifier_total: i32,                        // visible to all
    pub success: bool,                              // public outcome
}
```

#### Public information

- Code name (player-chosen; e.g. "Project Rattlesnake")
- RP allocated per cycle
- Die roll results per cycle
- Success/failure of each roll
- When project completes (which code name finished)

#### Private information (only home faction sees)

- The actual `TechTreeNodeId` the code name refers to
- Internal modifier breakdown (per-category bonuses)

#### Deduction mechanics

Other factions can try to DEDUCE what code name refers to:
- Pattern: if home faction always rolls +3 modifier on "Rattlesnake", probably a category that has +3 inherent bonus for that race
- Time pattern: T4 atomic research takes 1+ year; if "Rattlesnake" has been ongoing for 2 years, probably T4
- Resource pattern: high RP investment per cycle suggests T3-T4 tier
- Combined: deduction is uncertain but tactical

#### Decoy code names (advanced)

Players can DELIBERATELY use misleading code names:
- Name "Project Cookbook" for atomic weapons → bluff
- Name "Project Hephaestus" for plant cultivation → distract
- Counter-deduction: AI factions get smarter at decoy detection at higher difficulty

#### Codebreaking interaction (per M7.1.5)

If M7.1.5 codebreaking enabled + faction has Level 5 codebreaking:
- Player can REVEAL one enemy code name per cycle
- Cost: 1 covert op + 200 BP
- Success probability based on codebreaking level + target counter-intel

#### Replay events

- `research.code_name_assigned { project_id, faction_id, code_name, actual_tech: PRIVATE }`
- `research.die_roll_made { project_id, code_name (public), roll_value, modifier, success: PUBLIC }`
- `research.code_name_revealed { code_name, actual_tech, revealed_by: codebreaking|completion }`

### Power-coupled crafting

Per M7.6 integration:
- Fabricators consume power per recipe; brown-out STOPS crafting (in-progress recipe paused; resumes when power restored)
- Brown-out risk visible in recipe card: "Caution: 5 kW draw may trigger brown-out; current grid has 3 kW headroom"
- Player can queue recipes during off-peak hours (overnight when no combat)
- IC10 chip can pause / resume crafting based on grid state

### Survival-friendly progression curve (DR-023 onboarding-aligned)

T0 → T1 → T2 → T3 → T4 escalation pacing:

- **First 30 minutes (T0)**: player gathers wood + stone; builds camp fire; crafts spear; survives night
- **Hours 1-3 (T1)**: player builds workbench; mines iron; builds smelter; crafts rifle + iron armor + first solar panel
- **Hours 3-10 (T2)**: player builds fabricator; produces electronics; builds reactor; powered armor + advanced weapons
- **Hours 10-50 (T3)**: player explores other worlds; acquires titanium + plasma cells; builds mech + plasma weapons; defeats world bosses
- **Hours 50+ (T4)**: Material Lab puzzles; exotic materials; endgame combinations

### Repair + modification system

Per Cortex Command + Stationeers parity:

- Damaged items can be **repaired** at their fabrication station (consumes some materials; max repairs limited)
- Items can be **modified** with attachments (M2.2A weapon attachments + chassis modifiers M5 + 30+ Noita-style modifiers M5)
- Modifications are reversible (player can detach + reattach)
- Salvage: destroyed items can be broken down into partial materials at salvage station (75% material recovery)

### Deep simulation — Stationeers/Factorio/Terraria-grade fabrication chain

#### Material purity + quality + grading system

Every raw material has a **purity** value (0.0-1.0) that propagates through the fabrication chain:

```rust
pub struct MaterialStack {
    pub material_id: MaterialId,
    pub quantity_units: f32,
    pub purity_pct: f32,                    // 0.0-1.0; surface ore = 0.3-0.5; deep ore = 0.7-0.95
    pub temperature_k: f32,                 // current; affects some recipes
    pub source_world: Option<WorldId>,      // for traceability
    pub mined_at_tick: u64,
    pub package_provenance: PackageRef,     // mod / vanilla / faction
}
```

**Purity affects output quality** (per Stationeers parity):

| Input purity | Smelting output | Notes |
|---|---|---|
| < 0.3 | 50% material + 50% slag | Wasteful; player learns to avoid surface ore |
| 0.3 - 0.5 | 75% material + 25% slag | Industrial baseline |
| 0.5 - 0.7 | 90% material + 10% slag | High-grade ore |
| 0.7 - 0.95 | 99% material + impurities | Deep crust ore |
| > 0.95 | 99.9% material | Endgame T4 exotic |

Slag is itself a craftable input (can be used in low-tier recipes; useful for crash-building).

#### Temperature + pressure recipe requirements (Stationeers parity)

Some recipes require specific environmental conditions:

| Recipe | Temperature requirement | Atmospheric requirement | Notes |
|---|---|---|---|
| Smelt iron → steel | 1538°C+ | Any atmosphere (or vacuum + sealed crucible) | Standard smelting |
| Manufacture electronics | 20-30°C | Inert atmosphere (N2 or Ar) preferred; humidity < 30% | Sensitive to oxidation |
| Forge plasma weapon | 8000°C+ (plasma) | Vacuum OR sealed plasma chamber | Endgame |
| Cure polymer | 80-120°C | Dry atmosphere | Drying time real-time |
| Refine uranium | Heated centrifuge; 800°C | Sealed atmosphere; radiation shielding | T3 |
| Forge superconductor | < -200°C (cryogenic) | Vacuum + cryogenic coolant flow | Mimas/Europa native bonus |
| Brew chemicals | 20-200°C | Sealed container | M5.6 + alchemy table |
| Cook food | 60-300°C | Atmosphere | Per M7 cooking |
| Grow plants | 18-25°C | O2 + CO2 cycle + humidity 60% | Per M7 plant growing |
| Cure leather | 20°C; 7 days in-game time | Salt tank; dry | T0 primitive |

Failure when conditions wrong: recipe fails OR produces degraded output OR wastes materials.

#### Multi-step recipe chains (Factorio-style)

Endgame items require chained recipe steps:

**Example: Plasma Rifle (T3)** — full chain:

```text
1. Mine raw iron + raw copper + raw uranium    [M8.6 mining]
2. Smelt iron → steel                            [Smelter; 1538°C; 30s × per unit]
3. Smelt copper → pure copper                    [Smelter; 1085°C; 20s]
4. Manufacture electronics chip                   [Fabricator; 25°C; 60s; needs steel + pure copper + plastic]
5. Refine uranium → plasma cell                   [Enrichment Reactor; 800°C; 5 min × per cell]
6. Forge capacitor                                 [Plasma Forge; 6000°C; 2 min; needs steel + electronics]
7. Assemble plasma rifle                          [Assembly Line; 25°C; 10 min; needs steel + electronics + plasma_cell + capacitor]
8. Test fire (optional)                           [Test range; consumes 1 plasma_cell]
```

Each step is its own recipe; player can automate via conveyor belts (per M8.6) routing inputs/outputs between stations.

#### Production rate optimization (Factorio assembly lines)

Per Stationeers + Factorio:

- **Single recipe** at a station: time × multiplier × purity
- **Module slots** in stations (T2+): productivity modules increase yield (+20-50% but more power); speed modules reduce time (+50%); efficiency modules reduce power consumption (-50%)
- **Crafting speed multiplier** stacks (e.g. 4 productivity modules at T3 fabricator = 4× output)
- **Power scaling**: faster crafting = more power consumption; player must balance grid

UI shows station's effective rate + power draw per recipe.

#### Recipe difficulty tiers + failure modes

Per Terraria parity (recipes are not always successful):

- **T0-T1**: 100% success rate; deterministic
- **T2**: 95% success; 5% failure produces scrap + partial material loss
- **T3**: 85% success; 15% failure; failure can damage station
- **T4**: 70% success; 30% failure; failure can cascade (e.g. plasma forge explosion)

**Failure mode events:**
- `craft.recipe_failed { recipe_id, reason: 'wrong_temp'|'wrong_atm'|'station_damaged'|'random_failure', materials_lost, station_damage }`
- `craft.station_damaged { station_id, damage_pct, repair_cost }`
