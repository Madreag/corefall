# M14I — Long-Term Consequences + Scars + Phantom Limbs + Aging + Veteran Persistence Functional Layer

## Status

`active`

## Intent

Promote scars from M45A's cosmetic layer + M41's persistent veteran roster into a **functional long-term-consequence system**: per-veteran scar timeline with functional debuff (reduced max-resource, reduced limb-function, reduced sensory range), phantom limb psychological condition, memory loss per concussion accumulation, chronic conditions, biological aging clock with per-cycle age-degradation curve, prosthetic replacement loop, and veteran-retirement / death-of-old-age terminal state.

## Canonical ownership

Canonical owner of functional long-term-consequence persistence + biological aging + prosthetic loop. M45A scar visuals consume M14I scar records. M41 veteran dossier consumes M14I scar timeline + aging clock. M48C pilot dossier renders M14I narrative.

## Player-facing behavior

### Scar timeline

Every wound that closes via sutures / cauterize / surgery converts to a `ScarRecord` on the actor:

```rust
pub struct ScarRecord {
    pub scar_id: ScarId,
    pub source_wound_kind: WoundKind,
    pub zone: ZoneId,
    pub severity_at_close: f32,
    pub closure_method: TreatmentKind,
    pub tick_acquired: TickId,
    pub functional_debuff: FunctionalDebuff,
    pub cosmetic_decal_id: VisualDecalId,
    pub narrative_context: Option<NarrativeEventId>,
}

pub enum FunctionalDebuff {
    None,
    ReducedMaxBlood { ml_lost: f32 },
    ReducedZoneStrength { zone: ZoneId, pct: f32 },
    ReducedAimAccuracy { pct: f32 },
    ReducedMoveSpeed { pct: f32 },
    SensoryLoss { sense: SenseKind, pct: f32 },
    ChronicPainBaseline { pain_points: f32 },
    Limp,
    PhantomLimbRisk { chance_per_panic: f32 },
}
```

### Functional debuff matrix

Each `WoundKind` × closure_method × severity-at-close maps to a `FunctionalDebuff`. Example: `LacerationSevere` closed by `sutures_v1` at severity 0.8 → `ReducedZoneStrength{zone, 0.05}` (−5% local strength forever). `Burn3rd` closed by `cauterize_v1` at severity 0.9 → `ReducedZoneStrength{zone, 0.15}` + `ChronicPainBaseline{2}`.

### Phantom limb (M16C consumer)

When a limb is severed via M14 `attachable.detached` AND the actor survives, the actor gains `PhantomLimb` trait. The trait triggers per-week panic-attack rolls (M16C consumer). Resolution: prosthetic installation reduces panic frequency by 75% but does not eliminate.

### Memory loss

Each Concussion that exceeds the KO threshold increments `concussion_count`. Above `memory_loss_threshold` (5 KOs default), the actor gains `MemoryLossMinor`; above 10, `MemoryLossMajor`.

### Chronic conditions

From M16C lifecycle: `chronic_<condition>` traits map to per-tick baseline debuffs. `chronic_depression` → Move 0.9× + Refuse non-essential orders chance 10%. `chronic_pain` → Pain baseline 4 pts permanently.

### Biological aging clock

Every actor with `origin ∈ {human, android_organic_side, powered_organic, heavy_biomech}` has `age_in_game_years: f32`. Per in-game year passing:
- `caloric_max` decreases by configured rate (humans most; biomech least).
- `max_speed` decreases by aging curve.
- `wound_heal_rate` decreases.
- At age `retirement_age` (default 55 for human), the AI bot prefers non-combat assignments.
- At age `terminal_age` (default 80 for human), per-week mortality roll fires.
- Robots and crystallines do NOT age biologically; instead `chassis_wear_pct` accumulates.

### Prosthetic replacement loop

- **Procure** — craft (M32) OR salvage (M30) OR purchase (M36).
- **Install** — surgery (M14H Phase 1–4) + medic_t2 skill + dedicated surgery table; 60s sequence.
- **Maintain** — per-week wear check; below threshold, prosthetic malfunctions; routine maintenance restores.
- **Tune** — prosthetics can be upgraded (T1 → T2 → T3); each tier reduces the FunctionalDebuff multiplier.
- **Prosthetic catalog (10 launch items):** prosthetic_leg_t1, prosthetic_arm_t1, prosthetic_eye_t1, prosthetic_ear_t1, prosthetic_tooth_full_set, cybernetic_leg_t2, cybernetic_arm_t2, cybernetic_eye_t2_thermal, cybernetic_lungs, cybernetic_kidneys.
- Per-origin compatibility: only `human / android / powered_organic` accept biological prosthetics.

### Veteran-retirement / non-combat ending

When an actor reaches `retirement_age + 5`, the M41 veteran roster offers a "Retire" action. Retired veterans become advisor NPCs (M26) with reduced combat availability but full narrative role.

### Long-term radiation → cancer (M16B consumer)

M17 cumulative dose feeds the M16B cancer.lifecycle entry. M14I owns the per-veteran tracking + UI surface.

## Acceptance criteria

```gherkin
Scenario: ScarRecord acquired on closure
  Given a LacerationSevere closed via sutures_v1 at severity 0.8
  When treatment.completed fires
  Then scar.acquired fires with kind=LacerationSevere zone=arm_left severity=0.8
  And the actor's scar_list gains the record
  And FunctionalDebuff::ReducedZoneStrength{arm_left, 0.05} is applied passively

Scenario: Phantom limb after limb severance
  Given an actor's leg_right severed via M14 attachable.detached
  And the actor survives DYING → recovery
  When the post-survival pass runs
  Then phantom_limb.acquired fires
  When 1 in-game week elapses:
    Then phantom_limb.panic_attack fires
    And M16C psych.panic_attack lifecycle activates

Scenario: Memory loss after multiple concussions
  Given an actor with concussion_count=4
  When the 5th concussion triggers
  Then memory_loss.minor_acquired fires
  When concussion_count reaches 10:
    Then memory_loss.major_acquired fires

Scenario: Biological aging degrades stats per year
  Given a human actor at age 30 with caloric_max=100
  When 10 in-game years elapse
  Then age.year_advanced fires 10×
  And caloric_max decreases to 95
  When the actor reaches age 55:
    Then age.retirement_offered fires

Scenario: Veteran death of old age
  Given a human actor at age 81
  When the per-week terminal-roll fires + passes
  Then age.terminal_roll fires with outcome=death
  And actor.actor_status_changed STABLE → DEAD with cause="old_age"

Scenario: Prosthetic restores limb function
  Given an actor with a severed leg_right + phantom_limb trait + a prosthetic_leg_t1 in inventory
  When act.player.install_prosthetic fires + 60s surgery completes:
    Then prosthetic.installed fires
    And the actor's leg_right ZoneState transitions Severed → Prosthetic
    And max_speed restored to 70%
    And phantom_limb panic-roll multiplier × 0.25

Scenario: Prosthetic maintenance loop
  Given a cybernetic_leg_t2 installed 7 in-game days ago
  When wear_pct > 0.6:
    Then prosthetic.malfunctioned fires
  When act.player.maintain_prosthetic fires:
    Then prosthetic.maintained fires
    And wear_pct resets to 0

Scenario: Per-origin aging differs
  Given a heavy_biomech actor at age 30
  When 10 in-game years elapse
  Then caloric_max decreases by only 0.2%/yr × 10
  Given a robot actor: NO age.year_advanced fires
  And instead chassis_wear_pct accumulates

Scenario: Chronic condition baseline debuff
  Given an actor with trait="chronic_depression"
  When the per-tick passive pass runs
  Then move_speed_multiplier is set to 0.9×
  And per-AI-tick the "Refuse non-essential order" roll fires (10% chance)

Scenario: Long-term radiation → cancer hand-off
  Given a human actor with cumulative_dose > cancer_threshold
  When the per-cycle cancer-roll fires
  Then disease.exposed fires (vector=long_term_radiation) via M16B

Scenario: Determinism — identical scar timelines across sessions
  Given identical seed + identical wound history
  When 100 in-game days elapse
  Then identical scar_list per actor
  And identical functional_debuff applications
  And identical aging-stat curves
```
