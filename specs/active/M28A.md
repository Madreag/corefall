# M28A — Base Build Mode UX

## Status

`active`

## Intent

**M28A is the base build mode UX milestone** — full UX for base construction: build palette (categorized + favorites + search), placement preview (ghost + cost + requirements + collision check), rotation + mirror + grid snap, room categorization with completion bonuses (per ONI), blueprint mode (save/load designs), power + atmospheric overlay integration, demolish + repair modes, multi-player build permissions.

**Why after M28 (base atmospherics):** by M28 close, the base building gameplay (60+ base modules / atmospheric kernel / room state HUD) is complete. M28A polishes the build mode UX — the most-used screen in PvE survival.

**Why this milestone exists:** Stationeers + Rimworld + ONI + Factorio all live and die by base build UX. Players spend HOURS building bases. Without M28A, base building is functional but tedious. With M28A, base building is intuitive + satisfying + creative.

M28A promise: **"placing a wall, routing a pipe, building a fabricator, or designing a 200-module base feels as polished as Stationeers / Factorio / ONI; per-tier perf 60Hz on Steam Deck even with 500-module bases; multiplayer co-build works seamlessly; blueprint mode lets players share base designs."**

## Player-facing behavior

### Build mode activation

- Press [B] (remappable) to enter build mode (per M11 pause/slowdown integration)
- HUD overlay: build palette + per-module preview + cost feedback
- Per-mode toggle: Build / Demolish / Repair / Wire / Atmospheric / Blueprint
- Press [B] again to exit; player returns to default HUD

### Build palette UX

Categorized + searchable + favorites:

- **Categories** (per M25 + M28 + M29 + M32):
  - Walls + Floors + Doors
  - Power (per M29: 8 generators + 6 cable tiers + storage + turrets)
  - Atmospherics (per M28 + M19: pumps + valves + regulators + filters + condensers + airlocks + vents)
  - Crafting (per M32: 8 fabrication stations)
  - Storage (cargo bays + cabinets + safes)
  - Defense (turrets + traps + sensors + barricades)
  - Mining + Refining (per M30: extractors + refiners)
  - Habitation (beds + chairs + tables + decoratives)
  - Lighting (per-light-source)
  - Hydroponics (per M28: algae terrarium + plant beds + grow lamps)
  - Industry (per M32 + M35: smelter + enrichment reactor)
  - Critter ranching (per M28 ONI parity: hatch / pacu / slickster pens)
- **Per-category sub-categories** — Walls → Iron / Concrete / Insulite / Reinforced / Decorative
- **Favorites** — star a module; pinned to top of palette
- **Recent** — last 10 placed modules
- **Search box** — keyword + tag (e.g. "pump" finds all pump variants)
- **Tier filter** — T0 / T1 / T2 / T3 / T4 per M32; greys-out unavailable tiers
- **Per-module icon** — M9A SVG → M32A Tier 2 polished
- **Per-module cost preview** — materials + research-required + power
- **Per-module description** — flavor text from M25A bible

### Placement preview (ghost)

When player selects module:
- **Ghost rendering** at cursor — translucent module preview (alpha 50%)
- **Per-placement validation** — green = valid; yellow = warning (low power; near hazard); red = invalid (collision; missing prereq)
- **Per-grid snap** — modules snap to grid; per-module footprint visible
- **Rotation** — Press [R] rotates 90°; modules with directional intent (pump-flow / pipe-junction) show direction arrow
- **Mirror** — Press [M] mirrors X-axis (for symmetric base designs)
- **Per-placement collision check** — overlaps with existing modules / terrain blocked / spawn zones forbidden
- **Per-placement power preview** — wires auto-route from nearest power source; M29 grid validity check; voltage class verified
- **Per-placement atmospheric preview** — M28 + M19 integration shows expected room atmosphere change
- **Per-placement cost feedback** — "5 iron + 2 plastic + 60s build time + 1 kW continuous power" (red highlights missing materials)
- **Multi-place mode** — Shift+drag places N modules in a line/row
- **Blueprint paste mode** — paste pre-saved blueprint at cursor

### Rotation + mirror + grid snap

- **Grid snap** — default 1-tile grid; Shift+G toggles half-tile snap
- **Rotation** — [R] rotates 90° CW; Shift+R rotates 90° CCW
- **Mirror** — [M] mirrors X-axis (per-module respecting directional flow)
- **Free placement mode** — Shift+F toggles off-grid placement (rare; for decoratives)
- **Per-module directional indicator** — pumps show flow direction; doors show open-direction; vents show direction

### Room categorization (per ONI)

- **Auto-detect rooms** — closed-volume detection per M19 atmospheric kernel
- **Per-room categorization** — system detects "Bedroom" / "Kitchen" / "Bathroom" / "Workshop" / "Power Station" / "Atmospherics" / "Hydroponics" / "Reactor Room" / "Mech Bay" based on contents
- **Per-room completion bonus** — ONI-style; fully-equipped Bedroom gives NPC sleep bonus; fully-equipped Workshop gives crafting bonus
- **Room status overlay** — per-room icon visible in HUD when entered
- **Per-room atmospheric state** — M28 integration; current O2/CO2/Vol/temp/pressure
- **Per-room power state** — M29 integration; current load / capacity
- **Per-room recommended modules** — palette suggests missing modules for completion

### Blueprint mode

- **Save blueprint** — select region (multi-select per M27A); save as in-memory `Blueprint` struct (canonical persistent `.cfbp` / `.blueprint.ron` format + disk export + Steam Workshop sharing owned by **M28F**)
- **Load blueprint** — paste at cursor; cost preview shows total resources needed
- **Per-blueprint metadata** — title + description + author + version + dependencies (mods + research tier) — schema canonical at **M28F**
- **Blueprint sharing** — owned canonically by **M28F** (`cf-blueprints` crate + `cf-net::workshop_client`); M28A only exposes the in-base capture + paste UX
- **Blueprint conflict detection** — paste location conflicts with existing modules; show diff UI
- **Blueprint version control** — per-blueprint versions tracked; older versions retrievable
- **Per-server blueprint library** — server admin can curate per-server blueprints

### Power + atmospheric overlay integration

Per M29 + M28:

- **Power overlay (F5)** — Factorio-style topology; cables tinted by voltage; live load graph
- **Atmospheric overlay (F4)** — per-room state colors; gas composition visible
- **Wire routing preview** — when placing power-consuming module, wires auto-route + ghost-render to nearest power source; player can manually re-route
- **Per-cable amperage warning** — yellow if near amperage cap; red if over (per M29)
- **Per-pipe flow warning** — backflow indicators (per M19)
- **Insulation visualization** — per-tile thermal conductivity overlay (per M28 ONI parity)

### Demolish + repair modes

- **Demolish mode** — click module to demolish; recovers 75% materials per M27 salvage rate
- **Bulk demolish** — drag-rectangle selects multiple modules; bulk demolish + recovery preview
- **Repair mode** — damaged modules highlighted; click repairs; uses M27 modification system
- **Per-damage state UI** — Pristine / Scratched / Cracked / Critical / Destroyed (per M9 5-tier signature)
- **Auto-repair drone** — assign repair drone (per M13 drone allies) to auto-repair queue
- **Demolish confirmation** — destructive action requires hold-to-confirm per M11

### Quick-bar for common modules

- **Hotbar 1-8** during build mode (per M11 hotbar integration)
- **Default bindings** — Wall / Floor / Door / Pump / Solar Panel / Battery / Turret / Workbench
- **Per-player customizable** — drag any palette module to hotbar slot
- **Per-platform** — Steam Deck D-pad shortcuts to hotbar

### Multi-player build permissions (M40/M41 integration)

- **Per-player build permissions** — Admin / Builder / Viewer per server config
- **Per-base permissions** — only base owner can demolish; co-op players can place if Builder permission
- **Build history** — per-module: who placed + when + cost paid; for audit per M36 anti-cheat
- **Anti-grief** — Demolish requires consensus in co-op (server admin opt-in)

### Steam Deck + controller-first layout

- Build palette as radial menu when controller detected (per M11 pie menu integration)
- Hotbar as D-pad shortcuts
- Per-module preview rotated via controller stick
- Build confirm via South button; cancel via East button

## Notes for the implementer

### Architecture rules

- **Build mode is a sim-affecting overlay** — placement modifies world state per replay determinism
- **Ghost preview is cosmetic** — no sim side-effects until placement confirmed
- **Per-module placement event** — `build.module_placed { actor_id, module_id, position, rotation, cost_paid }` for replay
- **Per-blueprint hash** — deterministic blueprint replay per seed

### Decision-record alignment

- **DR-046 (player-facing surfaces)**: M28A is canonical build mode UX
- **DR-027 (campaign + base)**: base building foundation extends to M28A
- **DR-029 (save model)**: base blueprints persist across sessions

### Pitfalls

- **Ghost-preview perf with 500 modules**: cull off-screen ghost rendering
- **Auto-room detection accuracy**: flood-fill closed-volume per M19; cache results
- **Blueprint conflict resolution**: diff UI on paste; merge or replace per player choice
- **Multi-player race conditions on placement**: server-authoritative placement order per M36
