# M23C — Per-Biome Wildlife Catalog + Behavior + Combat Stats + Drop Tables + Food Chain + Migration

## Status

`active`

## Intent

Ship the wild-fauna catalog that fills every populated biome on every populated world with species the player can hunt, be hunted by, eat, skin, get bitten by, get infected by, and watch migrate seasonally. Wildlife is **WILD**: not colony-tameable (that is M19I critters), not faction-allied (that is M26/M48), not military-grade combatants (that is M23 archetypes) — wildlife is the third bucket: persistent neutral / hostile / passive fauna that lives in biomes per a per-world catalog, with per-actor combat stats, drop tables, predator-prey food chains, per-biome population caps, seasonal migration, and per-species disease vectors. After M23C, an Earth forest has wolves stalking deer that flee a hunting bear, a Mars dust-flat has dust-crawlers ambushing the player's resupply convoy, a Vulcan magma stream has lava-trout that drop fire-meat, and a Europa ice cavern has cryo-lobsters that scavenge wolf-kill leftovers.

M23C promise: **"every populated biome on every populated world has its own wildlife table; hunting deer drops venison + hide; wolves drop rabies if they bite; the food chain runs even when the player isn't watching."**

- `cf-ai::wildlife_behavior` (passive / wary / territorial / pack-hunter / ambush-predator / migratory behavior trees; consumes M22B pathfinding + reads M23 archetype interface but does NOT use it) — **owned by M23C** (NEW).

## Player-facing behavior

- **26 wildlife SKUs across 7 populated worlds** — Earth (10), Mars (3), Mimas (2), Europa (3), Vulcan (3), Venus (3), Belt (2). Moon / Phobos / Deimos / Orbital / Sol-zone are explicitly stripped (no native fauna; matches their atmospheric / gravity profile).
- **6 behavior archetypes** — `passive_grazer` (flees on threat), `wary_scavenger` (flees when within sight-range; opportunistic feeder), `territorial_apex` (charges within territory radius), `pack_hunter` (coordinates with same-species packmates; uses M22B for flanking), `ambush_predator` (idle until prey within strike-range; bursts forward), `migratory_swarm` (flock-leader + followers; seasonal route).
- **Per-actor combat stats from M14** — every wildlife SKU declares `max_hp`, `bite_damage`, `bite_chance_per_strike`, `melee_reach_m`, `armor_natural` (chitin / hide / fur), `attack_speed_per_sec`, `flee_threshold_hp_pct`. Stat block is loaded from `content/wildlife/<species_id>.ron` and consumed by `cf-actor::sim` exactly the way humanoid combat stats are; no special wildlife-vs-actor code path.
- **Drop tables via M27B** — each species has a `loot_table_id` (`wildlife_wolf_drops`, `wildlife_bear_drops`, etc.) registered with M27B. On death, the standard M27B weighted-pool roll runs: meat / hide / bone / sinew / venom-gland / antler / fur / chitin / feather / talon / scale. Player skinning UX is M27B's existing per-corpse loot panel; no new UX surface.
- **Food chain runs continuously (even off-screen)** — `cf-environment::food_chain` declares per-biome predator → prey edges (wolf → deer; bear → elk / deer; hawk → hare / fish; spider → insect / hare; mars_dust_crawler → sand_vermin; vulcan_magma_skitter → heat_locust). Every 60s sim tick, each unsleeping predator within prey-search-radius rolls a predation attempt; success drops prey HP + reduces prey population in that biome's wildlife table. Off-screen predation uses a cheap statistical model (per-biome population delta) instead of per-actor sim — replay-deterministic via biome-seeded RNG.
- **Per-biome population caps** — each biome declares `max_population_per_species: HashMap<SpeciesId, u32>` (e.g. earth_forest: 8 wolves, 24 deer, 4 bears, 60 small-fauna). World gen seeds initial population per cap; predation + births + player kills + migration adjust it. When population drops to zero in a biome, that species is locally extinct until migration repopulates from a neighboring biome (or never, if no neighbor has it).
- **Seasonal migration (M31 day/night + weather carry)** — migratory species (`earth_hawk`, `earth_elk`, `mars_scavenger_flock`, `vulcan_heat_locust`) declare a `migration_route: Vec<BiomeId>` and a `season_trigger` (e.g. `winter_onset`, `summer_solstice`, `mars_dust_storm_global`). When the world clock crosses the trigger, the flock-leader actor recomputes target biome via M22B region-grain pathfinding; followers track the leader. Off-screen migration: population subtracts from source biome + adds to destination biome on the tick the trigger fires; no per-actor pathing required.
- **Per-species disease vectors (M16 carry)** — `wolf_bite` rolls `rabies` (M16 affliction) at 5% per bite that breaks skin; `spider_bite` injects `spider_venom_necrosis` at 80% per successful envenomation; `boar_gore` rolls `trichinosis` at 15% if the player eats boar meat raw; `mars_dust_crawler_bite` rolls `mars_dust_rot` at 25%; `venus_sulfur_leech_attach` rolls `blood_parasite` continuously until detached; `mimas_null_grub_burrow` rolls `null_rot` at 10% per minute of contact. Disease firing emits the standard M16 `affliction.applied` event; M23C does not introduce new affliction types — it wires existing M16 afflictions to wildlife bite / claw / sting / attach events.
- **Predator-versus-actor combat** — when a wildlife predator detects a player or NPC actor in its threat range, it engages using its species behavior (pack-hunter wolves flank via M22B; territorial bears charge directly; ambush spiders strike from cover). Wildlife AI does NOT use M23 military archetypes (no DoctrineString, no LLM mind, no formation-slot pather); it uses M22B + simple per-species BT. Reason labels are species-tagged: `wildlife_wolf_flank_left`, `wildlife_bear_charge`, `wildlife_spider_ambush_strike`.
- **Hunting affordance for the player** — player kills + skins + butchers per the existing M27B corpse-loot panel; M14 melee + ranged combat math applies; no new hunting UX. Tracking (footprints, blood trails) is M22C scope, not here.
- **Replay-deterministic** — wildlife AI ticks on M8A's `par_iter` scheduler in stable actor-id order; population deltas + predation rolls + migration triggers use a per-biome seeded RNG (`biome_id + tick_n`), never `thread_rng()`. Every population change, predation event, migration arrival, and disease firing emits a typed `wildlife.*` event; replays of "the day the wolf pack found us" reproduce bit-exact.

```gherkin
Scenario: Earth forest world gen seeds the locked wildlife table
  Given a freshly generated earth_forest biome at world load with seed 42
  When the wildlife_seeding pass runs
  Then population_registry reports 8 wolves, 24 deer, 4 bears, 12 elk, 6 fox, 12 hawk, 30 hare, 10 boar, 40 spider, 60 fish in that biome
  And wildlife.wildlife_spawned fires once per actor with species_id + biome_id + pos
  And no Earth species spawn in moon_regolith / phobos_surface / deimos_surface / orbital_station / sol_zone_corona biomes

Scenario: Wolf pack flanks and hunts a lone deer
  Given an earth_forest biome with 3 wolves (pack) within 30 m of 1 deer
  And the deer is at full HP
  When the wildlife AI ticks for 10 sim seconds
  Then at least 2 wolves request M22B paths with distinct approach angles (flank left + flank right)
  And the pack-leader wolf engages the deer in melee
  And the deer flees toward the nearest biome edge (passive_grazer flee threshold reached at 80% HP)
  And reason labels include wildlife_wolf_pack_flank_left + wildlife_wolf_pack_flank_right + wildlife_wolf_pack_engage

Scenario: Bear territorial charge against player
  Given the player walks within 8 m of an earth_bear at full HP
  When the wildlife AI ticks
  Then the bear charges the player directly via M22B tile-grain pathfinding
  And the bear's reason label is wildlife_bear_charge
  And on hit, M14 melee math applies 35 damage to the player
  And a 10% roll fires affliction.applied with affliction_id="bear_claw_infection" via the existing M16 pipeline

Scenario: Spider ambushes player and injects venom
  Given an earth_spider_recluse hidden in cover and the player walks within 0.4 m
  When the strike trigger fires
  Then the spider executes one ambush strike (wildlife_spider_ambush_strike reason label)
  And on hit, 4 damage applies
  And an 80% roll fires affliction.applied with affliction_id="spider_venom_necrosis"
  And the spider then retreats to nearest cover tile

Scenario: Player kills earth_wolf and skinning drops follow M27B table
```

## Out of scope

- Colony-tameable critters (Hatch / Slickster / Puft / Pip / Pacu / Drecko / Shine Bug) — M19I owns these. M23C wildlife is **not** tameable; player cannot assign it to a pasture.
- Wildlife-faction diplomacy / relations — M26 / M48 own faction relations. Wildlife is a "neutral" actor class without diplomatic state.
- Military / faction-bot AI archetypes (DoctrineString / LLM-mind / formation-slot pather) — M23 / M23B / M7B own these. Wildlife uses simpler per-species BT.
- Cover-finder for wildlife — M22B's cover-finder is military-bot oriented; wildlife uses raw M22B tile-grain pathing without cover-scoring.
- Footprint tracking / blood-trail hunting UX — M22C scope, not here.
- New affliction types — M16 owns the affliction catalog. M23C wires existing afflictions (rabies / spider_venom_necrosis / trichinosis / tularemia / mars_dust_rot / null_rot / bear_claw_infection / blood_parasite / thermal_burn / venus_acid_burn) to wildlife events; if any of these is missing in M16, M23C lists it as a blocker, not as new work.
- Per-actor wildlife perception sim (vision cones / hearing) — uses M22's existing perception envelope; no new perception model.
- Wildlife breeding mechanics with genetics / morphs — M19I owns morph logic for critters. Wildlife births here are simple population deltas, not genome sim.
- Wildlife taxidermy / trophy-display items — possible M27 / M28 extension; not in M23C.
- Wildlife-vs-vehicle collision damage — M14 + M44 own vehicle collision; wildlife is treated as a soft-body actor by those systems.

## Notes for the implementer

- **Wildlife is NOT critter.** `cf-actor::wildlife` is a separate actor kind from `cf-actor::critter` (M19I). Do not collapse them. Critters live in pastures, are groomed, lay eggs, and produce industrial outputs; wildlife lives in biomes, has territories, and produces meat/hide/disease.
- **Off-screen predation must be statistical.** Per-actor sim of every wolf hunting every deer in every biome at all times is a non-starter for perf. Use a per-biome population delta model: every 60s, for each predator → prey edge, roll a Poisson-distributed kill count from `predator_pop × predation_rate × prey_density`. Drop the result into `population_registry`. On-screen biomes use full per-actor sim; off-screen ones use the statistical shortcut. The replay event `wildlife.wildlife_predation` is emitted in both paths so replays are still deterministic.
- **Use biome-seeded RNG, NOT `thread_rng()`.** The sim crate ban on `thread_rng()` applies here. Seed every roll with `(biome_id, tick_n, species_id)` or similar deterministic tuple so two replays of the same seed produce the same predation history.
- **Wildlife actor count budget.** Across all on-screen biomes, target ≤200 wildlife actors loaded simultaneously. Use M22B sleeping-AI gate aggressively: wildlife outside the player's perception envelope sleeps; sleeping wildlife consumes only the off-screen statistical model, not per-tick BT.
- **Disease wiring is one-line per species.** Each wildlife_kinds/<species>.rs file's `on_bite_hit_actor()` hook emits `m16::roll_affliction(target, AfflictionId::Rabies, 0.05)` (or equivalent for that species). Do not introduce a new disease-resolution pipeline; reuse M16.
- **Migration off-screen.** When a flock-leader is in an unloaded biome, do not pretend-pathfind for it. Just record `(source_biome, dest_biome, depart_tick, arrive_tick)`; on arrival tick, subtract from source population + add to destination. When the player loads the destination biome after arrival, the flock spawns as live actors. M22B region-grain path is only computed when at least one flock-member is in a loaded biome.
- **Stripped worlds matter.** Moon / Phobos / Deimos / Orbital / Sol-zone explicitly have `max_population_per_species: {}`. Do not "helpfully" add fauna to them — they are vacuum / airless / artificial by design and the empty wildlife tables are a feature, not a gap.
- **Loot table conventions.** Wildlife loot tables MUST follow M27B's existing `LootTable` schema literally (`id`, `rolls_per_kill`, `weighted_pool`, `luck_sensitivity`, etc.). Do not invent a wildlife-specific schema variant.
- **Replay determinism is non-negotiable.** Wildlife introduces a lot of new randomness (predation rolls, birth rolls, migration timing, disease rolls). Every single random source must be seeded from sim state, never from wallclock or `thread_rng`. Run a 2× replay-equivalence test as part of acceptance.
- **AI archetypes are per-species, not per-actor.** A wolf actor's behavior tree is shared across all wolves; only the per-actor state (target, last-known-prey-pos, pack-bond) differs. Keep the BT modules small (50-100 LOC); push species variation into `content/wildlife/<species>.ron` stat blocks.
