# M27B — Loot Table Registry + Per-Enemy + Per-Container + Per-Location Drops

## Status

`active`

## Intent

Loot pipeline canonicalization: per-enemy / per-container / per-mission / per-location / per-difficulty loot tables. Locks the LootTable schema (a weighted pool of `{ item_id, drop_chance, min_count, max_count, rarity_override }`) + per-actor luck stat + conditional drops + drop deduplication.

## Canonical ownership

Canonical owner of loot tables, drop rolls, per-actor luck, and conditional drops. M27 provides rarity tiers + affixes; M27B specifies WHAT drops WHERE. M27C handles identification UX.

## Player-facing behavior

- **Per-enemy loot table**: every enemy archetype declares `loot_table_id` (`enemy_grunt_drops`, `enemy_heavy_drops`, `enemy_sniper_drops`). On kill, table rolls + emits `loot.dropped` events.
- **Per-container loot table**: every chest / crate / vault declares `container_loot_table_id`.
- **Per-mission scripted loot**: M25 mission director places `scripted_loot { mission_id, step_id, drop }` overrides.
- **Per-location loot pool**: biome / world / chunk-tag declares `loot_pool_id` (Mars cave → iron + uranium; Earth city → electronics + plastic; vacuum scrap field → titanium + plasma cells).
- **Per-difficulty scaling**: `loot_rarity_multiplier_per_difficulty { rookie: 0.5, normal: 1.0, hard: 1.5, nightmare: 2.0 }`.
- **Per-actor luck stat**: new `luck` field (0.5-2.0; baseline 1.0). Traits / perks / curses modify. Loot roll = `base_rarity_chance × luck × difficulty_multiplier × storyteller_multiplier`.
- **Cursed loot drops** (M27) wired through same pipeline.
- **Conditional drops** per RimWorld: drop only when condition met.
- **Drop deduplication**: prevent same legendary dropping twice in one mission.
- **Material drops from breaking items**: broken weapon → scrap loot table.

## LootTable schema (canonical)

```ron
LootTable (
    id: "enemy_grunt_drops",
    rolls_per_kill: 1,
    weighted_pool: [
        WeightedEntry (item_id: "ammo_rifle_30", weight: 40, min_count: 1, max_count: 2, rarity_override: None),
        WeightedEntry (item_id: "bandage_simple", weight: 20, min_count: 1, max_count: 3, rarity_override: None),
        WeightedEntry (item_id: "rifle_m1", weight: 10, min_count: 1, max_count: 1, rarity_override: Some(Common)),
        WeightedEntry (item_id: "rifle_m1", weight: 2, min_count: 1, max_count: 1, rarity_override: Some(Magic)),
        WeightedEntry (item_id: "rifle_m1", weight: 0.3, min_count: 1, max_count: 1, rarity_override: Some(Rare)),
        WeightedEntry (item_id: "rifle_m1", weight: 0.05, min_count: 1, max_count: 1, rarity_override: Some(Legendary)),
        WeightedEntry (item_id: "scrap_metal", weight: 25, min_count: 2, max_count: 5, rarity_override: None),
    ],
    luck_sensitivity: 1.0,
    difficulty_sensitivity: 1.0,
    conditional_drops: [],
    drop_dedup_within_mission: false,
)
```

## Acceptance criteria

```gherkin
Scenario: Per-enemy loot table rolls deterministically
  Given grunt killed at tick 1234 + RNG seed 5678
  When loot rolled:
    Then loot_table_rolled fires with table_id=enemy_grunt_drops + seed used
    And loot_dropped_with_provenance fires per item with source_enemy_id + table_id
    And replay reproduces same drops

Scenario: Per-container loot table
  Given chest_basic_world1 opened
  Then loot_table_rolled fires with table_id=chest_basic_world1
  And 3-6 items drop per chest

Scenario: Per-location loot pool overlay
  Given enemy grunt killed in Mars cave (loot_pool=mars_cave)
  Then enemy_grunt_drops applies BUT items biased toward mars_cave pool (iron + uranium boost)

Scenario: Per-difficulty scaling
  Given normal difficulty kill (multiplier 1.0)
  Then loot rolls baseline
  Given nightmare kill (multiplier 2.0):
    Then rare+ rarity chance × 2

Scenario: Per-actor luck modifier
  Given player has trait "lucky" (luck=1.5)
  When kill rolls loot:
    Then luck_modifier_applied fires
    And rare+ chance × 1.5

Scenario: Drop dedup within mission
  Given boss_world1 loot table has dedup=true on "legendary_plasma_rifle"
  When boss respawns + dropped legendary already this mission:
    Then re-roll skips legendary; picks next-rarity item

Scenario: Scripted loot override
  Given mission step requires "find_ancient_key"
  When boss killed:
    Then scripted_loot.applied fires
    And ancient_key drops 100%
```
