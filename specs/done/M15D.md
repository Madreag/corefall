# M15D — Reaction Matrix Buildout (50+ Locked Reactions, Noita Alchemy + Stationeers Stoichiometry)

## Status

`active`

## Intent

M15 promises "30+ reactions" but enumerates only ~12 in prose; M19 locks 6 combustion. **Neither ships a Noita-grade alchemy table with full stoichiometry, activation energy, rate constants, autoignition thresholds, and per-pixel vs. per-cell variants.** M15D ships **one canonical reaction registry of 55 locked reactions** — combustion, corrosion, dissolution, neutralization, phase transmutation, precipitation, explosive cascade — each fully numerically specified so M15 (CPU CA), M15B (GPU CA), M19 (PV=nRT), and M3B (per-tile heat) read the same source of truth.

Promise: **"acid eats iron, lava boils water to steam, gunpowder + spark = boom — real chemistry, replay-byte-identical, mod-extensible."**

## Canonical ownership

Canonical owner of the **reaction registry**. M15 / M15B / M15C / M19 / M19B / M3B read from it; they do not redefine reactions locally.

| Topic | Owner |
|---|---|
| Material registry (50+ thermo entries) | M15C |
| Gas + liquid registries | M19L |
| **Reaction registry (this spec)** | **M15D** |
| Per-pixel CA kernel (CPU + GPU) | M15 / M15B |
| Per-tile heat + mass | M3B |
| Room atmospherics PV=nRT + combustion | M19 |

## Player-facing behavior

- Acid on iron → rusts in ~2s, leaves residue, emits hiss + bubbles.
- Lava + water → flash to steam + obsidian crust; sealed room over-pressurizes per M19.
- H2 + O2 + spark → stoichiometric flashbang; steam fills room; deafens within radius.
- Oil + fire spreads at 0.8/s, emits smoke + ash; cascades to adjacent oil tiles.
- Gunpowder + spark → explosion (2 tiles/kg radius) + smoke plume; chain-propagates.
- Acid + alkali → neutralized brine (no thermal release); player counter to acid traps.
- Iron tile > 1811 K → molten_iron; molten_iron + water → steam + iron; M25 smelting feed.
- F8 tile inspect shows active reactions per tile: name, rate, ETA, ΔH so far.
- cfctl `query.material.reactions` lists all 55 — mods + UI build off one registry.
- CPU + GPU paths replay byte-identical (M15B determinism contract preserved).

## Reaction schema (locked)

```rust
pub struct ReactionDef {
    pub id: ReactionId,
    pub display_name: String,
    pub inputs: Vec<ReactionInput>,        // mole coefficients per input
    pub outputs: Vec<ReactionOutput>,      // mole coefficients per output
    pub delta_h_kj_per_mol: f32,           // negative = exothermic
    pub activation_energy_kj_per_mol: f32,
    pub rate_constant_per_s: f32,          // Arrhenius pre-exponential
    pub min_temperature_k: Option<f32>,    // autoignition threshold
    pub min_pressure_kpa: Option<f32>,
    pub catalyst: Option<MaterialId>,
    pub variant: ReactionVariant,          // PerPixel | PerCell | Both
    pub emits_event: bool,
    pub propagates: bool,
    pub auto_ignite: bool,
}
pub enum ReactionVariant { PerPixel, PerCell, Both }
```

- M19: PV=nRT accepts mole deltas from reactions.
- M3B: per-tile model accepts mass + temperature deltas.

## Notes for implementer

- **Audit first.** ~12 of the 55 ship in M15 today. Mark them `PASS (already in)`; file `.ron` entries only for the missing 43.
- Arrhenius evaluator = pure function; unit-test at T ∈ {273, 500, 1000, 2000} K for 3 reactions.
- Mass-balance validation runs at registry **load time**, not per-tick.
- `rxn.radio.uranium_fission` is reactor-only; do NOT enable autoignition. M29 is sole caller.
- PerPixel = indoor cascade; PerCell = sealed-room PV=nRT. The variant tag picks the kernel.
- Mod authors append; never mutate existing IDs (replay compatibility).
