# M12B — HRTF Spatial Audio + Per-Room Reverb + Per-Material Echo + Per-Source Occlusion

## Status

`active`

## Intent

Make every sound in Corefall feel **like it came from a real place** — HRTF-based 3D source positioning so a stereo-headphone player can locate gunshots, footsteps, and voices by ear; per-room reverb tail driven by M19 room volume + material; per-material echo response so concrete bunkers ring and cloth-lined dens dampen; per-source occlusion through walls; Doppler shift on relative velocity; per-environment low-pass when sound passes through dense media. After M12B, **closing your eyes and listening tells you where the threat is, how big the room is, and what it's made of**.

## Player-facing behavior

- **HRTF 3D positioning** — every SFX/voice has a world-space `Vec2` source position. On stereo headphones, sounds left of the player pan left + filter through left-ear HRIR; right-of-player sounds pan right + filter through right-ear HRIR. Forward/back differentiation via HRIR notch + spectral tilt. Player can locate a footstep "10 m to the upper-left, 5 m down" by ear alone within ~15° accuracy.
- **Per-room reverb** — every M19 room atmosphere has a derived **reverb profile** (volume → tail length; wall material → decay coefficient; aperture state → wet/dry mix). A pistol shot in a 4×4 m steel bunker has a tight, ringing slap-back tail; the same shot in a 30×20 m concrete warehouse has a long, booming tail with ~2.5 s decay.
- **Per-material echo response** — wall material registry adds an `echo_coefficient` (0.0-1.0) + `decay_band` (low/mid/high tilt). Concrete = strong + bright echo. Cloth/fabric = dampened (echo_coefficient ≤ 0.1). Metal = ringing + high-frequency-favored. Wood = warm + mid-frequency-favored. Glass = bright + short. Snow/sand = nearly anechoic.
- **Per-source occlusion through walls** — every wall between source and listener attenuates by wall material's `acoustic_transmission_loss_db`. Concrete wall: -28 dB; steel: -32 dB; cloth curtain: -3 dB; glass: -18 dB; cardboard: -6 dB. Sources behind walls also get a low-pass cutoff (concrete: 800 Hz cutoff; metal: 1.2 kHz; cloth: 4 kHz pass).
- **Doppler shift on relative velocity** — projectiles, drones, vehicles, falling debris emit Doppler-shifted audio per the relative velocity between source and listener: `f_observed = f_source × (c + v_listener) / (c + v_source)` where `c = 343 m/s` (atmosphere-corrected per M19 medium density). A sniper round whizzing past at 800 m/s shifts ~2× pitch into the player's ear.
- **Per-environment low-pass filter** — sounds traveling through water, smoke, dense gas, or vacuum get medium-specific filtering. Water: 800 Hz cutoff + 60% volume; thick smoke: 1.5 kHz cutoff + 80% volume; vacuum: no audio path (DR-014 vacuum_no_voice); ammonia atmosphere (Mimas): -3 dB attenuation + slight high-cut.
- **Accessibility-compliant spatial fallback** — captions show direction marker per HRTF angle: "GUNSHOT — NW 12 m" / "RELOAD — behind you". Deaf-mode + spatial-audio off = same caption with the same direction string; nothing is locked behind hearing the audio.
- **Determinism** — HRTF + reverb + occlusion are pure math on the sim's `Vec2` positions; no `thread_rng`, no frame-time integration. Two engines with the same seed produce identical `audio.spatial_resolved` event streams.

## Per-room reverb profile derivation (locked)

For every M19 room atmosphere per tick, the reverb profile is derived deterministically:

```
ReverbProfile {
    tail_seconds: clamp(0.18 + 0.0008 * volume_m3, 0.2, 4.0),
    decay_coefficient: weighted_mean(wall_material.echo_coefficient, by_surface_area),
    decay_band: dominant_band(wall_material.decay_band, by_surface_area),
    wet_dry_mix: clamp(0.15 + 0.5 * decay_coefficient, 0.1, 0.85),
    early_reflection_delay_ms: clamp(2.0 + 0.3 * sqrt(volume_m3), 4.0, 40.0),
    aperture_attenuation_db: -3.0 * fraction_of_walls_open,
}
```

- `volume_m3` = M19 `room.volume_m3` (existing field).
- `wall_material.echo_coefficient` = read from `cf-material::registry`.
- `fraction_of_walls_open` = open apertures / total wall surface area; an open door drops `wet_dry_mix` toward dry.

Examples:
- 4×4×3 m steel bunker (V=48 m³, walls 100% steel): tail = 0.22 s, decay 0.92, wet 0.6, bright_ringing band.
- 30×20×4 m concrete warehouse (V=2400 m³, walls 100% concrete): tail = 2.1 s, decay 0.85, wet 0.57, bright band.
- 10×10×3 m fabric-lined office (V=300 m³, walls cloth+wood): tail = 0.42 s, decay 0.31, wet 0.3, dampened band.
- Open outdoor (no room): tail = 0.0, decay 0.0, wet 0.0, dry only.

## HRTF resolution (locked)

Per audio source emit, compute the listener-relative spatial envelope:

```
SpatialEnvelope {
    azimuth_rad: atan2(source.y - listener.y, source.x - listener.x) - listener.facing_rad,
    elevation_rad: 0.0,  // 2D side-view; reserve for future M14 verticality
    distance_m: norm(source - listener),
    gain: source_gain(distance_m, source.base_gain),
    hrir_index: lookup(azimuth_rad, elevation_rad),  // 32 × 8 grid
    occlusion_db: sum(wall.transmission_loss_db for wall in walls_between(source, listener)),
    medium_filter: medium_at(midpoint(source, listener)),
    doppler_factor: (343.0 + dot(listener.vel, dir_to_source)) /
                    (343.0 + dot(source.vel, dir_to_source)),
    reverb_send_db: reverb_profile.wet_dry_mix * 0.6 if listener_in_same_room else 0.0,
}
```

Direction-string for captions:
- `|azimuth_rad| < π/12` → `"ahead"`
- `|azimuth_rad - π| < π/12` → `"behind you"`
- `distance_m < 1.5` → `"here"` (overrides direction)
- Else: 8-way compass projection (`N`, `NE`, `E`, `SE`, `S`, `SW`, `W`, `NW`)

## Out of scope

- 3D-vertical HRTF elevation rendering — Corefall is 2D side-view; HRTF table reserves an 8-row elevation grid but only the horizontal row is consumed at M12B. Vertical HRTF lands when M14 verticality ships.
- Per-actor HRTF personalization (head circumference / ear shape) — uses generic MIT KEMAR. Per-player calibration deferred to M48B audio polish.
- Ray-traced reverb (per-room geometry impulse-response synthesis) — M12B uses pre-baked IRs selected per material+volume bucket. Ray-traced IR generation deferred to M48B.
- Per-tile acoustic occlusion at sub-meter resolution — wall-segment granularity only (one wall = one transmission_loss event).
- Per-frequency reverb shaping beyond `decay_band` (low/mid/high tilt) — full multi-band shelf shaping deferred to M48B polish.
- Surround-sound (5.1 / 7.1) speaker layout output — stereo headphone target only. Multi-channel output deferred to M48B.
- Convolution-reverb modder pipeline (custom IRs) — modders extend `material_registry` + select from the 8 baked IRs; custom IR uploads land in M37A modder authoring extensions.

## Notes for the implementer

- **HRTF table format**: `game/content/audio/hrtf/mit_kemar_subset.bin` — fixed-layout binary, 32 azimuth × 8 elevation × 2 ears × 128 samples × 4 bytes (f32) ≈ 256 KB on disk after compression. Loaded once at startup into a `Arc<HrirTable>`; lookup is `O(1)` index math, no allocation per audio frame.
- **HRIR convolution at playback time only**: `cf-audio::spatial` produces a `SpatialEnvelope` descriptor; the actual convolution lives in `cf-app::audio_backend::hrtf_convolution` (Bevy + bevy_audio + rustfft). Determinism surface stays in `cf-audio`; convolution stays out of the sim.
- **Reverb send is one global send bus, not per-room**: the IR loaded into the send bus is swapped when the listener crosses a room boundary (per M19G boundary detection). Cross-fade the IR over 250 ms to avoid clicks.
- **Doppler safety**: clamp `doppler_factor` to `[0.25, 4.0]`. The clamp also catches NaN/Inf if listener or source velocity is broken. The replay event carries `clamped: bool` so debugging is straightforward.
- **Atmosphere-corrected speed of sound**: read from `cf-atmos::medium_at(pos).speed_of_sound_m_per_s`. Default = 343 m/s (Earth-air STP). Vacuum = 0 → short-circuits to `gain=0` before doppler math.
- **Wall-traversal segmentation**: `walls_between(source, listener)` does a Bresenham-style raster of the 2D line segment against the M3B/M19G wall registry; deterministic in `(x, y)` raster order. Cap at 8 walls per ray (rare; concrete-on-concrete fortifications get capped).
- **Cosmetic-event classification**: the 4 new replay events MUST register in `cf-audio::deterministic_replay::is_cosmetic_audio_event`. Treating spatial resolution as non-cosmetic would mean the replay verifier compares audio output, which we explicitly DO NOT want (player headphone state varies; only the sim state must converge).
- **No `unwrap()` on material lookups**: missing acoustic fields fall back to `(echo_coefficient=0.2, decay_band=warm_mid, transmission_loss_db=8.0, low_pass_cutoff_hz=2000)` (the "default dirt" row). Log via `tracing::warn!` once per missing material id.
- **HRTF data attribution**: MIT KEMAR dataset is in the public domain (Bill Gardner, 1994). The subset on disk MUST carry a `LICENSE.txt` co-located in `content/audio/hrtf/`.
- **Caption parity is non-negotiable**: every `audio.spatial_resolved` event MUST produce the same caption direction string regardless of `settings.spatial_audio_enabled`. ACC-A holds.
