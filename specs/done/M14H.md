### Field-medic decision tree (M7 Medic doctrine extension)

1. **Assess** — read M11 silhouette + scanner data + active afflictions; produce priority score per wound × per actor.
2. **Triage** — sort patients by `compound_TTD` + `wound severity sum` + `mission-critical flag`.
3. **Stabilize** — apply tourniquet / bandage / trauma_pack to stop active bleed; clear life-threatening afflictions (hypoxia / heat-stack / cardiac arrest).
4. **Treat** — surgery / sutures / splint / cauterize / cure-course; per-wound treatment loop.
5. **Monitor** — re-scan every N ticks; raise alert on stage transition.

### Surgery minigame

- Phase 1: **Open** (10s) — exposes the wound; bleed risk during.
- Phase 2: **Diagnose** (15s) — Medical Scanner confirms internal damage extent.
- Phase 3: **Operate** (30–120s; per-wound) — remove shrapnel / repair organ / set bone; per-step skill check.
- Phase 4: **Close** (20s) — suture + seal; conversion to scar.
- Phase 5: **Recover** (30 min in-game in hospital bed) — monitored healing.
- Failure modes: bleed-out during Phase 1/3; infection from dirty tools; iatrogenic Wound.

### Defibrillator + CPR loop

When an actor enters **cardiac arrest** (triggered by `affliction.shocked` + heart organ at <30% OR M16C anxiety-acute-arrest), the M11 Triage Window switches to "CARDIAC ARREST — 30s window":
- CPR maintains perfusion (1-tick per round; max 5 rounds buys 100s).
- Defibrillator delivers shock; per-shock success roll (50% baseline; +10% per consecutive CPR round preceding); 4 charges per pack.

### Triage UX (M11 extension)

New panel: **Patient Queue**.
- Per-patient row: name + compound_TTD + top wound + top affliction + status.
- Sortable by TTD ascending.
- Click patient → opens Patient Detail (full wound list + per-wound Treat button).

## Acceptance criteria

```gherkin
Scenario: Bandage stops bleed and soaks through
  Given a LacerationModerate at severity 0.5 + bleed_rate 5 ml/s active
  When act.player.treat kind=field_bandage_v1 fires + 5s elapse:
    Then treatment.applied fires + treatment.completed fires
    And bleed_rate drops to 0
  When 180 ticks elapse without re-bandage:
    Then wound.aged fires with new_state="bandage_soaked"

Scenario: Defibrillator restores rhythm after CPR
  Given an actor in cardiac arrest
  When 2 cardiac.cpr_round events fire (40s elapsed) + act.player.defib fires
  Then cardiac.defib_attempted fires
  And the success roll is 50% + 20% (2 CPR rounds) = 70%
  When the roll passes:
    Then cardiac.restored fires

Scenario: Surgery removes embedded shrapnel
  Given an actor with 3 ShrapnelEmbedded wounds on torso + surgery_table_v1 + surgeon
  When act.player.surgery_start fires
  Then surgery.phase_started fires phase=Open
  When the full 5-phase sequence completes:
    Then 3× treatment.applied fires (one per shrapnel removed)

Scenario: Triage UX surfaces compound TTD
  Given 4 squadmates in various states of injury
  When the player opens the Patient Queue
  Then the panel lists 4 rows sorted by compound_TTD ascending

Scenario: Field Medic AI auto-treats per decision tree
  Given a Medic NPC with TriageDownedAlly priority 9
  And an ally with compound TTD 10s and 3 wounds
  When the AI tick fires:
    Then the Medic moves to the ally
    And applies the highest-priority treatment first (tourniquet for arterial bleed)
    Then re-scans
    Then applies next treatment

Scenario: Per-origin treatment compatibility
  Given a robot actor with a damaged module
  When act.player.treat kind=field_bandage_v1 fires
  Then treatment.failed fires with reason="wrong_origin"
  When act.player.treat kind=repair_tool fires:
    Then treatment.applied fires correctly

Scenario: Determinism — same seed reproduces surgery outcome
  Given identical seed + identical patient + identical surgeon
  When the 5-phase surgery completes
  Then identical phase outcomes + identical wound-state transitions
```
