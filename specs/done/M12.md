## Visual direction (per DR-019)

**Reference aesthetic**: closer to **Hades / Streets of Rage 4 / Into the Breach / Cuphead / Hyper Light Drifter** than pure black-on-white noir. Corefall is a **color-rich + detail-rich** game.

| Element | Direction |
|---|---|
| **Palette** | Per-faction 8-color palettes (primary + secondary + accent + dark + light + 3 tints) — saturated, expressive, ON. Faction-coherent. Origin-coherent. Material-coherent. **No "all black" minimalism.** |
| **Linework** | **Optional toolkit, not a requirement.** The art pipeline MAY apply ink-line outlines selectively where they help readability (actor silhouettes on busy backgrounds, faction emblems, boss splash callouts) — taking notes from Hades / Streets of Rage 4 / Cuphead — but ink-line is one styling tool among many. Soft-edge shading, dithered ramps, painted edges, and edge-free rendering are all valid. The game is NOT defined as "everything has black outlines". |
| **Fill** | Rich gradients + dithered shading + per-material texture details. Not flat. Every sprite has internal detail (rivets, plating seams, weathering, faction insignia, lighting). |
| **Detail density** | High — players see weapon iron sights, chassis joint articulation, armor plate seams, faction patches. Inspired by Into the Breach's mech sprites + Cortex Command's busy-but-readable pixel art. |
| **Color grading** | Dynamic per-scene + mission mood — daylight scenes are bright + saturated; nighttime / hazard scenes get atmospheric color shift but never flatten to monochrome. |
| **Lighting** | Per-tile thermal glow (hot tiles glow orange, cold tiles glow blue, hazard tiles strobe), per-weapon muzzle flash, per-explosion radial bloom. Color carries information. |
| **Faction differentiation** | Every faction's units immediately distinguishable by palette + silhouette + insignia + decal language. Hostile-Corp = sterile blue / silver / red accents; Frontier = rust orange / dark green / leather brown; Marauder Tribes = bone white / blood red / fur trim; Scientist Order = lab white / electric cyan / brass accents; Drone Collective = chrome silver / electric magenta / black; Mercenary Guild = mottled olive / desert tan / scuffed brass; Religious Order = deep purple / gold / cream; Pirates = weathered teal / brass / driftwood gray. |

What M12 does NOT do:
- ❌ Force every scene into a static filter (noir or otherwise)
- ❌ Drop color in favor of black/white minimalism
- ❌ Simplify silhouettes to the point of losing detail
- ❌ **Make the game look like a comic book.** Comic-style framing is an OPTIONAL flavor used in specific moments — never the dominant style.
- ❌ **Mandate ink-line outlines on every sprite.** Ink-line is a toolkit the art pipeline can use selectively where it earns its place — not a defining identity rule.

What M12 DOES do:
- ✓ Vivid faction palettes + detailed sprites + rich material textures
- ✓ Dynamic color grading per scene-mood (NOT a static filter)
- ✓ Juice rules layered per-surface (hover / click / banner / hit-stop / weapon swap)
- ✓ One **CCCP-style opening intro slideshow** that tells the universe backstory through 8 painted slides + subtitle text + music + voice-over
- ✓ Selective comic-style flavor (speech bubbles for chatter, onomatopoeia stamps for impacts, comic-panel boss intros) **applied to specific moments where it earns its place, never as the global aesthetic**
- ✓ Selective ink-line styling **as one of several available rendering toolkits** — applied per-asset where it helps silhouette readability, never as a global "everything has black outlines" rule

### Comic-style framing — opt-in juice, not core identity

Speech bubbles, onomatopoeia stamps (BOOM / CRACK / KCHK), and comic-panel layouts ship as **`comic_style_overlay` flag** behaviors:

- `comic_style_overlay = full` — speech bubbles for chatter, onomatopoeia on impacts, comic-panel boss intros, comic death-recap toggle available
- `comic_style_overlay = subtle` (DEFAULT) — speech bubbles for storyteller events only; no onomatopoeia stamps; comic death recap available behind toggle
- `comic_style_overlay = off` — never render any comic-style framing; all chatter shows as plain captions; impacts use particle juice only; death recap is timeline-only

The flag lives at `settings.ux.comic_style_overlay`. Per-scene mood / per-faction can request `full` framing temporarily (e.g., boss intros), but the player's setting always wins.

## Acceptance criteria

```gherkin
Scenario: Vivid faction palettes render correctly
  Given M12 active + any scenario with all 8 factions visible
  Then every faction is immediately distinguishable by palette + silhouette + insignia
  And no sprite is rendered in pure black/white minimalist style

Scenario: Dynamic color grading per scene
  Given a scenario with daylight, nighttime, and hazard segments
  Then daylight scenes are bright + saturated
  And nighttime scenes shift cool but never go monochrome
  And hazard scenes shift warm but never go monochrome

Scenario: Button hover juice
  Given a focusable button
  When cursor hovers:
    Then scale animates 1.0 → 1.05 over 80ms ease-out
    And glow halo appears
    And tick SFX plays
  When reduce_motion=true:
    Then animation skipped (instant 1.05)

Scenario: Click punch juice
  When button clicked:
    Then scale 1.0 → 0.95 → 1.0 over 120ms
    And brighter flash + click SFX
  When reduce_motion=true: skipped

Scenario: Banner slide-in
  Given new banner pushed
  Then banner slides from right edge over 200ms ease-in-out
  When reduce_motion=true: instant appear

Scenario: CCCP-style intro slideshow plays on New Campaign
  Given a fresh player profile
  When the player starts a New Campaign
  Then the 8-slide intro slideshow plays
  And subtitle text fades in/out synced to music
  And ElevenLabs narration audio plays alongside the music
  And player can skip via Space / Esc
  And player can replay it from Main Menu → Story → "Replay Intro"

Scenario: Boss intro splash with selective comic flavor
  Given boss arena entered
  Then boss splash painted illustration shows
  And one boss voice line plays
  When settings.ux.comic_style_overlay >= subtle:
    Then a single onomatopoeia callout overlays the splash
  When settings.ux.comic_style_overlay = off:
    Then no onomatopoeia overlay; splash + voice only

Scenario: Mission briefing is plain text (no comic panels)
  Given mission start
  Then briefing screen shows title + setup text + objective list + recommended loadout + risk badge
  And no comic-panel framing is rendered
  And player dismisses with Space or auto-advances after 8s

Scenario: Death recap default is timeline (M10), not comic
  Given player brain death
  When settings.ux.comic_death_recap = false (default):
    Then M10 replay viewer opens at death tick with cause-chain walker
  When settings.ux.comic_death_recap = true:
    Then 4-panel comic-style cause chain renders
    And player can switch back to timeline view

Scenario: Comic-style overlays can be disabled
  Given settings.ux.comic_style_overlay = off
  Then no speech bubbles render for any chatter
  And no onomatopoeia stamps render on any impact
  And death recap is timeline-only
  And boss intros render painted splash without comic callout

Scenario: All juice respects accessibility
  Given Settings.reduce_motion=true + reduce_flash=true + reduce_shake=true
  Then every juice rule respects the flags
  And no juice violates the accessibility floor
```
