# M14G — Per-Wound-Type Granularity + Severity Bands + Visual Decals

## Status

`active`

## Intent

Close the "abstract wound" gap by introducing a **per-wound-type registry** with 28 canonical `WoundKind` variants, a **6-band severity ladder**, **per-wound metadata** (bleed_rate / pain_contribution / infection_chance / heal_time / treatment_difficulty / visual_decal), and the **producer surface** that converts M14 collision events + M14C tank rounds + M15 chemistry reactions + M16 hazards into discrete wound records on `ActorWoundList`.

## Canonical ownership

This spec is the **canonical owner of the WoundKind registry + severity ladder + per-wound metadata + wound visual decal lifecycle**. M14 collision events emit `WoundKind`. M14H consumes the registry for treatment difficulty. M14I consumes the registry for scar persistence. M16C consumes the registry for Pain contribution.

## Player-facing behavior

- Every hit that breaks skin / cracks armor / bruises tissue creates a `Wound { id, kind, severity, zone, age_ticks, dirt_pct, bandaged: bool, sutured: bool }` record on the actor.
- The 28 `WoundKind` variants:
  - **Penetrating:** `LacerationLight`, `LacerationModerate`, `LacerationSevere`, `Puncture`, `StabThrough`, `GunshotEntry`, `GunshotExit`, `GunshotThrough`, `ShrapnelEmbedded`, `ShrapnelThrough`.
  - **Blunt:** `BruiseLight`, `BruiseHeavy`, `CrushLimb`, `Concussion`.
  - **Skeletal:** `FractureSimple`, `FractureCompound`, `FractureComminuted`, `Dislocation`, `SprainStrain`.
  - **Thermal:** `Burn1st`, `Burn2nd`, `Burn3rd`, `Frostbite1st`, `Frostbite2nd`, `Frostbite3rd`.
  - **Chemical:** `AcidBurn`, `ChemicalBurn`.
  - **Sensory:** `EyeInjury`, `EarInjury`, `DentalDamage`.
- 6-band severity: `Scratch (0–0.15) → Light (0.15–0.3) → Moderate (0.3–0.5) → Severe (0.5–0.75) → Critical (0.75–0.9) → Lethal (0.9–1.0)`. Each band has a per-band UX label, color, auto-triage threshold, and per-treatment-difficulty curve.
- Per-wound visible state: fresh / soaked-bandage / clean-bandage / scab / suture-line / scar. M11 silhouette renders per-zone wound stack (max 5 per zone; 6+ collapse to "+N").
- Wounds **age**: bandaged wounds soak through over time; clean wounds scab; unscabbed dirty wounds escalate `dirt_pct` and feed infection risk (consumed by M14H + M16B).
- M14C HEAT / APFSDS hits emit clusters: HEAT → 1 `Burn3rd` + 1 `GunshotThrough` per organ traversed; APFSDS → 1 `ShrapnelThrough` per module + spalling fragments per zone.

## Tunable defaults

| Constant | Value |
|---|---:|
| Default per-wound bleed at severity 0.5 | 2 ml/s |
| GunshotThrough bleed multiplier | 2.0× |
| Burn3rd healing time (Severe band) | 6 in-game hours |
| Fracture healing time (Severe band) | 24 in-game hours |
| LacerationLight scab time | 60 s |
| Frostbite3rd → Necrosis threshold | 30 min untreated |
| Max wounds per zone before "stack collapse" | 5 |
| Stale-bandage soak-through time | 180 s |

## Acceptance criteria

```gherkin
Scenario: GunshotEntry + GunshotExit emitted for through-and-through hit
  Given a human actor with intact torso armor (sharpness 0.4)
  When a rifle round penetrates and exits the torso
  Then wound.created fires twice: kind=GunshotEntry zone=torso_front and kind=GunshotExit zone=torso_back
  And bleed_rate_total rises by sum of both wound contributions
  And the M11 wound_strip shows 2 wound badges on the silhouette

Scenario: Burn degree escalates with sustained fire exposure
  Given a human actor adjacent to a fire tile
  When 5 ticks elapse with foot zone in contact
  Then wound.created fires with kind=Burn1st severity=0.2 zone=foot_right
  When 30 ticks elapse
  Then wound.escalated fires with kind=Burn2nd severity=0.5 zone=foot_right
  When 60 ticks elapse
  Then wound.escalated fires with kind=Burn3rd severity=0.85 zone=foot_right

Scenario: Frostbite escalates inversely with thermal exposure
  Given a human in a tile at 250 K (cold)
  When 60 ticks elapse with hand zone exposed
  Then wound.created fires with kind=Frostbite1st zone=hand_right
  When 600 ticks elapse without warming
  Then wound.escalated fires with kind=Frostbite3rd
  And after 30 in-game minutes untreated the hand zone enters Necrotic state (M14I consumer)

Scenario: Fall produces FractureSimple → Compound based on impulse magnitude
  Given a human actor falling onto concrete from 10m
  When fall_impulse_chain computes a leg-joint impulse of 0.7 of severance threshold
  Then wound.created fires with kind=FractureSimple zone=leg_left severity=0.5
  When impulse is 0.9 of severance threshold
  Then wound.created fires with kind=FractureCompound zone=leg_left severity=0.8
  And the open-bone status increments dirt_pct by 0.3

Scenario: Shrapnel embedded leaves removable fragments
  Given a frag grenade detonates 3m from actor
  When 3 shrapnel fragments hit
  Then wound.created fires three times with kind=ShrapnelEmbedded
  And ActorWoundList[zone].shrapnel_count == 3
  And M14H surgery_kit can remove each fragment via individual treatment_applied event

Scenario: Wound ages with bandage soak-through
  Given a LacerationModerate at severity 0.4 + clean bandage applied
  When 180 ticks elapse without re-bandage
  Then wound.aged fires with new_state="bandage_soaked"
  And bleed_rate returns to half of pre-bandage rate

Scenario: Severity bands surface per-band caption
  Given a wound at severity 0.85
  Then the M11 silhouette badge shows "[!!] CRITICAL"

  Given a robot actor hit by a melee blade

Scenario: M14C HEAT round emits typed wound cluster
  Given an APC chassis hit by HEAT round (10 MJ)
  When the jet penetrates 3 modules + crew compartment
  Then wound.created fires 3× kind=Burn3rd zone={mod_a, mod_b, mod_c} on crew + 1× kind=GunshotThrough zone=crew_torso
  And the M41 kill cam labels each wound type

Scenario: Dental damage from blunt face hit
  Given a melee blunt hit (impulse > tooth threshold) to head zone front
  Then wound.created fires with kind=DentalDamage severity=0.6
  And M19H morale drops by configured amount
  And M19I (food intake) chewing penalty applied

Scenario: Determinism — same seed produces identical wound stream
  Given two engines + identical projectile/target setup + same seed
  When 600 ticks elapse
  Then identical wound.created event sequence
  And identical wound.aged transitions
```

## Out of scope

- Treatment producers (apply bandage / surgery) — M14H.
- Infection lifecycle (dirty → inflamed → septic) — M14H + M16B handshake.
- Scar visual baking — M45A (already owns cosmetic side; M14I owns functional debuff).
- Pain affliction wiring — M16C.

## Dependencies

- M14 (done) — collision producers exist; M14G replaces generic `wound` emit with typed `WoundKind`.
- M14C (active) — HEAT/APFSDS producer wiring; M14C emits wound clusters via M14G registry.
- M15 (active) — chemistry reactions feed AcidBurn / ChemicalBurn.
- M17 (active) — per-origin wound forbiddance reads M17 origin matrix.

## Notes for the implementer

- Use M14's existing producer surface; replace the generic `wound` emit with typed `WoundKind` per zone/material/projectile context.
- Per-wound aging runs on a 1-tick cadence but only mutates state every N=5 ticks (perf-bound).
- Wound visual decal IDs map 1:1 to M45A scar-decal art pipeline + M11 silhouette badge atlas.
