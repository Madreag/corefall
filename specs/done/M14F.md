# M14F — Lateral Wall Collapse + Sidewall Structural Integrity

## Status

`active`

## Intent

Extend M14E's per-pixel structural integrity field from ceiling-only to full lateral wall collapse — sidewall pressure → bulge → rupture cascade — the missing 90° rotation of the same engine so vertical mineshafts, retaining walls, dam structures, and base perimeter walls behave as load-bearing the same way ceilings do.

## Player-facing behavior

- Vertical mineshafts dug straight down need lateral reinforcement (Stationeers vertical mine + ONI deep dig parity).
- Retaining walls holding back terrain pressure (post-explosion crater walls) progressively bulge → crack → rupture if pressure exceeds material yield.
- Dam structures holding water (M19/M15 fluid simulation) need reinforced walls; rupture → catastrophic flooding cascade.
- Bunker perimeter walls under siege take cumulative damage; integrity field reflects accumulated impact stress.
- Pressure differential (M19 atmospherics) applies lateral force to walls; sealed-room sudden-vacuum-exposure can blow out walls.
- Reinforce via support beams (M14E support_beam, but rotated to the lateral axis) + brace_strut item + sandbag-style barriers (M28A blueprint).

## Out of scope

- Per-pixel rebar mesh inside reinforced concrete — M48+.
- Active anti-collapse damper (Stationeers Active Vent variant) — M48+.
- Per-actor-impact stress accumulator separate from explosive damage — built-in by absorbing into M14 impulse routing.

## Dependencies

- M14E per-pixel structural integrity (active sibling — ceiling collapse kernel this rotates to lateral axis): the integrity field + cave-in roll + support-beam contract M14F mirrors 90° for sidewalls. M14F shares the per-chunk `structural_integrity_field` buffer + `compute_integrity_pass` cadence + cave-in cascade pattern with M14E; only the axis differs.
- M14 collision physics (done): impact damage routing
- M15 active material kernel (active): fluid simulation for dam scenarios
- M19 atmospherics (active): pressure differential as lateral force source

## Notes for the implementer

- Per-material lateral_yield_strength = approximate Stationeers values: concrete 50, brick 30, steel 200, wood 15, dirt 10.
- Lateral pass runs at same N=15 cadence as M14E ceiling pass; total perf budget is bounded by the union.
- Brace strut placement mirrors M14E's `support_beam_placer` UX; same hold-to-place + same cost class.
- Pressure differential blowout reads M19 `cell_pressure_kpa`; threshold = `wall.lateral_yield × wall_area`.
