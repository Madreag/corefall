# M16B — Disease Registry + Per-Disease Lifecycle + Cure Recipe + Vaccine + Quarantine + Per-Origin Susceptibility

## Status

`active`

## Intent

Replace M19H's 3-disease stub with a **17-disease canonical registry** with **per-disease lifecycle** (exposure → incubation → prodromal → manifest → recovery|chronic|death), **per-disease cure recipe** (drug + dose + duration), **per-disease vaccine** (procurement + side-effects), **per-disease isolation requirement** (room-class quarantine), **per-disease R0 spread model** (contact / airborne / vector / waterborne), and **per-origin susceptibility matrix** (10 races × 17 diseases).

## Canonical ownership

Canonical owner of the disease registry, lifecycle FSM, cure/vaccine recipe, isolation protocol, and per-origin susceptibility matrix. M19H germs feed the **exposure** stage. M14G wounds feed the **wound-borne** exposure path (tetanus / sepsis). M16C consumes the matrix for mental-illness diseases (depression, anxiety disorder).

- **Lifecycle FSM:** `Exposed → Incubating → Prodromal → Manifest → (Recovering | Chronic | Dying | Carrier)`.
- **Cure recipe schema:**

```rust
pub struct CureRecipe {
    pub treatment_kind: TreatmentKind,
    pub item_required: Option<ItemId>,
    pub dose_count: u8,
    pub dose_interval_hours: f32,
    pub success_chance: f32,
    pub partial_course_consequence: PartialConsequence,
    pub origin_compatibility: BTreeSet<OriginId>,
}
```

- **Isolation class:**
  - **Class A (airborne; high R0):** sealed room, atmospheric analyzer + filter + airlock. M19E auto-quarantine triggers on detection.
  - **Class B (bodily fluid; moderate R0):** dedicated medical bay with surface sterilization.
  - **Class C (foodborne / contact; low R0):** isolation cot + dedicated mealware.
- **R0 spread model.** Each disease has `r0_per_exposure_event` and `transmission_vector_table`. Pandemic emerges when `(infected_actors / total_actors) × r0 > epidemic_threshold` for a contiguous time window.
- **Per-origin susceptibility matrix (10 races × 17 diseases).** Methane breathers immune to oxygen-respiratory diseases. Robots immune to biological diseases. Photosynthetics 0.3× to bacterial; 1.5× to fungal.
- **Medical Scanner device** (M14H consumer): diagnoses disease + reads dose + age.

## Acceptance criteria

```gherkin
Scenario: Foodborne outbreak traces to specific dish
  Given a kitchen with food quality below threshold (per M19I)
  And 3 actors eat from that batch
  When 1h elapses
  Then disease.exposed fires for all 3 actors with vector=foodborne source_item_id=<dish>
  And disease.stage_changed fires Exposed → Incubating
  When 12h elapses
  Then disease.stage_changed fires Incubating → Manifest

Scenario: Antibiotic course must complete to fully cure
  Given an actor with Pneumonia + 14-dose antibiotic course assigned
  When the actor takes 11 of 14 doses then stops
  Then disease.relapsed fires with reason="partial_course"
  And drives_resistance rolls; if pass:
    Then the next infection is resistant_strain

Scenario: Per-origin susceptibility — methane breather immune to slimelung
  Given a methane-breather actor in a slimelung-germ-saturated room
  When the per-tick exposure check runs
  Then disease.exposed does NOT fire (immunity_multiplier = 0)

Scenario: Tetanus from M14G wound + M15 rust contact
  Given a LacerationModerate wound on the actor's hand
  And the actor's hand contacts a rust tile (M15)
  When the per-tick infection-vector check runs
  Then disease.exposed fires with vector=wound_contact pathogen=tetanus
  And the wound's dirt_pct rises by 0.3

Scenario: Medical Scanner diagnoses disease in 30s
  Given an actor with Manifest pneumonia + a Medical Scanner T1 placed
  When the Scanner runs for 30s
  Then disease.diagnosed fires with disease=pneumonia confidence=0.95
  And the actor's disease_dashboard surfaces full lifecycle stage + cure recipe

Scenario: Pandemic auto-declares + base lockdown
  Given a flu strain mutates (per cf-storyteller) and r0 doubles
  When (infected / total) > 0.1 for 24h
  Then pandemic.declared fires
  And M19E auto-quarantine triggers across all rooms
  And M28D damper closes on every airlock
  And the M11 chatter ticker surfaces "PANDEMIC: locking down quarters"

Scenario: Sepsis cascade from untreated wound
  Given a LacerationSevere with dirt_pct=0.7 and age=30h
  When the per-tick sepsis check runs
  Then disease.exposed fires with vector=wound_infection pathogen=sepsis
  And lifecycle skips Incubating → Manifest within 3h
  And TTD drops to 6h untreated

Scenario: Vaccine prevents exposure
  Given an actor with flu_vaccine immunity record active
  And the actor exposed to flu germs
  When the per-tick exposure check runs
  Then disease.exposed does NOT fire
  And the actor's vaccine record decrements remaining_duration

Scenario: Class A quarantine enforces room sealing
  Given an actor diagnosed with TB
  When act.player.quarantine_actor fires
  Then disease.quarantine_entered fires with room_class=A
  And the room's airlock closes via M28D damper

Scenario: Determinism across pandemic spread
  Given identical seed + identical initial infected set + identical actor positions
  When 1 in-game week elapses
  Then identical infected_count + identical recovered_count + identical death_count
```

## Notes for the implementer

- All 17 disease lifecycles share the same FSM; only the per-stage timing values differ.
- Per-origin susceptibility matrix lives in `content/diseases/_susceptibility_matrix.ron` — single file with 10×17 grid.
- Pandemic.declared is gated on a 24h sliding window of infected/total ratio; deterministic via tick-counter not wall-clock.
